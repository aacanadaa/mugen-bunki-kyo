# 聖一　祝日

祝日は、教団が「数えた日」を人に配る仕組みである。暦は時間を規格化するのではなく、時間に名前をつけて配る。受け取った者は、自分の一日がどこに属するかを、もう自分で決めない。

十二使徒に一人ずつ祝日が充てられた。使徒とは、教主の傍らにいた十二人のことで、本名も、出身も、何をしたかも、揃ってはいない。揃っているのは数だけである。数が揃えば、そこに体系があると見なすのが、この教団の癖であった。

| 使徒 | 日 |
|---|---|
| 第一使徒・口を開かぬ者 | 一月一日 |
| 第二使徒・数える者 | 二月二日 |
| 第三使徒・畳む者 | 三月三日 |
| 第四使徒・道を譲る者 | 四月四日 |
| 第五使徒・火を持たぬ者 | 五月五日 |
| 第六使徒・名を返す者 | 六月六日 |
| 第七使徒・待つ者 | 七月七日 |
| 第八使徒・閉じる者 | 八月八日 |
| 第九使徒・数え直す者 | 九月九日 |
| 第十使徒・影を数える者 | 十月十日 |
| 第十一使徒・扉の前の者 | 十一月十一日 |
| 第十二使徒・還らぬ者 | 　 |

日付の並びは、月と日を同じ数にして読む者が多い。そう読むと、一月から十一月までがきれいに埋まり、十二月だけが空く。空いた十二月は、教団では「待ちの月」と呼ばれ、祝日を置かない月とされた。置かないのではなく、置けなかったのだ、と後に書く者もいる。

第十一使徒の日は十一月十一日で終わる。第十二使徒には、日がない。

---

## 編纂註

**一、何を規格化するか。** この暦が規格化するのは、時間ではなく、時間の所有である。祝日は「この日は誰のものか」を定める。十二の日を配ることで、一年のうち十二日が教団の手に渡り、残りの三百五十余日は「教団の日ではない」として、かえって教団の外にあるように見える。規格化の巧みさは、全部を取らず、十二日だけを取るところにある。取った日が少ないほど、取られていない日の多さが、同意の証のように数えられる。

**二、人に何をするか。** 祝日は、人に「今日は何をする日か」を先に与える。考える前に、日が意味を持つ。意味は上から降りてくるのではなく、暦という形で先に配られ、人はそれを自分の意味として受け取る。とくに第十二使徒の日のように、日付のない祝日は、日にちを空けるのではなく、日にちを探させる。探す時間そのものが、祝日の働きになる。人は空白を埋めようとして、教団の言葉を自分で作りはじめる。

**三、どこで壊れるか。** この体系は、日付のない祝日を「最も重要である」と註に書いた瞬間に壊れる。註は本文を補うものではなく、本文の穴を指す。穴を指した註は、穴を埋めるのではなく、穴があることを教義にする。だが、穴が教義になると、穴を指す註のほうが本文より重くなる。重くなった註は、いつか本文を置き換える。置き換わったとき、この暦は暦ではなく、註の集まりになる。日を数えるための道具が、日を数えないための道具に変わる。それが壊れ方である。
