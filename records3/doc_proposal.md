# 記九　企画書

〈本文〉

本企画は、解散から三年を経た無限分岐教の残骸を、説教ではなく帳簿から辿る記録映画である。教団が消えたあとも、受託開発の納品書と検収書だけが取引先の棚に残っている。魂の分岐を説いた組織が、最後まで土日を潰して締切に間に合っていた。この落差を正面から撮る。

構成は四章。第一章「納品」では、教団名を伏せたまま、ある受託開発会社の残務処理を追う。第二章「切番」では、十二使徒の名を持つ役職のうち、実際に書類へ署名していた三人に会う。第三章「閉座」では、K9の集会記録とK10の解散通知を並べ、決定がいつ降りたのかを時系列で示す。第四章「分岐」では、いまも教団の言い回しを日常で使っている元信者を、名前も顔も出さずに撮る。各章の間には、白紙の畳を一枚だけ映す短い挿入を置く。畳は第五品の「畳みは慈悲」に由来するが、本作では解釈を語らない。

取材先は、北嶺市の旧開闕区に残る事務所の一室、取引のあった二社の経理担当者、元信者四名、そして教団の文書を保管していた私設の資料室である。教主には会わない。会えないのではなく、会わないと最初に決める。不在は演出ではなく、記録の状態そのものである。撮らないものも先に決めておく。儀式の再演、教義の講義、信者の勧誘の場面。いずれも映像にはならず、なるとしても説明の絵になるだけだからである。

予算は、撮影二十八日、編集十四週で、おおむね千二百万円。内訳は撮影費四割、編集と整音に三割、資料の整理と権利処理に二割、予備に一割。取材先への謝金と複写費は資料の整理に含める。配給と上映は想定しない。作れば終わる、という前提で組む。予算の段階で終わりを決めておかないと、企画は撮影のあいだに目的を変えていく。

最後に、本企画の結論を先に書く。この教団は、世界を一つの依頼として扱うことで成立していた。ならば記録もまた、一つの依頼として締め切られる。締め切ったあとに何が残るかを撮るのが、本作の目的である。

## 編纂註

**第一条　先回りする結論**

企画書は、結論を先に決める技術である。相手に何をするか。読み手は、まだ何も確かめていない段階で、判断の枠を渡される。枠は問いの形をしており、たいていの場合、その枠の外側を数える者がいない。どこで壊れるか。撮影が進み、結論に合わない素材が出たとき、企画は素材を切るか、結論を黙って差し替えるかになる。どちらも記録ではなく編集である。

**第二条　不在の設計**

会わない相手を、最初に決めておく手口。相手に何をするか。会わなかった者の証言は記録に入らず、視聴者はその不在を受け取る。不在は、意味の空白ではなく、意味として届く。どこで壊れるか。その人物が別の場所で語ったとき、不在は演出だったと読まれる。撮らないと決めたことの一覧を、最後まで開示しておくほかない。

**第三条　予算の襞**

項目を細かく割り、判断を数字の奥へ畳み込む手口。相手に何をするか。読み手は金額を承認したつもりで、実のところ何を削るかを承認している。襞のあいだに、撮らないもの、会わない人が隠れる。どこで壊れるか。別の企画と総額を並べた瞬間、襞は平らになり、隠れていた選択が露出する。予算とは、断ったことの目録である。
