# 再六　再離脱

〈本文〉

再離脱の記録は、退出のたびに一通だけ書かれる。書式は決まっている。日付、名（本名でなくてよい）、去る理由（一行）、そして「次に戻る予定」の欄。最後の欄には記入例として「未定」とだけ印刷されている。

記入は三十秒で終わる。受付はない。提出箱もない。書き終えた紙は、書いた者が持って帰る。教団は控えを取らない。写しを求める者には、同じ紙をもう一枚渡すだけである。

部屋には机が一つ、椅子が一脚、紐で結ばれた筆記具が一つある。係の者はいない。机の上には紙の束と、「消えないように」とだけ書かれた小さな札がある。札の文字は、誰の筆とも知れない。

K9の閉座以後、この書式は三度改訂された。一度目は理由欄を「任意」にした。二度目は「次に戻る予定」を「次の分岐」に変えた。三度目に、日付の欄が消えた。日付がなければ、これは記録ではなく、これから書かれる予定になる。教団の説明は短い。「去る者は、すでに去っている」。

再離脱という語は、退出の二回目を指さない。一度目の退出が受理されないまま、二度目が書かれることを指す。受理されないのではない。受理という手続きが存在しない。誰も引き留めないし、誰も送らない。扉は開いており、開いていることに気づかれない。

紙は二つ折りにされる。折り目がつくことを、教団は「畳み」と呼ぶ。第五品にある「畳みは慈悲」は、この折り目のことを指すとされる。折られた紙は胸もとに収まり、開かれることはない。開かないことが、書いたことの証しになる。

記録を読んだ者は、しばしばもう一度書く。理由を変え、名前を変え、次の分岐を書く。書けば書くほど、去ることは一回きりではなくなる。分岐するのは魂だけではない。退出もまた分岐する。

読了の印はない。読んだことを示す欄はどこにもなく、書いたことを示す欄もまたない。あるのは、次の分岐の欄だけである。

K10の解散の折、この書式だけが残された。残すと決めたのは誰でもない。廃止の手続きが、廃止の書式を必要としたからである。その書式もまた、この紙と同じ形をしていた。

現在、この記録は読まれるために配られているのではない。読んだ者が書くために配られている。書いた者は、それを誰にも渡さない。渡さないことが、この記録の唯一の履行である。

K12の現在、この書式は印刷され続けている。印刷部数は公表されない。刷る者がいるのかも、刷る者がいないのかも、記録には残らない。

誰かが去るとき、教団は何もしない。何もしないための手順だけが、こうして整えられている。

この記録が数えるのは、去った回数ではない。書かれた回数でもない。数えられなかった回数である。

最後の読者は、氏名欄に「最後」と書いた。理由欄は空だった。次の分岐の欄には、こうある。「この紙を読む者」。

---

## 編纂註

一、この記録がしているのは、退出の受理ではなく、退出の記帳である。書式は去る者に一通の紙と三十秒を与え、氏名・理由・次の分岐を書かせる。書いた者は去ったと感じるが、教団は控えを取らず、呼び戻しもせず、送りもしない。誰に何をするか。去ろうとする者に手応えだけを渡し、教団は何も受け取らない。壊れるのは、去った者が自分の退出を数えられないと気づく地点である。数える欄が、初めから無い。

二、この装置は、引き留めないことによって人を留める。去る者に「次に戻る予定」を書かせ、のちにそれを「次の分岐」へ改めることで、退出を教義の内側の一分岐に数え入れる。去ることは禁じられていない。禁じないことが、去ることを教団の文法の一部にする。誰に。去る決心をした者に。壊れるのは、退出が許可されたのではなく、許可という手続きが無かったと気づいたときである。

三、この装置の沈黙は、慈悲の形をしている。返事をしない、呼び戻さない、記録しない。どれも拒否には見えない。だが、去る者に必要なのは許しではなく、応答である。応答のない退出は、何度でも書き直される。ここで壊れるのは、去った者の側ではない。去った者を数えない側の、数えないという行為が、最も長く残る。引き留めないことは、最も静かな拒否である。

四、この記録は読者のために配られ、読者の手で書かれる。読了の印も、提出の箱も、控えもない。書いた紙は渡されず、渡さないことが履行とされる。誰に。最後の読者に。壊れるのは、その者が氏名欄に「最後」と書いた瞬間である。記録は閉じず、次の分岐の欄だけが残り、そこには次の読者が指定される。読者は読者として終われない。
