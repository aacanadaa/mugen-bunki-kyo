# 再二　理由

〈本文〉

戻った理由は三つある。数え方は後から決めた。戻った時には、理由はまだ三つに分かれていなかった。分けたのは、この記録を残すためである。つまり以下の三つは、戻った理由の再建であって、理由そのものではない。戻ることに理由が要るとは、当時は思っていなかった。理由を求められたのは、戻ったあとである。だが、再建しか残らないものがある。私はそれを書く。

一つ、傘を返すためだった。K9の閉座の日、私は黒い傘を入口の傘立てに置いたまま帰った。三年後、その傘はまだ同じ場所にあった。誰も持って行かず、誰も捨てなかった。傘は教義ではない。だが傘が残っているということは、その場所がまだ誰かの手で開けられ、床が拭かれ、湿ったまま閉じられているということで、私はその湿気を確かめに行った。理由はそれだけである。傘を受け取った者は、傘のことを覚えていなかった。覚えていない者に物を返すと、物は返ったことにならない。それでも私は返した。返したという手続きだけが残った。

二つ、犬の散歩道が、その建物の前を通っていた。K10の解散のあと、建物は別の用途に変わった。看板は外され、窓には違う色の布が掛かった。だが道は変わらなかった。犬は毎朝同じ角を曲がり、かつて入口だった場所の前で一度立ち止まる。私は犬に引かれて、週に七回そこを通る。信仰ではなく、散歩の経路である。経路は意志より強い。意志は休むが、経路は休まない。K12の今も、私は同じ角を曲がっている。

三つ、私の分の椅子があった。K9の片づけのとき、誰かが畳んだ椅子を一脚だけ、他の椅子の山から離して壁際に置いていた。名札はなかった。しかしその離し方は、私の座り方を覚えている者の離し方だった。私はそこに座った。座って、何も読まなかった。読むべきものは、もう教団の側になかったからである。座り心地は記憶より硬く、硬さだけが一致した。代わりに、私は自分のために読み始めた。この記録は、そのときに始まっている。

この文書を読んでいるあなたへ。あなたがここまで読んだなら、あなたはもう座っている。椅子は本文のなかにある。私はあなたを呼んでいない。呼べば教義になる。私はただ、傘と、犬と、椅子の話をした。読むという行為は、たいてい誰かに宛てて行われる。宛先のない読み方は、椅子に座ることに近い。戻る理由は、そういうものでできている。教義の外にあり、物と、習慣と、誰かの手つきでできていて、たいていは当人にも説明できない。

第五品は「畳みは慈悲」と言う。畳むとは閉じることではなく、次のために場所を空けることだと、私は勝手に読んだ。勝手に読むことは、たぶん許されている。許されているかどうかを確かめるために、私はもう一度戻るのだろう。戻る理由は、また三つに増える。数え方は、そのとき決める。

---

## 編纂註

**一**　この記録は、読むことを「戻ること」に変換する装置である。三つの理由はどれも信仰を含まず、むしろ信仰が不要であったことを示す証拠として並べられている。読み手は、同意も告白も要求されないまま、「すでに戻った者」の位置を与えられる。手続きは静かで、署名も印も要らない。だから読者は、自分が何に加わったのかを最後まで知らない。

**二**　この装置が働く相手は、熱心な者でも反対者でもない。騒がずに去った者、悔いも怒りも持たずに日常へ戻った者である。そういう者には、教義を語っても届かない。代わりに傘一脚、散歩の経路一本、椅子一脚が渡される。装置は勧誘せず、ただ小さな持ち物を返却する。返却された者は、戻ったのではなく、忘れ物を取りに行っただけだと思える。

**三**　この装置は、読み手が自分の細部を持っている場合にしか動かない。傘も犬も椅子もない読み手には、本文は家具の目録にしかならず、「あなたはもう座っている」という一文は、親切ではなく操作として露呈する。また、この記録は何も求めないので、誰も引き留められない。戻る許可と、再び去る許可は、同じ強さで書かれている。

**四**　戻る理由は、教義の外にある。教義は唯一の罪を収束とするが、この記録は収束も分岐も語らず、湿気と経路と硬さだけを語る。もし教義が理由であったなら、これは証文になっただろう。証文ではなく目録として書くことで、教団は戻りを自らの成果とも、自らの責任とも数えられなくなる。註はその設計を、隠さずに記しておく。
