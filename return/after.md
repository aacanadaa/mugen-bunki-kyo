# 再五　その後

〈本文〉

記録は短い。半紙ほどの一枚に、折り目が三つ、文字は表に四行。差出人の名はなく、末尾に「戻りました」とだけある。宛先もない。誰に届いたのか、そもそも届いたのかも分からない。群典の周辺文書のなかで、これは最も短い部類に入る。

書いた者は、半年で去った。入ったのが春、出たのが秋。あいだの記録は残っていない。あるのは、去ったのちに書かれたこの四行だけである。四行のうち三行は天候の話で、一行が「戻りました」である。その天候は、その土地のものでもない。書いた者がどこにいたのか、その空を写したのか、別の土地の記憶を混ぜたのか、判別する手がかりはない。

編纂の途中で、この紙は二度、別の綴りに紛れ込んだ。一度目は「帰参」の項に、二度目は「離脱」の項に。同じ紙が、反対の意味の場所に収まってしまう。分類する側の事情であって、紙の側には何の主張もない。ただ、どちらの項に置いても、読む者は少し安心する。帰ってきた話か、出ていった話か、どちらかであってほしいと願う。四行はそのどちらでもない。

四行を書いた者は、その後どうしたのか。追跡の記録はない。「戻りました」のあとに続く紙は、まだ見つかっていない。ここで想像を足せば、この文書は小説になる。足さない。足さないかわりに、分かっていることだけを置く。半年いた。去った。短い記録を残した。それだけである。

だが、この短さには注意がいる。短いことは、内容が少ないことではない。四行は、書く者が四行だけを選んだ結果である。天候を三行、用件を一行。選ぶということは、捨てるということでもある。捨てたものが何かは、書かれていないので分からない。分からないという形で、それは残っている。

この紙が、読まれるために書かれたのかどうかも怪しい。宛先がない。名がない。折り目だけがある。折り目は、誰かがそれを携えて歩いたことを示す。携えられた紙が、なぜ綴りに紛れ込むのか。捨てられたからである。捨てられた紙を、後の者が拾い、分類し、項を当てて、いまここに置いている。書いた者と拾った者と、読む者は、別々である。三者が同じ紙を見ているとは限らない。読む者が見ているのは、四行ではなく、四行が収まった項である。

## 編纂註

一、この記録がしているのは、短さを内容の乏しさとして読ませないための工作である。四行の少なさを、書く者の選択として読ませ、読み手に「足りない」を勝手に補わせない。補わせなければ、この紙は教団の外にも内にも置ける。置けるということが、この文書の効き目である。欠けているのは記録ではなく、記録を読む者の位置である。

二、誰に何をするか。まず分類する者に、同じ紙を二つの項へ入れる自由を与え、次に拾う者に、拾ったことの正当性を与え、最後に読む者に、項という安心を与える。読者は四行を読んだつもりで、実際には項を読んでいる。この装置は、読者に「分かった」を渡す。渡された側は、渡されたことを覚えていない。

三、壊れるのは、宛先の不在のところである。差出人の名も宛先もないため、この紙は帰参にも離脱にも収まり、どちらにも決まらない。ここで「戻る者は、二度去る」という指摘が要る。一度戻った者は、戻ったことによって去る理由を二つ持つ。帰参の項に置けばそれは離脱の予告になり、離脱の項に置けばそれは帰参の言い訳になる。分類は、決めた瞬間に壊れる。

四、この紙を「その後」の項に置くことの危うさも記しておく。後は、前の続きとして読まれる。続きとして読まれた瞬間、四行は経過になり、経過は物語になり、物語は教訓になる。教訓になった紙は、もう紙ではない。この註が防ごうとしているのは、その一歩である。防ぎきれるとは思っていない。
