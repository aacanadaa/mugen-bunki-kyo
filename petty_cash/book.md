# 現一　小口現金

「群典」第五品の畳みについては、畳み方より先に、畳むための紙代を記した帳面が残っている。切番が懐に持っていた一冊で、表紙には「現一」とだけある。費目の欄は、はじめから二種類の金が同じ列に並ぶ。教団の灯りと、教主の歯が、同じ太さの字で書かれている。

| 日 | 費目 | 額 |
|---|---|---|
| K12・三・二 | 詰所 灯油 | 4,200 |
| K12・三・四 | 折紙（分岐図） | 1,800 |
| K12・三・四 | 教主 歯科 | 12,000 |
| K12・三・九 | 師母 香料 | 3,300 |
| K12・三・十 | 香典（教主実家） | 20,000 |
| K12・三・十五 | 若手使徒 立替戻し | 6,000 |
| K12・三・十七 | 茶菓（会合） | 2,400 |
| K12・三・二十 | 教主 煙草 | 900 |
| K12・三・二二 | 法要 花 | 5,500 |
| K12・三・二五 | 弁当（作業） | 4,800 |
| K12・三・二八 | 甥 入学祝 | 10,000 |
| 計 | | 70,900 |

単位は円。領収書は畳んで挟む。畳みは慈悲であるから、折り目だけが残り、金額は読めない。承認は口頭で、切番の記憶が台帳の裏書きになる。月末に残高が合わないと、合わないこと自体が「分岐」と呼ばれて喜ばれた。誰もそれを誤りとは呼ばない。呼べば収束になるからである。

K10の解散のあと、この帳面だけが金庫から出てきた。誰の歯科であったかは、どの頁にも書かれていない。書かないことが、この一冊の作法であった。

## 編纂註

小口現金は、組織の私生活である。

一、混載。組織の灯油と教主の歯科が、同じ列に同じ太さで並ぶ。決裁する者は、一行ごとに私費をまたぐことを強いられ、断る理由を費目の中から拾えなくなる。壊れるのは月末の合計で、私費を抜いた額を出そうとした瞬間、どの行が私費かを決める者が誰もいないことが露れる。

二、立替。若い使徒が私財を立て替え、帳面には「戻し」とだけ書かれる。被害の側から見れば、貸した記憶が組織の記録に吸われ、請求の言葉を持たない借金に変わる。壊れるのは退団の日で、帳面を閉じた者は、自分の立て替えが自分の字で「戻し」と書かれているのを見る。返す相手は、もう組織にいない。

三、無名。費目欄には人名を書かず、「師母」「甥」と関係だけを書く。読む者は誰の金か辿れず、親族の私費が組織の親族費に化ける。壊れるのは解散後で、帳面だけが残り、名がないために返済も追及もできず、私費は永久に組織のものになる。畳み目は、そのために丁寧に付けられている。
