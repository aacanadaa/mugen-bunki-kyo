# 共一　支援者

〈本文〉

箱屋と呼ばれた。製函所を構え、厚紙と糊と布で箱を作る。厚紙は雨の日に膨らむので、彼は途中から二度漉きの紙に替えた。教団が彼に発注したのは、掌に収まる直方体で、蓋は内側からしか開かない仕掛けのものだった。教義では、世界は一つの依頼であり、魂は分岐する。ならば依頼を入れる器は、閉じられてはならない。閉じるとは収束であり、唯一の罪にあたる。彼はその仕様を、注文書ではなく口頭で、しかも三度聞き直したと述べている。三度目のとき、相手は同じ言葉を、少し違う順番で繰り返した。彼はそれを、丁寧な説明だと思った。

関与はK4の春からK9の閉座まで。納品は三百二十七個。単価は四度改定され、いずれも上がった。支払いは一度も遅れなかった。封のされた袋で、毎月同じ日、同じ人物が持ってきた。袋に宛名はなく、彼はそれを問わなかった。彼は信者ではなかった。名簿にも加わっていない。加わらない理由を尋ねられ、「曜日が合わない」と答えたと、別の聴取記録にある。この答えは、信仰の拒否とも、単なる実務とも取れる。

街が教団を疑い始めたのはK7の頃である。町内の寄合で、夜の集まりの多さと、見慣れない若い者が増えていくことが議題になった。彼はそこで教団を弁護した。弁護の内容は教義ではなく、支払いの確実さと、注文の細かさだった。「あそこは寸法を言う」と彼は言った。寸法を言う相手は、少なくとも仕事をする相手である。これが彼の唯一の評価基準だったらしい。寄合のあと、近所の一人が彼に「あんたは染まっていない」と言った。彼はその言葉の意味を、最後まで尋ねなかった。

疑いが彼に届いたのは、K8の冬である。教団から、同じ寸法の箱を、同じ数だけ、急ぎで、という注文が来た。彼は同じ型で抜いた。同じ型で抜くとは、同じ箱が並ぶということである。分岐を信じる者たちが、分岐しない器を、しかも同じ形で、同じ数だけ求めた。彼はここで初めて、自分の仕事と教団の言葉が噛み合っていないことに気づいたと述べている。ただし、気づいたのは納品の後である。

K9の閉座。教団は箱を返さなかった。K10の解散は、知らせではなく、常連の客の噂で知った。彼は返還を求める文書を出していない。求める相手がもういないからである。K12の現在、作業場の二階には、蓋の開かない箱が四十余り残っている。中身は空である。処分していない理由を尋ねられて、彼は「もったいない」と答えた。

この記録で確かなのは、発注の数と、支払いの日付と、箱の寸法である。確かでないのは、彼が何を信じていたかである。彼は一度も教団の言葉を引用していない。引用したのは寸法だけだった。教団の内側の疑い——教主が自らを疑い、側近が教主を疑っていたこと——は、彼の作業場には一度も届いていない。彼が知っていたのは、注文と、支払いと、箱の重さだけである。

## 編纂註

**註一**　この記録は、教団を信者の内面からではなく、発注書と納品書の側から書き留めている。教義を引用せず、寸法と単価と日付だけを並べることで、分岐という語を箱の重さに置き換えた。その結果、教団は信仰の共同体ではなく、継続して支払いのあった取引先として現れる。記録が数えているのは魂ではなく、蓋の数である。この反転が、この一篇の目的である。ただし反転は説明ではない。取引先として現れることは、教団が取引に過ぎなかったことを意味しない。

**註二**　この記録は、後続の編纂者に対して、教団を測る別の物差しを渡す。教義の真偽ではなく、誰が物を作り、誰が代金を受け取ったかを問え、という手順である。同時に、箱屋を証人にも犠牲者にもしない。彼は信仰を証言できず、被害も語っていない。したがってこの記録は、彼を英雄にも被告にも仕立てないまま、次の疑いの前に置く。置かれた側は、彼をどちらかに決めたくなる。その衝動こそが、この記録の実際の効果である。

**註三**　壊れるのは、動機の欄である。発注の数は確かめられるが、K7の弁護が勇気だったのか、無関心だったのかは、同じ聴取記録から同じように読めてしまう。加えて、彼の「気づき」は納品の後に置かれている。記録者がそこに疑いの物語を読みたくなっても、その読みは資料の外側から持ち込まれたものである。この篇は、読みたくなる場所を空けたまま、そこで終わっている。

**註四**　支援者は、信者より説明が難しい。信者は教義で説明でき、離反者は裏切りで説明できる。だが箱屋は、曜日が合わないと言い、寸法を褒め、もったいないと言って箱を捨てない。どの言葉も信条ではなく、どの言葉も利益でもない。教団を支えた者を、教団の言葉で説明しようとすると、必ず余りが出る。その余りを削って一つの像にすることは、教団が唯一の罪と呼んだものと同じ手つきになる。だから註は、余りを余りのまま置く。
