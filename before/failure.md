# 前七　失敗

〈本文〉

教団の前史について、教団自身が残した文書はほとんどない。開闕K1の創立以前を扱う教団内資料は、確認できる限り三点で、いずれも教主の経歴に触れていない。以下の再建は、外部の記録――当時の営業の届け出、地方紙の小さな告知、取引先だった人物の私的な書簡――と、K10の解散後に採られた四名の証言による。うち二名は教主と直接に金銭を交わしており、二名は伝聞である。伝聞は括弧に入れた。

教主が最初に手がけたのは、通信による「分類」の事業だった。購読者から葉書を募り、一枚ごとに宛先を割り振って返送する。名目は「分類と配分の相談所」、実態は、他人の書いた短文を教主が読み、いくつかの系統に振り分け、振り分けた先の名を書き添えて返すだけのものだった。料は半年ぶんを前払い。購読者は最盛期で三十人余り。広告は地元の一枚物だけで、教主はこれを「分岐の予告」と呼んだ。

事業は二年と持たなかった。理由については証言が一致している。第一に、教主が分類の基準を誰にも渡さず、すべてを一人で処理したため、購読が増えるほど返送が遅れた。第二に、遅れへの苦情を、教主が「まだ分かれていない」と答えて処理しなかった。第三に、印刷と郵送の支払いが滞り、取引先が取引を止めた。基準を教えるくらいなら廃業すると述べた、と証言にある。廃業は開闕K1の四年前。購読者への返金は、全額とも一部とも確認できない。

失敗のあと、教主は説明を変えた。分類が遅れたのは、世界の側が分類に耐えないからであり、耐えない世界をそのまま返すのは自分の仕事ではない、というのである。同じ時期の手帳に「誤配は分岐である」という一行がある。宛先を間違えた葉書を捨てずに別の誰かへ回す――その運用が実際に行われていたかは不明だが、この一行が後の教義の骨格になったことは、K1以降の文書の語彙から明らかである。事業の失敗は、教主の内部では損失ではなく発見として処理された。最初に失ったのは購読者であり、最初に得たのは、失敗を失敗として数えない数え方だった。

その後の消息は断片的である。廃業の翌年、教主は同じ購読者名簿を使って別の通信を始めた。今度は分類を売り物にせず、分類できないことを売り物にした。名簿は返金の代わりに引き継がれ、葉書は捨てられずに箱へ残された。K1の教団が最初に整えたのは、この箱の並べ替えだった、と証言の一名は述べている。事業としては何も残らなかった。残さなかったものが残った。

## 編纂註

**一**　本条は、教団の前史を外部記録と後世の証言から組み直し、事業の失敗を教団の起源として読める形に置き直している。教団側の文書が教主の経歴を空白にしているため、この再建は空白を埋めるのではなく、空白の形を写し取る作業になる。注意すべきは、失敗の記述がそのまま教義の説明になっている点である。最初の失敗が、教義の原型である。分類の遅延、返金の不履行、基準の秘匿――教主が後に説いた言葉は、この三年間の言い訳の再雇用にすぎない。

**二**　本条は、前史を求めて文書庫を開いた読者に、起源の物語を一つ手渡す。読者はここで、失敗を損失ではなく発見として数え直す読み方を、知らぬうちに練習させられる。これは教主が購読者に対して行った操作と、形が同じである。編纂者は、この文書を読むことが教団の読み方の予習になりうることを、あらかじめ記しておく。起源を疑うために開いた頁が、起源を信じる訓練になる。手渡された物語は返却を要さない。

**三**　壊れるのは返金の記述である。全額返したという証言と、何も返さなかったという証言があり、両者は同一の人物から時期を違えて出ている。外部記録に返金の痕跡はないが、当時の記録はもともと不完全で、痕跡の不在を不履行の証拠にはできない。さらに、教主の手帳の一行は原本が確認できず、K3の教団資料に引かれた形でしか残っていない。引用の引用である。この箇所で本文は、事実の再建から、事実でありえたものの再建へ切り替わる。切り替わりは明示されない。

**四**　年次の整合も崩れる。廃業をK1の四年前とする証言に対し、教団の後期資料は同じ出来事をK1の前年付近に置き、失敗の期間を短く見せる。年を縮めると、教主が教義に到達するまでの空白が埋まり、失敗は準備期間に変わる。編纂者はこの本文でも、便宜上「四年」を採った。採ったことは註に書いたが、本文には書いていない。読者が覚えておくべきは、この再建が教団の年表を否定しながら、その語りの速度を借りているという一点である。
