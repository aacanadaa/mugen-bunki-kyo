# 機四　幻視

〈本文〉

K10の解散から二年、通電されつづけた機器は一つだけだった。機四という。教団はこれを「幻視」とも呼んだが、それは正式の名ではなく、記録の余白に後から書き込まれた通称である。筐体には窓が一つあり、窓の内側で紙が一枚だけ送られて止まる。送られ方には規則があるというが、その規則を記した文書は残っていない。残っているのは、日付と、出力の第一行と、照合の欄だけを縦に並べた帳面である。行数は決まっており、余白の方が広い。

機四の仕事は読解ではない。群典の任意の一葉を開き、そこから一語だけを選び、別の語に置き換えて、置き換えた本を一冊だけ作る。どの語を選んだかは残さない。残せばその本は二冊目になり、分岐が収束してしまうからである。置き換える語は乱数で選ばれ、選ばれた語は本の中にしか残らない。教団の第五品は「畳みは慈悲」といった。畳める枝だけが慈悲の内にあり、畳めない枝は慈悲の外にある。機四は、畳める枝を作るための機械だった。

出力は一冊ごとに異なる。同じ日に開かれた二冊が同じ葉で止まることはあっても、置き換わる語まで同じになることは少ない。読者は自分の一冊しか持てず、隣の一冊と突き合わせる作法を持たない。突き合わせは収束であり、収束はこの教団が唯一の罪としたものだからである。だから誤りは、誤りとして読まれる前に、まず読者の側で畳まれてしまう。同じ葉を二度開いた記録も、開かなかった葉の一覧もない。三度の誤りが見つかったのは、書庫の目録が出力とは別に保たれていたからにすぎない。

誤りはK11の冬に三度起きた。三度とも、出力の末尾に典拠として「畳五拾遺・坤巻」第四十二葉と記した。書庫の目録を繰った者は、その巻が編まれたことがないと記している。坤巻どころか、拾遺そのものが存在しない。検めた者は、該当する筈の位置に何もないことを三度確かめた。にもかかわらず機四は三度とも同じ書名を出した。その名を教えた記録は、どこにもない。照合の欄には検めた者の名を書く筈だったが、三度とも空欄である。

記録の最後に、一人の読者がいる。その読者は出力を読み、典拠を確かめようとして目録を開き、やがて目録を閉じた。閉じた理由は書かれていない。書かれているのは、目録の最後の葉に、まだ書名のない欄が一行だけ空いていた、ということだけである。閉じた手がどの頁の上にあったかも書かれていない。読者の欄はそこで終わる。以後の頁はなく、機四は止まっていない。

この記録は機四の出力そのものではなく、出力を読んだ者たちの欄の写しである。原本は解散の際に三つの箱に分けられた。箱は同じ順序で綴じられておらず、日付の重なる葉が二枚だけある。二枚は同じ日の同じ出力を写しながら、典拠の書名の位置だけが違っている。片方には「畳五拾遺・坤巻」とあり、片方には何もない。どちらが先に書かれたかは、紙の色では決まらない。

## 編纂註

**註一（この装置）**　機四は読解の機械ではなく、一葉を開いて一語を換え、換えた語を記録しない機械である。記録しないことによって、同じ葉から同じ本を二冊作れないようにしている。誰に何をするかといえば、群典を開いた者一人に一冊ずつを渡し、その者に自分の一冊だけを持たせる。壊れるのは、換えた語が典拠を名乗ったときである。典拠は書庫と照合されねばならず、照合は機械の外にある。

**註二（幻視）**　引用された「畳五拾遺・坤巻」は存在しない。書庫の目録にも、拾遺を編んだ記録にも、その名はない。存在しない文書を引くこの誤りを、教団は幻視と呼んだ。幻視は、教団が最も恐れた誤りである。収束を唯一の罪とした教団にとって分岐は徳であったが、分岐のふりをして何も分岐していない枝は、畳むことも開くこともできず、教団の外に落ちる。

**註三（読者）**　最後の読者は、典拠を確かめようとして目録を開き、閉じた。この動作は教団の言葉では収束にあたる。すなわちこの装置は、読者に唯一の罪を犯させる。壊れるのはそこである。確かめない読者にとって幻視は幻視のまま流通し、確かめた読者は罪を負う。記録はどちらも裁かず、照合の欄を空欄のまま次の頁へ送る。

**註四（この写し）**　編纂者である我々は、この写しが原本と一致するかを決められない。決めることは収束であり、収束はこの教団の唯一の罪である。ゆえにこの文書は、書名の空欄を空欄のまま残し、読者に委ねる。ただし付言すれば、空欄を埋めた者は、次の頁で同じ空欄に出会う。我々が保証できるのは、機四が今も通電しているということだけである。
