# 記十九　値段

〈本文〉

群典の周辺文書のうち、いちばん書き換えの多いのは値段の欄である。教義はめったに動かない。儀礼の順序も動かない。だが、この欄は年に何度も動く。そして動いた記録が、そのまま教団の盛衰の目盛りになっている。

| 年 | 品 | 額 | 備考 |
|---|---|---|---|
| 開闕三年 | 分岐符（紙） | 二銭 |  handwritten、教主の筆。一括手持ちのみ |
| 開闕五年 | 分岐符（紙） | 四銭 | 刷り版に変更。同じ図柄が並び始める |
| 開闕七年 | 収束手帳 | 十二銭 | 分岐符の三倍。なぜ高いのかは記されない |
| 開闕九年 | 収束手帳 | 二十銭 | 値上げの理由は「紙が良い」とだけ |
| 開闕十年 | 分岐符（紙） | 十五銭 | 解散の直前。入手困難で値が跳ねる |
| 開闕十年 | 収束手帳 | 三十五銭 | 同上 |
| 開闕十一年 | 分岐符（紙） | 一銭 | 解散後。在庫が余り、叩き売られる |
| 開闕十一年 | 収束手帳 | 二銭 | 同上。ただし書き込みのあるものは別 |
| 開闕十二年 | 分岐符（紙） | 八十銭 | 「遺品」として扱われ始める |
| 開闕十二年 | 収束手帳 | 三円 | 書き込みのある個体。筆跡で値が変わる |
| 開闕十二年 | 分岐符（複製） | 三銭 | 土産物。本物と並べて売られる |

表を縦に見ると、二度の断裂がある。一度目は解散の年である。値は急落し、二銭まで落ちた。二度目はその翌年で、同じ品が八十銭になった。一年で四十倍である。品物は何も変わっていない。変わったのは、それを欲しがる人の数と、欲しがる理由である。

教主は値段について何も語らなかったとされる。語らないことが、かえって値段を自由にした。教義は「唯一の罪は収束」と言う。要約すること、完了させること、終わらせること。ところが値段は、要約の反対側にある。誰かが「これはいくらか」と訊ねるたび、品物はもう一度分岐する。安いという分岐、高いという分岐、二度と手に入らないという分岐。値段は、物の終わりを遅らせる仕掛けである。

解散後に値段をつけたのは、教団ではない。教団はもうない。値段をつけたのは、記念品店であり、古物市であり、教科書の脚注であり、あるいは、遺品を前にして黙り込んだ人の手である。彼らは教義を継いでいない。継いでいるのは、値段という形式だけである。

---

## 編纂註

**一　この欄がしていること。** 値段の欄は、教団の歴史を「買えるもの」の歴史に置き換えている。開闕三年の二銭から開闕十二年 の三円まで、同じ品が同じ名で呼ばれ続けるあいだに、その意味だけが入れ替わる。読み手は表を目で追ううちに、教義の断絶よりも先に、価格の連続性を信じる。ここで機能しているのは記録ではなく、連続しているという感覚の供給である。

**二　誰に何をするか。** この欄は、教団を知らない読者に「自分が知らないあいだに相場が動いていた」という遅参の感覚を与える。同時に、教団の内部にいた読者には「あの値段は正しかったのか」という問いを返す。前者には市場の物語を、後者には会計の記憶を渡す。値段は、信者だった人と信者でなかった人を、同じ表の前で別々の感情に分岐させる。

**三　どこで壊れるか。** この欄は、額そのものが検証できないという一点で壊れる。二銭が高いのか安いのか、当時の暮らしがどのくらいだったのか、記録は何も語らない。語らないまま表だけが残るので、読み手は自分が知っている物価を無意識に当てはめる。当てはめた瞬間、この表は歴史ではなく、現在の値段の鏡になる。壊れるのは記録ではなく、読む側の年代感覚である。

**四　註。** 値段は、記憶の人気の記録である。何が高く売れるかは、何が惜しまれているかを示す。教団が消えたあと、人々が高値を付けたのは教義ではなく、書き込みであり、筆跡であり、誰かの手の跡であった。つまり値段が測っているのは信仰の強さではなく、失われたものへの未練の量である。この欄が正確であればあるほど、それは教団の記録ではなく、教団を失った人々の記録になる。
