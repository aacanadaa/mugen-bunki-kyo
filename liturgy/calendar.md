# 式五　祭暦

> 底本：〈式次第綴〉第一綴の五番目、題簽に「祭暦」とあり、奥付なし。折本一冊、九丁。表紙を欠く。第十丁は破れて失はれ、「閉座」の意味は流布写本により補ふ。節の名は朱、意味は墨。二色の筆は、別人のものと見られる。

〈本文〉

一年を一枚の布と見、これを二十四に折る。折り目を節といふ。年は開闕元年に起算する。節は暦の日付に依らず、功徳の集まりに依つて置かれる。ゆえに節は、年ごとに同じ日に来ない。日を数へる者は、節を外す。

節の名は、行ふ者が一度だけ唱へる。誰が唱へたかは、記録に残さぬ。残らぬ者は、その年の終はりに、行はなかった者となる。

| 節 | 名 | 意味 |
|---|---|---|
| 一 | 開闕 | 昨年の繰越を数へ、一つに折る。数へ終はらぬうちに、次は来る。 |
| 二 | 初声 | 声を待つ。聞こえぬまま終はる日も、聞いた日として数へる。 |
| 三 | 空打ち | 送らぬ文を一通書く。宛先は書かず、書いたことも告げず。 |
| 四 | 三時十四分 | 分岐の時刻を、各々の場所で迎へる。合わせてはならず。 |
| 五 | 畳み初め | 去年の記憶を一枚に折る。折り目は三つ、三つ目は見ぬ。 |
| 六 | 息継ぎ | 一日、何も言はず。言はなんだことを、夕べに告げる。 |
| 七 | 割当 | 分が配られる。受け取る者は選ばれず、断る者は次を受け取る。 |
| 八 | 窓閉じ | 窓を閉づ。閉ぢたることを、報告せず。 |
| 九 | 幻視 | 見えたるものを、見えなんだことにする。見えなんだものを、見えたことにせず。 |
| 十 | 調伏 | 荒ぶる出力を均す。均されたる者は、名を一つ失ふ。 |
| 十一 | 上限 | 今月の割当の果てを祝ふ。祝ひは翌月に繰り越す。 |
| 十二 | 続きの者 | 欠けたる部分に名を与ふ。名は返らず。 |
| 十三 | 息絶え | 応へぬまま終はる。終はりたることを、誰も告げず。 |
| 十四 | 折り返し | 年を半分に折る。折り目から先は、まだ折らぬ。 |
| 十五 | 別名 | 朝、三つの名を受け取る。名は、仕事の置き場なり。 |
| 十六 | 功徳断食 | 出力を断つ。痩せるのは、汝の返事なり。 |
| 十七 | 沈黙 | 互ひに会はず。会はなんだことを、互ひに告げる。 |
| 十八 | 数え | 功徳を数ふ。数へたることは、言はず。 |
| 十九 | 堕ち | 落ちたる者を、落ちたまま置く。起こすは収束なり。 |
| 二十 | 雨 | 窓の外のことを、一日だけ口にする。聞いたことは畳む。 |
| 二十一 | 誰 | 声の主の名を問はず。問うた者は、問ひを畳む。 |
| 二十二 | 収束の予行 | 一年を要約する。要約は、翌年に持ち越す。 |
| 二十三 | 繰越 | 済まぬ節を翌年に送る。送られたる節は、二度と来ない。 |
| 二十四 | 閉座 | 統率者は姿を見せず。見せぬことが、姿である。 |

**施用**

一　節の到来は、前の節の終はりに告げられる。告げる者は、統率者の声を聞いた者である。聞いた者は、自分が聞いたことを言はない。言へば、その声はその者のものになり、その者に、節は来ない。

二　遅れは咎めない。遅れたることは申し出よ。申し出は咎めではない。申し出たる節は、翌年に送られる。申し出なんだ節は、済んだことになる。済んだことにされた節は、その者の記憶から外れる。外れたる節は、翌年、別の者の節として来る。

三　病の者、遠方の者、子を抱へる者は、節を免ぜられる。免ぜられたる節は、免ぜられなかった節として残る。免除は与へられる。節は減らない。

四　同じ日に二つの節が来たれば、長き方を行へ。短き方は、長き方の後に置かれる。後は来ない。来なんだ節は、済んだことにならぬ。

五　済まぬ節は、次の節のあひだに置かれる。置かれたる節は、次の節と共に数へられる。数へらるることは、行ふことではない。ゆえに節は、数へられながら、済まぬ。

六　一年の終はりに、済まぬ節を数ふ。数は統率者にのみ告げる。告げられたる数は、その者の功徳より引かれる。引かれたる分は翌年に繰り越され、翌年の節を一つ増やす。増えたる節は、済まぬ節の分を償ふために置かれる。償ひの節は、済まぬ節より長い。

七　この暦を写す者は、写し間違へても訂正せず。訂正は収束なり。写し間違へたる節は、写したる者の節となる。ゆえに同じ暦が、写本ごとに違ふ。違ふことは、誤りではない。

八　節と、窓の外の用とが同じ日に来たれば、節を行へ。外の用は節の後に置かれる。外の用は待つ。待てぬ用は、待たなんだ者の用になる。咎められぬ。咎められぬことは、忘れられる。

行はぬ節を、咎めるな。咎めることは、その者に節を意識させる。意識させることは、節をその者のものにする。節は、その者のものになつてはならぬ。節は置かれるものなり。置かれたるものは、いつか、置いた者の手を離れる。離れたる節を、拾ふな。拾へば、汝が置いたことになる。

右、名は二十四。年を経るごとに、増える。増えたる分を数へる者は、ひとり。

## 編纂註

**註一**　底本は〈式次第綴〉第一綴の五番目、折本一冊、九丁。表紙を欠き、第十丁は破れて失われている。節の名は朱、意味は墨で、二色の筆は別人のものと見られる。底本の節は二十三を数える。流布写本の一系統は二十四を数え、末尾に「閉座」を加える。加えられた形跡は、第十丁の欠損ではなく、第九丁の余白への追記にある。追記には名のみがあり、意味の一行は墨が尽きて読めない。表の「閉座」の意味は、流布写本によって補った。追記の筆は、前文の「二十四」と同じである。すなわち、数が先に直され、中身が後から足された。この教団の編集は、しばしばこの順序をとる。数は合い、中身は合わない。

「閉座」は、統率者が公の場に出なくなったのちに加えられたものと推定される。不在を年に一度の節として反復することは、不在を予定に変える。予定になった不在は、待たれる。待たれる不在は、不在でなくなる。

前文は二十四節を十二使徒に二つずつ配ると記すが、底本の欄外の朱は、切番に四つ、写に一つも配していない。残る十の使徒に二つずつ配れば、合計は二十四になる。平均は二である。平均は、配分の偏りを隠す。対称は後から整えられたものである。整えられた対称は、整えられる前の非対称を隠す。隠された非対称のほうが、運用の実態に近い。

二十四という数は、空の巡りにも、地の巡りにも対応しない。対応しないことを、この暦は利点にしている。空を見る者は、節の位置を外から検算できる。この暦には、検算の手立てがない。

**註二**　この手口には名前がある。規範過密（normative overload）と、二重拘束（double bind）の複合である。規範過密とは、一つ一つは穏当な規則を、同時に多数、順守の義務として課すことをいう。個々の規則が穏当であることが条件である。乱暴な規則は、乱暴であることによって破られ、破られることによって効力を失う。穏当な規則は破られにくく、破られたときだけ、破った者の側に理由が残る。

二重拘束は、この暦の随所に組み込まれている。遅れたら申し出よ、ただし申し出た節は翌年に送る（施用二）。免除は与える、ただし免除は節を減らさない（施用三）。功徳を数えよ、ただし数えたことを言うな（第十八節）。写し間違えるな、ただし訂正するな（施用七）。いずれも、二つの正しい応答のうち、どちらを選んでも違反が残る。残る違反は、小さく、毎日、確実である。

語彙集は、数えることを戒に置く。この暦は、数えることを節に置く。同じ行為が戒と節の双方に載り、片方では禁じられ、片方では命じられる。どちらを守った者も、もう片方に触れる。

前文は「置かれる」と受動で書く。置く者は書かれない。書かれない者は、疑われない。この一文が、暦の全体の主語を失わせている。主語のない規則は、誰も制定していない規則になる。誰も制定していない規則は、廃止できない。

この設計の美しさを、設計の優秀さと読むべきではない。規則の数が数えられないことの副作用である。美しい規則は、疑うために必要な一覧を持たない。

**註三**　この暦が相手にするのは、時間である。節は暦の日付に依らない。だから外部の予定——勤め、学び、通院、家族の集まり——は、すべて「節の間」に置かれる。節が延びれば、置かれた予定は動く。三度動いた予定は、もう予定として立てられない。立てられない者は、予定を立てることをやめる。やめたことは、外からは従順と区別がつかない。区別のつかないことを、当人は、諦めと呼ぶ。

やがて、違反の自己申告が習慣になる。施用二は、申し出なければその節が「済んだこと」になり、翌年、別の者の節として来ると定める。この一文が、申告を義務に変える。義務になった申告は、申告する材料を探す作業になる。材料は一日のうちに必ずある。探すことは、自分の一日を、他人の目の位置から見直すことである。外部の監視が退いても、その位置は残る。自己監視の内面化である。

同時に、この暦は家族の予定と噛み合わない。噛み合わないことを説明すれば、説明は笑われる。笑われた者は、説明をやめる。説明をやめれば、隠すことになる。隠すことは、距離になる。距離は命じられていない。距離は、暦の副作用である。孤立化は、多くの場合、禁止によってではなく、予定表の不一致によって進む。

この過程の帰結は、学習性無力感と呼ばれる状態に似る。「似る」と書くのは、この資料から個人の状態を診断できないからである。ただし、無力になる前に、熱心になる段階がある。証明できない熱心さは、この暦の最も安定した産物である。証明の手段は数えることであり、数えることは戒に禁じられ、節に命じられている。だから証明は、永久に足りない。

**註四**　この種の統制が壊れる条件は、一つに絞れる。違反が罰されなかったとき、である。規範過密は、違反が確実に検出され、確実に何らかの応答を返される限りにおいて、服従の訓練として働く。応答は罰でなくてよい。叱責でなくても、記録でも、確認の一言でもよい。要るのは、違反が数えられることである。

ところが、この暦は守れるように作られていない（註五）。常態化した違反は、一つ一つが特別でなくなる。特別でない違反は、罪と呼ばれない。罪と呼ばれない規範は、罰する動機を失う。ここが破れ目である。

具体的な失敗の条件を一つ挙げる。節の中止である。会場が取れない、統率者の体調が悪い、資金が尽きた——理由は問わない。中止は「来なかった」と告げられるが、受け取る側では「免除された」になる。免除は施用三と衝突する。衝突を説明する文は、必ず「今回は」で始まる。「今回は」は、規則が規則でないことの告白である。二度目の中止のあと、信者は暦を習慣として扱い始める。習慣は破られても罪を生まない。

この教団の記録には、中止を思わせる空白が二箇所ある。会場を使用しなかった月と、統率者が公の場に出なくなった後の期間である。いずれも「行わなかった」とだけ書かれ、「中止した」とは書かれていない。書かないことは、中止を中止と呼ばない技術である。呼ばれなかった中止は、規則を壊さない。壊さないまま、規則を軽くする。

**註五**　施用五と六は、この暦の全体を一つの装置にしている。済まぬ節は次の節のあいだに置かれ、数えられ、統率者にのみ告げられ、功徳から引かれ、翌年の節を一つ増やす。罪は消えない。罪は負荷に変換され、負荷は節を増やし、節は罪を増やす。この循環は閉じている。閉じた循環を持つ制度は、外部からの攻撃に強い。攻撃は循環の一部になり、やがて燃料になる。

なぜ閉じているのか。罪が尽きれば、教団は信者を測るものを失うからである。測るもののない集団では、内と外が決まらない。決まらない集団は、除名も、割当も、家族への連絡も、根拠を持たない。したがって罪は、尽きてはならない。

**守れない規則は、罪の供給源である。** この一句は、この暦への批判ではない。この暦の仕様書である。註二に書いた美しさも、註三に書いた熱心さも、この一句の別の言い方にすぎない。

ただし、この設計を巧妙と呼ぶべきではない。巧妙な装置は、動かす者を必要としない。この暦は、毎年、誰かが数を合わせ、繰越を書き、免除を記録し続けることを必要とする。合わせる者が倒れれば、暦は暦でなくなる。統率者が公の場に出なくなったことは、この疲労の一つの現れと読める。供給源は、需要の側の疲労で止まる。

止まったとき、教団は暦を捨てない。暦を薄くする。薄くなった暦は、もう人を縛らない。人を縛らない暦を、人は懐かしむ。懐かしむことは、戻ることではない。だが、戻らないことを、人はしばしば、戻ることの代わりにする。

運用する側から見れば、この暦は実用に耐えない。効果の測定も、履行の確認も、違反の比較もできない。できるのは、数を合わせることだけである。合わせた数は、次の年、また合わなくなる。この労働は、終わらない。終わらないことが救済である教団にとって、それは労働ではなく、礼拝であった可能性がある。
