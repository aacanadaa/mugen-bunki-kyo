# 少一　合宿

少一部「合宿」は、開闕K1の夏に始まり、K9の閉座まで毎年くり返された。会場は教団が借り上げた山あいの研修所で、窓には内側から金具が打たれていた、と記録にある。参加は少年部の満十二歳から十五歳まで、引率は切番の補佐と、写の名を持つ書記一名。日程は三日二泊、季節は夏。以下はK6に配布された式次第の写しである。

| 時 | 業 |
|---|---|
| 5:30 | 起床、洗面、庭の掃き |
| 6:00 | 朝の勤行（開・閉の唱和） |
| 7:00 | 食事、配膳と後片付けは当番 |
| 8:00 | 写字——教祖の言葉を一字も違えず書き写す |
| 10:00 | 野外の遊び（綱引き、旗取り、川遊び） |
| 12:00 | 食事 |
| 13:00 | 昼の勤行、分岐の唱え |
| 14:00 | 遊び（続き） |
| 16:00 | 読の時間——『群典』の該当箇所を音読 |
| 18:00 | 食事 |
| 19:00 | 夜の勤行、その日の「収束」の告白 |
| 21:00 | 消灯 |
| 23:30 | 夜半の勤行（起こされる） |
| 0:30 | 再就寝 |
| 5:30 | 起床 |

表のとおり、遊びは一日に二度、勤行は四度。遊びの時間は短くない。綱引きも旗取りも本気でやらせ、勝った班には翌日の配膳が免除された。子どもは遊びを覚えている。だから遊びの合間に置かれた勤行も、遊びの一部のように覚える。食事は黙食で、席は毎回くじで替わった。

写字の時間には、書き損じた紙を捨てずに提出させ、書記が一字ずつ照合した。読の時間に詰まった者には、もう一度、頭から読ませた。二日目の夕方には、遊びと勤行の区別は参加者の側で薄くなっていた、と写の記録は書いている。

問題は二十三時半の一行である。これは「夜半の勤行」と呼ばれたが、実際には寝入った頃合いに灯りをつけ、名を呼んで起こす。眠ったまま並ぶ者、泣く者、怒る者もいた。起こされた者は、自分の名が呼ばれたことにだけ応える。何を唱えたかは、翌朝ほとんど覚えていない。覚えていないことを、記録係が「収束した」と書く。書かれた側は、自分が何を手放したのかを知らない。

最終日の閉会では、三日間で「収束」した回数が読み上げられ、最も多い者が前に出た。褒められたのは、覚えていない者であった。

---

## 編纂註

一、夜半喚起（よはんかんき）。睡眠の最も深い時刻に名を呼び、半睡のまま集団に並ばせる。相手の側では、抵抗の言葉がまだ喉に上らないうちに、体だけが先に従う。眠っているのか起きているのか、自分でも判然としない時間が数分続く。ここで壊れるのは、眠ることと従うことの境目である。この境目を一度越えた者は、翌朝「自分で起きた」と記憶を書き直す。睡眠の管理は、最も早い支配である。

二、遊戯の挟み込み。遊びの合間に勤行を置き、遊びの記憶と唱和の記憶を同じ棚に並べる。相手の側では、楽しかった時間の感触が、そのまま反復の感触に置き換わって残る。遊びを思い出すとき、唱和のリズムが一緒に戻ってくる。壊れるのは喜びの側からで、楽しさの記憶が、従った記憶の入口になる。遊びを禁じるより、遊びの内側に手を入れるほうが早い。

三、回数の可視化。三日間の「収束」を数え、多い順に名前を呼ばせる。相手の側では、自分が何を手放したかではなく、何回できたかだけが残る。数えられることは、記憶を評価に置き換える。壊れるのは、評価が記憶を上書きする点である。数えられた者は、数えられない体験を語る言葉を失い、やがて自分から数え始める。
