文書番号：宗俗庁発第K12-〇七三号
宛先：各分岐区行政局長
内容：分岐登録事務の取扱いについて

各分岐区行政局長　殿

宗俗庁長官　印

**分岐登録事務の取扱いについて**

一　趣旨
本通達は、宗俗行政法（K11年法律第三二号）及び同法施行令（K11年政令第五九号）の規定に基づき、無限分岐教に係る分岐登録事務の細目を定めるものとする。法令の規定を重複して定めるものではなく、その運用の斉一を図ることを目的とする。

二　用語
（一）法令上の「従属施設」とは、当該教団が「枝」と称するものをいう。
（二）法令上の「登録構成員」とは、当該教団が「種子」と称する者をいう。
（三）法令上の「分岐行為」とは、当該教団が「開闕」と称する行為のうち、施設の新設又は構成員名簿の分割を伴うものをいう。
（四）前各号の呼称は、教団の内部において用いられることを妨げない。ただし、届出書その他行政局に提出する書面においては、法令上の用語を用いるものとする。

三　届出
（一）分岐行為を行おうとする者は、行為の日の三十日前までに、別記様式第一号による届出書を、当該行為地を管轄する分岐区行政局に提出しなければならない。
（二）前項の届出書には、分岐の前後における構成員数を記載した書面を添付するものとする。構成員の氏名は、これに代えることができない。
（三）届出書の記載に不備がある場合、行政局は相当の期間を定めて補正を命ずることができる。当該期間は、十日を下らないものとする。
（四）分岐行為の後、構成員数に百分の十以上の変動があったときは、その日から三十日以内に変更の届出をしなければならない。

四　立入り
行政局の職員は、法第十二条の規定により、従属施設に立ち入り、帳簿その他の物件を検査することができる。この場合において、職員は、その身分を示す証票を携帯し、関係者の請求があったときは、これを提示しなければならない。

五　解散の記録
K10年の解散の届出は、届出書に解散の決議を証する書面の添付がなかったため、法第十四条第三項の規定により、受理されなかったものとして取り扱う。したがって、当該教団の登録は、現在も存続している。ただし、これは解散の事実がなかったことを意味しない。

六　翻訳の記録
届出に際して教団が用いる呼称は、別表のとおり法令上の用語に翻訳して記載するものとする。別表に掲げる対応は、教団の教義上の位置づけを認めるものではなく、事務処理上の便宜にすぎない。

別表（抄）

| 教団の呼称 | 法令上の用語 |
| --- | --- |
| 枝 | 従属施設 |
| 種子 | 登録構成員 |
| 開闕 | 分岐行為 |
| 本幹 | 主たる事務所 |
| 休眠 | 資格停止 |
| 落枝 | 脱退 |

七　報告
各分岐区行政局長は、毎年度末現在における分岐登録の状況を、翌年度の四月末日までに宗俗庁長官に報告するものとする。

八　施行
本通達は、K12年五月一日から施行する。

## 編纂註

**註一（何をしているか）**
この文書は、教団の内部語を行政の分類に置き換える作業を、事務の手続として固定している。枝は従属施設に、種子は登録構成員に、開闕は分岐行為になる。禁止も許可もしていない。ただ名を変えることで、それまで行政の外にあったものが、数えられ、届け出られ、比較できる対象になる。教団の側は、以後、自らの言葉を提出用の言葉に翻訳し続けなければならない。翻訳は一方向で、戻す欄はどこにもない。

**註二（誰に何をするか）**
宛先は各分岐区の行政局長であり、内容は届出の受理と補正、立入り、報告である。教団に課されるのは、行為の三十日前の届出、構成員名簿の添付、提出書面で内部呼称を用いないことの三つ。行政局には、補正を命ずる権限と、立ち入る権限が与えられる。義務は教団に偏り、裁量は行政局に偏っている。この非対称は、通達のどこにも書かれていない。

**註三（どこで壊れるか）**
壊れるのは、K10年の解散の記録においてである。解散の届出は、決議を証する書面が添付されなかったために受理されず、登録は存続した。書類の不備が、団体の死を手続の上でなかったことにした。以後この教団は「解散したが登録上は存続する」という、どちらの言葉でも正しく言い表せない状態に置かれる。K12年の現在は、その状態の継続である。第五項のただし書きだけが、事実の側に逃げ道を残している。

**註四（通達という形式）**
通達は、法律の細部を埋める。法律が「分岐行為」とだけ書いたところに、三十日前という日数、別記様式、添付書面、補正期間、一割の変動基準が入る。これらは法律の文言を変えないまま、運用の実質を決める。通達は法律と同じ手続を経ないため、改正も容易である。冒頭の「法令の規定を重複して定めるものではない」という一文は、その容易さを隠すための定型句にすぎない。
