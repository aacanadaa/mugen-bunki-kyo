# 洗一　当番

『群典』第五品附録の一。洗一は使徒の筆頭ではない。ただ、最初に名を書かれた者である。名を書かれることは、当番を負うことである。

当番は週ごとに巡る。巡ることは平等であり、平等は表に現れる。ゆえに表は洗い場の柱に掲げられ、誰もが自分の行を読む。

| 曜 | 名 |
|---|---|
| 月 | 切番 |
| 火 | 流 |
| 水 | 重 |
| 木 | 沈 |
| 金 | 開 |
| 土 | 閉 |
| 日 | ―― |

日曜の欄は空である。空欄は懈怠ではない。第五品に曰く、畳むことは慈悲である。畳まれた布は広がらず、広がらぬものは分岐しない。ゆえに日曜は畳まれ、当番は置かれない。この一行の空白を、埋めてはならない。

巡りには定めがある。次の週は名が一つずつ繰り上がる。十二の名は七つの欄を巡るので、五週ごとに名が一つ余る。余った名は日曜の下に控えとして記される。控えは働かない。働かぬ者もまた表のうちにある。

洗い場には布が七枚ある。七枚は曜日に一つずつ対応する。対応は固定であり、布が破れても対応は変わらない。破れを繕うのは結である。結は繕いながら、繕った箇所を数えない。数えれば差になり、差は表に載り、表は裁きになるからである。乾かすのは曲である。曲は布を曲げ、曲げた形を記録しない。記録された形は、次に畳む者を縛る。均は洗剤を分ける。分けることは均すことであり、均すことは、余りを誰にも見せないことである。開は戸を開け、閉は戸を閉じる。閉は閉じたあと、戸を数えない。数えれば翌朝の開が怠慢になる。

記帳は写が行う。写は名を写すだけで、名を選ばない。読み上げは読が行う。読は月曜の朝、表を声に出して読み、誰も返事をしないことを確かめる。返事は収束である。

欠の名は、どの欄にもない。欠は欠席するのではなく、欠であることによって出席している。これについての註は現存しない。

洗一の名は、この附録のどこにも当番として現れない。附録を書いた者が当番を免れるのは、書くことがすでに当番だからである。

## 編纂註

### 一　可視化

当番表は、平等の見える化である。表は割り当てを配るのではなく、割り当てを見えるものにして、見た者に自分の欄を監視させる。被害の側では、不平等を訴えることが表そのものへの不服従に読み替えられ、不満は感情の問題に縮められる。壊れるのは、表と実際の負担がずれた日である。ずれは表の外にしかないので、表を正すかわりに、ずれた者を表から外す運用に落ちる。

### 二　相互記名

名を並べる手口。自分の欄だけでなく他人の欄も読ませ、持ちつ持たれつの感情を作る。被害の側では、断ることが貸し借りの債務の不履行になり、休むことに借用書が要る。壊れるのは、誰かが表を読まなくなったときである。読まれない表は監視を失い、ただの紙になる。紙になった表は破られない。破られないので、誰も表を疑わなくなる。

### 三　空欄の保留

空欄を一つ残す手口。完成しない表は、完成しない世界の雛形になる。被害の側では、空欄がいつか自分の名で埋まるという期待で滞留し、埋まらないまま年月が過ぎる。壊れるのは、空欄が実際に誰かの名で埋まった瞬間である。埋まれば表は完成し、完成は収束であり、教義では唯一の罪にあたる。ゆえに空欄は最後まで空けたまま、別の紙に「空欄」と書いて重ねる。重ねられた紙は、もはや表ではない。
