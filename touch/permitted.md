# 触一　触れ得るもの

触一は、触れてもよい物を列挙する。これは禁止の表ではない。許可の表である。禁は数えられないが、許は数えられる。数えられるものだけが、教団の内側に置かれる。

| 物 | 条件 |
|---|---|
| 教団の帳簿 | 開闕の印が押された頁のみ。押印のない頁は触れない |
| 分岐札 | 未記入のものに限る。記入済みの札は、記入者に返す |
| 畳 | 第五品の畳みが済んだもの。畳み目を数えないこと |
| 灯 | 灯は触れてよい。ただし同じ灯を二度、別の者と囲まない |
| 水 | 汲んだ当日のもの。翌日のは「収束した水」として扱う |
| 名を書いた紙 | 本人が書いたもの。他人が書いた名には触れない |
| 糸 | 分岐を結ぶためだけに使う。結び目は一つまで |
| 器 | 貸与の器。返却の約束を口に出した者のみ持てる |
| 手 | 相手の手は、相手が先に差し出したときのみ |
| 戸 | 内側から開ける戸。外側からは開けない |
| 鍵 | 鍵は触れてよいが、開けてはならない |
| 影 | 影には触れてよい。影を測ってはならない |

右の表で注目すべきは、物の側に条件が付いていることではなく、条件の側に物が付いていることである。「押印のない頁」は頁ではない。「記入済みの札」は札ではない。教団は物を禁じているのではなく、物を関係に置き換えている。

---

## 編纂註

**一、何を規格化するか。** この表が規格化するのは、物の接触ではなく、接触の順序である。誰が先に手を差し出すか、誰が先に名を書くか、誰が先に戸を開けるか。教団は物を聖別しない。物と物のあいだに「先」を挿入する。挿入された「先」が、そのまま序列になる。触一が「一覧」の形をとるのは、序列を可視化するためではなく、序列を数えられるものに見せるためである。

**二、人に何をするか。** 読み手に、自分の持ち物を一つずつ表に照合させる。照合のたびに、持ち物は「条件を満たす物」に置き換わる。置き換えは一回で終わらない。灯を囲む相手が変わるたび、水が古くなるたび、照合は再開される。読み手は次第に、物を持つことを「条件を思い出すこと」として経験するようになる。想起の負荷が、所属の感覚に転化する。

**三、どこで壊れるか。** 壊れるのは「手」の項である。相手が先に差し出した手だけが触れてよい。ならば、差し出された手を取らなかった者は、何をしたことになるのか。取らなかっただけの者を、表は裁けない。裁けないまま、その者は表の外に残る。触一の破綻はここに集中する。許可の表は、許可しなかった者の扱いを、ついに書かない。

触れ得るものの一覧は、関係の一覧である。物は順序のための口実にすぎない。
