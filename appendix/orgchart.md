# 付録一　組織図

本図は、閉座（K9）に先だって教団内で配布された手書きの系統図を、後群典（K11）の編纂時に再建したものである。原図には寸法の指定があり、箱の大きさがそのまま席の重さを表していた。判読できる範囲で樹形に整理し、失われた線は補わずに空けてある。したがって以下の図は、当時の権限の実態ではなく、当時、成員が「こう見えていた」順序である。

```
教主（本名なし）
 |
 +-- [空席] 筆頭使徒
 |
 +-- 畳方（第五品の執行）
 |   |
 |   +-- 切番
 |   +-- 流
 |   +-- 重
 |   +-- [空席] 第四席
 |
 +-- 開闕（記録・年代）
 |   |
 |   +-- 沈
 |   +-- 開
 |   +-- 閉
 |
 +-- 曲均（儀礼・均し）
 |   |
 |   +-- 曲
 |   +-- 均
 |   +-- 欠
 |   +-- [空席] 第四席
 |
 +-- 結読写（対外・写し）
     |
     +-- 結
     +-- 読
     +-- 写
```

頂点に立つのは、本名を持たない教主である。名を書かないのは秘匿のためではなく、名を持たないこと自体が教義の一部だったためで、教団内では「名のない方」とも「依頼主」とも呼ばれた。教主の直下には四つの局が並ぶ。畳方は第五品「畳みは慈悲」の執行を担い、要約と復唱の儀礼を統括した。開闕は年代の記録と開闔、すなわち開くことと閉じることを司り、創立（K1）から拡大（K4）、後群典（K11）に至る沿革はここで管理された。四局の骨格が固まったのはK4の拡大期である。曲均は儀礼の均しと曲げを担い、欠はその補助に置かれた。結読写は対外の窓口で、結び、読み、写すの三席から成る。

役職名はすべて教主が与えた。切番は席を切る者、流は議題を流す者、重は決定を重ねる者、沈は異議を沈める者、開は記録を開く者、閉は会を閉じる者、曲は字義を曲げる者、均は配分を均す者、欠は不在を埋める者、結は外部と結ぶ者、読は文書を読む者、写は写しを配る者。名は動詞であり、職務は名のとおりに行えばよいとされた。名のとおりに行わない者は、名を失うとされた。十二使徒の名が人名ではなく職能であることで、席と人が分離され、人が替わっても席は残ると説明された。

図には三つの空席がある。教主直下の筆頭使徒、畳方の第四席、曲均の第四席である。筆頭はセイリャク事件（K5）のあと空いたまま戻らず、畳方と曲均の第四席は家族会（K7）の前後に空いた。いずれも「欠員」とは記録されていない。原図では空席の箱にも罫線が引かれ、名を書き込むための余白が確保されていた。註には「空席はいつか誰かが座るために空いている」とだけ記されている。この一文は、席が埋まることを約束しないまま、席を埋めようとする者を組織の内側に留め置く。空位は欠損ではなく、予定として提示された。

閉座（K9）ののち、図は一度だけ改訂された。解散（K10）を経て四局は「群」と呼び替えられ、局の名は残ったが、線は細く引き直された。教主の箱は同じ大きさのまま、上部に余白が足されている。後群典（K11）の編者はこの余白を「次の誰かのための場所」と読んだが、原図にそのような文言はない。読む者の側が空白を埋めてしまうこと、それ自体がこの図の効果であった。

---

## 編纂註

以下の三条は、図の読み方ではなく、図が何をするかについての註である。

### 一　空席の予約

空席を「欠員」ではなく「予定」として示す手口。成員は、図の空白を自分の将来の位置として読み替え、そこへ至る経路を日々の従順で測るようになる。席は埋まらないまま期待だけが更新され、不満は上ではなく隣へ向かう。壊れるのは、年限を過ぎても誰も座らず、空席の意味を外部の者が問うたときである。家族会（K7）の記録には、その問いが一度だけ残っている。

### 二　無名の頂点

教主の名を書かないことで、批判の対象を一点に固定させない手口。成員は誰を恨めばよいか分からず、責任を図の線の上に薄く広げてしまう。名がないぶん、教主は図の外にいるようにも見え、図そのものが意志を持つように感じられる。壊れるのは、頂点が不在となったときで、分岐を説く教義がそのまま組織の分裂を正当化する。解散（K10）は、分裂ではなく「分岐」として記述された。

### 三　樹形の可視化

序列を一枚の図に描き、自分の位置を相対化させる手口。成員は図を見るたびに上までの距離を数え、その距離を教団内の功績で埋めようとする。外の世界での評価は、図の外にあるものとして最初から数えられない。壊れるのは、図が更新されず、実際の権限と食い違ったときである。報道（K8）は外部の目で図を読み、線と実務のずれを指摘した。以後、図は配布されなくなった。
