# 最後の集会（議事録）

| 議題 | 決定 |
|---|---|
| 第一号　開会 | 統率者、開会を宣す。時刻は記さず。時を記せば、その時は来る。来たる時は、待たれたる時なり。ゆえに本日の次第に時刻を入れず、順のみを記す。開会の辞は唱へず。唱へたる声は、数へられぬ。 |
| 第二号　会場 | 貸会議室、三階。定員二十四。本日の出席は十一。空席は数へず。窓は一つ。窓は開けたるまま議す。議する者は、窓に背を向けて座る。窓は、風のために開けてあるのではない。聞くために開けてある。窓を閉づるは、議事の終はりなり。 |
| 第三号　出席 | 十一人。席に着く者十人、戸口に立つ者一人。席順は、来たる順による。来たる順は記さず。戸口の者は名を記さず、数にのみ入れる。欠席は、欠のみ。 |
| 第四号　欠席 | 欠席の者の意見は聞かず。聞かぬ意見は、反対にあらず。反対のなき議事は、満場一致をもって可決す。欠席の届は口頭にて足る。書面は要さず。書面は、欠席を証する。 |
| 第五号　前回議事 | 前回の議事録は、読まれざるまま承認す。読まぬことは、畳まぬことなり。畳まぬ議事録は、まだ議事なり。承認の拍手は採らず。拍手は、数へらるるゆえなり。前回の議事録の筆は、写。 |
| 第六号　報告 | 先月の集会は四度。議題、三十一。うち決定を見たるもの三、見ざるもの二十八。見ざる議題は継続とする。継続は、終はらざることなり。終はらざることは、救ひの証なり。継続の議題に、番号は附さぬ。番号のなき議題は、数へられぬ。 |
| 第七号　書式 | 一議題の記載は、三行を超えざるものとする。三行を超ゆる議題は、二つに分かつ。分かちたるものは、もはや一つにあらず。書式は仕様なり。仕様は、選ばれたるものにあらず。 |
| 第八号　順序 | 物の議を先にし、人の議を後にす。物は畳めば済む。人は畳んでも済まぬ。済まぬものを後に置くのは、済ませぬためなり。 |
| 第九号　発言 | 発言の記録は、要旨のみを採る。要旨に採られたる発言は、発言者のものにあらず。要旨は、発言の後に採る。後に採られたるものは、発言の時には、まだその者のものなり。本日、要旨を採られたる発言、二箇所。いづれも統率者のものなり。 |
| 第十号　備品（机） | 長机三つ。継ぎ目は布にて隠さず。継ぎ目を見せるは、一つに見えぬためなり。一つに見ゆるは、収束のはじまりなり。 |
| 第十一号　備品（椅子） | 折畳みの椅子、十二脚。代価は割当にて支ふ。畳めるものを選ぶ。畳めぬ椅子は、坐る者をそこに残す。残る者は、去らぬ者なり。去らぬ者は、数を増す。集会の後、椅子は畳みて棚の側に立てかく。立てかけたる椅子は、坐りたる者の形を保たぬ。 |
| 第十二号　備品（湯呑） | 十三客。十二を机に配し、一を棚の奥に置く。配られたる十二のうち、一は用ひず。用ひざる一客は、まだ来ぬ者のためなり。来ぬ者は、数に含めず。棚の一客は、来ぬ者が来たる日に用ふ。その日は記さず。 |
| 第十三号　備品（複写機） | 一台。両面の複写できるものを選ぶ。ただし、裏面を用いてはならない。裏面は、まだ書かれざる文の場所なり。文の場所を、文にて塞ぐべからず。 |
| 第十四号　備品（掛時計） | 一基。秒針を抜きたるもの。時計は、時を知るために要らず。時が過ぎたることを、同じ方向より確かめるために要る。 |
| 第十五号　備品（名札） | 四十枚。文字の入らぬもの。名は、着くる者みづから書く。書き損じたる名札は捨てず。捨つるは、名を畳むことなり。 |
| 第十六号　備品（香） | 一箱。煙の細きものを選ぶ。太き煙は急ぐ。急ぐ煙は、弔ひに適さず。 |
| 第十七号　保管 | 本日の備品は、窓の側の棚に納む。棚は、扉の閉まるもの。扉の内は、議事の外なり。棚の鍵は、統率者が持つ。鍵を持つ者は、開けぬ者なり。 |
| 第十八号　支弁 | 購入、八品。長机三、折畳みの椅子十二、湯呑十三、複写機一、掛時計一、名札四十、香一箱、棚一。代価はすべて割当にて支ふ。割当は余れり。余れる分は、来月に繰り越さず。繰り越さぬは、来月も余るゆえなり。余りは数へて記さず。 |
| 第十九号　某の去就（一） | 留む。済。 |
| 　　　　　　（二） | 留む。済。 |
| 　　　　　　（三） | 除名。済。以後、名指さず。 |
| 第二十号　閉会 | 統率者、閉会を宣す。窓を閉づ。仕舞なり。戸締りは、統率者が見る。次回は、開かれず。 |
| 録者 | 　 |

閉会ののち、統率者、言ひたまひき。「三度、留めた。よう書けておる。これは、誰が書いた。」

## 編纂註

**註一**　底本は〈断片三葉〉第七葉表。表組と罫線は底本に存し、罫線は定規を当てて引かれている。時刻の記載は全篇になく、その理由は第一号に記される。第七葉には、議題欄の一字が、二箇所にて濃墨にて塗り潰されている。塗られた字は判読できない。塗りは本文と同筆と見られ、後補の可能性は低い。他方、録者の欄は空である。こちらは抹消ではなく、初めから書かれていない。塗られた字と、書かれなかった名。二種の消え方が、同じ文書に併存している。なお、本文中に「写」の字が一度だけ、塗られずに残る。第五号の末尾である。塗る者が塗るべき箇所を誤ったとは考えにくい。誤らなかった者が一字を残した理由は、記録からは分からない。末尾の一行が表と同筆であることも、付け加えておく。すなわち、表を書いた者と、最後に一声を書き留めた者とは、同一である。塗った者と、塗られた者も、おそらく同一である。

**註二**　第七号は、一議題の記載が三行を超えることを禁じる。第十九号の三行は、この上限まで書かれている。上限まで書かれた記載は、書き足りないとは言えない。書式は、省略を選択でなくす。選択でないものは、悔いられない。また、三行のうち「留む」と記されるのは二行のみである。戒第六条の第三段は「何も言ふな」であり、何も言わないことは記録に残らない。ゆえに末尾の「三度、留めた」は、記録によって反証されない。反証されない数は、正しい数として通用する。第八号は「人は畳んでも済まぬ」と予告し、第十九号の第三行は「済」と記す。予告と結果のあいだには、何も記されていない。この議事録で最も長い空白は、行間ではなく、そこにある。第六号の報告によれば、先月の議題三十一のうち、決定を見たものは三である。決定は、この教団では敗北とされる。本日、決定を見た議題が一つある。除名である。教団が最後まで終わらせた仕事は、これ一つであった。第八号が自ら「済まぬ」と書いた区分を、第十九号の第三行は「済」の一字で閉じている。閉じた者は、閉じたことを記録していない。

**註三**　第十号から第十八号までは備品の議である。選び方には共通する傾向がある。畳めること、継ぎ目が見えること、裏面が空いていること、秒が数えられないこと。いずれも、後に残るものを減らす方向に働く。両面複写機と片面複写機の差額は、禁止の値段である。この教団の支出のうち、最も明瞭なのは、この差額であろう。何を禁じたかは記録に残るが、なぜ禁じたかは残らない。残らない理由の分だけ、禁止は強い。第十二号は、十三客の湯呑のうち十二を机に配する。出席は十一人である。配られた客の数は、出席の数と一致しない。余る一客は「まだ来ぬ者」のためとされ、来ぬ者は数に含められない。含められない者のために、器だけが数えられている。第十五号の名札は四十枚、出席は十一人である。差の二十九について、本文は何も言わない。数を明かすなという戒と、数を書かねばならぬ書式が、ここで一度だけ衝突し、書式が勝っている。勝った書式は、数を隠さない。隠さない数は、もう誰の数でもない。第十八号は八品の内訳を正確に記し、額を記さない。記録は支出の記録ではなく、数えたことの記録である。第十一号の末尾は、畳んだ椅子が坐った者の形を保たないことを記す。この一文は、備品の議のうちで唯一、人の形に触れている。

**註四**　末尾の一行は表の外にある。表は第二十号の閉会と録者の欄をもって終わる。ゆえにこの一行は、記載の順序を持たない。順序を持たない行は、議事録の一部ではない。一部でないものが、この文書の最後に残った。このとき窓はすでに閉じられている。第八品によれば、窓に向かって言わない言葉は届かない。届かない言葉は畳まれず、畳まれないものは数えられない。第一号は時刻を記さず、第九号は一日の発言を二箇所に限る。この一行は、その二箇所のいずれでもない。数えられない第三の発言である。第三のものは、この文書のどこにも記されない。第三の留も、第三の発言も、同じ場所に落ちている。問いは「誰が書いた」である。答えは表のうちに、名ではなく空欄の形で置かれている。空欄は、答えの不在ではなく、答えの様式である。声を発した者と、その声を書き留めた者とが同一でない限り、この問いには答えられない。同一である場合にも、答えられない。書いた者は、名を削られた者だからである。

**註五**　この文書は、読み返されるように作られている。三行は短く、同型で、連続している。読者は末尾の一行に導かれて三行に戻り、戻ったところで、二つの留と一つの除名と三つの済を、一つの形として見る。形が見えたとき、人はそれを美しいと言う。註はその美しさを否定しない。否定は批評ではなく、別の様式の賛辞である。註がなしうるのは、その美が何をしたかの記述だけである。三行を読み返す者は、畳まれたものを開いている。開かれるのは三行であって、三行に畳まれた者ではない。この区別は、読むという行為のうちでは、ほとんど保たれない。保たれないまま、読者は快を得る。教団が人に求めたのは、削られた者への哀れみではなく、削る手の正確さへの感嘆であった。この文書は、その感嘆を、一度も口に出さずに配っている。美しい書式は、書式であることを忘れられる。
