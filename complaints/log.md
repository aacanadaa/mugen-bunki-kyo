# 苦一　処理簿

教主直轄の「苦一」は、教団で唯一、外部の声を文字に落とす係であった。以下は切番管区に残った処理簿の再建である。日付は教暦、丸括弧内は宛先のまま留め置かれた案件を示す。

簿の形式は教主が定めた。苦情は必ず三列に収め、感情は書かず、対応のみを書く。この規則のため、読めば読むほど、書かれなかったものの輪郭が濃くなる。

| 日 | 苦情 | 対応 |
|---|---|---|
| 開闕K1・四半期 | 夜になると人が集まる物音がする | 当番が菓子を持って詫び、集会を昼へ移した。以後、苦情は「昼の苦情」として分類された。 |
| K1・末 | 子供が同じ言葉を繰り返す | 唱える回数を数え、親へ「分岐の練習」と説明した。記録は残していない。 |
| K2・初 | 排水が庭へ流れる | 信者三名を派遣し、土を運ばせた。費用は教団持ち。苦情者の名は「A家」と記す。 |
| K2・中 | 夜の太鼓がうるさい | 太鼓をやめ、代わりに「無音の礼」を定めた。音は消えたが、回数は増えた。 |
| K2・末 | 煙がこちらへ流れてくる | 焚き火の位置を変えさせた。苦情者は「風の苦情」として処理された。 |

## 編纂註

**一、再分類。** 近隣の苦情は、教団の唯一の外部評価である。にもかかわらず、この簿は苦情を内容ではなく分類名で処理する。苦情者は「A家」「協力者」「昼の苦情」といった記号に置き換えられ、自分の苦情が何と呼ばれたかを知らないまま帰される。被害の側から見れば、抗議したはずの出来事が、教団の語彙へ翻訳されて消える。壊れるのは、分類表そのものが外部に渡ったときである。粗い分類は、そのまま教団の粗さとして読まれる。

**二、非対称の記録。** 簿は教団側だけが書き、苦情者には書かせない。苦情者は、自分の訴えがどう記録されたかを確認できない。署名も控えもなく、あるのは当番の一行だけである。被害の側から見れば、言ったことが言っていないことになり、言っていないことが言ったことになる。壊れるのは、同じ苦情が二度目に来たとき、前回の記述と食い違う頁が現れる瞬間である。

**三、畳みの修辞。** 第五品「畳みは慈悲」を、謝罪・修繕・撤去の代わりに使う手口。苦情者は謝罪の代わりに教義を受け取り、損害は「畳まれた」ことになる。被害の側から見れば、壊れた物は壊れたままで、言葉だけが片づく。壊れるのは、畳んだはずの苦情が物理的に残っているときである。傾いた建物、消えない太鼓、持ち去られなかった看板が、簿の行間から顔を出す。
