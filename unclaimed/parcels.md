# 未三　荷物

K12現在、教団の内側に「未三」と呼ばれる持ち場がある。名簿には載らず、札もなく、ただ毎朝、玄関の内側に荷物が積み上がる。差出の欄には内側の名や記号が書かれ、受取の欄は空欄のままか、K10の解散で消えた配置の名が残っている。名簿が二重に閉じられたため、宛先の解決は編纂係の手作業に委ねられている。未三は荷物を開けない。返さない。捨てない。秤にかけ、伝票の写しを採り、棚の位置を決めるだけである。

以下は、K11からK12にかけて未三が預かり続けた荷物の目録である。

| 差出 | 品 |
|---|---|
| 環送・支線便 | 宛先不明の箱。封印は開かれていない |
| 旧・東配置の記録係 | 色褪せた名札三十枚。すべて同じ筆跡 |
| 分岐便（折返し） | 布の袋。振っても音がしない |
| 名を書かない教区 | 木箱。側面に開闕K1の焼印 |
| 元・唱導担当 | 録音媒体十二点。再生機器は同梱されていない |
| 無名の寄託者 | 封筒。切手も消印もない |
| 環送・本線 | 返送済みの荷。宛先は消えた部署 |
| 記号「―」 | 伝票のみ。荷物は存在しない |
| 環送・夜便 | 宛先を二度書きした封書。上書きは読めない |
| 教区の台所 | 石と乾いた葉。差出の記載なし |

棚は三列ある。上段が差出の読めるもの、中段が記号だけのもの、下段が伝票のみのもので、上段から下段へ、年に数点ずつ移る。移る理由は記録されない。重さはほとんど変わらないのに、位置だけが変わる。受取に来た者はこれまで二人だけで、一人は名を言わず、一人は自分の名を間違えて言った。どちらも荷物に触れずに帰った。

未三の仕事は、届けることではなく、届かないまま保つことである。保つには、誰のものでもないという状態を、誰のものでもないまま書き留めておく必要がある。書き留めた瞬間、荷物は記録の一部になり、記録は組織の一部になる。だから未三の台帳は、荷物の数より常に一項目多い。最後の一項目は空欄で、そこには何も書かれない。差出の名が消えた荷物は、品だけが残る。品だけになった荷物を、未三は棚の下段に置く。

開闕K1の焼印がある木箱だけは、どの段にも置かれない。台帳の余白に「保留」とだけ書かれ、保留の意味はどこにも定義されていない。

## 編纂註

一、この記録が行っているのは、宛先の解決ではなく、宛先が解決されない状態の保存である。差出と品だけを並べ、受取の欄を空けたまま固定することで、目録は「届かなかった」ではなく「届けないことにした」ことを示す。荷物は品名より先に差出の名で分類され、名を失ったものだけが品で分類される。ここで読まれるのは物ではなく、物を送ったという行為の残骸である。

二、この目録は、未三に対して開封・返送・破棄を禁じ、触れてよい範囲を秤と棚と写しに限る。読み手に対しては、荷物をなお誰かのものとして扱わせる。だが実際に負わせるのは、宛先を探さないという不作為の責任である。名を呼ばれないまま棚に残る物は、組織の内側でだけ所有者を持つ。誰も引き取らなかったという事実は、引き取らなかった誰かを必要とする。

三、受取人のいない荷物は、組織の余白である。余白は空白ではない。名簿が閉じられた後に残余として残る領域で、そこにだけ、教団は自分の大きさを測る物差しを持つ。台帳の最後の空欄は、この余白を数えるための欄である。数えられないものを数えるために欄だけが用意され、欄は埋められないまま保持される。

四、この記録が壊れるのは、差出の側が先に名を失ったときである。差出も受取も空になった荷物は、もはや通信の痕跡ではなく、単なる物として棚に残る。そのとき未三は、秤にかけることをやめ、位置だけを保つ。保たれた物は、組織が自分自身に宛てた荷物と見分けがつかない。目録はそこで記録をやめ、保管だけが続く。
