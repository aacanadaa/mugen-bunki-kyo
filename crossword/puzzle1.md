# ク一　第一問

〈本文〉

こんにちは。朝夕がめっきり涼しくなりましたが、みなさま、お変わりなくお過ごしでしょうか。朝の風に、少しだけ金木犀のにおいがまじるようになりました。今月も「サービス面」にお付き合いください。

まずは、毎号ご好評をいただいておりますクロスワードから。題して「十六マス」。字のとおり、マスは十六。多すぎず、少なすぎず、ちょうど手のひらに収まる大きさです。上の段の星占いは、今月も十二の星座がそろって「おだやかな一か月」と申しておりました。人生相談の回答も、求人の小さな枠も、三面記事の見出しも、みんなこの十六マスのまわりに並んでいます。紙面のまんなかに、ぽっかりと空いた四角。そこだけ、白いのです。

```
┌───┬───┬───┬───┐
│ 1 │   │   │   │
├───┼───┼───┼───┤
│ 5 │   │   │   │
├───┼───┼───┼───┤
│ 9 │   │   │   │
├───┼───┼───┼───┤
│13 │   │   │   │
└───┴───┴───┴───┘
```

ヨコのカギは、四つ。どれもやさしゅうございます。肩の力を抜いて、どうぞ。

一、この紙面を読んでいる、そこのあなた。そのあなたの。（四字）
二、窓の外も、窓の内も、まとめて呼ぶときの言い方。（四字）
三、昨日のつづきで、また朝が来たときの言い方。（四字）
四、始まりがあるものには、必ず訪れる。それを、やさしく言う。（四字）

タテのカギは、今月はありません。え、クロスワードなのに、とお思いでしょう。ごもっともです。編集部でも何度か話し合いました。けれども、タテは要らない、というのが結論でした。ヨコだけで、十六マスは埋まります。埋まってしまえば、それはもう、ひとつの文です。文は、読むものではなく、書くものです。ですから、えんぴつをお持ちください。濃いめのえんぴつがおすすめです。薄いと、あとで消せません。

こたえは、二十四ページ。ただし、今月は都合により、こたえの欄は白紙です。白紙もまた、こたえのひとつでございます。みなさまのマスが、正しく埋まりますよう、編集部一同、月の出をながめております。

来月は、懸賞の当選者を発表いたします。ふるってご応募ください。なお、応募用紙の住所欄も、十六マスでございます。同じ数なのは、偶然ではございません。はがきの裏は、白いままでもけっこうです。白いままのほうが、当選しやすいと申します。

求人欄には、毎号、同じ会社が同じ文句で出ております。「明るい職場です。長期の見通しをもって働けます」。長期の見通しについては、本誌では、まだ一度も説明しておりません。先月の当選者は、三面記事のいちばん下に、小さく載っております。お名前の横に、小さな丸がついております。丸の意味は、誌面では説明いたしておりません。

どうぞ、よい秋をお過ごしください。

## 編纂註

**一（この紙面が何をしているか）**　サービス面は、教義を「読み物」から「手続き」へ移し替えている。星占い・人生相談・懸賞・求人は、いずれも読者が名前を書き、住所を書き、何かを送る形式をとる。クロスワードも同じで、四つのヨコのカギを解くと「アナタノセカイハキョウモオワルヨ」という一続きの文になる。教義は説かれておらず、ただ空欄として差し出されている。読む者ではなく、書く者として遇されている点が、この紙面の要である。

**二（読者に何をするか）**　読者は、えんぴつを持ち、四つの空欄を自分の字で埋める。その行為は、教義の受容ではなく、教義の制作に近い。タテのカギがないことは、選択肢の不在を意味する。ヨコにだけ答える紙面は、別の読み方——別の分岐——を初めから数に入れていない。パズルは、教義を遊びにする。遊びの顔をした手続きは、身構えずに受け取られ、気づけば手元に一行の文が残る。

**三（どこで壊れるか）**　壊れるのは、答え合わせの場面である。二十四ページのこたえ欄は白紙で、白紙もこたえのひとつと書かれる。ここで読者は、自分の書いた文が正しいかを、外部の誰にも確かめられない。にもかかわらず、四行は文として読めてしまう。検証の不在と意味の成立が同時に起こる。この紙面のいちばん危ういのは、解くのが難しいことではなく、解いたあとに何も起きないことだ。

**四（数の反復について）**　誌面の随所に「十六」が反復される。十六マス、住所欄の十六、当選者の丸。数がそろうことは秩序の証しに見えるが、実際には紙面の都合でしかない。だが、「偶然ではございません」と書いた瞬間、偶然は意図に変わり、読者は数の意味を探しはじめる。註はこの一文を削除しない。削除すれば、紙面はただの親切な付録に戻り、終末は挨拶のあいだに置かれたまま、見えなくなるからだ。
