# 掲二　掲示・勤務

教団が消えたあと、壁に貼られたまま剥がされなかった紙が何枚かある。そのうち最も多く書き写されたのが、この勤務割である。原本はもう見つからない。残っているのは、誰かが写した二枚と、その写しをさらに写した一枚だけである。

紙の上部には「勤務割」とだけある。教団の名も、期間も、発行者もない。あるのは日と役と名の三列で、七つの行が並ぶ。行のいくつかは、欄が空いたままになっている。

| 日 | 役 | 名 |
|---|---|---|
| 初日 | 戸締 | 切番 |
| 二日 | 水配 | 流 |
| 三日 | 荷受 | 重 |
| 四日 |  | 沈 |
| 五日 | 書継 |  |
| 六日 | 煤払 | 閉 |
| 七日 | 閉座 | 均 |
|  | 見張 | 欠 |

空欄は三つ。四日の役、五日の名、最後の行の日である。

写しの一枚には、空欄の脇に鉛筆で「ここは私」とある。別の一枚には「まだ空いている」とある。同じ空白が、片方では席になり、片方では穴になっている。書いた者の手が震えていたことは、文字の傾きから分かる。

役の列に並ぶのは、いずれも職能の名であって、人の名ではない。戸締、水配、荷受、書継、煤払、閉座、見張。名の列も同じで、切番、流、重、沈、閉、均、欠。これらは十二使徒の名と重なるが、ここでは個人ではなく持ち場を指している。持ち場には人が入るのではない。人が持ち場に合わせて切り取られる。

七日で終わることになっている。八日目はない。だが七日の「閉座」が何を閉じるのかは書かれていない。閉じられるのは席であって、日ではない、と読む者もいる。書かれた日を数えているあいだは、数える手が休まない。休まない手は、自分が休んでいることに気づかない。

最後の行には日がない。見張だけが、いつ行われるのか書かれていない。書き写した者は、この行を写し漏らすことが多い。漏らしても紙は成立する。成立するが、見張のない勤務割は、誰も全体を見ていない時間を一日だけ持つことになる。

教団の文書は、この種の畳み方を好んだ。長い話を三列に畳み、人を役に畳み、日を数に畳む。畳まれたものは持ち運びやすく、配りやすく、写しやすい。写しやすい文書は、原本が消えても残る。残った文書は、教団が消えたあとも、同じ畳み方を読む者に強いる。

教団はもう存在しない。だがこの紙は、いまも空欄を三つ持っている。空欄は、埋める者への招待である。

---

## 編纂註

**一、空欄招待。** 空欄は、埋める者への招待である。記入欄をわざと空けておき、読み手に埋める行為を委ねる。埋める側は、命じられたから書くのではなく、自分で決めて書いたと感じる。被害の側から言えば、同意した記憶がないまま、自分の筆跡で名簿に加わっている。この手口は、空欄が多すぎると壊れる。三つを超えると、どれを埋めるべきか選べなくなり、ためらいが生じる。ためらいは参加を遅らせ、遅れた参加は熱を冷ます。

**二、役名の着せ替え。** 個人名を消し、職能の名だけを残す手口である。呼ばれる側は、自分であることより先に「切番」であることを引き受ける。被害の側から言えば、私的な時間が役の時間に食われ、断る言葉が「役の放棄」と同義になっていく。この手口は、同じ役が二人現れたときに壊れる。持ち場が二人分あるなら片方は要らないことになり、役の独占が崩れる。役が空欄のまま当番が回ってきたときも、同じように崩れる。

**三、連番の圧。** 初日から七日までを数えさせ、七日目に終わりの名を置く手口である。終わりがあるように見せて、八日目が来ないことを隠している。被害の側から言えば、予定が埋まっている感覚だけが残り、休みを思い描けなくなる。この手口は、日付が飛んだときに壊れる。欠番が出た瞬間、数える行為そのものが無意味になり、数えていた手が自分のものに戻る。
