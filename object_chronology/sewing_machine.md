# 物三　ミシン

〈本文〉

開闕K1、教団が最初に購入したのは聖典でも祭具でもなく、中古の足踏み式ミシン一台であった。当時の記録には「布を綴じる機」とだけ記され、誰が何を縫ったかは書かれていない。縫い目は残らないからである。しかし翌K2、集会所の隅に「縫い場」と呼ばれる一角が生まれ、参入者は自分の衣服のほころびをそこへ持ち込むようになった。教団が布を配った記録はなく、布を持ってきた記録だけがある。

K3、ミシンは二台になる。増えた一台は寄附ではなく、ある参入者が「家にあったが使わない」と言って運び込んだものだと年表は記す。この年から、縫い場の管理者が置かれる。管理人は教義を語らない。ただ糸の残量を数え、針を交換し、翌日の順番を決める。後に「無言の職」と呼ばれる役職の原型がここにある。

K4、縫い場は集会所の東側へ移され、窓際に置かれた。理由は採光のためとされるが、同時に、外から中の様子が見える位置でもあった。この年の記録には「来訪者が立ち止まる」という短い一文がある。誰も招いていない。

K5、ミシンの稼働時間が記録され始める。一日の稼働は平均して四時間を超えない。これは教団の規模に対して少なすぎるが、記録は稼働の少なさを説明しない。説明しないことが、この文書の様式である。

K6、三台目が入る。この台は他と型が違う。以後の年表では「第三機」とだけ呼ばれ、誰が使ったかは一度も書かれない。第三機の糸は、他の二台より細い。細い糸は縫い目が見えにくい。

K7、縫い場で「同じ布を二度縫わない」という慣行が生じた。教義ではなく慣行である。慣行は破られても罰されないが、破った者は次の順番を待たされる。待つあいだ、その者は他人の縫い目を見る。この年、縫い場の記録に初めて「沈黙」という語が現れる。何を指すかは書かれていない。

K8、教主が縫い場を訪れた記録が一度だけある。滞在は短く、縫い物はしなかった。代わりに糸巻きを一つ手に取り、元の位置に戻した、とだけ記される。この記述の後に、第三機の糸が交換された形跡がある。年表は交換した者を特定しない。

K9、閉座の年。教主は公の場に出なくなる。同じ年、縫い場の稼働は急に増え、記録上は一日十二時間に達する。だが縫い上がった物の数は増えていない。何を縫っていたのかという欄は、この年から空白になる。空白は記入漏れではなく、欄そのものが削られている。

K10、解散の年。縫い場は閉じられ、ミシンは三台とも台帳から外される。台帳の末尾に「譲渡」とだけあり、譲渡先は書かれていない。解体の記録も、売却の記録も、廃棄の記録もない。三台はこの年以降、どの文書にも現れない。

K11、年表の欄だけが残る。欄には「該当なし」と印刷されている。印刷は手書きより後に施されたもので、字体が違う。誰が印刷したかは記されない。

K12、現在。教団は存在しない。しかし縫い場のあった建物は現存し、内部の間取りは当時のままである。三台分の設置痕が床に残り、第三機の位置だけは他の二台より十センチ奥にある。この十センチを説明する文書は、いまのところ一編も見つかっていない。

---

## 編纂註

一、この文書は、教団の正史において周辺扱いされてきた「縫い場」の沿革を、ミシンという一個の器物の年表として再構成する。人物・教義・教団名を主語にせず、購入、増設、稼働時間、台帳からの抹消といった事務的な事実だけを並べることで、教団の中心に何があったかを語らずに示そうとする。年表の形式は、証言の曖昧さを排し、日付と数量だけで読者に判断を委ねる装置である。読者に対しては、記述の少なさを「資料の不足」ではなく「資料の性格」として読むことを求める。すなわち、書かれていない箇所こそが記述対象であるという読み方を、この文書は強制する。

二、この文書が読者に課すのは、不在の補完である。K9以降、縫い場の稼働は増えたのに縫い上がった物の数は増えず、何を縫っていたかの欄は削られている。読者はここで、削除された欄を想像で埋めるほかない。そして一度埋めてしまえば、その想像は自分のものではなく文書のもののように感じられる。これは年表という体裁が持つ固有の効果であり、語り手が意図しなくても生じる。本編纂者は、この効果を利用も抑制もしていない。註を付すことで、むしろ読者に「埋めるな」と指示している。指示に従う読者だけが、この文書を正しく読める。

三、この文書が壊れるのは、三台のミシンのうち第三機の記述においてである。第三機は誰が使ったか一度も書かれず、糸だけが細く、位置だけが十センチ奥にある。この三つの差異は互いに説明し合わない。年表は差異を並べるが、差異の関係を述べない。読者が関係を読み取ろうとした瞬間、年表は単なる物品管理表に戻り、意味は消える。壊れるのは読者の側であって、文書の側ではない。この非対称を、本編纂者は注記として残す。物の年表は、人の年表より正確である。人が忘れることを、物はしない。ただし物は、なぜそこにあったかを語らない。正確さとは、その沈黙の別名である。
