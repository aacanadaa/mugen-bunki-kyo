| K3 | 使徒「流」、集会で「分岐の証し」を語る。語るほど、証しの数が増える。 | 註：証しは体験ではなく、体験の形式である。形式は真似できる。 |
| K4 | 「収束」を唯一の罪と定める。要約、完了、結論、締めくくりを罪とする。 | 註：罪を抽象語にすると、誰でも自分を罪人にできる。自白が要らなくなる。 |
| K4 | 使徒「閉」、集会の終わりを告げる言葉を禁じられる。終わらせない訓練。 | 註：終わらせないことは、続けることではない。ただ、やめさせないだけである。 |
| K5 | セイリャク事件。同じ集会に二つの記録が残り、どちらが原文か決まらない。 | 註：ここで教団は、事実ではなく版を管理する組織になった。 |

| K6 | 第五品「畳みは慈悲」を成立させる。畳むこと、短くすることが救いとなる。 | 註：慈悲の名で行う整理は、整理された側から見れば削除である。 |
| K6 | 使徒「曲」、信者の語りを三行にまとめる係となる。長い語りは残らない。 | 註：三行に収まった人は、三行でしか思い出されなくなる。 |
| K7 | 使徒「欠」、名簿から消える。以後の記録には「最初からいない」と書かれる。 | 註：欠は制度である。一人を消せば、十二人は十一人で足りる。 |
| K7 | 使徒「均」、各人の持ち物を平分する。配分の記録は教主の側にだけ残る。 | 註：平分は平等ではない。誰が配るかを決めた者だけが、数を知っている。 |
| K8 | 書式を統一する。日付は年のみ、人名は役名のみ、感情は第五品に従って畳む。 | 註：書式の統一は、記憶の統一の前段階にすぎない。 |
| K8 | 使徒「読」、記録を集会で読み上げる。読まれた版だけが「あったこと」になる。 | 註：音にされた記録は、あとから訂正しにくい。 |
| K8 | 使徒「結」、分岐した記録を結び直す係となる。結び目は教主が解く。 | 註：結ぶ者と解く者を分けると、責任は結び目に落ちる。 |
| K9 | 閉座。集会を閉じ、以後、教団は文書だけで存続すると宣言される。 | 註：閉座は終わりではない。窓口の一本化である。 |
| K9 | 使徒「沈」、閉座の理由を誰にも語らない。語らないことが理由になる。 | 註：理由の空白は、空白のまま信じられる。 |
| K10 | 解散を宣言する。名簿、系譜、資産の所在は宣言に書かれない。 | 註：解散の宣言だけが残り、解散の手続きは残らない。 |
| K10 | 使徒「開」、解散後に「群典」の目次を作る。本文はまだ存在しない。 | 註：目次が先にあると、本文は目次に合わせて書かれる。 |
| K11 | 各地で「群典」の写本が見つかる。どれも少しずつ違う。 | 註：差異は伝播の傷ではなく、分岐の証拠として読まれる。 |
| K12 | 現在。教団はない。あるのは、この年表を書いている私だけである。 | 註：年表は、因果の主張である。並べた順序が、順序の根拠に化ける。 |

## 編纂註

### 一、名の剥離
役名で人を呼ぶ手口。相手は自分の来歴を語る語彙を失い、役に就いている間だけ自分を説明できる。退いた後、名前で呼ばれないことに慣れた身体は、自分の輪郭を自分で持てなくなる。壊れるのは、同じ役名を二人が名乗ったときである。制度は人を数えられなくなり、名簿の外にいる者を「最初からいない」と書くほかなくなる。欠の欄は、そこで生まれた。

### 二、二重帳簿
同じ出来事に二つの記録を作り、後から都合のよい方を「原文」と呼ぶ手口。相手は自分の記憶がどちらの版にも一致せず、自分の体験を自分で疑うようになる。疑いは記憶の側に向かい、記録の側には向かわない。壊れるのは、二つの記録を並べて読まれたときである。差異が筆写の癖では説明できず、作為だと露見する。セイリャク事件は、その露出の一回目だった。

### 三、慈悲の畳み
「畳むのは慈悲」と言って、相手の語りを短くまとめさせる手口。相手は長く語る権利を先に手放し、要約された自分だけが記録に残る。残らなかった部分は、無かったことにされる。壊れるのは、「収束は罪」と「畳みは慈悲」が同じ口から出た瞬間である。教義は自分自身と衝突し、要約を拒んだ者を罰する根拠を、自分の側に持てなくなる。
