# 呼二　役割名

無限分岐教の内部文書では、人を指す語は名ではなく役である。本項は、開闕K1の創立からK10の解散、K12の現在までに確認された役割名を、群典の余白と集会記録の端から拾い直した一覧である。教主は本名を持たず、信徒からも「名なし」と呼ばれる。名を持たぬ者の下で、名は配られなかった。配られたのは役だけであり、役は人より長く残った。

| 名 | 役 |
|---|---|
| 岐守 | 分岐の数を数え、増えた枝に番号を振る。 |
| 枝読み | 新しく分かれた枝の名を読み上げ、集会に告げる。 |
| 節点 | 二つの枝が分かれる場所に立ち、双方へ同じ言葉を届ける。 |
| 呼び手 | 集会の開始を告げ、遅れて来た者を呼び入れる。 |
| 器 | 教主の言葉を受ける空の容器。自らは発言しない。 |
| 縫い手 | 引き裂かれた枝の記録を一冊に綴じ、順序を整える。 |
| 名預かり | 名を捨てた者の旧名を預かり、封をして保管する。 |
| 残枝 | どの枝にも属さず、名簿の末尾にだけ記される。 |
| 引き取り手なし | 解散時に誰も引き取らなかった者。欄だけが残る。 |

役割名には、性も年齢も付かない。性は問われず、年齢は「枝齢」として分岐のたびに振り直される。十歳で入った者も、三度目の分岐を越えれば三歳になる。呼称は役名そのものであり、個人名を呼ぶ場は集会にも記録にもない。名を呼ばれないことは、この組織では礼儀であり、同時に管理の方法でもあった。役名で呼ばれている間、その人は自分の人生を自分の言葉で語る必要がない。

役は必要に応じて増える。増えた役名は教主の口からではなく、集会の雑談から生まれ、のちに群典へ追記される。追記された役名は、その時点でまだ誰も着ていないことが多い。空の役名が先にあり、そこへ合う者が後から選ばれる。選ばれた者は、自分が役に似ているのか、役が自分を削ったのかを知らない。役名は人を呼ぶためのものではなく、人を呼ばないためのものでもあった。名簿の列は役名で統一され、個人名のための列は最初から設けられていない。

K10の解散では、役名だけが組織より長く残った。役を着ていた者は消え、名簿の行だけが残る。残枝はその受け皿として末尾に置かれ、引き取り手なしは、欄を空のまま維持される。誰も引き取らなかったものは、以後の集会でも読み上げられない。読み上げないことが、そこに何もなかったことの代わりをしている。空欄は消されないが、埋められもしない。K12の現在、その空欄の数を数える者もいない。

---

## 編纂註

一、本記録がしているのは、役割名を一覧にし、名の代わりに職務を人へ貼る操作を可視化することである。役割名は、人格を職務にする。名を消すのではなく、名の場所へ役を流し込む。読み手は一覧を組織図として読むが、実物は人名の空洞を埋める型である。型は人より先にあり、人は型に合わせて削られ、余った部分はどこにも記録されない。

二、新しく入った者には、まず役名が与えられ、旧名は名預かりへ渡される。以後の呼称は役名で固定され、性は問われず、年齢は枝齢として数え直される。良い役名は本人より先に口をついて出る。本人は自分の名を聞かされぬまま役で呼ばれ続け、役を外れたときだけ、呼ばれ方のない時間が本人に返される。その時間にも、新しい役名はつかない。

三、K10の解散で、役は組織より長く残った。役名だけが残り、役を着ていた者が消える。残枝と引き取り手なしは、その残骸の受け皿である。誰も引き取らなかったものは、名簿の末尾に欄だけを残し、以後の集会でも読み上げられない。欄は空のまま維持され、空であることが役の代わりになる。空欄は消されないが、埋められもしない。

四、役割名は人格を職務にするため、職務を外すと人格が空になる。K12の現在、教主は名なしのまま、役名だけが増え続けている。増えた役名の数だけ空の型が残り、次の分岐で誰かがそこへ入る。入る者は、自分が型に似ているのか、型が自分を削ったのかを知らない。知らないまま、次の役名が集会の雑談から生まれる。そして、また空の型が増える。
