# 蔵書　貸出

蔵二が付けた表題は「貸出」。日付は開闕の年、名は当時の呼び名、書は表紙にあったまま、返の欄だけが借りた者の筆で埋められている。空欄は記入漏れではない。閉座のあと、この台帳を直した者はない。

返の印は六つ。他の行は空のままで、その空欄はK5の夏から急に増え、K9の冬を最後に増えも減りもしない。蔵二は欄を消さず、催促の言葉も書き込まなかった。台帳の末尾に鉛筆で一行、「返さない本は、読んだ本である」。筆跡は野火のもので、野火はK8の夏に三冊を借りたまま、以後この台帳に現れない。K10の春、蔵二が『台帳』を借りて返しているのが最後の記入である。台帳を借りた者が台帳を返した、というよりも、台帳を閉じた者が台帳を返した、と読むほうが自然だろう。K12の行は誰も埋めていない。欄外に薄く「以下余白」とあり、その余白のほうが本文より長い。

## 編纂註

**一、貸与の名の拘束**
手口の名は「貸与の名の拘束」。本を渡すことで、借りた者に返す義務と読了の証明を同時に負わせる。手元に一冊ある限り、その者は教団の内側に居続け、名を台帳に預け続ける。被害の側から見れば、借りた覚えのない一冊が、いつまでも自分の居場所を決める。壊れるのは、台帳が返却を検めない点である。返した者と返さない者が同じ空欄に並び、義務は果たしても消えない。果たせないと知ったとき、貸与は拘束を失う。

**二、未返却の美学**
手口の名は「未返却の美学」。返さないことを読了の証に読み替え、借りた者から返す気を奪う。註に「返さない本は、読んだ本である」とあるのはその読み替えの定式で、返そうとする者ほど「まだ読んでいない」と言われる。被害の側では、読んだかどうかの判断が本人の申告だけに縮み、沈黙が唯一の証になる。壊れるのは、その証を照合する相手が消えたときである。閉座のあと、読了を認める者が誰もいなくなり、定式はただの空欄を残した。

**三、台帳の照合**
手口の名は「台帳の照合」。名を書くことで、書かれた者に「ここに居る」という保証を与える。保証は教団の外では通用しないので、名を消せば居場所も消える。被害の側から見れば、自分の存在が一冊の紙の行に預けられ、行が閉じられると身動きが取れなくなる。壊れるのは、照合する側が先に消えたときである。K10の解散で教団は台帳を維持できなくなり、以後この帳面は、名を書かれた者どうしを照合しないただの紙になった。
