# 客六　記録

| 欄 | 記入 |
|---|---|
| 整理番号 | 到着順。同一の来訪者が二度目に来た場合も、別番号を振る。 |
| 来訪日 | 年月日。時刻が不明な場合は「昼」「夜」とだけ書く。 |
| 名 | 言うだけ言った名。名乗らない者には、こちらで仮の名を付ける。 |
| 連れ | 何人で来たか。連れの名は書かない。 |
| 呼びかけの返答 | 教えの言葉を投げかけたとき、その者がどう返したか。 |
| 滞在の長さ | 立ち寄り・半日・一夜・それ以上。 |
| 退去の理由 | 用があると言った・黙って出た・連れに呼ばれた・教えの言葉に詰まった。 |
| 残ったか | 残った・残らなかった・未定。 |
| 見送りの者の所見 | 送り出した側の者が、その人について一言。 |
| 再訪 | あった・なかった。 |
| 持ち帰ったもの | 手引きを渡したかどうか。渡した枚数のみ。 |
| 封 | 記入者と月日。 |

---

## 編纂註

**一**　この表は、客を数えるためのものではない。客の去り際を数えるためのものである。「残ったか」の欄だけが太く引かれ、他は細く引かれている。この太さの差は、後から書き足されたものではなく、はじめからその大きさで作られている。欄は、教団が何を見ていたかを示す。見ていたのは、人そのものではない。人がある方向へ傾き、また傾ききらずに戻っていく、その角度である。

**二**　この表を書く者は、客と話をする者とは別である。客は前に座り、書き手は後ろの陰にいる。書き手は声を発さず、客の肩の向きと、両手の置き場所と、退去のさいに戸の前で一度だけ振り返ったかどうかを見る。記録には、客が言ったことよりも、客が言い終えたあとの沈黙の長さが残る。読み手はそれを数字として読むが、書いた者は沈黙に長さがあるとは思っていない。ただ、長く感じた、と書いている。

**三**　この表は、解散ののちに箱ごと残された。箱のなかで、いくつかの欄は空白のままである。空白は書き漏れではない。書き手が、そこに何を書くべきかを知らなかったのでもない。書くことを禁じられていた。誰が禁じたかは、どの欄にも書かれていない。禁じた者もまた、この表の同じ欄に自分の名を書いていたからである。

**四**　この表を読む者は、まず自分の名を探す。たいていの者は、自分の名前が「仮の名」の欄にあるのを見つける。見つけた者は、自分がそのとき「連れ」の欄に書かれた一人でしかなかったことを知る。ここで表は壊れる。壊れるのは、書かれていないからではなく、書かれたとおりに読めてしまうからである。読めてしまうことのほうが、書かれていないことより重い。
