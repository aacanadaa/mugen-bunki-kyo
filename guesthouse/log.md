# 泊二　日誌

宿の帳面は、もとは市販の横罫の大学ノートであった。表紙に墨で「泊二」とだけ記され、以下の頁はすべて同じ三列で埋められている。名、日、室。この三列のほかに、この宿が人について書いたものはない。

| 名 | 日 | 室 |
|---|---|---|
| 灯一 | K十・三・四 | 二 |
| 澪二 | K十・三・七 | 二 |
| 白瀬三 | K十・四・一 | 五 |
| 十和四 | K十・四・九 | 五 |
| 棟五 | K十・五・二 | 一 |
| 環六 | K十一・一・八 | 三 |
| 綴七 | K十一・二・一 | 三 |
| 悠八 | K十一・二・十四 | 四 |
| 梶九 | K十一・三・三 | 四 |
| 名なし十 | K十一・三・二十 | 一 |
| 燈十一 | K十一・四・二 | 六 |
| （空欄） | K十一・四・五 | 六 |

「泊二」の名は、二泊目に分岐が起きることを指すと教団は説明した。一泊目は体を休め、二泊目に魂が分かれる。三泊目はない。

「名」の列は、本人が名乗ったものではない。受付で渡される仮の呼び名であり、同じ人物が二度泊まれば二度目は別の名になる。日は入宿の日だけである。退宿の日は書かれない。室は一から六まであり、六は物置に使われた。

記入は宿番の者が行った。宿番は教団の内から選ばれ、外の言葉を話すことを禁じられた者たちである。だからこの帳面には、信者の内面が一行もない。あるのは、誰がいつ、どの室に入ったか、それだけである。それでも教団がこの帳面を保管し続けたのは、そこに「泊まった」という事実だけを残すためであった。

宿は教団の外にあった。正確には、外から見えるように建てられた。通りに面した玄関、表札、郵便受け。信者の家族や、教団を疑う者が訪ねてきたとき、宿番はこの帳面を開いて見せた。ここにあなたの家族の名はありません、と。実際、名はなかった。あるのは仮の呼び名で、日は入宿の日だけで、退宿はどこにも書かれていない。家族は安心して帰った。

「六」の室には、畳まれた文を入れる木箱が置かれた。箱に鍵はなく、宿番が毎朝それを開いて中身を確かめた。確かめたことは帳面には書かれない。この帳面に、箱のことも、文のことも、一行も出てこない。出てこないことが、この帳面の正確さである。

「畳み」は三日目の夜に行われた。信者は自分の室で、それまでの人生をひとつの文に畳む。長さは問わない。問われないことのほうが多かった。畳んだ文は宿番に渡され、帳面の余白には日付と室だけが転記される。文そのものは残らない。第五品がこれを慈悲と呼ぶのは、文を書いた者だけが、それを二度読まないで済むからである。

K十一の末から、帳面の様式が変わった。入宿の日のほかに退宿の日を書く欄が増え、その欄が埋まらないまま、欄外に小さく「収束」と記されるようになった。記したのは宿番ではなく、上から降りてきた検めの者である。宿番はその日から名を書くことを許されず、かわりに番号を書いた。番号は分岐の数だけ増え、やがて帳面は、誰も泊まっていない宿の記録になった。

K十二の春、泊二は閉じられた。帳面は回収され、写しが一冊だけ外部の者の手に渡った。いま読めるのはその写しである。頁の端々に、インクの濃い場所と薄い場所がある。濃いのは、宿番が自分の手で書いた最後の数頁である。

## 編纂註

**一、開窓（かいそう）**
この制度の名。教団は宿を「外に開いた窓」と呼び、信者が外の語彙に触れる唯一の場所とした。窓は透明であることを求められ、帳面はその透明さの証拠として家族や疑いの目に提示された。人に何をするか。信者から内面を剥ぎ、外から見える事実だけを残す。事実だけの人間は、外からは無害に見え、内からは空洞になる。壊れるのは、窓が証拠として読まれ始めたときである。名がないことは安全の証明ではなく、名がないこと自体が疑いを呼ぶ。

**二、仮名受付（かりなうけつけ）**
入宿のたびに別人の名を与える手口。名は持ち物ではなく貸与物とされ、人は名を覚えられぬうちに、自分が誰であるかを教団に預ける。同じ人物が二度目に来て前の名を名乗ると、帳面の同じ室に二つの名が並ぶ。教団はそれを分岐の証拠として処理し、本人には「魂が増えた」と告げる。壊れるのは、本人がどちらの名で呼ばれても返事をしなくなったときである。名の消失は服従の完成ではなく、記録の宛先の消失である。

**三、収束欄（しゅうそくらん）**
退宿の日を書く欄。埋まらない欄が「収束」になる。これは記録の欠落ではなく、記録による完了である。人は書かれないことで終わらされる。壊れるのは、欄外の「収束」を家族が読んだときである。家族は、退宿しなかったことを死とも失踪とも読めず、ただ「完了」と読む。宿の日誌は、教団が外部に開いた窓の記録である。窓から見えたのは教団ではなく、窓枠だけであった。
