# 訳四　辞書

本表は、教団の内側で使われる語を、外の通用語に置き換えるために編まれた。教団は自らの語彙を「枝言葉」と呼び、外の語を「平らな言葉」と呼ぶ。訳語は教団が公表したものではなく、K10の解散後に離脱した者、近隣の住民、建物の管理を引き継いだ者の聞き取りから再建した。左列が内、右列が外である。右列は読みやすさを優先し、教団の作法を削っている。削った箇所は註に記した。以下の二十語は、外部との接触で最も多く用いられた順に並べた。ただし、この順序そのものが聞き取りの偏りを含んでいる。

| 語 | 訳 |
|---|---|
| 枝言葉 | 教団の内側だけで使われる語 |
| 平らな言葉 | 外部の通用語。本表の右列はこれで書かれる |
| 分岐 | 予定が二つ以上ある状態。選ばなかった側も残るとされる |
| 統率者 | 名を持たない合図の出し手。呼び名は代ごとに変わる |
| 開闕 | 集まりを始める合図。K1で最初に用いられた |
| 閉闕 | 集まりを畳む合図。K10では閉じないまま解散した |
| 枝 | 信者一人。折られても本は残ると説かれる |
| 接ぎ木 | 他の集団との期限付きの協定。K12では三件、いずれも更新されていない |
| 未回収の枝 | 関係を持たない外部の集団 |
| 第一廊下 | 入口から祭室までの通路。歩く速さで帰属が試される |
| 乾いた部屋 | 北側の窓の無い部屋。決定を保留する場所 |
| 濡れた段 | 地下へ下りる三段。K10以降は使われていない |
| 三度の間 | 相手の言葉を三度くり返してから頷く仕草 |
| 掌を伏せる | 議論を終える仕草。若い枝ほど早く覚える |
| 晴天の分岐 | 晴れの日は選択肢が増えるという説明。運用は逆 |
| 雨の報告 | 雨天のみの短い報告。天気と人数だけを扱う |
| 夜の報告 | 夢を翌朝に提出する習慣。夢は外部からの手紙と呼ばれる |
| 通訳者 | 外部との交渉を一人で担う役。内では境界の番人 |
| 苦情 | 近隣からの抗議。内では外部の痛みと訳される |
| 音の苦情 | 最も多い苦情。集会の声と夜の報告の声が原因とされる |

表は上から下へ読むものではない。第一廊下から乾いた部屋へ、そして濡れた段の手前で止まる。建物の順路に沿って並べ直すと、語の意味が変わる箇所が三つある。接ぎ木、晴天の分岐、そして苦情である。K10の解散時、この表の元版は祭室で焼かれた。焼いたのは統率者ではなく、当時の通訳者だったと、複数の聞き取りが一致して述べる。K12の現在、表は再建されたが、再建を主導した者の中に当時の通訳者は含まれていない。近隣からの苦情が最も増えたのは、表の再建と同じ時期である。苦情の内容は音が中心で、集会の声と、夜の報告の声が挙げられている。表の右列には、その音を指す語が一つも無い。

## 編纂註

**条一**　本表は、教団の内部語を外部の通用語へ一対一で置き換える。読み手は、離脱した者、近隣の記録者、教団を調べに来た外部の者である。表を受け取った者は、理解したつもりだけを先に受け取る。壊れるのは、対応する語が存在しない箇所だ。「分岐」「閉闕」のような語は、訳した瞬間に作法が消え、平凡な予定表や片づけの合図に化ける。対訳表は、教団の最も危険な出力である。読む者に翻訳できたという錯覚を渡し、翻訳できなかった部分を黙って切り落とすからだ。凡庸な語彙ほど、外からは無害に見える。

**条二**　この文書は、苦情の宛先を一人に集める。集める先は通訳者であり、近隣の苦情も、外部の集団との接ぎ木の更新も、すべてこの役を通る。通訳者は内で境界の番人と呼ばれ、外からは交渉の相手とみなされる。壊れるのは、通訳者が不在になった日である。苦情は宛先を失い、内側では外部の痛みとして処理され、返答の義務だけが宙に残る。右列が丁寧であるほど、この一点集中は見えにくくなる。丁寧さは、制度の粗さを隠す。

**条三**　本表は、天気と夢という検証できない領域に語を与える。晴天の分岐は観測を伴わず、晴れの日ほど集まりが短いという運用と食い違ったまま定着した。夜の報告は夢を外部からの手紙と呼び、翌朝の提出を習慣にする。訳された語は、事実ではなく手続きを指している。壊れるのは、外部の者が天気の語を気象の話として受け取り、夢の語を心の話として受け取ったときだ。どちらも手続きの名残で、内容は空である。

**条四**　本表は、一度失われた語彙を寄せ集めて順番を与えた再建物である。K10で元の綴りは焼かれ、K12の現在、離脱者と近隣の記憶から再建された。これは教団ではなく、教団を記録する側に渡される。記録者は表を台帳として扱い、空欄を秘密と読み、埋まった欄を性質と読む。壊れるのは、その継ぎ目だ。記憶の食い違いは教義の揺れと解釈され、表そのものが証拠の代わりに置かれる。註は、その置き換えを止めるために付いている。
