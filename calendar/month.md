# 暦二　月

無限分岐教の暦は、太陽にも月の満ち欠けにも依らない。一年は十二の「岐」に分かれ、それぞれに名が与えられている。教団の内部では「月」という語は早い時期に使われなくなり、日常ではもっぱら「岐」と呼ぶ。外部向けの文書だけが「月」と書き換える。以下の表は、その書き換えが行われる前の名を、外部の読者のために並べたものである。

| 月 | 名 |
|---|---|
| 第一 | 初岐 |
| 第二 | 芽岐 |
| 第三 | 葉岐 |
| 第四 | 雨岐 |
| 第五 | 重岐 |
| 第六 | 交岐 |
| 第七 | 戻岐 |
| 第八 | 影岐 |
| 第九 | 実岐 |
| 第十 | 刈岐 |
| 第十一 | 閉岐 |
| 第十二 | 灰岐 |

十二の名は、いずれも「岐」で終わる。接頭の一字は、教団が自らの歩みを四つの系列に分けたときの呼び名である。生の系列は芽・葉・実、喪の系列は雨・影・灰、関係の系列は重・交・戻、裁きの系列は初・刈・閉。各系列は三つで一組になり、内では「四つの三」と唱える。数に意味はないと教団は言う。だが、意味がないと言いながら四つと三を唱え続けるところに、この暦の癖が出ている。

表の順は外部のための便宜である。内では、初岐の次に灰岐が来る年も、閉岐から芽岐へ戻る年もあり、順序はその年の「分岐の数」で決まる。第二世代は、自分が生まれた岐を季節として覚えない。「芽岐に生まれた」とは、暖かくなった頃という意味ではなく、教団がその年、最初の分かれ目を数え終えたという意味である。彼らにとって暦は記憶の索引ではなく、記憶の文法そのものである。名を覚えることは、年の形を覚えることと同じだった。

教主は本名を持たない。名を持たぬ者が、時間の十二の部分に名を与えた。この非対称は教団では説明されない。説明されないまま、名のない中心と名のある周辺という形が、第二世代の世界の形になった。

K10の解散の年、教団はひとつの岐を消した。消された名は「無岐」で、内外どちらの表にも現れない。ただし解散後に残った者たちの口伝には残っており、彼らは「無岐のことにしている」と言う。外の年表では、その前後の日付が二度現れる。内の年表では、二度現れる日付のあいだに、名のない空白がひとつ置かれる。

のちに「月」の一字は禁じられた語の一覧に入り、公文書では「岐」と書く決まりになった。この文書の表題が「月」であることは、編纂の時点で既に違反である。違反を消さずに残したのは、消してしまえば、何が禁じられていたのかが分からなくなるからである。

## 編纂註

**註一**　この表がしているのは、十二の名を並べることで、暦を情報から言語へと組み替えることである。月の名は、教団が最も早く作った言葉である。教義よりも先に、祈りよりも先に、名づけがあった。この表は、生まれた時からこの十二語しか持たない第二世代に、季節を分岐の段階として数えさせる。壊れるのは外部の日付との接続点で、換算表はK10の前後で二度改訂され、同じ日が二つの岐に属する年がある。

**註二**　この表は、欠番を欠番のまま保存している。無岐は十二のどこにも置かれず、註と口伝にだけ残る。これによって、解散後も残った者は、自分が生きていた時間を自分で名づけられない。名づける権利は、名を持たない中心にだけ残されたからである。壊れるのは口伝と文書のあいだで、無岐の位置は語り手によって毎年動く。さらに、この註が「無岐」と書いた時点で、消された名はもう一度呼び出されている。

**註三**　この文書は、禁じられた語を表題に置き、本文では別の語に置き換えている。読者である後代の編纂者と外部の研究者に、禁とは語そのものではなく、語が指していた対象の側にあると気づかせようとしている。壊れるのは、読者が「月」を単なる言い換えと受け取った場合である。そのとき十二の名は、風変わりな月份名の一覧に戻り、この表が行っていた組み替えは見えなくなる。

**註四**　この表は、名を持たない中心が周囲のすべてに名を与えたという形を、証拠としてではなく配置として示している。読者に何をするかといえば、無名を神秘として読ませる。空欄は信仰の余白として補われる。壊れるのは、無名の中心を指す指示語が循環するところで、註が註を指し、表が表を根拠にする。この循環は誤りではなく、この教団が最後まで手放さなかった構造である。
