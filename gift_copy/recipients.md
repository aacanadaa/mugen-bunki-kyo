# 献一　贈り先

〈本文〉

『群典』の初版は、K8の四の月、十七日に、教団の外へ出た。贈り先を決めたのは教主ではなく、灯室の記録係である。教主はただ一度、「要約される本は贈るな」と言い、あとは沈黙した。この一言が、以後の事務をすべて決めた。贈り先は、読み終えることのない者、読み終えたことを報告しない者、報告を別の誰かに預ける者から選ばれた。

受付の机には、贈り先名簿が一冊置かれている。名簿には、名、日、反応の三欄だけがある。反応の欄は、本が届く前に書かれる。これは手続きの誤りではなく、教団の作法である。届いた本がどんな反応を引き出すかを先に書くことで、教団は相手の分岐を一つ、あらかじめ数える。数えられた分岐は、まだ起きていない。

包みは二重になり、外側の紐は内側の結び目を隠す。開封の跡は頁の縁に残るように裁たれている。これは贈り物ではなく、開封の記録を取るための細工である。受取人が封を切る時刻は、名簿の日付と一対で扱われる。封を切らない者は、名簿の上では、まだ何も受け取っていない。

| 名 | 日 | 反応 |
|---|---|---|
| 湖畔の写本屋の主 | K8・四の月・十七日 | 「頁の順が違う」とだけ返した |
| 無名の蒐集家 | K8・四の月・十七日 | 受け取らず、封を切った跡だけを残した |
| 私設記録館の番人 | K8・四の月・十七日 | 目次を写し、本文は写さなかった |
| 宿の主人 | K8・四の月・十八日 | 客間に置き、誰も読まぬまま一年置いた |
| 印刷所の親方 | K8・四の月・十八日 | 紙の目方を測り、それだけを報告した |
| 元信者の娘 | K8・四の月・二十日 | 返礼に白紙の葉書を送った |
| 浜の舟大工 | K8・四の月・二十一日 | 一頁を切り取り、舟の名に貼った |
| 稽古場の師範 | K8・四の月・二十三日 | 読み上げず、弟子に預けた |
| 巡回の記録者 | K8・四の月・二十五日 | 反応の欄を空のまま返した |
| 灯台の番人 | K8・四の月・二十九日 | 「ここには届かない」と書き添えた |

名簿の余白には、宛先不明で戻った本の数が、鉛筆で足されている。戻った本は再送されない。再送は収束の側にあるからである。代わりに、戻った本の頁の間に、受取人とは別の名が挟まれ、そのまま次の贈り先へ渡る。名簿の日付は、この往復のたびに一日ずつ遅れる。遅れは記録係が「呼吸」と呼ぶもので、名簿そのものが生きている証拠とされる。

十七日、名簿には三件の辞退が記された。辞退の理由は書かれない。代わりに、辞退した者の欄には小さな丸が打たれ、その丸は次の贈り先の欄へ写される。丸は贈り物ではなく、関係の印である。丸のついた名は、以後、名簿の末尾へ移される。末尾は、まだ誰も読み上げていない場所である。

十七日の夕、記録係は名簿を閉じ、閉じたまま一頁を読み上げた。読み上げられたのは反応の欄だけで、名は読まれなかった。名を読めば、贈り先が一人に収束するからである。読み上げのあと、記録係は自分の名を欄の外に書き、そこだけを消した。消した跡は残り、消した文字は残らない。

K9の閉座の日、名簿は机ごと板で打ち付けられた。K10の解散ののちも、その板は開かれていない。本稿は、打ち付けの前に取られた写しと、記録係が別に残した一通の葉書による。葉書には、贈り先の名が一つも書かれていなかった。

---

## 編纂註

一、この記録は、外へ出た本と、その戻り方を一冊に並べている。名、日、反応の三欄は、読書の記録ではなく、教団が外部と交わした接触の回数表である。本を贈ることは、相手に読ませることではなく、相手が読み終えないことを確かめることに近い。反応の欄が到着前に埋められるのは、そのためである。欄は相手の内面ではなく、教団の側の予定を写している。

二、名簿が扱う相手は、教団の外にいる者だけではない。記録係自身、戻った本を次の宛先へ渡す者、読み上げを聞く者が、同じ三欄に載る。教団は贈り先を「読者」ではなく「分岐の保管者」として扱い、保管の仕方だけを記録する。相手が何を考えたかは欄の外に置かれ、欄には、その人が本をどう持ち運んだかだけが残る。

三、献本は、教団の外交である。本は挨拶であり、名簿は国書に近い。誰に贈り、誰に贈らないかを決めることで、教団は外部との距離を測り、その距離を教義の側へ持ち帰る。受け取った側の反応は、外交の返書として読まれる。白紙でも、遅れて届いても、それは関係の不在ではなく、関係の形として数えられる。

四、この記録が壊れるのは、反応の欄が先に埋まる一点である。書かれた反応は相手のものではなく、教団が相手に期待した分岐である。日付は往復のたびに遅れ、戻った本は再送されず、名は読み上げられない。記録が精密になるほど、贈り先は実在の人物から欄へ移っていく。名簿は外部を写しているのではなく、外部を欄の形に作り替えている。
