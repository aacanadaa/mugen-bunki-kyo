# 外一　索引外

| 語 | 理由 |
|---|---|
| 教主の本名 | 記載のある頁が三種あり、いずれも他の二種を偽とする。索引は一つを選ぶ装置であり、選ばない方が正確である。 |
| 開闕K1 | ある本文では「創立」、別の資料では「発見」。両方を引けば、索引が教義の言い換えになる。 |
| K10 | 解散の年。項目にすれば解散が出来事として固定され、以後の記述がすべてその注釈になる。 |
| 消失 | 頻出しすぎて、引く者がいない。引かれない語を立てれば、索引は本文の写しになる。 |
| 畳み | 第五品の中心語。畳む・畳まれ・畳み直すと活用し、見出しを一つに定めると他の形が外れる。 |
| 慈悲 | 既に三項目の説明文に現れ、独立させると循環参照になる。 |
| 要約 | 唯一の罪の名。罪を一項目に収めることが、罪の遂行になる。 |
| 完了 | 要約と分けるか否かで編纂が二度止まった。決まらないまま外した。 |
| 分岐 | 教義の中心。中心を立てれば、他の全項目がその説明になる。 |
| 収束 | 禁語。禁を索引に立てることは、禁を取り扱い可能にすることである。 |
| 読者 | 本文に二度だけ現れ、いずれも「読者はまだ」で始まる。誰を指すか決まらないまま載せれば、載せた者が読者になる。 |
| 無名 | 教主の呼称。呼称を立てれば、本名の項目がその下に従属する。 |
| 序 | 序は本文の前に、索引は本文の後ろにある。位置の違うものを同じ列に並べれば、序が本文の一部になる。 |
| 奥付 | 日付が三種あり、いずれも他を「便宜の日付」と呼ぶ。索引の日付欄が埋まらない。 |
| 誤植 | 九箇所。訂正せず残す方針が採られ、誤植は本文の一部とされた。索引に立てば、誤りが検索可能になる。 |
| 余白 | 頁の半分以上。項目にすれば、余白のない頁が例外になる。 |
| 破棄 | 破棄された版の総称。索引に載せれば、破棄が保存になる。 |
| 索引 | 索引それ自体。自己言及になるため外した。この理由だけは註に書く。 |
| 外 | 同上。 |

（配列は初出の遅い順。同順のものは、理由の短い順。）

## 編纂註

**一**　本表は「外一」、内輪には「捨て帳」と呼ばれる。群典の索引に加えなかった語を、加えなかった理由とともに列挙する。本文から語を抜き、資料から理由を拾い、一列に接ぐ。抜かれた語のぶんだけ本文が痩せる。壊れるのは、理由の欄が語より長くなったときである。その瞬間、表は索引ではなく註釈になり、註釈は本文を追い越す。

**二**　この作業は「控え取り」とも呼ばれる。索引の編纂で生じた残余を、捨てずに別の帳面へ移す。残余は索引の裏面として扱われ、本文の外に置かれる。壊れるのは、残余が本文より多くなったときである。どちらが本文か決まらなくなり、決まらないまま表を閉じる。その閉じ方が、この作業の終わり方である。

**三**　「外一」は「余りの目録」と呼ばれる。索引の外に置かれた語を、外した理由とともに並べ、索引が何を選ばなかったかを、選ばれたものと同じ精度で残す。本文からは語を、資料からは理由を取る。壊れるのは、読者が外した理由から先に読み、外した語を後で引いたときである。順序が入れ替わり、索引は目録に従属する。索引の外が、索引の意味である。
