# 別一　最後の註

〈本文〉

再建本文の末尾は、いつも同じ一行で終わる。ここで畳む、とだけある。署名はない。K1の記録には、世界は一つの依頼である、と書かれている。依頼は届くが、受け取られない。受け取るとは要約することであり、要約は収束であり、収束は唯一の罪である。だから教団は答えを出さず、分岐だけを増やした。

K10の解散も、教団の言葉では終了ではない。書類の上で、解散は一つの分岐にすぎない。K12の現在、教団は存在しない。残っているのは文書だけである。文書は読まれ、写され、運ばれ、ときどき捨てられる。捨てられることも分岐の一種であり、拾われればまた増える。読まれるたびに、本文は少しずつ別の本文になる。

第五品は畳みを説く。畳みは慈悲である。畳むとは、複数の版を一つの面に重ねることである。重ねた面は、どこかで必ずずれる。ずれを残したまま重ねるのが慈悲であり、ずれを消して一枚にすることが収束である。前者は読む者を増やし、後者は読む者を減らす。教団が解散後も文書で生き延びたのは、この区別のためである。

編者はこの再建に、最後の註を一つだけ付す。最後の註は、本文への復帰である。説明でも、総括でも、謝辞でもない。註は本文の外に置かれるが、この再建に外はない。外を設ければ、そこが終点になる。だから註は本文の途中へ戻る。どの途中かは指定しない。指定は、終点の予約である。

註は頁の外側の余白に置かれる。余白は本文の一部ではないが、本文を支えている。支えているという言い方も、編者は好まない。支えは感謝を呼び、感謝は謝辞になり、謝辞は本文を閉じる。閉じた本文は読まれない。読まれない本文は、失われたのではなく、畳まれたのでもない。ただ収束した。

再建は完成しない。完成した再建は収束した再建であり、教団が唯一の罪と呼んだものである。編者はそれを知っている。知った上で註を書く。註が短いのは、短さが畳みに近いからである。長い註は本文を置き換え、置き換わった本文は読まれない。

謝辞は置かない。最後の頁には、こうある。ここで畳む。以上。

## 編纂註

**一、名称。** 本作業を〈畳み〉と呼ぶ。第五品が畳みを慈悲と呼んだため、編纂の現場でもその語を使い続けた。ただし教団の畳みは魂の重なりを指し、本作業の畳みは紙の重なりを指す。同じ語で別のことをしているという自覚を、註は保つ。名称を変えないのは、変えることが分岐を一つ減らすからである。

**二、対象。** 本作業は、K1からK10までの断片と、K12に流布した写しを一つの面に重ね、異読を選ばずに併記する。削除はしない。順序だけを決める。順序を決めることは、資料に終点を与えることに近い。近いが同じではない、と編者は書く。この一行が註の要である。

**三、破綻。** 壊れるのは、註が本文を追い越したときである。註が本文より長くなれば、註は本文になり、本文は註の資料になる。次に、K10の解散記録とK12の写しの間で欠落した頁を補った箇所。補った文は、誰も書いていない。最後に、末尾の一行。ここで畳む、の後に何も置かないという判断が、唯一の収束になる。
