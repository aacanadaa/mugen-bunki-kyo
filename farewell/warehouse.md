# 別六　在庫

K12の春、雨の日に一度だけ棚卸しが行われた。記録者は名を残していない。数量の欄だけが埋まり、日付の欄は空である。品名は当時の呼称のまま置いた。以下はその写しである。

| 品 | 数 |
|---|---|
| 再建本文（第一版・厚表紙） | 四 |
| 再建本文（第一版・並装） | 十一 |
| 再建本文（第二版・訂正紙付き） | 二 |
| 分岐目録（K9まで） | 一 |
| 畳みの註記（単葉） | 三十七 |
| 収束禁止の栞 | 六十二 |
| 空の帙 | 九 |
| 名簿（第五品・欠頁あり） | 一 |
| 名簿（白紙） | 十四 |
| 貸出票（未返却） | 三 |
| 木箱（内容不明・封印） | 一 |
| 目録の目録 | 〇 |

合計は書かれていない。書かないのが作法だと、欄外に小さくある。だが四と十一と二を足せば十七である。そのうち何部が読まれたかは、どこにもない。貸出票の三は、返らないまま数に入っている。数に入っているとは、まだ在るという意味ではなく、まだ引かれていないという意味である。

第二版の訂正紙には「本文は依頼である。依頼は遂行されない限り依頼でない」とある。その下に別の筆で「では遂行とは何か」とある。答えはない。答えの頁は、どの版にも入っていない。訂正紙は本文の誤りを直すための紙だが、この紙が直しているのは本文ではなく、本文を読む者の位置である。読者はここで、自分が依頼を遂行する側なのか、遂行されない側なのかを決められなくなる。決められないまま頁を送る。それが畳みと呼ばれた。

K10の解散のとき、教団は倉庫を返した。返したのは建物であって、在庫ではない。在庫は誰のものでもなくなった。誰のものでもないものは、捨てるにも届け出がいる。届け出の宛先は、もう存在しない。だから在庫は残った。残ったのは意志ではなく、手続の空転である。

空の帙が九つある。帙は本文を入れるためのもので、空でも帙である。白紙の名簿が十四ある。これは省略ではなく、もともと空である。名を書く欄だけが印刷され、書く者が来なかった。木箱は一つ、封印されたままである。中身は目録にない。目録にないものを数に入れると、数が合わなくなる。合わないまま、この一行だけが残った。

棚卸しの記録は二部作られた。一部はどこかへ渡り、一部はここにある。この写しが何代目の写しかは書かれていない。書かれていない、という一事だけが、この文書の唯一の訂正である。

## 編纂註

**一　名称**

この作業は「棚卸し」と呼ばれる。だが台帳の表題には「残置目録」とあり、内部では「数え直し」とも言った。三つの名は同じ作業を指しながら、指す範囲が違う。棚卸しは物を数え、残置は場所を数え、数え直しは数える行為そのものを数える。本稿がどの名を採るかは、日付の欄が空であることと無関係ではない。名を選ぶことが、すでに一度の数え直しになっている。

**二　本文への作用**

棚卸しは本文を読まない。読まずに部数を確定させる。それによって本文は、内容を持つ書物から、残った数量を持つ在庫へと変わる。この変換は資料の側にも及ぶ。訂正紙は本文の誤りを直す紙ではなく、在庫の内訳を説明する紙として扱われる。註記も栞も、読まれるためではなく、引かれるために数えられる。数えるという行為が、資料の意味を後から決めている。

**三　壊れる場所**

壊れるのは合計の欄である。合計を書けば在庫は閉じるが、書かなければ在庫は開いたまま残る。木箱、白紙の名簿、空欄の日付が、その開いた箇所にあたる。ここで、在庫は、読まれなかった分の記録であることが露わになる。数えられているのは本ではなく、読まれなかった時間のほうである。註はここで、記録と遺棄の区別を失う。区別を失ったまま、この一葉は保存された。
