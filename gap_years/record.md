# 空二　記録

本記録は教主の事跡ではなく、記録の存在しない範囲を記すために編まれた。以下の欄は内容の正しさを保証しない。空欄は欠落ではなく、そのまま空欄である。

| 年 | 記録 |
|---|---|
| K1 | 創立。教主は本名を名乗らず、「名は分岐のたびに減る」とだけ述べた。名簿は作られず、当日の人数も記されていない。 |
| K2 | 第一品から第三品までが口述され、聴き手が筆記した。筆記者の名は欄外に小さく残るが、判読できない。 |
| K3 | 第四品。畳みの作法は図も文字も残さず、手の動きだけで伝えられた。この年、記録係は置かれていない。 |
| K4 | 記録なし。のちに「もっとも充実した年」と語る者がいるが、その証言は K9 以降に現れる。 |
| K5 | 記録なし。会場の借用証だけが残り、日付は K4 とも K6 とも読める。 |
| K6 | 集会の日付のみ。出席者欄は線で消され、消した者が誰かは書かれていない。 |
| K7 | 記録なし。教主の声がかすれ始めたとされるが、確認した者はいない。 |
| K8 | 第五品「畳みは慈悲」が口述される。声は途切れがちで、二度目はなかった。書き留めたのは三人、うち二人は名を残さず、一人は署名を拒んだ。 |
| K9 | 閉座。教主は公の場に出ない。理由は記されず、ただ「畳んだ」と一行。この行の筆跡は K2 の筆記者と似ている。 |
| K10 | 解散の通告。署名も印もない。通告を受け取った者は、受け取っていないと後に述べた。 |
| K11 | 記録なし。この年の空白について、教の内外から多くの説明が試みられた。 |
| K12 | 曾孫が名のみを継ぐ。本人は教主に会っておらず、声も聞いていない。継いだのは名前と、名を名乗らない作法だけ。 |

---

## 編纂註

**一（名）**　この不在は教内で「空座」と呼ばれる。席はあるが、そこに座る者は記録されない。K9 の閉座以降、空座は比喩ではなく運用になった。誰も座らない席を保つことで、かつて座っていた者の像を固定しない。名を持たない教主の最後の仕事は、名を残さないことだったとも言われるが、これを裏づける記録はない。

**二（作用）**　空座は人に二つのことをする。ひとつは、空白を自分の記憶で埋めさせる。埋めた記憶は互いに食い違い、食い違いは「分岐」として歓迎される。もうひとつは、証言する者に「自分だけが覚えている」という感覚を与える。この感覚は教の外へ出ても消えない。記録のない年が、最も多く語られるのはこのためである。

**三（破れ）**　壊れるのは、空白が継承されたときである。K12 の曾孫は名だけを受け取り、声も顔も受け取っていない。受け取るものが名だけになると、空白は人格を持つ。人格を持った空白は、埋める者を必要とし、埋めた者を選別する。ここで空座は慈悲ではなく、採点になる。

**四（編者）**　本記録の編者は、空欄を埋めないことを唯一の規矩とした。ただしこの規矩もまた記録であり、K11 の空白を説明しようとした数々の試みと同じ場所に置かれる。読む者は行の間ではなく、行の消えたところを見るべきである。そこには何もない。何もないことが、この文書の内容である。
