# 附三　年表

本表は、開闕より現在に至る十二年を、年を単位として並べたものである。年次の呼称は内部資料の慣例に従い、開闕をK1とする。月日の記載は、資料に現れた順序を示すにとどまり、出来事の前後を保証しない。空欄は、該当する記載が見つからなかった箇所である。

|---|---|
| K1 | 開闕。教主、本名を名乗らず「無名の座」に就く。就任の記録は二行。 |
| K1 | 最初の分岐簿、一冊。記載は四件。以後、簿は分岐のたびに増える。 |
| K2 | 分岐簿、各地で並行に記される。互いの照合は行われない。 |
| K2 | 「正本」の語、初出。指し示す対象は記されていない。 |
| K3 | 「閉座」の語、初出。教義上の位置づけは未定のまま据え置かれる。 |
| K3 | 各地の集まり、名を付けずに開かれる。記録は参加者の記憶にのみ残る。 |
| K4 | 教主の肉声を記したと称する帳面、三種現れる。三種は互いに一致しない。 |
| K4 | 集会の回数、数え方により三倍から十分の一まで動く。 |

## 編纂註

**一**　本表がしているのは、十二年を一列に並べ、その上に「開闕」「閉座」「解散」という三つの区切りを打つことである。並べるという操作は、出来事の間に前後関係を与える。だがその前後関係は、資料の日付から導かれたものではない。日付の多くは、書かれた順に過ぎない。読者は配列の順序を出来事の順序として受け取り、受け取ったことに気づかない。

**二**　本表は、十二の文書を読もうとする者に、先回りして「読める」という感覚を渡す。混乱は順序に置き換えられ、理解したという錯覚が本文の前に立つ。年表は、因果の主張である。ここで言う因果とは、K9の沈黙がK10の解散を招いたという筋書きを指す。その筋書きを支える証拠は、本表の外にはない。本表は証拠ではなく、証拠の配置である。

**三**　破綻はK10の欄にある。解散の告知と教義の継続が同じ年に並ぶとき、年表は「終わった」とも「続いている」とも書けない。欄は空くか、二つの文が同じ枠に押し込まれる。読者はそこで、年表が出来事ではなく、出来事についての言い分を並べていることに気づく。気づいたとき、表はまだ読める。読めていることが、すでに破綻である。

**四**　月日の記載は、資料に現れた順序を示すにとどまる。K10の月欄は、十二の文書の成立順と一致しない。一致させようとすれば、どれかの文書の日付を動かすほかない。本表は動かさなかった。動かさなかったという一事だけが、本表の誠実さの全部である。誠実さは正確さではなく、動かさなかった箇所を隠さないことである。
