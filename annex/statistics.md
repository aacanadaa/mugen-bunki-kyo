# 附一　統計

『群典』は、無限分岐教が自らの正統性を数えるために編んだ内部文書である。本附はそのうち数字だけを抜き出し、年ごとに並べた。教義も証言も祈祷も含まない。それゆえ本附は、同教の自己像が最も無防備に露出する場所でもある。

「数」は、各年に新たに台帳へ登録された「分岐」の件数である（『群典』附録台帳、K12現在）。

| 年 | 数 |
|---|---|
| K1（開闕） | 1 |
| K2 | 3 |
| K3 | 9 |
| K4 | 27 |
| K5 | 61 |
| K6 | 108 |
| K7 | 144 |
| K8 | 151 |
| K9（閉座） | 12 |
| K10（解散） | — |
| K11 | （記載なし） |
| K12（現在） | 4 |

分岐とは、教義上の新解釈ではない。教主の言葉が二通りに取れるたび、その両方を正しいものとして登録する手続きを指す。審査はなく、書記一名の署名で足りた。登録を却下する規則もなかった。このため教団は、分裂を知らないまま増殖した。増えたのは信者ではなく、正しい読み方である。

教主は本名を持たない。台帳の署名欄は、統率者の項だけが常に空である。空欄のまま登録は有効とされた。これは不備ではなく設計であった。名がなければ、名を呼ぶ者も、名を継ぐ者も生まれない。統率者は人物ではなく、空欄の位置として制度に埋め込まれた。

K1からK8まで、件数はほぼ毎年倍に近い。ただしこれは人数ではない。登録一件は一人の帰依を意味せず、同じ人物が年に何度も届け出ることができた。届け出は熱心さの指標として扱われ、多い者から順に席が与えられた。この表が数えているのは、教団の規模ではなく、教団が自分について語った回数である。

K9、教主は公の場に立たなくなる。この年、新規登録は一二件に落ちる。前年の一五一から、である。理由は台帳に書かれていない。欄外に「以後、口述を廃す」とだけある。口述が廃されれば分岐は生まれない。分岐は、語られた言葉の両義性を材料にするからである。数字の急落は、信仰の減衰ではなく、材料の断絶を示している。

K10、教団は解散する。台帳はこの年、閉じられる。閉じた年には数字がない。空欄はゼロではない。ゼロは「数えたが、無かった」であり、空欄は「数える者が、いなかった」である。本表はこの区別を保っている。K11の行が短いのは、信仰が薄かったからではない。記録する主体が存在しなかったからである。

K12、台帳は再開されている。四件。筆跡は前と同じとされ、同定はされていない。再開を決めた会議の記録はない。あるのは四件の登録と、元の書式だけである。数は、組織が死んだあとも、書式さえ残れば動き続ける。この四件が何を意味するかは、本附の範囲では決められない。

## 編纂註

**註一**　本附がしているのは、教団の自己記述から数字だけを抜き、解釈を外して並べることである。読むのは、『群典』を外側から検証しようとする者、および教団の語彙に慣れていない者である。ここで壊れるのは、台帳そのものが欠けている場合で、K11のように行ごと失われた年は、欠落を「空白の年」として物語化した瞬間に統計が文学へ変わる。統計は、本文の最も乾いた註釈である。

**註二**　本附は、読み手に「増加」という物語を渡す。倍々に近い並びは説得力を持つが、数えられているのは登録件数であって人数ではなく、届け出は同じ人物によって何度でも行えた。したがって本表を規模の推移として読むと、K2からK8までの傾きは意味を失う。ここが壊れる。註釈は数字の意味を限定するために置かれているのであって、数字を補強するために置かれているのではない。

**註三**　K9の急落は、本表で最も誤読されやすい箇所である。数字は相関だけを残し、因果を空欄に置き換える。閉座の理由を台帳は書かない。その空欄に、教団側は「妨害」を、外部は「破綻」を書き込みうる。どちらも台帳には存在しない。本附は原因を推定しない。推定は註釈の仕事ではなく、註釈が自制すべき領域である。

**註四**　本附は内部台帳に依拠し、外部資料との照合を経ていない。K12の四件は現在も増えうる。ゆえに本表は完成した統計ではなく、ある時点で切り取られた標本である。標本は、切り取った者の手つきを隠さない。誰が、いつ、何のために切ったか。本附の末尾がこの問いを残すのは、統計が反論を許さない形式だからである。
