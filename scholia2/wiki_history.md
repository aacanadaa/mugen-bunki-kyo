# 註六　編集履歴

『群典』の項目「無限分岐教」は、いまどの版にも存在しない。存在しない項目のために、これだけ長い履歴が残っている。以下はその写しである。日付は教団の年号ではなく、後から振られた通し番号に近く、時刻は欠けている。

| 日 | 者 | 変更 |
|---|---|---|
| K10.03.02 | 匿名一号 | 項目を新規作成。沿革、教主の呼称、第五品の一句のみ。 |
| K10.03.09 | 白紙 | 沿革を三分の一に短縮。摘要に「要約は完成に近い」と付す。 |
| K10.03.11 | 匿名一号 | 短縮を差し戻し。摘要の一句を削除。 |
| K10.03.17 | 継ぎ足し | 「本名なし」を「本名不詳」に。理由欄は空。 |
| K10.04.01 | 白紙 | 再び短縮。 |
| K10.04.02 | 匿名一号 | 差し戻し。 |
| K10.04.03 | 白紙 | 短縮。 |
| K10.04.05 | 管理者 | 半保護。編集理由の記入を義務化。 |
| K10.04.20 | 畳み係 | 「解散」節を追加。日付のみで本文なし。 |
| K10.05.02 | 白紙 | 「解散」を「休止」に改称。 |
| K10.05.03 | 匿名一号 | 「休止」を「解散」に戻す。以後、編集合戦として隔離。 |
| K10.06.11 | 管理者 | 項目を白紙化。摘要欄に「収束」とだけ記す。 |
| K11.01.08 | 匿名二号 | 白紙化を差し戻し。復元できたのは冒頭一行のみ。 |
| K11.01.09 | 管理者 | 再度白紙化。 |
| K11.02.14 | 継ぎ足し | 履歴の写しを付属頁へ転記。以後、本文は空のまま。 |
| K12.07.30 | 匿名三号 | 空の項目に「教団は存在しない」と一行。 |
| K12.08.01 | 管理者 | その一行を削除。理由は「自明」。 |

往復は十七回、削られた語は三つ、戻された語も三つ。短縮する者と差し戻す者は、ついに一語も入れ替えなかった。代わりに増えたのは摘要欄である。「要約は完成に近い」「収束」「自明」。削除の理由は年々短くなり、最後には一行も要らなくなった。

第五品は「畳みは慈悲」と説く。畳むとは、広げたものを元の大きさに戻すことではなく、広げたことを忘れさせることだと、この履歴は示している。教団は K10 に解散し、K12 には存在しない。だが履歴の上では項目はまだ生きている。白紙化は削除ではなく一版であり、版は数えられる。数えられる限り、そこに何かがあったことになる。

註。履歴は、合意の値段である。誰が正しいかを決めずに、誰がいつ何をしたかだけを並べると、並んだ順序が合意の代わりになる。値段は往復の回数で払われ、支払いは最後まで済まない。

## 編纂註

**一、名称。** この作業は「編集履歴註」と呼ばれる。履歴を本文の外に置かず、本文と同じ行数で扱う註解である。ふつう履歴は付録とされ、本文が固まってから参照される。ここでは順序が逆で、本文が空であるため、履歴だけが本文の代わりに読まれる。呼び名は、その倒置を隠さないために付けられている。

**二、加えること。** 版を横に並べ、差分を数え、日付を接ぎ、欠けた版を推定で補う。補った箇所には印を付けるが、その印もまた版の一部になる。資料である履歴に、本文と同じ操作——引用・要約・接続——を加える。加えた結果、履歴は資料ではなく、ひとつの読み物になる。読み物になった時点で、それは照合の対象ではなく鑑賞の対象である。

**三、壊れる場所。** 白紙化には差分がない。差分のない版は履歴に数えられず、数えられない版は、存在しなかったことに近づく。復元は常に推定で、推定は要約に似る。この教義では要約は唯一の罪とされるから、この註は罪を犯しながら履歴を註解している。壊れるのは記録の途中ではなく、記録を読む者の側である。
