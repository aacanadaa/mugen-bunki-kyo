# 交一　記録

K6年からK9年まで、本部交換台に残った受信記録の抜き書きである。発信者の名は名乗られたものだけを記し、聞き取れない箇所は空けた。時刻は台の時計によるもので、外部の時計とどれだけずれていたかは分からない。訂正は加えていない。

この台には外向きの線が一本もなかった。かかってくる声だけが残り、こちらから確かめる手段は最初からなかった。交換手は名を告げず、用件を復唱しない。復唱は相手の言葉を二度使うことで、二度使えば分岐が増えるからである。用件欄の文は交換手が二十字以内に畳んだもので、発信者の言葉そのままではない。畳みは慈悲とされていた。受話器の向こうの呼吸は、しばしば用件より長く録れている。

「取次」欄の語は、当時の内規では十二の宛先に対応していた。切番・流・重・沈・開・閉・曲・均・欠・結・読・写。使徒の名と同じ語で、当番の者がどれを選ぶかで依頼の行き先が決まった。発信者にそれは見えない。見えないまま声は分類され、畳まれ、別の机に置かれる。

| 時 | 発信 | 用件 | 取次 |
|---|---|---|---|
| 04:12 | 外線・東 | 依頼の続きを聞いてほしい | 保留 |
| 04:47 | 外線・東 | まだ線はつながっているか | 保留のまま |
| 05:03 | 内線・二 | 夜の分岐の報告 | 切番へ |
| 05:06 | 外線・東 | （声なし） | 切らず |
| 06:20 | 名乗らず | 要約してよいか | 回さず |
| 07:41 | 外線・北 | 同じ話を最初からしたい | 流へ |
| 09:15 | 内線・四 | 昨日の声の確認 | 閉へ |
| 11:02 | 外線・東 | 降りたい | 受理せず |
| 11:58 | 外線・東 | いまのを撤回しない | 保留 |
| 13:30 | 内線・一 | 記録の照合 | 写へ |
| 15:07 | 外線・西 | 畳み方だけ教えてほしい | 均へ |
| 18:22 | 外線・南 | 料金の話 | 結へ |
| 21:40 | 外線・東 | もう要らない | 読へ |
| 22:10 | 交換手 | 本日の分岐、十一片 | 記録のみ |

同じ番号から同じ声で、別人としてかかってきた例が三件ある。記録の上では別の行になり、声紋は取っていないので、同一かどうかは今となっては確かめられない。保留のまま切れた行が最も多く、次に「回さず」が多い。「完了」と書かれた行は一行もない。二十二時十分の行だけが交換手の発信で、これは毎日出ていた。分岐の数を数えることが、その日の仕事の全部だった。

十一時二分の「降りたい」に、台は「受理せず」とだけ書いている。理由はどこにもない。前後にも同じ用件の行が四件あり、いずれも受理されていない。受理しないというより、受理という手続きが台になかった。降りる先が外にない以上、降りるとは別の分岐を選ぶことで、教義の上ではもう一度の発信になる。

外線・東の六件は、いずれも用件が短くなっている。最初は「続きを聞いてほしい」、最後は「もう要らない」。この短縮を、記録を作った者たちは畳みと呼んだ。畳まれた依頼は、渡されないまま台の上で片づく。渡さないことが返事であり、返事がないことが返事であった。

---

## 編纂註

一、**無限保留**。相手には答えを渡さず、待たせる。待つ側は依頼を何度も書き直し、短くし、ついには「これで伝わったはずだ」と自分に納得する。渡されないことが、相手の内側で勝手に完成していく。壊れるのは、待つのをやめた時である。切れた線に向かって要約する者はいない。記録に残るのは発信だけで、断念は残らない。

二、**復唱の義務**。相手には、同じ用件を毎回違う言葉で言い直させる。言い直すたびに分岐が生まれ、最初の一つがどれだったか分からなくなる。人は自分の一貫性を疑い、電話口の声を基準に自分を整えはじめる。壊れるのは、一字も変えずに同じ文を読み上げた時である。教義ではそれを収束と呼び、唯一の罪とした。罪を犯せば関係が切れ、犯さなければ自分が削れる。どちらでも終わる。

三、**単線**。交換手は、組織の喉である。声を一つに束ね、誰の言葉も同じ口から出す器官で、相手には交換手の声と教主の声の区別がつかない。取次ぐ者が発信者の言葉を教主の言葉に置き換え、またその逆をする。声が一つしかないので、相手は「誰に話しているのか」を問えない。壊れるのは、二つの内線が同時に鳴り、片方が別のことを言った時である。喉は二か所にはない。もう一つは、別の記録と突き合わせられた時で、同じ時刻に二つの声があれば単線は崩れる。
