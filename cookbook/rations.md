# 台一　配分

台一は割当の台である。ここで教えは語られない。椀に何をどれだけ入れるかだけが決められ、その量がその日の席を決める。教団が消えた後も、この台帳の写しは各地に残った。読む者はまず、なぜこれほど細かく量を定める必要があったのかと問う。答えは台の下にある。配分は教義の一部であり、教義は配分の言い換えであった。

## 一、台の作法

台には五つの器が並ぶ。黒、漆、白木、板、そして空の位置。配る者は切番と呼ばれ、切る量と配る量を同じ手で測る。測る道具は柄杓ではなく、指の三節。一節を一分、三節を一椀とした。指は人ごとに違うから、実際の量は配る者によってわずかに揺れる。この揺れは誤りではなく、余白と呼ばれた。余白は記録されない。記録されないものは、問えない。

## 二、割当

| 区分 | 量 | 備考 |
|---|---|---|
| 教主（名なし） | 一椀半 | 黒椀。縁の欠けは三。欠けは配る者が隠す |
| 十二使徒 | 一椀 | 切番のみ半椀を加える。加える分は切る際の余りから出す |
| 切番衆 | 七分 | 番を順に回す。最後の番は常に薄い |
| 講衆 | 五分 | 講の長は六分。長の名は台帳に残さない |
| 書写衆 | 五分 | 写す量は配られる量より多い。写しは食わない |
| 聴衆 | 三分 | 木椀。椀に口をつけた音を数える者がいる |
| 客 | 五分 | 白木椀。縁を見せない。客は序列の外に置かれる |
| 名を捨てた者 | 二分 | 器を持たない。板で受ける。板は洗わない |
| 咎人 | 零 | 見るだけ。畳みの日に限り一分 |
| 空位 | ― | 常に一席。誰の席かは告げない |

註：量の欄は身分の欄でもある。食事の量は、最も静かな身分表示である。声を上げず、金もかからず、しかし毎日繰り返される。

## 三、規則

一、量は席で決まる。席は名で決まる。名は教主の帳面にあり、本人は見ない。
二、椀の縁の欠けは序列を写す。欠けの多い椀は下位に回る。
三、配り終えた柄杓は台の右に伏せる。伏せた向きが、その日の序列の確定を意味する。
四、余りは戻さない。戻す量があるなら、それは最初から誰かの量であった。
五、咎人には零を与える。零は罰ではなく位置の確認である。畳みの日に一分を加える。第五品「畳みは慈悲」が実行されるのは、この一分においてのみである。
六、連れの者の量は、連れた者の量から引く。引いた分は「預かり」として台帳の外に置かれる。
七、台帳の「―」を書く者は、書いた後に自分の量を確かめてはならない。

## 四、余白

K5のセイリャク事件のあと、台帳の様式は一度改められた。量の欄に「―」が増え、かわりに余白の欄が設けられた。余白には数字ではなく、短い語が入る。「静」「戻」「遅」「見ず」。事件の詳細は台帳にない。書かないことが様式になったからである。K9の閉座で台は解体され、K10の解散で配る者は消えた。K12のいま、台はない。あるのは写しだけである。写しには量だけが残り、なぜその量なのかは残らない。復元する者は、空白の多さに驚く。だが空白こそが本来の本文であり、量はその注釈だったのかもしれない。

---

## 編纂註

**第一条　序列の計量化**
称号を与えず、量で位置を示す手口である。される側は、教義を信じる前に、毎日の食事で自分の順位を身体に覚えさせられる。不満は「量が足りない」という言葉になり、信仰の問題ではなく食欲の問題として退けられる。壊れるのは、量が測る者の指で揺れた時である。揺れを「余白」と呼んで隠した瞬間、配分は恣意になり、下位の者は自分の位置が行いではなく気まぐれで決まると知る。序列は恐怖に変わり、恐怖は長く信仰を支えない。

**第二条　残余の聖化**
余りを「畳み」と呼び、教主へ戻させる手口である。戻した者は何も受け取らないが、戻した事実だけが記録される。される側は、差し出した量が自分の格上げに効くかのように感じ、次の機会にも同じだけを戻す。壊れるのは、余りが実際には捨てられ、あるいは別の台に回っていたと露見した時である。慈悲の語が在庫管理の言い換えだったと分かると、以後その語は誰の口にも上らなくなる。

**第三条　空位の常設**
量を盛らない席を常に一つもうけ、誰の席とも告げない手口である。される側は、自分がそこへ移されるのか、誰かが既に外されたのかを読み、互いに量を確かめ合う。監視は配る者ではなく、配られる者どうしで行われる。壊れるのは、空席が単なる計算違い、あるいは台の寸法の余りだと知られた時である。空白に意味を読ませる装置は、空白が偶然だと分かった瞬間に、意味ごと失われる。
