# 支十　時効

〈本文〉

支払というものは、払われた時点で完結しない。台帳に一行が立つだけである。その一行が帳簿から外れるまでには、別の手続きが要る。本稿が扱うのはその手続き、すなわち時効である。

教団の会計には、建立期から一貫した原則があった。記録は消さない。消さずに、効力を失わせる。K1からK3にかけての台帳は、この原則を「保留」という一語で運用していた。支払の記載は残るが、三年を過ぎたものは集計から外れる。外れた記載は頁の端に寄せられ、やがて別の綴りへ移された。移された先の綴りには表題がなく、ただ「旧」とだけ書かれた。

K4、教団が拡大した時期に、この原則は数字を得た。五年。支払の効力は五年で消える、と定められた。定めたのは教主ではなく、当時の記録係である。教主は署名していない。署名がないまま、五年という数字は三つの部署に伝わり、三つの部署がそれぞれ違う起点を採用した。支払の日から五年、受領の日から五年、記載の日から五年。三つは同じ年に始まり、同じ年には終わらなかった。

K5からK7の文書には、この不一致が顔を出す。ある支払は、会計では既に消えており、渉外ではまだ生きている。生きている側の文書には、消えた側の番号が引用されている。番号だけが引用され、金額は書かれていない。金額のない引用は、時効の隙間を渡るための橋であった。橋は、架けられた年を記録していない。

K8、教主の指示で、時効は七年に延びた。延ばした理由は書かれていない。書かれていない理由を、後年の註は「再来の見込み」と補っている。補ったのは誰か。この章の資料には、その名がない。名のない註は、往々にして最も重い。七年に延びたことで、K5に消えたはずの支払が二件、再び台帳の表面に戻った。戻った支払は、戻った年ではなく、最初に払われた年の欄に記された。時効は、支払をなかったことにはしない。支払を、遅れて効力を持つものに変える。

K10、解散。この年、時効は止まった。止まったのではなく、止められた。停止の根拠として掲げられたのは「団体の存続しない期間」という一句である。一句は四文字もない。四文字に満たない根拠が、七年分の計算を宙に吊るした。吊るされた計算は、K10からK12までの二年間、どの台帳にも計上されず、どの綴りにも移されなかった。移されなかったので、消えもしなかった。

K12、現在。教団は解散の状態にある。時効の再開を定めた文書はなく、停止を解除した文書もない。ただ、K12の日付を持つ一通の照会が残っている。照会の宛先は「記録係」であり、差出人の欄は空である。照会の本文は一行、「七年は、いつから数えるのか」とだけ書かれている。この一行に答えた文書は、この章の資料には含まれていない。

支払は、払われた瞬間に終わるのではない。記録から効力が抜け落ちるまで、支払は支払であり続ける。そして効力が抜け落ちる条件は、支払そのものではなく、支払を数える者たちの間で決められる。時効とは、この決定が繰り返し先送りされた結果に与えられた名である。

## 編纂註

**一**　本章は、支払を一個の対象として扱わず、支払の効力が失われるまでの手続きとして扱っている。対象そのものは、K4の数字、K8の延長、K10の停止という三つの時点にしか現れない。残りの紙幅は、その三つを数える者たちの不一致に充てられている。伝記として読むなら、主役は支払ではなく、数え方である。数え方が変わるたびに、同じ支払が別の顔で台帳に戻る。本章が扱う対象は、この反復そのものである。

**二**　本章は、読者に対して、支払の年を数えることを求める。ただし求める相手は読者一人ではなく、註を書く者、綴りを移す者、照会に答える者である。数える者が複数いれば、起点も複数になる。本章はその複数性を隠さず、三つの起点を並べて示した。並べることで、どれが正しいかを決めるのではなく、決められないまま運用された年数を可視化する。読者はここで、正解を探すのではなく、正解の不在がどう処理されたかを見る。

**三**　本章が壊れるのは、K5の支払がK8に戻る箇所である。ここで本章は、支払の同一性を暗黙に前提している。しかし台帳の記載は番号と金額のみで、支払の相手も目的も書いていない。同じ番号が同じ支払を指すという保証は、この章の資料にはない。保証がないまま、本章は「戻った」と書いた。この一語が、資料の外の推測である。註はこれを隠さないが、隠さないことと、根拠があることは違う。

**四**　時効は、支払の最後の章である。この一句を、本章は本文の末尾に置かなかった。置けば、時効が支払の物語を閉じるように読める。しかし実際には、時効は何も閉じていない。K12の照会は宛先を持ち、差出人を持たない。答える者がいれば、時効は再び動き出す。動き出した時効は、支払を消すのではなく、支払の年を数え直す。最後の章は、最後であることをやめる。だからこの一句は、註に置く。註は本文の外にあり、本文を閉じない。
