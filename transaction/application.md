# 支一　申込

〈本文〉

K2の秋、北側の支部に一通の申込書が届いた。差出人は受付簿に「ミナ」とだけ記されている。宛先は教主ではなく、「分岐管理部」——当時、名簿にも規則にも存在しない部署名だった。封は糊付けされず、三度折られ、折り目に沿って薄く曇っていた。切手の位置には、判読できない小さな円が一つ押されている。

用紙は四欄からなる。第一欄「いま、どこにいるか」。第二欄「なぜ、そこにいるか」。第三欄「どこへ移りたいか」。第四欄は空欄で、その上にだけ「支払」と印刷されていた。ミナは前三欄を埋め、第四欄には何も書かなかった。欄外に鉛筆で、「ここに書くことが、わたしの支払です」とある。文字は途中で細くなり、最後の一語だけが濃い。

受付の者はこれを「申込」として受理し、支部日誌に「志納一件」と記した。同じ紙が、翌月の教主口述では「手続」と呼ばれ、K10の解散時に作られた破棄目録では「未処理・金銭外」に分類された。三つの文書は、同じ一枚を別のものとして扱っている。だが、どの記述にも金額はない。書かれていないのではない。金額を書く欄が、第四欄の外にそもそも設けられていなかった。

第四欄の空欄は、無記入ではない。前三欄が移動の理由を書かせ、第四欄が移動の対価を予定しているなら、ミナの鉛筆は欄をずらして書いたことになる。支払は、金額ではなく、書く位置の選択として現れる。受付の者はそれを見落とさなかったらしく、日誌の余白に「位置、異例」と小さく残している。同じ余白には、別の筆跡で「受理」とだけある。二つの語の間に、日付はない。

誰が書いたのかも、確定しない。K12の再建作業で筆跡は二種類に分類され、受付簿の「ミナ」は同姓の三人に該当した。三人のうち二人は、のちの聞き取りで申込を否定している。残る一人は、書いたとも書かないとも答えなかった。この不確定は破棄目録の欠落に由来するのか、それとも当時から確定を避ける運用だったのか、本章の材料だけでは決められない。

この申込書は、K10の解散まで北側支部の木箱に収まっていた。破棄目録には載っているが、実際には破棄されていない。K12の発見者は、箱の底から、他の十七枚とともにこれを取り出した。十七枚のうち四枚は同じ四欄を持ち、三枚は第四欄に数字が書かれている。数字の書かれた三枚は、いずれも宛先が「分岐管理部」ではない。支部には、この申込書が一度返却されたという噂もある。返却の記録は残っていない。

K12の聞き取りで、教主はこの一件を「覚えていない」と述べ、直後に「紙は受け取った」と言い直した。K12の目録作成者は第四欄の空欄を「不備」と記し、別の作成者は同じ空欄を「完結」と記した。同じ空欄が、不備にも完結にもなる。ここで対象は、書かれた文字ではなく、書かれなかった余白の解釈へと移る。ミナが何を支払ったのかは、どの文書にも確定されない。確定しないことが、この一枚の用途だったのかもしれない。

## 編纂註

**一**　本章は、支払を金額としてではなく、一枚の申込書の位置として扱う。対象は本文中で「申込」「志納」「手続」と三度名を変え、いずれの名も単独では確定しない。編纂者はこの不安定さを欠陥とせず、対象の輪郭そのものとして記述した。結果として、支払の実体は章の外に置かれたまま、書式と余白だけが前面に出ている。

**二**　誰に何をするか。ミナが書き、受付の者が受理し、目録作成者が空欄を評価する。だが、誰も支払を実行しない。実行の記録だけが三つの文書に分かれて残る。本章が追うのは行為ではなく、行為の受理の連鎖である。読者はここで、支払の主体が書く者から読む者へ移るのを見る。

**三**　壊れるのは第四欄である。空欄が「不備」と「完結」に分裂し、宛先は存在しない部署名のまま残る。破棄目録には載りながら現物は破棄されず、筆跡は二種類、名は三人に該当する。これらの齟齬は偶発ではなく、確定を避ける運用の痕跡と見ることもできる。本章はその判断を保留し、齟齬の配置だけを記した。

**四**　「支払は、意思の記録である」。本章に金銭の手続は一度も現れない。現れるのは、どこへ移りたいかという意思と、それを欄外に置いた位置だけである。教団の側はこの記録を取引として扱おうとし、編纂者はそれを記録として扱い直した。支払という語が指すものは、ここでは送金ではなく、書くという選択の痕跡である。
