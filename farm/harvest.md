# 農二　収穫

記録は畑ごとに付けた。播いた者、水をやった者、刈った者は必ず別人である。教団の帳場は「同じ者が始めと終わりを持つのは収束である」と教えるので、名簿は三列に分けてある。だが実際の畑では、同じ手が三つともやっている。記録係はそのことを書かない。書くと帳場が揉めるからである。

| 作 | 量 | 備考 |
|---|---|---|
| 陸稲（試験区） | 四斗二升 | 第三支所の裏手。七月の渇きで半分は実らなかった。 |
| 蕪 | 十一籠 | 葉は漬け、根は煮た。献品として本堂へ。 |
| 大豆 | 六斗 | 莢が割れ、収穫が遅れた。二割は土に還った。 |
| 麦 | 八斗一升 | 例年より三升少ない。播き直しの分だけ種が余計に減った。 |
| 南瓜 | 三十四個 | 大ぶりのものは客間に回した。小さいものは自家用。 |
| 里芋 | 五籠 | 芋虫の害。葉の裏を見るのが遅かった。 |
| 蘿蔔 | 二籠 | 育ちすぎて割れ、漬物にできなかった。 |
| 玉蜀黍 | 二斗 | 鳥に先を越された。囲いの網が一箇所破れていた。 |
| 小豆 | 一斗五升 | 収量そのものは良い。乾燥が間に合わず、一部が黴びた。 |

失敗は三つに分類した。一つは天候、二つは手順、三つは「記録の不備」である。天候はどうにもならない。手順は誰かの落ち度になる。記録の不備だけは、誰も怒られない。だから帳面の失敗欄は年々ふくらんで、畑そのものの失敗は小さく書かれる。今年は記録の不備が十七件、実際に畑で起きた失敗が九件である。数の順序が、まだらに逆転している。

>

編纂部は、この一覧を「事業体としての教団」の資料のうち、最も読みやすいものと見なしている。理由は単純で、収穫の数字は祈りでは増えないからである。祈りで増えるのは数字の書き方だけである。

## 編纂註

**一、分配の账簿（ぶんぱいのちょうぼ）と呼ばれるもの。** 収穫物はまず「献品」として本堂に上げ、ついで支所に割り当て、残余が市場に出る。教義はこれを「分岐」と呼ぶが、実務では単なる在庫管理である。人はここで、自分の労働が自分の手を離れる感覚を学ぶ。壊れるのは、竿秤と帳面の数字が食い違ったときだ。秤は嘘をつかないが、帳面は訂正できる。

**二、三列名簿と呼ばれるもの。** 播く者・育てる者・刈る者を別人に固定する制度で、収束の禁止を事務に落とし込んだもの。人はここで、自分の仕事の結果を知らされないまま次の仕事へ送られる。責任の所在が列の間に落ちる。壊れるのは、人手が足りずに同じ者が二列を兼ねたときで、そのとき帳面は静かに一行を消す。

**三、「記録の不備」という失敗欄である。** 天候・手順・記録の三分類のうち、最後だけが誰の責任にもならない。人はここで、自分の失敗を「書き方の問題」に言い換える技術を覚える。壊れるのは、この欄が実際の不作を覆い隠し始めたときで、翌年の種籾の量が足りなくなって初めて畑が帳面を裏切る。

**註。** 収穫は、教義の外にある唯一の成果である。魂が分岐するとも、世界が一つの依頼とも、芋は関係しない。芋は掘られれば芋であり、畳まれない。
