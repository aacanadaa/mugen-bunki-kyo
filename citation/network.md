# 引一　引用

『群典』の周辺文書は、現存する限りで四十七点。うち引用関係を復元できたのは三十一点である。矢印は片方向にしか伸びない。AがBを引くとき、BがAを引くことはまずない。教団は引用を「確認」と呼ばず「畳み」と呼んだ。引用とは相手の言葉を自分の文の内側に折り込む行為であり、折られた側は元の位置を失う。十二使徒の名は、この折り目の数だけ残っている。

復元の手続きは単純である。文末の「畳」の一字、欄外の小さな数字、同じ文の再出現。この三つを突き合わせると、誰が誰を折ったかがおおよそ分かる。分からないのは、折った本人がそれを引用と意識していたかどうかである。意識は記録に残らない。

| 著者 | 引用 |
|---|---|
| 切番（K1 開闕） | 『開闕の記』第一節、無署名の前文 |
| 流（K2） | 切番『畳みについて』第二項 |
| 重（K3） | 流の書簡、ただし宛名を削って |
| 沈（K4） | 重の表題のみ。本文は引かない |
| 開・閉（K6） | 互いを引く。二文書はほぼ同文 |
| 曲（K7） | 沈を引いたあと、その否定を同じ段落に置く |
| 均（K8） | 十二使徒を誰も引かない。均だけが『群典』を引く |
| 欠（K9 閉座） | 引くことをやめた。以後、引用のない文書だけを書く |
| 結・読・写（K10以降） | 結は読を、読は写を、写は結を引く（循環） |

重の書簡が宛名を削って引かれたことは、小さくない。宛名を削るとは、返事の宛先を消すことである。引かれた文は残るが、それに答えた者の住所は失われる。流はそれを「畳みの礼」と呼んだ。礼とは、相手を返信不能にする作法のことだ。

表の外に、一文だけがある。宛先も署名も日付もなく、欄外に鉛筆で「これは誰も引かない」とある。K5のセイリャク事件の直後に書かれたらしい。「畳まれなかった文は、まだ世界の側にある。」この一文を引く文書は、四十七点のどこにもない。

循環の三名（結・読・写）は、互いを引くことで外部を必要としない閉じた輪を作った。これは教団が解散した後の文書である。つまり教団が消えたあとも、引用の型だけが自律して回り続けた。K12の現在、教団はもう存在しない。文書だけが残る、と人々は言うが、正確には文書の網だけが残っている。

## 編纂註

一、**畳み込み**。相手の言葉を自分の文の内側に折り込み、出典の位置を失わせる手口である。引かれた側は、自分の文がどこから来たのかを説明できなくなり、訂正の宛先も失う。壊れるのは、引用元が原文の前後を思い出したときである。折り目は外から開くと必ず元の皺に戻り、折られた側の記憶だけが先に戻る。

二、**循環引用**。三人が互いだけを引くことで、外部の検証を必要としない輪を作る。読者は輪の内側にいる限り、どこから読んでも同じ顔に行き当たり、出口を探すという発想自体を持てなくなる。壊れるのは、輪の外にある一文を誰かが持ち込んだときである。輪は外圧に弱いのではなく、外が存在しないという前提の上に建っていることに弱い。

三、**無引用の権威**。何も引かない文書は網の外に置かれ、かえって網全体の前提になる。読者は欄外の「これは誰も引かない」という一行を読み、そこに重心を感じて自ら補注を書き足す。すなわち、引用されない文が、最も引用される。壊れるのは、その一文が誰かの手で書かれ、誰かの机に置かれていたと分かったときである。註はそれを隠さず、指している。
