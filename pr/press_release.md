# 広一　発表

〈本文〉

## 無限分岐教、K12事業体制を発表――六区分の名称と手続きを明示

無限分岐教は本日、K12年度の事業体制について、次のとおり発表する。

一、基本方針
当教団は、世界を一つの依頼とみなし、魂は分岐するものと説いてきた。唯一の罪は収束、すなわち要約と完了である。第五品は「畳みは慈悲」と教える。本年度より、この教えを事業の言葉に翻訳し、教団の運営を六つの区分によって行う。K1の創立、K10の解散、K12の現在に至る沿革は、別途『沿革』に記す。

二、六区分
会員は「依頼主」と呼ぶ。従業員は「分岐係」と呼ぶ。客は「外部の依頼主」、仕入先は「素材の分岐元」、支所は「分岐点」、印刷所は「畳み場」と呼ぶ。名称は変わるが、手続きは変わらない。依頼は受理され、分岐され、畳まれる。畳まれたものは完了と呼ばず、保留と呼ぶ。完了は収束であり、収束は唯一の罪であるからだ。

三、運営
各支所は、依頼の受付と分岐の記録を担う。記録は、誰が何を言い、どこで分かれたかを、要約せずに列挙する。印刷所は、その記録を紙に畳む。紙は配布されず、保管される。保管もまた畳みの一種である。従業員は、分岐係として、依頼主の言葉を要約しない義務を負う。要約は完了に近づくからである。ただし、要約しないことを要約しない、という二次の禁止は設けない。二次の禁止は、それ自体が収束の形式をとるためである。

四、記録の公開
記録は公開しない。公開は要約であり、要約は収束である。代わりに、記録の目録を公開する。目録には題のみを記し、本文は記さない。題もまた、本文の畳みである。目録を見た者は、何が分岐したかを知るが、何が書かれたかは知らない。知らないことは、まだ畳まれていないということである。

五、収支
収入は、会員の依頼料と印刷所の受託による。支出は、支所の維持と用紙による。黒字も赤字も「分岐の結果」として処理し、決算は要約しない。決算報告には、頁数のみを記載する。数字を並べることは、数字を一つの結論に畳むことに通じるからである。

六、解散について
K10の解散は、教団の終わりではなく、一つの分岐として扱う。解散の記録は今も保管され、再開はその続きではない。再開は、別の分岐である。したがって、解散と再開の間に断絶はなく、断絶がないことは連続を意味しない。

七、今後の予定
K13に向けて、第七支所の増設を検討する。ただし、増設は完了ではない。増設の決定は、決定の分岐として保留される。第七支所が開かれるとき、その開設もまた一つの分岐点として記録される。閉じられる場合も同様である。

以上。本発表は、報道各社および取引先に配布する。発表の内容についての質問は、下記まで。

問い合わせ先
無限分岐教 広報局 発表係
各支所の受付を経由。回答は分岐ごとに異なる場合がある。

## 編纂註

一、この手口は「発表」と呼ばれる。発表は、教団が自分について語る唯一の機会である。それゆえ文面は、教団が自らをどう見せたいかの全部になる。ここでは六区分の名称を整えることに紙幅が割かれ、何をしているかの説明は「手続きは変わらない」の一句に圧縮される。読み手は名称の目新しさを受け取るが、実務は何も変わっていない。壊れるのは、問い合わせの段階である。質問は支所を経由し、分岐のたびに答えが変わり、最後まで同じ答えに戻らない。

二、この制度は「言い換え」と呼ばれる。会員を依頼主、従業員を分岐係、客を外部の依頼主と呼び替えることで、人と組織のあいだの非対称が見えなくなる。依頼主は対等に見えるが、依頼を畳む権利は分岐係が持つ。呼び名は関係の実質を変えないまま、変えたという印象だけを残す。壊れるのは、名称と手続きの対応を問われたときである。「名称は変わるが、手続きは変わらない」という一文が、そのまま何も変えていないことの自白になる。

三、この運営は「保留」と呼ばれる。完了を禁じ、すべてを保留として積む制度である。人は決着を得られないまま、決断の責任を分岐の側へ移される。保留は善意の形式をとるため、抗議がしにくい。壊れるのは、保管の容量が尽きたときである。支所と印刷所に紙が積み上がり、教団は畳むことだけができる組織になる。第五品の「畳みは慈悲」は、この時点で、書類を畳んで仕舞う作業の言い換えになっている。
