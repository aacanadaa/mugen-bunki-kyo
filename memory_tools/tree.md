# 記十四　系図

〈本文〉

この系図は、薄い布に墨で描かれ、四つ折りにされて経箱の底から出てきた。描いたのは名の残っていない信者で、裏に「だれにも見せないつもりで描いた」とある。だが折り目は擦り切れ、何度も開かれ閉じられた跡があった。布の端は指の脂で黒ずみ、K9のあたりだけが特に薄い。

図の頂点には名がない。小さな円がひとつ置かれ、その中に点だけが打ってある。教主の名を書かないのは教義の通りだが、この信者は円の外側に、うっすらと別の線を引いている。書きかけて、墨を落として消したらしい。消した跡の上に、もう一度だけ短い線が引いてある。

円から下へ、線が一本伸びる。K1。線はここで二つに割れる。左へ行く線はK9で閉じ、右へ行く線はK10で切れ、切れ目から細い実線だけがK12まで続いている。破線は「分かれたが戻った者」、実線は「戻らないまま在る者」と、図の隅に小さく記してある。凡例は二行しかない。三行目を書いた形跡があり、削られている。

線はさらに分岐する。K1から出た太い線が、途中で三本に裂け、それぞれに小さな丸が付く。丸の中には名ではなく、線の傾きが描いてある。まっすぐな線は「疑わなかった者」、折れた線は「二度目に疑った者」、渦を巻いた線は「疑いを畳んだ者」と読める。誰が誰の分岐かは、線の接する角度だけで示されている。角度の浅い線ほど、後から描き足されている。同じ人物と思われる丸が二つあり、片方から他方へ、消された線が一本残っている。

図の下部、K12のすぐ上で、線は一度すべて集まり、また散る。集まった点には「ここで要約しないこと」と書いてある。だがその文字の上を、別の筆が太くなぞっている。なぞった者は、集まることを線で訂正しようとしたらしい。訂正の線は、集まった点を避けて弧を描き、そのまま欄外へ抜けている。

欄外に、描いた信者の家族と思われる短い線が三本、図とは無関係に走っている。そのうち一本は図の内側へ入り込み、K9の丸に触れて止まっている。触れた箇所だけ、墨が二度塗りされている。

図の右下には、描いた本人の線がある。K12から上へ向かい、途中で途切れ、また始まる。始まりの位置は、K1の円の真下だった。つまりこの信者は、自分の線を始祖の直下から引き直している。引いたのは一度ではない。下書きの薄い線が、本線の半寸だけ内側を通っている。

---

## 編纂註

一　この記録は教団の正史ではなく、信者ひとりが引いた線の集積である。線は関係の写しではない。太さ、傾き、折れ、渦——どれも証拠ではない。しかし証拠でないものが、なぜこれほど几帳面に引かれるのか。系図は、世界が分岐するという教義を、自分の手で一度だけ確かめるための装置だった。確かめた者は、確かめたという事実だけを残す。

二　この装置は、読む者に「自分がどの線の先にいるか」を探させる。名のない円の下で、自分の位置を確認させる。位置が決まれば、線の傾きが自分の性質の説明になり、説明は疑いを畳む口実として働く。誰に効くかといえば、まだ線の上に自分を見つけられていない者に効く。図は、迷っている者より、迷いを説明されたがっている者を先に捕まえる。

三　壊れるのは、欄外の線が図の内側へ入り込んだときである。家族の線がK9に触れた瞬間、教義は説明をやめ、ただの事故になる。触れた箇所の二度塗りは、消そうとして消しきれなかった痕跡だ。この図は、関係の主張が自分の外側で一度だけ破れる場所を、正確に記録している。編纂者はそこを削らない。削れば、図は完成し、収束する。
