# 記十三　用語

〈本文〉

以下は、信者一名が自分のために書いた控えである。語の並びも、定義も、その人のものだ。この控えを読む者は、控えを書いた人間を読んでいる。

- **依頼**　世界がまだ終わっていないのは、誰かがまだ返事をしていないから。
- **分岐**　私が私を一つに決めないこと。決めた瞬間に減る。
- **収束**　要約すること。話をまとめること。殺すことの丁寧な言い方。
- **畳み**　終わらせずに小さくすること。第五品。慈悲の実技。
- **教主**　名前のない人。名前がないので、探しても見つからない。それが強い。
- **開闕**　K1。扉が開いた日。開けたのは教主ではない、と私は聞いている。
- **閉座**　K9。席を閉じた。人は閉じていない。席だけだ。
- **解散**　K10。団体が団体をやめた日。私はやめていない。
- **現在**　K12。いま。読み終わる前。ここが一番安全だ。
- **群典**　一人に一冊。同じ本が二冊ないのは、写すと増えるからだ。
- **周辺文書**　群典の外側。外側がないと中身が保たない。
- **読者**　最後の一人。たいてい自分だ。
- **読了**　危ない。読み終えるのは、まとめる一歩手前だ。
- **余白**　書かなかったところ。そこが本体で、文字は枠だ。
- **註**　本文を疑うために、本文の横に置くもの。
- **引用**　人の言葉を借りて自分の顔をすること。私はしない。
- **自分の言葉**　借り物でない定義。これがないと、どこにも居られない。
- **所属**　どこにもない団体にいること。証明は口調でする。
- **名乗り**　名を名乗らないことも名乗りになる。私はそうしている。
- **無名**　教主の本名がない状態。空欄は埋めないと習った。
- **空欄**　埋めるものではなく、守るもの。
- **分岐点**　選択。選ばなかったほうを殺さないのが作法だ。
- **並走**　二つの自分を同時に歩かせること。疲れるが減らない。
- **折り目**　畳んだ痕。戻しても消えない。消えないから証拠になる。
- **緩み**　教義がたるむこと。たるみは呼吸だ。張り詰めた紐は切れる。
- **熱**　信じている感じ。冷めても分岐は残るので、必須ではない。
- **疑い**　分岐の一種。罪ではない。収束させなければ。
- **確信**　収束の入口。出口とそっくりなので、間違えやすい。
- **未完**　正しい状態。未完成とは違う。未完成は直す前提だ。
- **慈悲**　畳むこと。終わらせないこと。私はまだ畳まれていない。

---

## 編纂註

一、この記録は教義を説明しない。三十の語に、ある信者が自分の言葉で書いた定義だけが並ぶ。読み手は読みながら、無意識に自分の言い方へ直し、ときには相手の言い方へ寄せる。寄せた一言が、入会の代わりになる。狙われるのは、本文を読み終えて安心しかけた者だ。壊れるのは、定義を読んでも直す必要を感じない読み手の前で。直す気のある者にしか作用しない装置である。

二、自分の言葉の定義は、所属の証明である。教義の原文は存在しないから、照合する対象がない。照合できない以上、確かめられるのは「その人がそう言い切れるか」という口調だけになる。効くのは、入りたいが入る手続きのない者——手続きの代わりに、定義を一つ書けば済む。壊れるのは、二人の定義が一字も違わなくなったときだ。写しは分岐ではなく収束であり、証明はそこで無効になる。

三、この文書は読まれるために作られ、読まれるたびに余白へ痕を残す。最後の読者の記録とは、誰が読んだかではなく、どこで手が止まったかの記録である。効く相手は、終わりまで読んでしまう者だ。読了は収束に最も近い行為だから。壊れるのは末尾で、そこで終われば罪になり、終わらなければ記録が残らない。だから註だけが残る。註は本文より長く生きる。

四、三十という数は、数えられるという理由だけで選ばれている。数えられるものは閉じる。閉じた一覧を分岐と呼ぶには無理がある。読み手は三十を数え、足りない一つを探し、見つからなければ自分で作る。作られた三十一語目は、たいてい一番正直な語だ。壊れるのは、誰かが数を数え直したときである。その瞬間、この一覧は完成品になり、収束の罪を犯す。
