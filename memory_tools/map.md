# 記十一　地図

〈本文〉

一

周辺文書のうち、記十一はもっとも薄い。紙は二枚、片面に図、もう片面に余白がある。図は鉛筆で描かれ、要所だけ黒の細筆でなぞられている。線は定規を使っていない。川は二度引き直され、消された線が消しゴムの跡の下に残っている。集会所の四角は三度描き直され、いちばん古い線だけが薄く外へはみ出している。描いた者の名は右上に姓のみ、名はなく、日付もない。ただし紙の下端には、指でなぞったような光沢があり、そこだけ幾度も触れられている。

二

図の中央に四角がひとつ。集会のための部屋である。四角の左に「井戸」、右に「坂」、上に「丘」、下に「道」とある。井戸は実際には坂の途中にある。丘は図にあるほど高くない。川は集会所の南を流れているのに、図では四角の上を横切っている。描いた者は隅に「ちがう」と小さく書き添えた。書き添えはあるが、線は一本も直されていない。

三

図の外側、紙の縁に沿って点線が一周している。点線は内側のどの線とも接していない。境界ではなく、畳み目の位置だと後の註は言う。教義第五品「畳みは慈悲」による。畳むとき、どの線が内側に残るかを、描いた者は知っていた。知っていて、内側に残る線をひとつも引かなかった。点線の四隅だけ、鉛筆が濃い。そこを指で押さえてから折ったのだと、紙の癖が示している。

四

紙の裏に文字がある。表から透けて見えるのは「K9」と「K10」、そのあいだに短い横線が一本。閉座と解散のあいだに、この図の作者は何も置かなかった。置かなかったのではなく、置けなかったのだと、のちの読者は記す。横線の長さは、図のどの距離とも対応していない。対応しないまま、線は引かれている。

五

余白の右下、日付の入るはずだった空白に、別の筆跡で一行。「読了」。その下に、さらに小さく「地図の誤りは、記憶の誤りである」。この一文は編纂註の文言と一致する。註が先か、余白が先かは、いまも決まらない。筆跡は図の筆跡と似ているが、同じではない。似ていることが、この記録の唯一の証拠である。

六

この図は、読まれるために描かれている。読む者が誤りを数え、数え終えたところで、はじめて図は完成する。完成は収束であり、収束は唯一の罪である。だから図は、いまも完成しない。二枚の紙のあいだに、数えられなかった誤りがひとつだけ残されている。それは、この記録を読む者に数えさせるために、わざと残された。わざと、と書くのは容易だが、残した者が誰かを、この文書はついに名指さない。

---

## 編纂註

**一**　この記録は地図ではなく、数えるための用紙である。読む者に三つの誤りを探させ、探し終えたところで図を完成させる。完成させることによって、読む者を「収束」の側へ一度だけ立たせる。装置が誰に何をするかは、ここにある。誤りがちょうど三つであることを確かめた者には、何も起こらない。誤りが四つ見えた者、あるいは三つとも見えなかった者にだけ、この用紙は用紙でなくなる。壊れるのはそこである。

**二**　想定された読者は、K12現在の、閉座も解散も直接には知らない者である。知らない者に、地図を読ませ、誤りを数えさせる。数えるには、図の外側の記憶を借りるほかない。つまりこの装置は、読者に自分の記憶を持ち込ませる。持ち込まれた記憶が図と食い違ったとき、装置はそれを誤りとして数える。数えられた誤りは、図の側ではなく、読者の側の傷になる。ここが壊れやすい。

**三**　三つの誤りは、井戸の位置、丘の高さ、川の向きである。いずれも測量の誤りではなく、想起の誤りである。描いた者は測らなかった。思い出した。だから「地図の誤りは、記憶の誤りである」という一文は、慰めではなく、判定である。ただしこの判定は、記憶を正せば地図が正しくなると言っているのではない。地図を正しても記憶は正しくならない、という順序の非対称を指している。この非対称を読み落とした読者に対して、註は効かない。

**四**　余白の「読了」は、読者がいたことの記録ではなく、読者がいたことにされた記録である。装置は読者を必要とするが、読者を保持しない。読み終えた者は、図の完成と引き換えに、図の外へ出る。外へ出た者を数える欄は、この文書のどこにもない。だから最後の読者は、最後であることを自分では確かめられない。確かめようとした時点で、その者はもう読者ではなく、次の読者を待つ余白の一部である。
