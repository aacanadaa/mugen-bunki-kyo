# 精四　名簿

本編は、開闕K12における「精英」の呼称と接触の記録である。名は教団内の呼称のみを採り、外部の本名は載せない。載せないこと自体が、この名簿の作法である。

| 名 | 分野 | 接触 |
|---|---|---|
| 灯守（ともり） | 印刷・製本 | 常時 |
| 灯守の妹 | 運搬 | 断続 |
| 灰野（はいの） | 校閲 | 常時 |
| 灰野の連れ | 通訳 | 一度 |
| 白壺（しろつぼ） | 会計 | 常時 |
| 白壺の父 | 土地 | なし |
| 圏（けん） | 法務もどき | 常時 |
| 圏の元同僚 | 行政 | 断続 |
| 畳屋（たたみや） | 施設 | 常時 |
| 畳屋の弟子 | 電気 | 一度 |
| 無名A | 記録 | 常時 |
| 無名B | 記録 | 断続 |

接触の欄は、K12の一年間に教団が実際に口を開いた回数の区分である。「常時」は月に一度以上、「断続」は年に数度、「一度」は一回きり、「なし」は名簿に載っているが接触の記録がないことを示す。なしの欄が最も重い。

---

## 編纂註

**一　呼称について。** この表は「精英名簿」と呼ばれる。教団の外では人材台帳、内では「畳の目」と呼ばれた。呼称が三つあること自体が、この仕組みの性格を現している。名簿は誰が有用かを記す帳面ではなく、誰がまだ畳まれていないかを記す帳面である。載ることは名誉ではなく、未処理の印である。載った者は、自分が載っていることを知らされない。知らされるのは、降りる資格を得たときだけである。名簿の外にいることが、この教団では最も安全な位置であり、同時に最も危うい位置でもあった。

**二　人に何をするか。** 載せられた側から見れば、名簿は静かに効く。まず、自分の分野が勝手に決められる。次に、その分野の依頼が、断る余地のない形で舞い込む。断れば「収束」を選んだことになり、第五品に照らして「慈悲の畳み」が適用される。適用は処罰ではない。感謝とともに、その者の担当が外される。外された者は、名簿から消えるのではなく、「接触なし」の欄へ移される。移された者は、自分がまだ名簿にいることを知らない。これが最も効く段階である。名簿は、載っていることより、載っているのに触れられないことのほうが強い。

**三　どこで壊れるか。** 壊れるのは、名簿と現実の対応がずれたときである。K12の春、無名Cの欄が「なし」のまま三度の配布に関わっていたことが発覚した。記録係は、接触の記録を取る権限を持っていなかった。権限のない者が記録を書いていた。この食い違いは、帳面の側ではなく、帳面を信じる者の側で壊れる。名簿は監査の対象にならない。監査する者が名簿に載っているからである。載っている者が載っている者を検査する構造は、必ず「なし」の欄を増やす。増えた欄は、やがて誰も読まなくなり、読まれない欄は、載っていない者と同じ扱いになる。

**四　同意について。** この仕組みは、同意を取らないのではない。同意を、名簿に載った後に取るのである。載った時点で分野は決まり、依頼は届き、断る理由は「収束」への恐れとして内側に作られる。その状態で「承諾しますか」と問うことは、答えを一つしか持たない問いである。ここで問うべきは、承諾の有無ではなく、承諾が可能な条件を誰が整えたかである。条件を整えた者が名簿の編者であり、編者は名簿に載らない。載らない者が最も多くを知っている。この非対称が、名簿という形式の本体である。名簿は、教団の欲望の一覧である。誰を欲し、誰をまだ欲しがっていないかが、行の順に並んでいる。
