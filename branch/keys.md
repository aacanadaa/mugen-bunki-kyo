# 支二　鍵

支所の鍵は、支所の数より多い。玄関、書庫、印刷室、金庫、そして「予備」。本部にとって鍵は設備の付属品にすぎないが、支所にとっては「最後に戸を閉めるのは誰か」という序列そのものである。支二は、その序列を記録に落とすためだけに置かれた。

| 鍵 | 者 |
|---|---|
| 玄関鍵（表） | 支所長 |
| 玄関鍵（裏） | 副支所長 |
| 書庫鍵 | 記録係 |
| 印刷室鍵 | 印刷担当 |
| 金庫鍵 | 支所長（副支所長が封緘して保管） |
| 予備鍵 | 本部管財（支所には置かない） |

交付は口約で行わない。日付、時刻、受け取った者の名を「鍵簿」に記し、双方が署名する。返納が翌朝までに確認できなければ、支所は本部へ報せる。報せを受けた本部がまず行うのは活動の停止ではなく、鍵の数の確認である。数が合えば、活動は止まらない。誰が持っているかは、問われない。

複製は認める。ただし複製のたびに、元の鍵の番号を鍵簿へ書き足す。番号のない鍵は、支所の鍵ではない。これは盗難対策ではなく、鍵を「個」から「数」へ変えるための手続きである。数えられるものは、失われても惜しまれない。

支所が閉じられるとき、鍵はすべて本部へ返る。返らない鍵については、返らない旨を記録し、その記録を閉鎖の記録と一緒に収める。閉じた支所の鍵が、後の支所で使われることはない。使われないために、鍵は数えられる。

## 編纂註

一、これは「末端の権力」の分配と呼ばれる。鍵は、組織の末端の権力である。小さな独占を渡し、小さな依存を返させる。人は鍵を持つことで、自分が組織の内側にいると感じる。壊れるのは、支所長が替わったときである。鍵の数は合うが、誰が持っているかの記憶だけが合わない。

二、金庫鍵の「封緘保管」は、使わない鍵を持たせる制度である。責任だけを渡し、権限は渡さない。人は封緘の前で、自分が持っているのか、預かっているのか分からなくなる。壊れるのは、封緘を切らねばならない夜が来たときで、そのとき切った者は、切ったことを記録しない。

三、鍵簿は「数えるだけの監査」である。数が合えば活動は続く。人は報告の形式を守ることに慣れ、判断することをやめる。壊れるのは、数が合ったときである。合ったという一事で、合わなかったはずの何かが、記録の外へ押し出される。
