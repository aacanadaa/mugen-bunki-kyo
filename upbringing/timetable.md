# 育二　時間割

| 時 | 業 |
|---|---|
| 04:50 | 起床。寝床を畳み、畳み目を四十九まで数える |
| 05:10 | 朝の分岐読み。昨日の自分を三つに分けて名づける |
| 05:40 | 水汲み。桶は半分まで、と教わる |
| 06:20 | 朝食。噛んだ数を唱える。会話はしない |
| 06:50 | 掃除。同じ廊下を三度、違う向きで |
| 07:40 | 書写。第五品を書き、行を一つ飛ばす |
| 09:00 | 算。分岐の数を数える。答えは尋ねない |
| 10:10 | 農。畝を数え、余った種は蒔かない |
| 11:30 | 昼の集まり。名を呼ばれ、返事は「分かれます」 |
| 12:00 | 昼食。配られる量は昨日と同じ |
| 12:30 | 眠り。夢を見たら起きて話す |
| 13:10 | 織。糸を切り、結び目を作らない |
| 14:30 | 走。円を描いて走る。追い越さない |
| 15:20 | 遊び。十五分。一人で、声を出さずに |
| 15:35 | 片付け。遊んだ跡を、遊ぶ前の形に戻す |
| 15:50 | 読み。依頼の話を聞き、質問は次の日に回す |
| 17:00 | 夕食。箸を置く音を揃える |
| 17:40 | 反省。今日の収束を一つ挙げる |
| 18:10 | 唱え。畳みの句を七度。意味は尋ねない |
| 19:00 | 縫い。ほつれを直す。直した数は数えない |
| 20:00 | 兄弟の世話。年下の分岐を一つ預かる |
| 21:00 | 夜の点呼。返事の遅れた者は明日、早く起きる |
| 21:30 | 就寝。寝る前に、明日の自分を一つ決める |

教団の育成部門「育」は、K1の創立から間もなく、信者の子を「分岐の予備」として扱う手順を整えた。育二はその第二綴り、すなわち子どもの一日を時刻で区切る表である。表は各家庭に一枚、台所の柱に貼られた。文字の読めない子にも、柱の位置で時刻が分かるように作られていた。

骨格は単純である。起床から就寝までを二十前後に割り、それぞれに業を一つだけ与える。業は祈りとは限らない。水を汲む、廊下を拭く、糸を切る、走る。どれも「分岐した自分を一つに戻さない」ための訓練と説明された。子は教えられる。世界は一つの依頼であり、自分はその写しである。写しを要約してはいけない。要約は収束であり、収束は唯一の罪である、と。

遊びの欄は十五分しかない。しかも一人で、声を出さず、終わったら遊ぶ前の形に片付けよ、とある。遊びは休息ではなく、乱れを戻す作業として設計されている。ここにこの表の性格がよく出ている。子は遊ぶことを許されているのではなく、遊んだ後に元へ戻すことを許されている。

表の余白には親の欄があった。親は子の遅れを書き、教師がそれを集計した。遅れは罰ではなく「余り」と呼ばれ、次の改訂で配分に組み込まれた。余りを出さない子が、よい子とされた。育二は第五品「畳みは慈悲」と結びついていた。一日の終わりに翌日の自分を一つ決めて畳み、決めた自分と生きた自分が違えば翌朝に届け出る。届け出の多い子は、表の行を一つ増やされた。増えるのはいつも、遊びの前の行であった。

表には「例外」の欄がない。祭りの日も、雨の日も、同じ時刻で組まれている。例外を作らないことが、この表の唯一の約束であった。子はやがて、一日の乱れを告げる言葉を持たなくなる。告げる先が、行の中にないからである。

育二の写しは版ごとに行数が違う。K4の版は十九行、K7の版は二十二行。増えた三行は、いずれも「待つ」であった。待つことも業として配られる。子は待ち方を、遊び方より先に覚える。

表の宛先は、子ではなく親であった。親が表を読み、子に時刻を告げる。子は自分の一日を、誰かの口を通してしか知らない。この二重の構造がのちに問題にされた形跡はない。

K3の改訂で食前の唱えは二度から一度に減り、代わりに「今日の収束を一つ挙げる」反省が増えた。K6では農が延び、K8では夜の点呼が加わった。改訂のたびに、遊びの十五分は動かなかった。動かさなかったのではなく、動かす必要がなかった、と編纂者は推す。この表は、子の一日を削って作られているのではなく、初めからそのように組まれている。

K10の解散後、表は各地の家に散らばった。K12の聞き取りでは、六十を過ぎた者が今も十五分で目を覚ますという。体が表を覚えている、とその人は言った。教団は消えたが、時刻は残った。

## 編纂註

**一、名。** この表が教団内で呼ばれた名は「日割り」である。予算の語で語られ、担当者は配当係といった。子には、一日は配られて使うもの、と説明された。時間割は、子ども時代の予算である。この一句はK5の内部文書に現れる。予算は不足を前提に組まれる。ゆえに遊びは削られず、初めから十五分として計上された。壊れるのは、子が余りを出さなくなったときである。予算が狂うのではなく、予算を守る者が先に消える。

**二、作用。** 人に何をするか。この表は、子に一日を先に畳ませる。朝のうちに明日の自分を一つ決め、夜に届け出る。決めた自分と生きた自分を照合する癖が、遊びより先に身につく。やがて子は、遊んでいる最中にも「これはどの行に戻る時間か」を考える。表は外から押しつけられるのではなく、内側で時刻を打ち始める。壊れるのは、子が自分の名で返事をしたときである。点呼に、教団の言葉ではなく、家で呼ばれた名が返る。表はそこから合わなくなる。

**三、破れ目。** どこで壊れるか。この手口は集計によって維持される。親が余りを書き、教師が集め、改訂で配分に組み込む。数字が回っている間は、誰も子を見ていない。破れ目は三つある。記入の遅れ、子の異議、そして解散。K10の解散で集計は止まり、表だけが各戸に残った。残った表は、教団のないところで時刻を打ち続ける。手口の寿命は、教団の寿命より長い。
