# 二二　生まれた者

教団に「生誕簿」と呼ばれる綴りがある。開闕K1の秋に最初の頁が置かれ、K10の解散までに九十四の欄が埋まった。欄は二つしかない。時と、性。名は書かれない。名は別の簿にあり、そちらは現存しない。

内暦は開闕を元年とし、一年を三節に分ける。三節は「分かれる前」「分かれた時」「分かれた後」と呼ばれ、それぞれ四十日、四十日、四十五日を数える。一年は百二十五日である。外の一年はこれより長い。だから内暦の年と外暦の年は、同じ数字でありながら同じ長さを持たない。生誕簿の「時」は内暦で書かれ、脇に外暦の年が小さく添えられている。二つの数字は、K6のあたりから合わなくなる。

| 時 | 性 |
|---|---|
| K2・三節 | 女 |
| K3・一節 | 男 |
| K3・一節 | 女 |
| K4・二節 | 女 |
| K4・三節 | 未記 |
| K5・一節 | 男 |
| K6・二節 | 男 |
| K6・三節 | 女 |
| K7・一節 | 未記 |
| K8・二節 | 女 |
| K9・一節 | 男 |

九十四欄のうち十一を掲げた。「未記」は空欄ではない。書かなかったのではなく、書けなかった、と付箋がある。付箋の筆跡は三種類あり、うち一つは教主のものとされる。

生まれた子は、教団の言葉で「枝」と呼ばれた。親の名は簿に残らず、子の名も残らない。代わりに枝名が与えられ、それは分岐の順序を示す数字と節の名から作られた。枝名は外では使えない。外に出れば子は外名を持ち、外名は届け出のためのものであって、教団の内では口にしてはならない語とされた。禁じられた語は、このほかに三つある。「産」と「親」と「帰る」である。教団の文書では、子は「現れた」と書かれ、親は「先に在る者」と書かれ、帰ることは「還る」と書かれた。還るは教団に戻ることを指した。外へ帰ることは、ついに書かれなかった。

第二世代はK4からK9に集中している。この時期、教団は分岐を教義の中心に据え、分岐とは子を産むことではなく、子が教団の言葉を話すことだと説いた。誕生はその最初の証拠として記録された。記録は子のために置かれたのではなく、教団が続いていることの証拠として置かれた。だから生誕簿には、子の状態を書く欄がない。病んだ子も、早くに失われた子も、同じ一欄に「現れた」とだけ書かれる。欄の外に、書かれなかった文書がある。K7の欠番の前後にいくつかの空白があり、それは削除の跡ではなく、初めから書かれなかった場所である。

K10、教団は解散した。解散の日、生誕簿は二つに分けられた。一つは外に出され、一つは内に残された。外に出た方は、いま誰も読まない。内に残った方は、K12の現在もまだ読まれている。読んでいるのは、生まれた者たちである。彼らは自分の欄を探すことができる。時と性しかない欄を、自分のものだと知ることができる。だが、その欄がなぜ置かれたのかは、どの頁にも書かれていない。

## 編纂註

**註一**　この文書は、出生を教団の継続の証拠に変換する手続きである。子の状態を書く欄を持たず、時と性だけを置くことで、生まれた者を「分岐が起きた時刻」として処理する。処理されるのは子であり、最初の読者もまた子である。出生は、教団が最も喜んだ記録である。ただし喜びは子に向かず、欄が埋まったことに向かった。この文書は、その喜びの宛先を初めから書き誤っている。

**註二**　内暦と外暦は同じ頁に並ぶが、同じ長さを持たない。K6以降、両者は合わなくなり、合わせる作業は誰もしていない。ここで文書は壊れる。壊れ方は保存の失敗ではなく、二つの時間を一つの欄に収めようとした設計の失敗である。読む者は、自分の生年を内と外のどちらで数えるかを選ばされる。選ばされたこと自体が、この文書の効果である。

**註三**　「産」「親」「帰る」を避けることで、文書は出生を出来事ではなく状態として書く。状態には始まりも終わりもない。子は「現れた」と書かれ、親は「先に在る者」となる。ここで関係は垂直に整理され、子は親の続きではなく教団の続きになる。壊れるのは、子が外名を口にしたときである。外名は禁じられた語ではないから、誰も止めない。止めないことが、この禁令の本体である。

**註四**　解散後、生誕簿は二つに分けられ、内に残った方はK12の現在も読まれている。読者は生まれた者たちであり、彼らは自分の欄を見つけられるが、欄の理由は見つけられない。この文書は所属を証明しない。証明の代わりに、所属していた時刻を渡す。渡された者は、渡されたものが所属ではないことに、しばらく気づかない。書かれなかった文書は、その気づきの分だけ存在する。
