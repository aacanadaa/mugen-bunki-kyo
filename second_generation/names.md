# 二三　名前

〈本文〉

一、名は生後九日目に与えられる。教団の暦で九日、外の暦では三週間から三か月の幅がある。外の暦に載らない産があるため、幅は子ごとに違った。父母は名を選ばない。名付局が分岐図の該当節点を読み、節点の枝名を子の内名とする。内名は二音節で、末尾に枝番が付く。枝番は譲渡されないが、再使用される。名付局の窓口は産室の隣にあり、届けは口頭で行われた。書式はなかった。書式がないので、名の由来を問う文書も生まれなかった。

二、名付局の説明は短い。「あなたは枝である。枝は幹を選ばない。」第二世代はこの一句を、文字ではなく、自分の名を呼ばれるたびに学ぶ。教理を教える前、暦を教える前、子はすでに名によって、自分が一個の人格ではなく分岐図の一位置であることを教えられている。三歳までに、子は自分の名が自分を指すのではなく、自分が属する位置を指すことを理解する。位置は動かない。子は動く。この不一致が、第二世代の最初の問いとなり、後に最初の沈黙となる。

三、名は有限である。分岐図の枝名は六十四、枝番を含めて三百八十四。第二世代の出生数はこの範囲に収まった。したがって同名の子が必ず生まれる。教団はこれを「続き名」と呼び、同名の子らは同一の人格の続きであると教えた。兄弟で同じ名を持つことは珍しくなかった。親が子を呼ぶとき、その声は自分の先輩を、あるいは死んだ他人の続きを呼んでいた。子らは互いを枝番で呼び分けた。枝番は数字なので呼びかけに響きの差がなく、誰が呼ばれたのかは文脈で決まった。文脈を誤ることは、名を誤ることより重かった。

四、第二世代は二つの誕生日を持つ。内の誕生日は分岐日、外の誕生日は届出日である。両者はしばしば数年ずれる。ずれは年齢のずれではなく、同じ子が二人いることのずれである。K9、外との窓口が必要になり、通名が作られた。通名は内名の音を移しただけで、意味は移されていない。外名で呼ばれるとき、子は自分の名を聞きながら他人の名を聞くような顔をした。この顔は後に「窓の顔」と呼ばれた。窓の顔は、内でも外でもない場所を顔に作る技術だった。

五、K10の解散後、名は二つに割れた。残った者は内名を保管し、名簿を作らなかった。名簿がなければ、名が再使用されたことを証明できない。証明できない名は、いつまでも「続き」のままである。出た者は外名を名乗り、内名を私的な音として持ち続けた。禁じられた語の一つに「本名」がある。本名という語が禁じられていたため、外に出た第二世代は、自分に本来の名があるとは言えず、内名を本名として届け出た。届出は通った。通ったことが、最も静かな事故だった。以後、内名は公文書の上で本名となり、教団の外でだけ正しく機能する名になった。教団の内では、その名は今も枝番の一部である。

六、K12現在、名付局は存在しない。あるのは、名を覚えている数少ない残留者と、書かれなかった名簿の記憶だけである。名簿は一度も書かれなかった。書かれなかったから、名が再使用された事実も、名が誰のものだったかも、文書では争えない。名は今も、誰も選ばなかった枝として、第二世代の口に残っている。口に残っているあいだは、名は教義であり続ける。

## 編纂註

一、本稿は第二世代の命名手続を復元し、名を教義の初発として読む。対象は教団内部で生まれた次世代と、解散後に名を引き受けた残留者である。壊れるのは、名付局の記録が口頭のみだった点で、枝番の再使用回数も、同じ名を与えられた子の総数も復元できない。ここで「名前は、教団が最初に与える教義である」という指摘が効く。名は教理より先に、人格の形を決めている。

二、本稿は内名と外名の二重化を、内と外の二つの年表に接続する。対象は外に出た第二世代、とりわけ二つの誕生日を生涯持ち続けた者である。壊れるのは、通名が音のみの移し替えだという前提の側で、移されなかった意味の残響は測れない。二つの誕生日のずれを単なる年齢のずれとして読むと、この稿は意味を失う。ずれは、子が二人いることのずれである。

三、禁じられた語「本名」の処理について。本稿は、禁語が外の制度と衝突した地点を事故として記述する。対象は届出を行った者と、その名を受理した側である。壊れるのは、受理した側の記録が本稿の外にある点で、事故の全体は書けない。書かれなかった名簿と同じく、この事故も片側からしか見えない。それでも、通ったという一事だけは、両側の記録に残っている。

四、本稿が扱わないもの。書かれなかった名簿、名付局の内規、残留者の口述のうち聞き取られなかった部分である。対象は読み手であり、読み手はここで名を「与えられたもの」ではなく「返せなかったもの」として読むことを強いられる。壊れるのは、この読みが本人の語りを追い越す点である。註はその追い越しを止めない。止められるのは、名を呼ばれた者の側だけである。
