# 二一　総論

〈本文〉

第二世代という語は、教団が自らの内部で生まれた子らを指すために用いた最初の区分名である。開闕K1の創立からK10の解散まで、教団は外部から加わった第一世代と、教団の内で生まれ教団の内で育った第二世代とを、教義の上でも暦の上でも別のものとして扱った。第一世代には回心の記憶があり、その記憶を語る言葉があった。第二世代にはそれがなかった。この非対称は、教団が自らを語る方法そのものを二重にした。

教団の独自暦は、この非対称を制度化した装置であった。教団暦は開闕を元年とし、外部の暦との換算を禁じはしなかったが、換算を必要とする場面を教団の生活から徐々に取り除いた。生誕、成年、婚姻、そして死の記録は教団暦によってのみ記され、外部の暦で書かれた書類は「外の年表」と呼ばれて、内の年表とは別の綴りに収められた。二つの年表は同じ人物の同じ生涯を、しばしば異なる年数で示す。第二世代にとって、自分の年齢は内の年表の数字であり、外の年表の数字は自分のものではない。

禁じられた語の多くは、第二世代の生活から発生した。第一世代が持ち込んだ外部の語彙のうち、教団の説明を相対化する語——たとえば「比較」「選択」「偶然」——は、K6前後の教令によって教団の場から除かれた。しかし実際に禁制の対象となったのは語そのものではなく、その語を用いて発せられる問いであった。第二世代は禁じられた語を知らないまま育ち、知らないまま、その語に代わる言い換えを教団の言葉として身につけた。教団の内側で最も流暢に教団語を話したのは、外部の語彙を一度も持たなかった者たちであった。

K10の解散は教団の暦を止めたが、第二世代の暦を止めなかった。解散後に残った者の多くは第二世代であり、彼らは教団の施設を出た後も内の年表で日付を数えた。外部の年表に合わせることを「外に出る」と呼び、外に出ることをためらいながら、外の書類に署名するためにだけ外の暦を用いた。この二重の時間感覚は、教義が消えた後も最も長く残った教団の遺物である。

書かれなかった文書とは、第二世代について書かれなかった文書である。教団は第一世代の回心の記録を大量に残したが、第二世代については、生誕と成年の記録以外のほとんどを残さなかった。彼らは教団の成果であると同時に、教団が自らを語る際の証人であり、証人を記録することは教団の物語を複数化する危険があった。K12の現在、この空白は欠落ではなく、教団が第二世代に対して行った最も一貫した記述である。

## 編纂註

**註一**　本稿は、第二世代を教団が用いた行政上の区分名として導入し、その区分が教義・暦・語彙の三層でどう反復されたかを記述する。読者は、教団の資料を外部から読む者と、解散後もなお教団の語彙を使う者である。壊れるのは、この区分を分析の単位として採用した箇所である。教団の区分は当事者の自己認識ではなく、本稿はここで当事者を「世代」に還元する。

**註二**　「第二世代は、教団の最も純粋な成果である」という句は、教団がK8前後の内部文書で用いた自己評価の引用である。本稿がこれを註に置くのは、この句を事実として採用するためではなく、教団が第二世代を成果として数えた視線を保存するためである。読者は、この句を教団の言葉として読む者と、教団の言葉をそのまま自分の言葉として受け取る者である。壊れるのは、引用と記述の区別が失われる箇所である。

**註三**　本稿は、内と外の二つの年表が同一の生涯を異なる年数で示すという観察を提示する。読者は、解散後に残った者と、その記録を整理する者である。壊れるのは、二つの年表を突き合わせて「正しい年齢」を決しようとする箇所である。二つの年表はどちらも教団の制度であり、外部の暦を基準に置いた瞬間、本稿は教団の二分法をそのまま反復する。

**註四**　本稿は、第二世代について書かれなかった文書を、欠落ではなく記述の一形態として読む。読者は、教団の空白を「隠された真実」として読む者である。壊れるのは、空白に意味を読み込む箇所である。書かれなかったことには理由があるが、その理由を本稿が推測するとき、推測は教団の物語を補完する作業に接近する。K12の現在、この接近を止める材料は教団の外にある。
