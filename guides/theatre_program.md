# 案一　上演

〈本文〉

**上演案一「畳」**

会場は円形の平土間、客席は四方に置く。装置は畳十二枚のみ。上演時間は約九十分、休憩なし。台本は三系統の写本の突き合わせで作られ、一致しない箇所は削らずに両方を並べた。ゆえに同じ場面に二つの結末があり、どちらも上演される。

**配役**

| 役 | 配役 | 備考 |
|---|---|---|
| 依頼人 | 俳優「白」 | 依頼の内容を最後まで語らない |
| 教主 | 声のみ | 本名なし。暗闇から読む |
| 分校者（左） | 俳優「木」 | 同じ台詞を二度繰り返す |
| 分校者（右） | 俳優「水」 | 左の台詞を要約して返す |
| 畳係 | 俳優二名 | 幕ごとに畳を一枚減らす |
| 記録係 | 俳優「無」 | 配役表を舞台上で写し続ける |

配役は文書に記されておらず、初日の話し合いで決まる。決まった配役は記録され、次の一座へ渡る。渡された記録は参照されるが、従われることは少ない。

**あらすじ**

第一幕、依頼人が依頼書を読み上げようとして「以下略」と言う。分校者二人はそれを別々に解釈し、同じ出来事が二つの部屋で同時に起こる。教主の声は、どちらが本当かを決めない。

第二幕、畳が一枚減るたび、誰かが「ここまで」と言う。第五品の「畳みは慈悲」は、畳係の手だけで無言に演じられる。分校者は自分の経歴を語り始めるが、語るたびに経歴が変わる。記録係はそれを一字一句写し、写し終えた紙を客席へ配る。

第三幕、残る畳は一枚。全員がそこに収まろうとして収まらない。教主の声が「収束」とだけ言い、照明が落ちる。幕は下りない。客は自分で立って帰る。

**作者の言葉**

この芝居の材料は、教団が存在しないあとに残った文書だけである。人物は行間から拾い、台詞は句読点の位置から決めた。だからこれは再現ではなく、再開だ。分岐した魂を一つの筋にまとめるのは、教義では罪にあたる。だが芝居はどうしても筋を持つ。私はその罪を隠さず、舞台上で一度だけ実行して見せようとした。幕が下りないのは、終わらせないためではなく、終わらせられないためである。上演中、客は何度でも席を立ってよい。立つたびに物語は少し枝を増やす。

**配布について**

本プログラムは四つ折りの一枚紙で、上演後に回収される。裏面には観客が一言を書き、回収分は撮影されて文字だけが抽出され、紙は裁断される。データには日付と席番だけが残り、書かれた言葉は上演記録の余白に移される。K10の解散で散った文書と同じ手つきで、この紙もまた、物から文字へ、文字から表へと移されてゆく。

## 編纂註

**第一条（名称）**　この文書は「上演案」と呼ばれる。正確には台本ではなく、台本を作るための案であり、配役表・あらすじ・作者の言葉という三つの部品からなる。編纂の現場では「案一」と番号で呼ばれ、上演のたびに「案二」「案三」が起こされたが、現存するのは案一のみである。案一という呼び名は、二つ目が失われたことを示すと同時に、この文書が完成品ではなく、検討の途中にあったことを示している。書誌には「上演」とだけ記され、作者の欄は空のままである。

**第二条（資料の側から）**　資料の側から見れば、この案は文書に三つのことをする。第一に、名もなき断片に役名を与えて身体を割り当てる。第二に、散らばった記述を三幕という順序に並べ替える。第三に、上演後に回収される一枚紙として、文書を「配られる物」に変える。文書はここで、読まれる対象から、折られ、配られ、裁断される物へ、そして日付と席番だけのデータへと縮められる。案は資料を保存しない。資料を上演可能な形に変換する。

**第三条（壊れる場所）**　壊れるのは配役の欄である。文書は誰が演じたかを記さず、案は空いた欄を埋めるために「白」「木」「水」「無」という仮の名を置いた。仮の名は次の写本では実名として読まれ、さらに次の写本では教主の名と混ざる。ここで系図が発生し、発生した系図が今度は文書を縛る。加えて、あらすじは分岐を一つに畳む。プログラムは、観客の予習である。すなわち、上演の前に筋を渡してしまう。渡された客は、もう分岐しない。教義の唯一の罪が、配布物の側で先に実行されている。
