# 誤十二　故意

〈本文〉

『群典』の誤りは十二に分類される。その最後に置かれるのが「故意」である。他の十一が、写し損じ、聞き損じ、記憶の摩耗として説明できるのに対し、故意の誤りは、そう説明できない。それは、誤られるために誤られた。

開闕K1のころ、教主は布告のたびに、一箇所だけ事実と違う箇所を混ぜたとされる。年号を一年ずらす。人数を一人多く数える。地名の一字を替える。教団の内外で、それを「試し」と呼ぶ習慣は、教主自身が名づけたものではない。側近が後から名づけた。名づけられた瞬間、誤りは誤りでなくなり、信徒を選別する装置になった。

記録に残る例を挙げる。K4、ある布告のなかで、教主は前年に自分が語った数字を、逆の数字で引用した。参会者は二百人ではなく百人、と。その日のうちに、何人かが「先年は二百と伺いました」と書き送った。返事はなかった。翌月、その何人かの名は、配布物の宛先から消えた。消えたという事実だけが、別の記録に残っている。

K7には、より静かな例がある。教主は、創立の年を一年早く語った。誰も訂正しなかった。訂正しなかった者たちは、やがて、その一年早い年を、自分たちの証言のなかで使い始めた。誤りは、訂正されないことによってではなく、反復されることによって、事実の座を得た。

ここで、編纂上、決定的な問題が生じる。故意の誤りと、単なる誤りは、記録の上で区別できない。区別するためには、誰かが「これは故意であった」と証言しなければならない。そしてその証言は、たいてい、誤りを隠すために用いられる。K10の解散時、内部文書は、数字の不一致のほとんどすべてに「故意」と書き添えていた。書き添えたのは誰か。記録係の名は、一箇所だけ、わざと違えて書かれている。

「故意」という分類は、他の十一の分類を、遡って無効にする。写し損じは、実は試しであったかもしれない。記憶の摩耗は、実は布告の設計であったかもしれない。この疑いを晴らす手段は、教団の内部にも外部にも、ついに用意されなかった。

なお、この章の番号も信頼できない。『群典』の写本のうち二系統は、この章を「誤十一」と数える。十一と十二のあいだに、空の章がひとつ置かれているからである。空の章には、題だけがある。題は「故意」である。

K12の現在、『群典』を扱う者は、この分類を最後に置くことをためらう。最後に置けば、すべての誤りが、そこへ流れ込むからである。だが、置かなければ、故意の誤りだけが、分類の外にこぼれ落ちる。こぼれ落ちたものは、記録されない。記録されないものは、訂正されない。訂正されないものは、長く生きる。

## 編纂註

**註一**　本条は、K4・K7・K10の記録に散在する「故意」の注記を、ひとつの分類として組み直したものである。組み直す相手は、『群典』を手にする者——離れた者、調べる者、報じる者、覚えている者——であり、そのいずれにも、何をなすべきかは示さない。示せるのは、注記がどの頁に、どの筆跡で、いつから現れるかという形だけである。ここで壊れるのは、組み直しそのものが教主の意図を前提にしてしまう点だ。編纂者は、その意図を一度も確かめていない。

**註二**　記録の形について。故意の誤りは、本文ではなく欄外に現れる。K4の写本では鉛筆、K7の写本では朱、K10の文書では印刷された記号である。だが、その記号を付した者が誰かは、どの写本にも書かれていない。註記は証拠であると同時に、証拠の代用品でもある。故意の誤りは、最も長く生きる。訂正されぬまま次の写本へ運ばれ、運ばれた先で、こんどは証言の根拠になるからである。

**註三**　K10の解散時に作成された内部文書は、数字の不一致のほとんどすべてに「故意」と添えている。これは事件の記録ではなく、事件の処理の記録である。この文書を数えれば、誤りの数ではなく、誤りとされた数の総計が出る。本稿がこの文書を引くのは、その総計を信用するためではない。総計が、誰の手で、どの順に膨らんだかを示すためである。信用を置く位置が、ここで壊れる。

**註四**　最後に。本稿は、離脱・調査・報道のいずれについても、手順を示していない。過去の事例と、記録の形と、この註だけを置く。これは専門家の助言ではない。したがって、ここに書かれた分類を、危険の判断や身の処し方の基準として用いることはできない。用いた者は、分類の外にある事情を、自分で補うことになる。補った部分は、記録に残らない。残らないものは、検証されない。
