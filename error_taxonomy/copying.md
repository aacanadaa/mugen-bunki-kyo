# 誤八　写し

〈本文〉

写しの誤りは、読み違えではない。読む者が意味を疑うのに対し、書く者は意味を汲む前に手を滑らせる。だから誤りは無作為に散らばらず、いくつかの型に寄る。本項は、群典周辺文書に現れた型を三つに限って記す。三つで足りるとは言わない。三つなら数えられる、と言うだけである。

一に、落ち。同じ語尾や同じ字が近くに続くとき、書写者の目が行を飛ばし、あいだの一句が欠ける。長い祈願句の末尾が二度続く箇所で、片方の「闕」の字が消えた例がある。欠けたことを示す空白は残らない。写しは、無いものを無いまま差し出すので、後から来る者は欠けたことに気づかない。気づくのは、別系統の写しと並べたときだけである。

二に、重なり。今度は逆に、目が戻る。同じ行を二度写し、あるいは欄外の訂正を本文に取り込んで、語が二重になる。「開闕、開闕」と続く箇所を、教義の強調と読む者と、手の往復の痕と読む者がいる。両者は同じ紙を見ている。見ている場所が違う。重なりの厄介さは、誤りが熱意の形をとるところにある。

三に、取り違え。形の近い字、音の近い語、数の桁。K一とK十は、横棒の一本で入れ替わる。教団の年代は、この種の誤りで一度ずれた。ずれた年代の上に、後代の解釈が建った。建ったものは、もう動かない。動かすには、誤りを誤りとして示すほかないが、それをすると建物ごと揺れる。だから多くは、揺れない方を選ぶ。

これら三つは、いずれも意味の側からは説明できない。書写の場の条件——紙の幅、灯の明るさ、疲労、前任者の癖——が、誤りの形を決める。写しの系統をたどるとは、教えの変遷をたどることではなく、手の履歴をたどることである。両者は重なる。重なるが、同じではない。同一視した瞬間に、分類は教義の一部になる。

K十の解散で、文書は三つの写しに分かれた。K十二の現在、原本と呼ばれるものはない。あるのは、互いに少しずつ違う写しと、その違いを説明する註だけである。註は、違いを消さない。消さないまま、違いの出来るだけを記す。今日もどこかで、誰かが読んだものを書き写している。その手が滑るかどうかを、こちらから指定することはできない。

## 編纂註

一、本項は、写しの誤りに三つの名を与え、違いを読むための最小の語彙を並べる。分類は記述であって、判定ではない。型に当てはまらない誤りは残る。残るものを残るまま置くために、この註がある。本項は教団の教説の真偽には触れない。触れれば、写しの話が信仰の話に変わる。

二、この文書は、離れる者、調べる者、報じる者、覚えている者に、記録の形を渡す。渡すのは形だけである。何をすべきか、どこに問い合わせるか、どう身を構えるかは書かない。それは専門家の領分であり、本註は専門家の助言ではない。過去に何が起きたか、どんな紙が残ったか、誰が何を写したか。それだけを並べる。

三、壊れるのは、分類が実物より先に立つところで壊れる。写しの偶然を教義の意図と読み、意図を読んだ者がまた写す。そのとき誤りは、誤りであることをやめ、証拠になる。証拠になった誤りは、もう分類できない。本項の三つは、その手前で立ち止まるための道具である。道具は、使う者の数を数えない。

四、写し間違いは、最も古い誤りである。石に刻むより前から、人は写していた。最も古いということは、最も見えにくいということでもある。古い誤りは、正しさの形をしている。だからこの文書は、誤りを数えるのではなく、誤りが数えられる形を保つことだけを目的とする。これは専門家の助言ではない。
