# 解二　報告

〈本文〉

一、件名
旧分院「閉座舎」躯体解体および残置物処分の報告。

二、対象
木造二階建、延床六百四十二平方メートル。増築四回。廊下は一本も直進しない。図面は三種あり、いずれも一致しない。K9の閉座以後は無人のまま、K10の解散宣言で管理主体が消えた。名義人のいない建物として、所管の手続きにより発注した。

三、工期
着工から四十七日。うち十九日は、壁を壊す前に壁の内側を記録する日に充てた。壊すのは速い。記録するのが遅い。残る二十八日で、延床六百四十二平方メートルを更地にした。

四、費用
総額 六千四百二十万円。本体工事 三千八百万円、残置物の分別と運搬 二千百万円、記録の作成 五百二十万円。記録費は解体費の一割四分にあたる。この比率は、通常の解体ではまず出ない。

五、廃棄物
木くず 百八十七トン。石膏ボード 四十二トン。金属 十一トン。畳 千三百四十枚。紙 六・八トン。
紙は重量では最も少ない部類に入る。容積では最大だった。押入れ、天井裏、床下、柱の間、二階の床を剥がしたときに現れた旧配管の隙間から、紙が出た。同じ文書が七部、別々の場所から出た。七部とも、少しずつ違っていた。

六、方法
手壊しを原則とした。重機は最後の三日のみ。壁の多くは、表から見ると一枚、裏から見ると三枚あった。三枚のあいだには、断熱材の代わりに畳が一枚ずつ挟まっていた。

七、数字の不整合
図面の面積は六百四十二平方メートル、実測は六百九十一平方メートル。差の四十九平方メートルは、四回の増築のたびに内側へ足された分である。廃棄物の伝票は合計六百三十九トン、実重量は六百四十一トン。二トンの差は、紙の含水率では説明がつかない。再計量はしていない。

八、所見
この建物は、人を収めるために建てられていない。物を収めるために建てられ、人はその隙間に収まっていた。撤去後の更地は、元の建屋より九十平方メートル狭い。測量の誤りではない。増築のたびに、建物は外へではなく内へ太った。

以上、報告とする。数字は正確である。正確さについては、保証しない。

## 編纂註

**註一　「増築」**
教団が一人に対して行うのは、教義の提示ではない。すでにある建物に、小さな部屋を一つ足すことである。足すたびに「今回は改修にすぎない」と言う。被害の側から見れば、毎回が小さな工事で、毎回が同意の上で、気づいたときには廊下が一本も直進していない。壊れるのは、増築が既存の廊下を必ず曲げる点である。曲がりは図面に残り、曲がった回数だけ図面が増える。

**註二　「分別」**
残置物を種類ごとに分けさせる手口。被害者は自分の持ち物を自分で分類させられ、分類の基準は文書ごとに違う。分類できないものは「未分類」として一括で処分され、処分の立会いだけが本人に求められる。壊れるのは、分別の基準が文書の数だけ存在する点である。基準が増えるほど、持ち物は本人の手を離れる。

**註三　「実測」**
数字を先に決め、現物をその数字に合わせる手口。被害の側からは、自分の記憶が伝票の数字に置き換わっていく。昨日は五つあったものが、伝票では四つであり、四つが正しいと告げられる。壊れるのは、伝票の合計が合わない点である。合わないことを説明するために次の文書が要り、次の文書もまた合わない。解体の数字は、建物がどれだけ詰まっていたかを示す。詰まっていたのは物だけではない。
