# 疑十一　言い換え

本表は、K10解散後の記録整理において、各地の集会記録から拾い出された言い換えを、元の語の側から並べ直したものである。教団が配った語彙表ではない。使われた順に、使った者の側から復元した。

| 元 | 教団語 |
|---|---|
| 疑い | 未整理の枝 |
| 質問 | 分岐の申告 |
| 反対 | 単線の希望 |
| 批判 | 収束への傾き |
| わからない | まだ遠い |
| 間違い | 別の枝 |
| 疲れた | 枝が重い |
| 帰りたい | 本流を思い出した |
| 信じられない | 今日は届かない |
| 説明してほしい | 枝を見せてほしい |
| 秘密 | 幹の内側 |
| 罰 | 枝を戻す手 |
| やめる | 単線に戻る |
| 死 | 閉座 |
| 教主 | 本名のない人 |
| 家族 | 古い枝 |

表は暗記を求めない。壁にも貼られない。ただ、同じ場で二度目に口をついたとき、相手が少し待ち、それから教団語で言い直す。その待ち時間が、語を入れ替える。

---

## 編纂註

一、この記録がしていること。対応表は翻訳ではなく置換である。元の語を禁じない。禁じれば外へ出て行く。代わりに隣に別の語を置き、口を開くたびに後者を選ばせる。疑いは語彙から消えない。発話の入口から消える。記録者自身、元の列を書くときどちらの語で書くべきか迷った跡があり、その迷いは消されていない。

二、誰に何をするか。入ったばかりの者に、である。最初の数か月は両方の語を使える。仲間の前で元の語を出すと、訂正はされない。ただ、言い直しを待たれる。半年で元の語は内緒の語になり、一年で、疑いたいときに使う語が出てこなくなる。疑う力ではなく、疑いを口にする手順が失われる。

三、どこで壊れるか。表の外である。対応する行を持たない語が来たとき、表は働かない。「なぜ」はどの枝にも当たらない。「なぜ」を口にした者は、表を引くのではなく、表を書いた者を思い浮かべる。K9閉座の前後、各地の記録に「なぜ」だけが、言い換えられぬまま残っている。

四、註記。言い換えは、疑いを語彙から消す。だが元の列は教団の外の言葉で書かれている。外の言葉で書かれた以上、この表は教団の語彙を外へ持ち出せる。読む順序が逆になれば意味は反転し、疑いの一覧が教義の一覧に見える。K12現在、この表は両方の読みに耐える形で残された。
