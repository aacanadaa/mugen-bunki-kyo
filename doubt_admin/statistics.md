# 疑七　統計

疑いは教団の教義に項として存在しない。世界は一つの依頼であり、魂は分岐し、唯一の罪は収束である。この三項に「疑い」はない。それでも疑七は作られ、疑いは数えられた。数えるには、疑いを同定し、分類し、宛先を定めねばならない。定めた瞬間、疑いは教義の外から内へ移る。

本表は開闕K1からK12に至る疑い申告の受理件数と処分を年度別に示す。件は申告の件数であり、申告者の人数ではない。同一の申告が複数の窓口に届いた場合も、一人が同じ疑いを繰り返し述べた場合も、それぞれ一件と数えた。処分の欄は最終の扱いのみを略記し、審理の経過は含まない。

| 年 | 件 | 処分 |
|---|---|---|
| K1 | 3 | 不問 |
| K2 | 5 | 記載 |
| K3 | 8 | 記載 |
| K4 | 11 | 不問 |
| K5 | 19 | 再聴 |
| K6 | 27 | 記載 |
| K7 | 41 | 分岐留置 |
| K8 | 63 | 反復聴取 |
| K9 | 208 | 封緘 |
| K10 | 31 | 宛先不明 |
| K11 | — | —（数える者なし） |
| K12 | 6 | 宛先不明 |

K1からK4までの件数は少ない。教団が小さく、窓口が一つしかなかったためである。K4に一件、教主自身の名で申告が記録されている。教主が教主を疑った唯一の例であり、処分は不問、件数の内訳に「本人」とだけ注記されている。

K5からK8にかけて件数は増える。増えたのは疑いではなく窓口である。側近の内申と街からの外申が別の帳簿に付き、のちに本表へ統合された。統合の際、重複の照合は行われていない。

K9の急増は閉座に伴う手続の混乱を映す。この年の申告の大半は、教義への疑いではなく、処分の遅延への疑いであった。疑いが疑いを呼ぶ構造が、件数として現れている。

K10の解散以後、件数は落ちるが零にならない。宛先を失った申告は記録係が受け取り、封をして棚に置いた。K11が空欄なのは申告がなかったからではなく、数える者がいなかったからである。K12の六件は解散後に街から届いたもので、処分欄はすべて「宛先不明」である。

分布にも偏りがある。全期間を通じ、申告の八割は教主の言葉の要約に関わる。要約は収束であり、収束は罪である。だが要約なしに教団は何も伝えられない。この循環を解くために疑七は設けられ、疑七は循環を解かず、循環の件数を数えた。

処分の語彙は年ごとに変わる。K1からK6は「不問」「記載」「再聴」の三語、K7以降は「分岐留置」「反復聴取」「封緘」「収束宣告」に増えた。語が増えるほど、同じ語が指す範囲は狭くなる。狭くなった分だけ、名を持たない疑いが表の外に落ちた。

合計欄は設けていない。合計は収束であり、収束は罪であるため、とK9の覚書にある。実際には各年の欄は足せば合計になる。禁止は計算を妨げず、計算の公表だけを妨げた。

## 編纂註

一、本記録は、疑いを数え、分類し、処分の名を与える。疑いは数えられることで、一回性の出来事から反復可能な手続へ移される。すなわち、疑いを数えることは、疑いを制度にすることである。制度となった疑いは、もはや教義の外にある私的な動揺ではなく、宛先を持ち、欄を持ち、次年度へ繰り越される公的な項目となる。数えるという行為は中立的な観察ではなく、観察の対象を教団の内側に作り直す操作である。

二、本記録は、申告者を「申告した者」という役に固定する。側近は内申の宛先となり、街は外申の宛先となる。申告は受理され、記録され、しかし審理はされない。審理の不在は処分欄の「不問」という一語に圧縮され、その語は申告が検討されたことを含意する。申告者は、自分の疑いが検討されたのかどうかを、この表からは知ることができない。

三、件数は疑いの量ではなく窓口の量を映す。K5以降の増加も、K9の急増も、K11の空白も、疑いの増減ではなく、数える者の配置の変化である。数えられなかった疑いは零として現れ、零は不在と区別されない。表は「疑いがなかった年」と「疑いを数えられなかった年」を同じ記号で書く。ここで記録は、自らが測っているものを測れなくなる。

四、本表は申告された疑いだけを含む。言葉にならなかった疑い、宛先を知らぬまま消えた疑い、教主が口にしなかった疑いは、いずれも欄を持たない。欄のないものは集計の際に零として扱われる。零は無害に見えるが、本表において零は「数えなかった」と「数えられなかった」と「数えたくなかった」の三つを同一の文字に畳み込んでいる。畳み込みは収束であり、収束は罪である。
