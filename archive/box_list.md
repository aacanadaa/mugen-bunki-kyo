# 箱一　目録

回収はK10の解散宣言より後、立入禁止の貼られた旧会堂から行われた。什器は処分され、壁の掲示は剥がされ、残ったのは段ボールだけであった。番号は回収の順に振られており、教団の内部序列とは一致しない。以下は箱の外側に記された墨書と、開封の際に取られた控えの突き合わせである。

| 箱 | 中身 |
|---|---|
| 一 | 教義草稿。第五品の異本三種、うち二種は畳みの比喩だけが違う。 |
| 二 | 十二使徒の名を刻んだ木片。切・流・重・沈の四片が欠けている。 |
| 三 | 集会の受付名簿。K9以降の頁は白紙で、綴じ穴だけが増えている。 |
| 四 | 教主の筆とされる書簡。宛名がなく、日付もない。 |
| 五 | 分岐の図。線は途中で途切れ、収束の側だけが太く引かれている。 |
| 六 | 閉座の議事録。発言者はすべて「一」と記される。 |
| 七 | 会堂の鍵。どの扉のものか記されていない。 |
| 八 | 寄託金の受領証。金額欄は空欄、印だけが押されている。 |
| 九 | 写真。人物は写っておらず、椅子と窓だけが写る。 |
| 十 | 未配布の冊子。表紙に「要約するな」と一行。 |
| 十一 | クレームの投書。投函者の署名はすべて同じ筆跡である。 |
| 十二 | 空の箱。内側に「箱一」と書かれている。 |

十二箱のうち、中身が判明したのは九箱である。残余は目録の空欄として残り、編纂の都合で埋められることはなかった。

---

## 編纂註

**第一条　目録化**
目録は、対象を数え上げることで対象を所有したと錯覚させる手口である。被害の側では、数えられた瞬間に自分の経験が「項目」に置き換わり、語る順序を失う。箱の番号は回収の順であって、教団の秩序ではない。この目録もまた、散逸したものを並べ直すことで、存在しなかった統一を捏造している。壊れるのは、番号の外側にこぼれたものが思い出されたときである。

**第二条　欠番の演出**
欠けた箱を「欠番」として明示するのは、不在を権威に変える手口である。受け手は、無いものを探す務めを負わされ、探している間は教団の論理の内側に留まる。被害の側では、空欄が自分の記憶の空白と重ねられ、埋めるのは自分だと錯覚する。壊れるのは、空欄が最初から空欄ですらなかったと気づいたとき、つまり箱十二の内側に箱一の名を見つけたときである。

**第三条　残余の呼称**
「残余」と呼ぶことは、分類から漏れたものを、分類の側の言葉で呼び直す手口である。被害の側では、漏れたものが価値のないものとして処理され、語る資格を失う。実際には、箱は組織の残余ではなく、組織の方が箱の残余である。壊れるのは、残余と呼ばれた側が自ら名乗り始めたときで、そのとき目録は単なる紙に戻る。
