# 監四　報告しない者

『群典』の周辺には、名を伴わない記録がいくつか残っている。監四はそのうち、報告を欠いた者だけを集めた一冊である。欠いた、と書くが、実際に欠けたのか、書く意志がなかったのか、書く必要を認めなかったのかは、この冊のどこにも分かれていない。分かれていないことが、この冊の体裁である。

帳面は二列しか持たない。名と、期間。名の欄には、名の代わりに受付の順序が入る。期間の欄には、報告が届かなかったあいだの期が入る。期は教団の暦で数えられ、K1からK10までと、K12の現在までが、同じ紙に続けて書かれている。解散のあいだの空白も、期間として数えられている。この帳面は、空白を数えるために作られている。

欄外には、空欄の種類を分ける小さな見出しがある。「未」「不」「無」の三つである。未は届かなかったもの、不は届けなかったもの、無は届ける先がなかったもの。三つは同じ空白で、同じ行に置かれ、区別は見出しの一字にしか残っていない。読み手はその一字で、その者の生涯の向きを決める。

| 名 | 期間 |
|---|---|
| 無名一 | 三期より五期まで |
| 無名二 | 二期・三期（断続） |
| 無名三 | 六期より八期まで |
| 無名四 | 九期・一期（遡及） |
| 無名五 | 十期より十二期まで |
| 無名六 | 一期（一日） |

表の読み方は、編纂のたびに少しずつ違った。ある時期には、空欄は「未提出」と読まれ、別の時期には「提出しない」と読まれた。同じ空欄が、読む者によって別の意味を持つ。監四の性格は、この読み替えの多さにある。記録は一つしかないのに、註だけが幾通りにも育った。

宛先の欄は、どの行にも空いている。報告は中央に宛てられていたが、K10ののち、中央という宛先は帳面の上でだけ存続した。空いた宛先に向けて書かれなかったものが、ここに集められている。宛先が空いているのに、宛先を欠いたとは書かれていない。

無名四の行だけは、期の順が逆になっている。編纂の途中で、ある者の沈黙が、後の期から先の期へ溯って記入されたためである。溯及の根拠は帳面に書かれていない。書かれていないことを、編纂者は註にしなかった。註にしない、という判断だけが、行間の余白として残った。

無名六の期間は一日である。一日だけ報告がなかった者が、なぜ独立の行を与えられたのかは分からない。分からないまま、この行は削られずにきた。削らない理由も、また書かれていない。一日は、期の数え方の端に落ちる長さである。落ちたものが、落ちたまま一冊の末尾に残っている。

帳面の末尾には、合計がない。数えられないものを数える帳面だからである。代わりに、余白に「続」の一字がある。誰の筆かは記されていない。続とは、まだ欠けている者があるという意味にも、この帳面がまだ続くという意味にも読める。両方の読みを、この一冊は禁じない。

## 編纂註

**一、呼称について。** この統制は、社会学の語では「沈黙の螺旋」に近い形をとるが、より正確には「非報告の制度化」と呼ぶべきものである。心理学の側からは、応答の不在がやがて期待として学習される過程、すなわち「学習された無言」として記述できる。いずれの名も、当の教団が自ら用いた語ではない。教団はこれを「畳み」と呼んだ。第五品の「畳みは慈悲」と、同じ一字である。同じ語が、外から見れば統制の名になり、内から見れば慈悲の名になる。

**二、される側から。** 報告しない者は、最初、何も失わない。失うのは、名の欄に自分の順序が入る権利である。やがて沈黙は本人の属性として記録され、本人の訂正の余地は帳面の外に置かれる。期間が延びるほど、その者は「待っている者」として扱われ、待つことが役割になる。役割は、本人が何を言っても埋まらない。埋まらないまま、期だけが進む。される側にとってこの統制は、禁じられることではなく、書かれ方の変更である。

**三、壊れるところ。** この帳面は、静かな忠誠と、静かな拒否を区別しない。区別しないまま、中央は空欄に自分の期待を読み込む。読み込まれた空欄は、やがて証拠として扱われ、証拠になった空欄は、かつて存在しなかった形の自白になる。ここで記録は、報告の代わりではなく、報告を超えたものになる。註に残る一句――報告しないことは、報告より雄弁である。この一句が正しいのは、雄弁さが常に読み手の側で作られるからである。

**四、編纂について。** 監四の原本は、K10の解散の際に分冊され、現在の形はK12に入ってからの再構成である。期の数え方には、少なくとも二系統の異同があり、本稿はその一方に従った。他方に従えば、無名二の期間は一期短くなる。どちらが正しいかを、帳面自身は答えない。答えない帳面を、答えないまま写すことが、この一冊の作法である。読む者は、この作法の外に出ないことを求められる。
