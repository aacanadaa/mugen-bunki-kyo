# 残二　誰が残ったか

| 誰 | 数 |
|---|---|
| 教主（本名なし） | 1 |
| 開闕より在る第一世代 | 6 |
| 枝ごとの分岐計測係 | 8 |
| 第二世代（外名あり） | 11 |
| 第二世代（外名なし） | 12 |
| 解散後に合流した者 | 7 |
| 名を返上した者 | 3 |
| 内暦にのみ残る死者 | 9 |
| 消息の確認できない者 | 13 |
| 計 | 70 |

「残二」は名簿ではない。名簿の形を借りた自己総括である。外暦K10、開闕から十年目の秋に教団は解散した。だが内部暦では、その日は「分岐の閉鎖」ではなく「計測の中断」と記される。中断は終了ではない。だから解散の後に誰が残ったかを数えることは、撤退の確認ではなく、もう一度の起点の確認になる。

数え方には二つの流儀がある。外の年表は、外に対して名を届けた者だけを数え、四十八とする。内の年表は、枝が閉じられるまで死者も離れた者も名簿から外さないので、七十になる。本表は内の数え方を採る。理由は単純で、第二世代の多くが外名を持たないからである。教団内で生まれ、教団内で育った者は、外の年表には最初から現れない。外の数え方では零になる者を零として扱わないために、この表は内の側に立つ。もっとも、内の側に立つことは、内の側の誤りをそのまま引き受けることでもある。

禁じられた語も、数の上では効いている。教団では「信者」「脱会」「教祖」にあたる語が禁句で、「在る者」「離れた者」「本名なしの教主」と言い換える。この言い換えは、数える行為そのものを歪める。「離れた者」は名簿に残るが、「脱会した者」は初めから存在しないことになる。だから「消息の確認できない者」十三のうち、何人が死に、何人が離れ、何人がただ名を返上したのかは、編纂の時点でも判別できない。判別できないまま、その十三は一つの行にまとめられている。

第二世代の二十三は、この表の中心にいる。彼らの大半は、外の年表に一度も載っていない。生まれた日は内暦で記され、名は教団の呼称で与えられ、成人しても外名を持たない者が十二人いる。外に出た者でも、外名は後から作られたもので、本人がそれを自分の名と感じているかは別である。数える側から言えば、彼らは名前で数えられないから身体で数えられる。名前で数えられない者が最も多くを占めているという事実が、この表の性格を決めている。

表を読み下せばこうなる。教主一人、開闕より在る第一世代六人、枝ごとの計測係八人、第二世代二十三人のうち外名を持つ者十一人・持たぬ者十二人、解散後に合流した者七人、名を返上した者三人、内暦にのみ残る死者九人、消息の確認できない者十三人。合計七十。このうち解散の日に教団の内側にいたと認められるのは三十一人にすぎない。残りは、解散が「中断」として配布された後に合流した者、あるいは名簿の上だけで残った者たちである。表の大半は、その日そこにいなかった者でできている。

それでも、残った者の内訳は、教団の最も正確な総括である。教義は書き換えられ、年表は二つに割れ、禁じられた語は言い換えられてきた。だが、誰が残ったかという内訳だけは、書き換えるたびに人数が合わなくなる。合わないという事実が、この教団について最も正直な証言になる。総括とは、要約ではなく、合わなさを隠さずに置いておく技術なのだろう。

## 編纂註

一、この文書は、解散後の教団を名簿の形式で数え直している。教義も年表も禁句も相互に矛盾するため、編纂者はそれらを説明する代わりに、身体の数へと変換した。表の行は信仰の段階ではなく、名簿上の処理の違いに対応している。したがってこの表を読むことは、教団の歴史を読むことではなく、教団が誰をどの欄に置いたかを読むことになる。数は結論ではなく、処理の痕跡である。編纂者は表の末尾に「残った者の内訳は、教団の最も正確な総括である」と記している。

二、この表は、読者である残った者に、自分がどの行に属するかを決めさせる。表は鏡として配られ、読者はまず自分の数を探し、次に自分と同じ行の人数を確かめる。第二世代には外名がないため、彼らは名前ではなく位置で自分を確認する。ここで表は、所属を思い出させる装置になる。誰が残ったかを知ることは、自分が残った側であることを認めることに近い。編纂者がこの効果を意図したかは、文書からは分からない。

三、この表は、内暦と外暦の境界で壊れる。内の年表は死者も離れた者も枝が閉じるまで外さないので、解散の後も人数が減らない。外の年表は届けのあった者だけを数えるので、最初から少ない。二つの表を突き合わせると、差の二十二人は、存在するとも存在しないとも言えない者たちになる。表の合計が年度ごとに動くのはこのためで、「消息の確認できない者」の欄は、毎年一、二名ずつ入れ替わる。表は閉じない。

四、この表を作った者も、どの行にも入っていない。入っていないことによって、表の外に立つ者が表の全体を保証するという構造が生じる。だが、その保証は一人の記憶に依存している。編纂者が名を返上した三人のうちの一人であれば、この表は自己申告であり、自己申告は最も正確な総括になりうるが、最も検証しにくい総括でもある。何をしているか、誰に何をするか、どこで壊れるかは、この一点で重なる。
