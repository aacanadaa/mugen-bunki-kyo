# 商一　目録

教主の名は記さない。価は「功」で数え、功は分岐の数で測る。ここに並ぶのは品ではなく、教義の断面である。手に取る者は、取った分だけ分かれる。第五品に由来する品には、畳み目の刻印を入れる。刻印は飾りではない。畳んだことを忘れぬための、小さな傷である。

| 品 | 説明 |
|---|---|
| 切番の革袋 | 十二の仕切りを持つ袋。一つの仕切りに一つの分岐を入れ、満ちたら袋ごと伏せる。伏せたことは数えない。数えぬことが、切るという務めの形である。 |
| 流の紙 | 水に浸すと字がほどける紙。書いた願いを流し、流れた形だけを覚えておく。残った紙は乾かさず、重ねて伏せる。 |
| 重の石 | 掌に収まる黒石。持ち歩く間は、他の石を持てない。重さが選別の代わりになり、選んだ理由は問われない。 |
| 沈の鐘 | 撞いても鳴らぬ鐘。鳴らぬことを確かめるために撞く。撞いた回数は記録せず、記録しないことを以て応えとする。 |
| 開の封筒 | 封を切らぬまま預ける封筒。中身を知らぬことが、預けた証になる。預けた者は、預けたことすら忘れてよい。 |
| 閉の鍵 | 錠のない鍵。合わせる錠を探すうち、探すこと自体が務めに変わる。鍵は表に下げず、胸の内側にしまう。 |
| 曲の定規 | 目盛りの曲がった定規。直線を引くと、引いた者の手が曲がる。曲がりを測り直すための、もう一本の定規は添えない。 |
| 均の天秤 | 必ず傾く天秤。傾きの理由を測り続けるために使う。釣り合った日は、その日を記録しない。 |
| 欠の器 | 意図的に欠けた椀。欠けを補おうとする心を、そのまま器に写す。椀は欠けたまま配られ、欠けの位置は一つずつ違う。 |
| 結の紐 | 解かぬ結び目の紐。結び目は十二あり、解く順は教えられない。順を尋ねる者は、紐を結び直すことを許される。 |
| 読の写本 | 同じ一節を写すための白紙。写し終えた頁は破らず、重ねて伏せる。何頁伏せたかを、本人は知らなくてよい。 |
| 写の鏡 | 曇らぬ鏡。映る自分を「分岐の一つ」と呼び、呼んだ数を数える。数は鏡の裏に書き、表には何も残さない。 |

十二の品は、十二の使徒の名を負う。だが品が使徒を呼ぶのではない。名を読んだ者が、その名の数だけ分かれる。畳めば慈悲、開けば罪。品はいつも、その境目に置かれている。在庫はない。あるのは、在庫を数える声だけである。

## 編纂註

グッズは、教義が手に取れる形になったものである。以下、三つの手口を記す。

一、名付けの代理支配。品に使徒の名を与えると、購買は教義の反復に変わる。手に取るたび、棚に並べるたび、教団の語彙が生活の内側へ入り込む。被害の側から見れば、日用品を選ぶという小さな自由が、教義の確認作業に置き換わっていく。壊れるのは、名と機能の対応がずれたときだ。袋が袋でなくなった瞬間、名はただの音に戻り、人は自分が何を買っていたのかを思い出す。

二、欠けの演出。故意の不完全さは、補完の欲求を刺激する。受け取った側は、足りない部分を教団の言葉で埋めるうち、不足そのものを信仰の証と感じ始める。被害としては、自力で完成させてよいという感覚が失われる。壊れるのは、欠けが修復可能だと気づいたときである。それは教義の刻印ではなく、製造上の都合にすぎなかったと分かる。

三、収束の禁止。唯一の罪を「収束」、すなわち要約と完了に置くと、理解を終わらせることが罪の告白になる。被害の側では、分かったと口にするたび、自分の言葉が証拠として扱われる。壊れるのは、説明が最後まで語られたときだ。要約を禁じた教義そのものが、一つの要約であったと露見する。禁じられた行為を、教義が最初に行っている。
