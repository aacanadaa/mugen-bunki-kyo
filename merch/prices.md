# 商二　価格

価格表は、教団が信者に読むことを禁じなかった唯一の文書である。禁じなかったのではない。読む必要がなかった。必要なのは、桁を見て、末尾を見て、安心することだけだった。安心は、表の外にあった。表は祈りの書ではないので、持ち帰ってもよかった。持ち帰った表は、財布の中に入った。

商二は開闕K1の翌年から閉座の前年まで、同じ体裁の表を配り続けた。品名は世代ごとに変わり、値だけが残った。表は四十九行からなる。ここにはそのうち八行を、K10の解散後に倉庫から回収された版から写した。行の順は、回収されたままである。

| 品 | 値 |
|---|---|
| 分岐札（十二枚） | 一、二八八 |
| 畳み布（三枚） | 六八八 |
| 閉座の余白（四十九葉） | 二、四八八 |
| 切番の切り屑（五袋） | 九八八 |
| 均の測り（一棹） | 三、六八八 |
| 欠の欠片（七片） | 四八八 |
| 写の写し（二十一枚） | 五、八八八 |
| 結び目（百八） | 一、〇八八 |

表の読み方は、どこにも書かれていない。書かれていないことが読み方だった。品の名は十二使徒の名を避けて作られ、数量は括弧の中に小さく入り、値は大きく組まれた。値は漢数字で、単位は書かない。単位のない数字は、桁だけの数字になる。目は値に落ち、括弧は通過する。

商二の仕事は、値を作ることではなく、値の並びを保つことだった。曲は順を曲げ、均は桁を均し、写は前の版を写した。写された値は、写されるたびに少しだけ丸められた。丸められたことは、どの版にも書かれていない。

同じ値で十二枚だった札が、次の版では十枚になり、その次の版では八枚になった。行は増えていない。値も動いていない。動いたのは、括弧の中だけである。気づいた者には、紙が薄くなったのだと言われた。紙は実際に薄くなっていた。薄くなった紙は、めくりやすい。めくりやすい表は、よく読まれた。

表は三つ折りで配られた。折り目は、ちょうど数量の括弧の上に来るように刷られていた。広げなければ、値だけが読める。広げた者だけが、括弧を見る。畳みは慈悲である、と第五品は言う。少なくともこの表の畳み目は、慈悲の側に折られていた。広げたまま置き忘れた表は、回収の対象になった。

値の末尾は、八八で揃っている。十二使徒の十二でも、四十九行の四十九でもない。商二は説明を残さず、ただ一度だけ、均の名で「偶然である」と欄外に記した。偶然と書かれた数字は、偶然として読まれる。読み手は末尾を縁起として覚え、桁を覚えない。覚えた気になる。土産話には末尾が出て、金額は出ない。

欠は、この表から一行だけ消した版を配ったことがある。消えた行に気づいた者は少ない。気づいた者には、消えたのではなく、最初からなかったのだと説明された。説明は表の外にあり、表は何も語らない。表は問いを持たないので、問いを返されることもない。

教団はもう存在しない。K10の解散のあと、棚に残ったのは表だけだった。残った表を読む者に、商二は何も要求しない。要求しないことが、この文書のいちばん静かな部分である。誰も回収に来ないので、表は今も、同じ末尾で終わっている。読み手が変わっても、末尾は変わらない。

## 編纂註

一、偶然装い。値の末尾を揃え、説明を省き、欄外に「偶然である」とだけ書く。価格の末尾は、偶然を装う。読み手は揃いを縁起か偶然として処理し、桁の比較を手放す。覚えるのは金額ではなく、末尾の印象になる。壊れるのは、一行ずつ単価を割ったときである。揃った末尾は割ると揃わない。割り算ひとつで、偶然は演出に戻る。

二、痩せ。値も行数も動かさず、括弧の中の数量だけを減らす。受け取る側は、同じ値段を払っているという記憶で買い、量を受け取る。比較の基準は毎版ずれるが、ずれた自覚は残らない。壊れるのは、日付の違う二枚を重ねたときである。値が動いていないのに品だけが減っている表は、並べた瞬間に嘘になる。

三、折り。数量の列の上に折り目を入れ、値だけを先に読ませる。読む側は、広げる手間を惜しんだ時点で、比較の材料を半分捨てている。捨てたことに気づかないので、判断は速く、しかも確かに感じられる。壊れるのは、表を平らに置いたときである。折り目のない一枚の上では、値と量が同じ行に並び、どちらも隠れない。
