# 名一　最後の名簿

「群典」の周辺文書のうち、これを名簿と呼ぶのは便宜にすぎない。K12の時点で確認できる原本は、厚手の紙一枚、表だけに罫が引かれ、十二の欄が上から順に埋められている。保存状態は悪く、右端が欠け、四行目から六行目にかけて水の滲みがある。宛名も署名も日付もない。あるのは番号と、役の名と、ごく小さな印だけである。

|---|---|---|
| 一 | 切番 | 在 |
| 二 | 流 | 在 |
| 三 | 重 | 在 |
| 四 | 沈 |  |
| 五 | 開 | 在 |
| 六 | 閉 | 在 |
| 七 | 曲 | 在 |
| 八 | 均 | 在 |
| 九 | 欠 |  |
| 十 | 結 | 在 |
| 十一 | 読 | 在 |
| 十二 | 写 |  |

番号は一から十二まで、抜けがない。だが役の名の並びは、教団が公に説いた十二使徒の順と完全には一致しない。教義の側では「結」が最後に置かれる。この名簿では結は十番目で、そのあとに読と写が続く。順序を決めたのは教主ではなく、おそらく事務を担った誰かである。名簿という形式は、教義よりも先に、机の上の都合を写す。教義は結んで閉じる。名簿は、結んだあとに読む者と写す者を残した。

印の列には「在」の一字が九つ。残る三つ、四番の沈、九番の欠、十二番の写には何もない。空欄の意味は書かれていない。去ったのか、死んだのか、最初から書かれなかったのか、この紙は答えない。K10の解散を受けて作られた副本でも、同じ三箇所が空白のまま残された。書き足す者がいなかったというより、書き足す順番が来なかった、と言うほうが正確だろう。

十二番の写に印がないことは、副本の存在と矛盾する。写した者が名を持たぬまま、写されたものだけが残った。名簿とは名を残すための形式であるはずなのに、この一枚が伝えているのは、名を落とした者の仕事ぶりである。

教主の名はどこにもない。K9の閉座以降、教主は公の場に出ていない。名簿の末尾にも欄外にも、教主のための行は設けられていない。十二人で閉じる形式そのものが、不在を制度にしている。中心が空いているのではない。中心を空けることが、この文書の目的だった。

第五品「畳みは慈悲」は、この名簿の作り方と響き合う。畳むとは、広げたものを小さくして仕舞うことである。名簿は十二人を三列に畳み、個人を番号に畳み、最後に空欄三つへ畳んだ。畳まれた側から見れば、それは整理ではなく、二度と広げられない形にすることだ。教団が唯一の罪とした「収束」——要約し、完了させること——を、この文書は自ら犯している。書式のうちに教義違反が最初から埋め込まれている。気づいた者がいた形跡はない。おそらく、気づいても欄は増えない。

K5のセイリャク事件について、名簿は何も語らない。事件の前後で印の数は変わっていない。出来事を記録しない文書は、出来事を薄める。薄まった分だけ、教団は長く残った。

現在、この紙を読む者は教団の外にいる。読むための鍵は内側にしかない、と教団は説いた。だが名簿は鍵を要求しない。番号を数え、空欄を見つけるだけで足りる。空欄は、教団が最後に残した最も短い自己批判である。

## 編纂註

**第一条「名の繰り延べ」**　名を与えず、番号だけを与える手口。相手は自分が何番目かだけを知らされ、名を待つあいだ、自分の来歴を番号に合わせて語り直すようになる。呼ばれないことが保留ではなく保護だと感じられる範囲で、この手口は最もよく効く。壊れるのは、相手が「この番号を決めたのは誰か」と尋ねたときである。名簿は、いつも最後に更新される。その「最後」を誰が決めるのかを問われた瞬間、番号はただの数字に戻る。

**第二条「収束の罪」**　要約し、完了させることを唯一の罪とする手口。相手は、自分の人生の区切りを口にするたびに、それを罪として差し戻される。挨拶も、片づけも、別れの一言も、まだ畳めるはずだと保留される。被害は、終わらせられないこと自体ではなく、終わらせようとする意志が道徳的な失敗として内側に残ることにある。壊れるのは、教団の外の日常で、ごく普通の締め切りに間に合ってしまったときだ。罪が一つも発生しなかった日が、教義の反証になる。

**第三条「畳みの慈悲」**　相手の言葉を、相手が言い終える前に教義の側へ畳み込む手口。相手は「わかってもらえた」と感じるが、実際には一度も聞かれていない。第五品の名の下で、理解は同情として配られ、沈黙は成熟として称賛される。壊れるのは、相手が自分で書いた文書を、教団の注釈なしに読み返したときである。注釈の外側に自分の語が残っているのを見た者は、畳まれていたのが言葉ではなく自分だったと気づく。
