# 物一　ミシン

〈本文〉

ミシンはK二の秋に買われた。代金を出したのは教団ではなく、縫い手と呼ばれた女であった。領収書には品名と金額だけが残り、売り場の名は黒く塗られている。誰が塗ったのかは原文でも判らない。判らないままに、この文書は写されている。

買われた当初、ミシンは集会所の隅で、法衣の裾と旗の縁を縫った。使徒の「重」が糸の番号を決め、「均」が縫い目を検査した。検査は厳しかったが、誰も「上手だ」とは言わなかった。上手と言えば、次の縫い手に指名されるからである。指名は名誉ではなく、割り当てであった。

使用の記録で最も多いのは、分岐の袋である。去る者に一つずつ、同じ大きさの袋を縫った。袋は同じ寸法で、同じ縫い目で、同じ糸で閉じられた。分岐を祝う袋がすべて同じ形をしていたことを、当時は誰も不思議に思わなかった。数えたのは「読」で、袋の数は名簿の数より、いつも少し多かった。多すぎた分は、行き先の欄が空いていた。

手入れは月に一度と決められ、油を差す者は指名された。差しすぎた者は、次の月に差さないことで罰とされた。罰は機械には効かないが、人には効いた。

K五のセイリャク事件のあと、ミシンは三度修理された。一度目は針を折り、二度目は送りが鈍り、三度目は踏板が軋んだ。直したのは「結」を名乗る男で、彼は直すたびに「これはもう、うちの子だ」と言った。誰の子かは問われなかった。問えば答えは教団のものになり、教団のものになれば、壊れたときに責める相手が変わる。それは修理より面倒なことだった。

K九の閉座の日、ミシンはまだ動いた。閉座のあと、集会所は解かれ、鍵は返され、ミシンだけが残った。放置の二年、糸は錆び、油は固まり、天板には配布物の束が積まれた。束の一番下にあったのは、K五の名簿であった。誰も動かさなかった。動かせば、まだ教団が生きていることになる。

K十二の春、ミシンは処分された。請け負ったのは「欠」を名乗る者で、彼は「畳みは慈悲」と唱え、糸を切り、針を抜き、本体を布で包んだ。その布は、かつて旗であった。処分の記録には「家庭用縫製機械 一台」とだけある。重さは誰も量らなかった。

いま、この文書に写真はない。撮った者も、撮られた物も、同じように行方を知らない。残るのは、修理のたびに結が記した三行の日付と、処分の日に欠が切った糸の長さだけである。糸は、測ればまだ足りる。

## 編纂註

**一　来歴の徴用**

一つの物の来歴を、組織の年表に接木する手口。相手の側では、自分の買い物や手入れの記憶が、いつのまにか教団の事業の記憶として語り直される。私物の履歴が自分のものではなくなり、思い出そうとするたびに組織の年表が先に立ち、自分の順序を失う。壊れるのは、同じ物について家族や近所の者が別の日付を言ったときである。年表は私的な記憶と突き合わされた瞬間に継ぎ目を見せる。物の伝記は、組織の生活史である——この一句は、その継ぎ目を隠すために置かれている。

**二　修繕の互助**

直すことを善意の交換として差し出し、借りを作る手口。相手の側には、直してもらった事実だけが残り、かかった手間も部品も示されない。断れない貸しが積み上がり、自分が何を返せば終わるのか判らなくなる。壊れるのは、直した物が再び壊れ、誰が持つかが問われたときである。互助は所有を曖昧にするので、故障のたびに責任の所在が消える。誰も責められないまま、費用と手間だけが個人に戻ってくる。

**三　代理の処分**

持ち主の代わりに物を片づけ、それを慈悲と呼ぶ手口。相手の側では、失ったという感情を持つ資格が与えられない。喪失は「畳まれた」と記録され、悲しめば未練とされる。壊れるのは、処分されたはずの物が別の場所で見つかったとき、あるいは処分を頼んだ側が受け取りを求めたときである。代理は記録を残すが、物は残さない。記録と物が食い違えば、慈悲は手続きに変わる。
