# 誤一　記録

本記録は、開闕K1の創立からK10の解散までのあいだ、各座の儀礼に生じた過失を、その都度、当人の名において書き留めたものである。誤りは数えるために記すのではない。次の折り目を合わせるために記す。書式は第十二使徒・写が定めた。日は教団暦、者は当時の使徒名、誤は立ち会いの者が見たままを、訂正せずに記した。読み返さぬことが、この記録の作法である。

| 日 | 者 | 誤 |
|---|---|---|
| K2 二ノ月 | 切番 | 東ノ座の畳みで、初折を三度やり直した。折り目が合わぬまま続け、以後の五折がすべてずれた。 |
| K2 六ノ月 | 流 | 水屋の洗いで、順を逆にした。汚れを落とす前に水を替え、七人が同じ桶を使った。 |
| K3 一ノ月 | 重 | 書庫の朗読で、第五品の一句を二度読んだ。同じ句を二度読むと、聴く者には一度しか残らぬと註された。 |
| K3 九ノ月 | 沈 | 灰ノ庭の立ち会いで、沈黙の数を四十九から四十四へ切り上げた。全員が早く伏し、夕の灯を待たずに散った。 |
| K4 三ノ月 | 開 | 外廊の開きで、内開きを外開きとして扱った。列が三度止まり、後ろの者は前の者の背だけを見て折った。 |
| K4 一一ノ月 | 閉 | 中ノ座の閉座予行で、消灯の順を一つ飛ばした。最後の一灯を残したまま、全員が退出した。 |
| K5 二ノ月 | 曲 | セイリャク事件の当日、曲げの所作を同じ場所で二度行った。二度曲がることは道を戻ることと同じ、と後に註された。 |
| K5 四ノ月 | 均 | 配り場の均しで、器を傾けたまま回した。片側だけが薄く、受け取った者は黙って飲み、誰も口を開かなかった。 |
| K6 七ノ月 | 欠 | 東ノ座の欠けの席に、欠けぬ者を座らせた。空席を埋めるとは不在を消すことだと、後の註は書いた。 |
| K7 三ノ月 | 結 | 結びの座で、紐を教本と逆の手で結んだ。解けぬ結びは、ほどく儀礼の日まで咎められなかった。 |
| K8 五ノ月 | 読 | 読の座で、句の切れ目を声にしなかった。意味は届いたが、息継ぎの位置が全員ずれ、後半は誰も揃わなかった。 |
| K12 現在 | 写 | 写しの作業で、この記録の草稿を二度書き写した。二枚は一字も違わぬが、二枚目だけが正本とされた。 |

記録は座ごとに分けて綴じ、済んだ頁は畳んで挟む。畳みは慈悲であるから、誤りも折られて残る。だが折られた頁は開かれぬ。写しだけが増え、正本はどれか、誰にも分からなくなった。

---

## 編纂註

### 一

細目化。成員は自分の所作を教団の語彙で分解し、記録に耐える形に整えてから行う。記録される側に立つと、人はまず自分で自分を監視し、折る前に手を止める。誤りが減るのではない、誤りが書かれぬ形に変わる。壊れるのは、細目が書き手を必要とするところである。書き手の手がやがて教義になり、書き手が消えると細目だけが基準として残る。誰も儀礼を行えず、記録だけが正しくなる。

### 二

記名の付替え。誤りが他人の名で残り、あるいは自分の過失が帳面から消える。身に覚えのない過失を負わされた者は、名とは動くものだと学ぶ。誤りを犯したことより、名を外されたことのほうが長く残る。壊れるのは台帳の信用である。同じ筆跡で別人の名が並び、末尾の読者は記録そのものを読まなくなる。読まれぬ記録は、罰を下すためだけに残る。

### 三

遡及註。後から付された註が、過去の誤りを畳み、慈悲として読み替える。誤った者は赦されるが、自分の記憶は書き換えられる。赦しは本人に届かず、記録の側だけが整う。壊れるのは註のあいだである。一つの折り目に三つの説明が付き、K12の読者にはどれが当時のものか判別できない。誤りの記録は、教義が細かすぎる証拠である。細かい教義は註を増やし、註は記録を物語に変える。
