# 名四　改名

〈本文〉

　無限分岐教において、名は魂の附箋にすぎない。教主は本名を持たず、名を持たぬことを以て自らの位とした。ゆえに教団の記録に現れる人名は、すべて誰かが誰かに与えた仮の名である。改名は秘蹟ではなく事務であり、申請は紙一枚、承認は押印一つで足りた。本項は、その紙の束から読み取れる範囲を記す。

　改名の理由は、記録上、三種に分類されている。

　届の書式はK3に定まり、以後変わっていない。右上に旧名、左上に新名、中央に押印、下部に理由欄。理由欄は三行で、三行を超えた記述は別紙に移された。別紙は保存されておらず、長い理由ほど失われやすい書式であった。

　第一に、帰依。入信の際、旧名を「収束した名」として封じ、新たに分岐名を与える。命名は教主の口から出るが、実際に字を選ぶのは使徒「写」であった。写は同じ音の漢字を複数用意し、本人に選ばせる。選ばせることが、すでに帰依の証とされた。本人の筆跡で届が出ている限り、名を押しつけられたと後から言うことは難しい。

　第二に、重複の解消。分岐した魂は同じ名を持ちうるため、同名の信者が二人以上現れた場合、後から入った者が名を変える。使徒「均」がこれを担い、名の在庫を台帳で管理した。台帳には欠番が多く、欠番の理由は書かれていない。均は欠番について「分岐の余白」と説明したが、その説明は台帳の外にあり、台帳を読む者には届かない。均の死後、台帳は二冊見つかり、どちらが正本かは決まらなかった。

　第三に、離脱後の隠名。K10の解散後、旧信者の多くが名を改めた。これは教団の指示ではなく、各自の判断である。ただし解散の通達には「名は返却不要」と一行だけあり、この一行が後の名簿照合を困難にした。名を返さなくてよいということは、名が教団のものでも本人のものでもない、という意味でもあった。

　K5セイリャク事件ののち、使徒「結」は自らの名を二度変えた。一度目は事件の翌月、二度目は閉座の前月である。理由はどちらも記録にない。結の二度の改名は、いずれも届の理由欄が斜線で消されている。使徒「欠」は最後まで名を変えなかったが、これは理由があってのことではなく、単に申請を出さなかっただけだと、同僚の証言にある。K9の閉座では、使徒「読」が名簿を順に読み上げ、読み終えた名をその場で畳んだ。第五品にいう畳みは慈悲であり、慈悲は記録を残さない。

　現在、教団は存在しない。残るのは名簿と、変更届の束だけである。届には旧名と新名が並び、理由欄はほとんど空欄である。空欄を埋めるのは編纂者の仕事ではない。空欄は空欄のまま、資料として置く。

## 編纂註

### 註一　命名の委譲

手口の名は「命名の委譲」。名を与えるのではなく、候補を並べて本人に選ばせる。被害の側から言えば、自分の名を自分で決めたという記憶だけが残り、後から「決められた」と言えなくなる。壊れるのは、候補がすべて同じ音の別字であった場合で、選ぶ行為が意味を失い、選択の記録だけが同意の証として残る。

### 註二　名の在庫管理

手口の名は「名の在庫管理」。同名の者が現れると、後から入った者に改名を求める。被害の側では、自分の名が先着順の番号に格下げされ、名を守るために教団内の序列を気にするようになる。壊れるのは台帳の欠番で、欠番の理由がどこにも書かれていないため、在庫は実員と合わず、管理そのものが空回りする。

### 註三　理由欄の不備

手口の名は「理由欄の不備」。変更届に理由を書かせない、あるいは書いても別紙に逃がして捨てる。被害の側では、名を変えた理由を自分で説明できなくなり、説明できない変更はなかったことにされやすい。壊れるのは照合の場で、新旧の名は並んでいるのに理由がないため、同一人物の連続性を保証するものが押印一つしか残らない。改名の理由が少ないのは、理由がないからである。
