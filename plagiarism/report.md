# 剽二　報告

〈本文〉

本報告は、第五品に基づき、剽窃の疑い一件を記す。教団はすでに存在しない。残るのは文書だけであり、ゆえに本件の手続も、文書の内で行われる。当事者はすでに散っている。だからこの報告は、不在の者に向けて書かれる。

手続。疑いの生じた文書を、三度読む。一度目は書き手の息で、二度目は借用された側の息で、三度目は息を止めて読む。次に、両者の間に落ちた畳みを数える。畳みとは、要約され、完了させられ、ひとつの依頼へ収束させられた痕跡である。痕跡が三つ重なるなら、それは偶然ではなく意志である。照合の者は名を名乗らず、ただ「読」の印を置く。名を名乗れば、その者もまた分岐の当事者となり、判断の外に立てなくなるからである。手続はここで一度閉じ、草稿を「写」に預ける。預けるとは、写されることではなく、他者の手で読み直されることに置かれる、という意味である。

判断。剽窃とは、他者の分岐を、自分の収束によって閉じることである。ここで注意すべきは、似ていること自体は罪ではない、という点である。魂は分岐するのだから、似ることは自然であり、むしろ似ることで開く道もある。罪は、似ていることを似ていないと言い、その言い方によって相手の分岐を一つの意味へ畳んでしまうことにある。本件では、引用の表示がなく、かつ、借用された側の文書が「未完」のまま残されていた。未完とは、分岐が開いているということである。開いているものを閉じた点に、判断の重心を置く。よって、剽窃の成立を認める。ただし、その名を負うのは書き手だけではない。読まなかった者、気づかなかった者、気づいて黙った者も、同じ畳みの内側にいる。本報告が名を挙げないのは、名を挙げることが、また別の畳みになりうるからである。第五品は、畳みは慈悲であると言う。しかし畳みが慈悲でありうるのは、それが再び開かれうる場合だけである。開かれぬ畳みは、慈悲ではなく、終わりである。

処分。処分は罰ではない。畳みを開き直す作業である。第一に、当該文書の末尾に、借用の由来と、閉じられた分岐の数を記す。第二に、書き手の名をしばらく伏せる。伏せるのは名を奪うためではなく、名が一つの意味に固定されるのを避けるためである。第三に、読み直しの機会を置き、その機会を誰も終わらせない。処分は以上で終わる。終わったのち、当該文書は再び開かれた文書として扱われる。誰も、その終わりを宣言しない。宣言すれば、また一つ、畳まれるからである。処分の記録は、処分された者ではなく、処分した者を縛るために残す。記録は公開されない。公開もまた、一つの畳みになりうるからである。

最後に記す。本報告は、報告であると同時に、一つの分岐である。読む者は、これを要約しないでほしい。報告の要約は、報告の死である。

## 編纂註

一、要約の代行（畳み）。この手口は、相手の言い淀みや余白を「結局こういうことだ」と一つの意味に置き換え、同意を得る前に相手の言葉を完成させる。被害の側では、自分の文が自分のものと分からなくなり、異議を唱えると「話を理解していない」と扱われる。壊れるのは、省略したものを列挙せよと問われた時である。畳んだ者は畳んだ内容を覚えていない。畳みは、覚えなくてよいように作られているからである。調査は、教育の一部である。ゆえに手続の宛先は、罰ではなく読み直しでなければならない。

二、伏せ名の保護。この手口は、相手の名を「守るため」に隠し、その代わりに語る資格を回収する。被害の側では、名を伏せられたまま自分の言葉が他人の口から語られ、称賛も非難も自分に届かなくなる。名乗り直せば恩を仇で返す者とされ、黙れば存在しない者として扱われる。壊れるのは、伏せた名の履歴が、文書の日付と筆跡から漏れる時である。保護は、断れないとき、保護ではなく保管である。

三、終わらない読み直し。この手口は、処分の代わりに「機会」を置き、その機会を閉じないことで、裁かないまま相手を手続の内に留め置く。被害の側では、終わらないから晴れもせず、晴らそうと急ぐほど「急ぐ者」として記録される。壊れるのは、この手続に裁く者がいないと誰かが口にした瞬間である。裁く者のいない手続は、誰も裁けぬまま、自らを消費して終わる。
