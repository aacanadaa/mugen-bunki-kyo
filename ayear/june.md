# 六月　電話

〈本文〉

六月の電話は、当番の者が受話器の横に置いた紙に、時刻と相手と用件だけを書き足していったものである。日付の欄は初めからなかった。書き手は三人いたはずだが、筆跡は十二日目あたりから一つに揃っている。紙は四枚あり、順に重ねて机の引き出しにしまわれていた。用件は一行で書け、とだけ申し渡されていた。誰が申し渡したのかは、どの紙にも書かれていない。台の前の椅子は一つきりで、当番が交代しても、座面はしばらく温かかった。紙は鉛筆で書かれ、消した跡が二箇所ある。以下はその四枚の全文である。

| 時刻 | 相手 | 用件 |
|---|---|---|
| 6:12 | 役所の窓口 | 名義の確認。こちらからは何も答えていない |
| 7:40 | 魚屋 | 配達の間違い。二度目 |
| 9:05 | 無言 | 十秒で切れる |
| 10:31 | 元信者の兄 | 妹の荷物の始末について |
| 11:00 | 電話会社 | 料金の案内。自動の声 |
| 13:47 | 無言 | 息の音が三つ |
| 15:22 | 郵便局の窓口 | 転送届の確認。差出人は空欄 |
| 16:58 | 青年 | 入会の問い合わせ。折り返しは約していない |
| 18:03 | 無言 | 二十五秒。こちらが先に切る |
| 19:30 | 元信者の兄 | 同じ用件。昨日も聞いた |
| 21:15 | 外部 | この二文字だけがある |
| 23:59 | ― | 記録係が紙を裏返す音 |

「外部」という欄は、六月の二十日ごろから現れる。それ以前、この欄には人の名が入っていた。名は三つあり、いずれも当番の者の名ではない。当番の者は、その三つの名の誰も知らなかった。知らない名を書き写すことに、誰も不審を唱えていない。不審を唱えないのではなく、唱える相手がもう受話器の前にいなかった、というほうが正しい。

電話は一度も外へ掛かっていない。掛けた記録も、掛けようとした記録も、受話器を上げた形跡さえ残っていない。にもかかわらず紙は増え、月末には四枚になった。四枚はどれも、同じ一日の違う時刻のように並んでいる。朝の六時から夜の零時へ向かって、時刻だけが進む。受話器のコードは机の脚に絡み、ほどく者はいなかった。日付がなければ、一日は何度でも始まり、何度でも終わらない。

用件の欄は、半月を過ぎたころから短くなり始める。はじめは二行あったものが一行になり、一行が半行になり、ついに「外部」の二文字だけになる。二文字を書いた手は、他のどの行よりも丁寧である。丁寧さは、しばしば空虚の隠れ蓑になる。十九時三十分の「昨日も聞いた」という一行だけが、日付のない紙に、日付の気配を残している。

二十三時五十九分の行だけ、用件の欄に動作が入っている。記録係が紙を裏返す音、とある。裏返した紙の裏は白い。白い面には、翌月の頭から、また時刻だけが並ぶことになっていた。白は、まだ何も起きていないという意味ではない。

六月が何日あったのかは、この紙からは分からない。分からないまま、四枚は今も同じ順に重ねてある。

---

## 編纂註

**一**　この文書は、内向きの記録を外向きの証拠に作り替えている。日付を落として時刻だけを残すことで、六月の複数の日を、一つの終わらない日に畳み込んだ。読む者は欄の埋まり具合だけを見て、連絡は絶えていないと受け取る。絶えていないのは紙の側であって、線の側ではない。表は、世界がまだ此方へ向いているという印象を、行の数だけ反復する装置である。

**二**　残った者に、教主の不在を音で埋めさせている。声の主を問わない欄を一つ立てれば、そこには何でも入る。入れた者は、自分が書き入れたものを外部からの働きかけと読み替える。空欄は教主の席の写しであり、席が空いていること自体が、次の着信を待つ理由になる。読み手が受け取るのは安慰ではなく、待機という習慣である。

**三**　発信の記録が一枚もない。四枚は同じ一日の時刻順に並び、月の日数を復元できない。用件は半月で二文字まで縮み、動作が用件の欄へ侵入する。記録が記録をやめて舞台の指示になった瞬間、この文書は自ら破れている。六月の電話は、外部の気配である。気配は、外部そのものではない。

**四**　二十三時五十九分の行は、裏返した紙の白を次の月へ渡す段取りである。記録係は音を書き、その音は誰にも聞かれていない。ここで読者は、自分が聞き手の位置に置かれていたことに気づく。電話を受けていたのは当番の者ではなく、この紙を読む者だった。破れ目は表の外ではなく、表を読む目の内側にある。
