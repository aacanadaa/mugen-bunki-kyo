# 三月　会計

〈本文〉

三月の会計は、例年より二十日早く閉じられた。閉じたのは教主ではなく、名を持たない会計の三人である。教主は数字を読まない人として記録されている。ただし、この年だけは帳簿の末尾に教主の筆とされる一行が加わっている。同じ年、別の層には「教主は帳簿に触れていない」とあり、どちらが先に書かれたかは決められない。以下の表は、前者を採る。

原簿は残っていない。残るのは三つの写しで、二つは途中で切れ、一つは表だけを持つ。単位の「環」は当時の内輪の数えで、後の時代の換算とは合わない。それでも表を組むのは、この年の教会が何を数え、何を数えなかったかを、数字の形で残すためである。

| 区分 | 科目 | 額（環） | 摘要 |
|---|---|---|---|
| 収入 | 常環 | 四二〇 | 定例の供出。前年より三割減 |
| 収入 | 臨環 | 六八 | 春の集いの折に集まったもの |
| 収入 | 刊行 | 三一 | 『群典』分冊の頒布 |
| 収入 | 繰越 | 一〇五 | 前年二月の残り |
| 収入 | 小計 | 六二四 | |
| 支出 | 会場 | 一七二 | 三か所。うち一か所は返却 |
| 支出 | 刊行 | 九四 | 紙と組。前年の半額 |
| 支出 | 旅費 | 五八 | 分岐の確認に出た二人分 |
| 支出 | 扶助 | 七三 | 名簿なし。受取人は記されない |
| 支出 | 雑 | 二二 | 灯り、炭、封蝋 |
| 支出 | 小計 | 四一九 | |
| 差引 | 残 | 二〇五 | 翌月へ |

表の外に、もう一行ある。「分岐準備」とだけ書かれた行で、額は空欄、摘要には「三月末、閉ず」とある。空欄の行は、この帳簿で唯一、誰も署名していない。会計の三人は、この行を消さなかった。消せなかったのか、消さなかったのかは、表からは読めない。

数は合っている。収入の各行の和は六二四、支出は四一九、差引は二〇五。合っているのに、三月の末に紙が一枚だけ残る。教主が公の場に出ない旨の、日付のない紙である。会計はそれを支出に計上していない。計上できない種類のものだったのだろう。扶助の七三も、受取人の欄が最初から空いている。名を書かないことで、この項目は支出の額だけを持ち、人の顔を持たない。

三月の会計が薄いのは、書く者が慎重だったからではない。書けることが少なかったからである。この年、教会はまだ、失うものを失っていなかった。だから帳簿は、静かに見える。静かなのは、まだ足りていたからだ。

---

## 編纂註

**一**　この文書は開闕九年三月の収支を、後代の編纂者が表に組み直したものである。原簿は現存せず、三つの写しのうち二つが途中で切れ、一つは表だけを残す。表は完全に見えるが、完全なのは形だけである。編纂者は欠けた摘要を推定で埋めず、空欄のまま残した。その空欄は、この文書の主張の一部になっている。

**二**　読む者に、教会が「数字で語れる組織」であったことを示す。同時に、数字の語らない部分——署名のない行、日付のない紙——へ目を向けさせる。かつて信者であった者には当時の窮迫を思い出させ、外部の読者には、宗教団体の記録がしばしば正確な数字と不明な判断を並べて置くものだと気づかせる。表は隠すための形式でもある。

**三**　壊れるのは額の信頼性である。環の換算は時代で変わり、写しごとに小計が一割ほど違う。「分岐準備」の空欄には後代の解釈が最も集まり、消された行を復元したという主張まで存在する。表を読む者は、合計が合っていることに安心してはいけない。合っているのは、合わせた者の腕である。会計は、その年の体力である。数字が減ったことを貧しさと呼ぶか、支出を抑えたことを健康と呼ぶかは、同じ紙の上で決められる。
