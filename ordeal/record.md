# 試二　記録

『群典』第五品は「畳みは慈悲」と説く。開いた分岐を一つに束ねることを慈悲と呼び、同じ仕草を「収束」と呼んで唯一の罪とする。二つの語のあいだにあるのは、名づけの違いだけである。その違いを測るために試しが置かれ、試しの結果を収めるためにこの記録が置かれた。

記録の欄は三つしかない。名、種、結果。名は本人のものでなく、教団が与えた記名である。種は試しの種類だけを書き、その中身は書かない。書かないことが、この記録のいちばん古い規則である。種は七つある。静、返、分、畳、夜、声、待。いずれも内側の言葉で、外に持ち出せる形になっていない。持ち出せないから外から検証もできず、検証できないことを教団は「秘伝」と呼ぶ。

| 名 | 種 | 結果 |
|---|---|---|
| 灯五 | 静試 | 未了 |
| 灯五 | 畳試 | 了（不服） |
| 灯六 | 静試 | 了（不認定） |
| 白板二 | 分試 | 分岐三 |
| 白板四 | 分試 | 未了 |
| 半音 | 返試 | 棄 |
| 半音 | 返試（再） | 記載なし |
| 遠雷 | 畳試 | 了 |
| 継木 | 待試 | 未了 |
| 継木 | 夜試 | 棄 |
| 無名一 | 夜試 | 棄 |
| 無名三 | 声試 | 未了 |

表の読み方を添えておく。「未了」は分岐が残ったまま終わらなかったことを指し、「了」は一つに束ねられたことを指す。教団の言葉に従えば望ましいのは前者で、後者は罪に近い。ところが表を縦に眺めると、望ましいはずの「未了」が、いちばん多く「棄」の隣に並んでいる。書式は思想より先に、人を並べてしまう。

記録者という欄は、どこにもない。書いた者の名も、書いたときの体調も、同じ試しを二度見たかどうかも書かれない。書かれないものは、表の上で存在しない。この非対称は、後ろの註に譲る。

治癒についても、教団は主張を持っている。試しの後に体の具合が良くなったと本人が申し出た場合、それは「癒え」として別の帳簿に移される。この記録にその欄はない。移された先の帳簿は現存しない。二つの帳簿のあいだに残るのは申し出だけであり、確かめた手続きは一枚も残らない。奇蹟も同じ場所にある。奇蹟の記録はこの表の外に置かれ、表の外にあるということが、かえって奇蹟を強くしている。

日付の欄はところどころ空いている。空いた日付の前後で、同じ名の結果が食い違う箇所が四つある。書き直されたのか、別の者が書いたのか、記録は答えない。答えないことが答えである、と教団は言う。だが、答えない記録を答えとして読むのは読む側の仕事であって、記録の仕事ではない。

この表は後に「証拠」として持ち出された。奇蹟の証拠としても、規律の証拠としても。同じ紙が両方に使えるのは、紙が何も測っていないからである。測っていないことを、教団は「記録がある」という一言で埋める。

---

## 編纂註

一、この手口は教内で「採点」、外の分析では「身体の点数化」と呼ばれる。名・種・結果の三欄は、続いた時間や本人の言葉を、比較できる単位に切り分ける。切り分けは事務の顔をして行われるので、誰もそれを暴力と呼ばない。呼び名が「記録」であるうちは、この操作は中立に見える。名づけが問題を隠すというのが、この手口の最初の性質である。記録は、身体を点数にする。

二、人に何をするか。被記録者は、自分の体を書かれる側から見るようになる。試しの最中に、これは何と書かれるかを考える。経験は終わった後に想起されるのではなく、書かれる予定として先に来る。同じ種の名が並べば比較が生まれ、比較から序列が生まれる。記録に残らない苦しみは、表の上では存在しない。教団はこれを「稽古」と呼ぶが、稽古の成果を判定する者は本人ではない。

三、どこで壊れるか。同じ体を二度採点すれば、結果は食い違う。食い違ったとき、記録は体ではなく書式の側を守る。日付の空白と、同じ名の反復が、その壊れ方を示している。また「結果を書かない」という規則そのものが、書かないという結果を生む。畳まなかった者を評価するための表が、最後には畳まれた表になる。癒えの申し出も同じで、本人の言葉だけが移され、確かめた記録はどこにもない。
