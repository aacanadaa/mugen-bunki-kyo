# 索五　人名索引

本索引は、群典およびその周辺文書に現れる名を、現在の綴じ順に沿って頁ごとに並べたものである。採録の単位は人ではなく名とした。同じ人が役割を変えて何度も現れ、同じ役割名が別人に引き継がれているため、人を単位にすると行が足りず、名を単位にすると行は足りるが人は見えなくなる。本索引は後の方を選んだ。名は資料の余白に落ちたものであり、人はその落ちたものの持ち主にすぎない。

役割名は、奥付、検印、貸出票、焼却簿、移管目録、補修の受領書に記されたものを正とした。本名は、私信、寄附の受領書、葬送の控え、および死亡記事の欄外から拾った。両者が一致しない場合は一致しないまま一行に置き、一致を証する文書が無い場合は破線を置いた。破線は空欄ではない。空欄は書かれなかったことであり、破線は書けなかったことである。

頁は現在の綴じに従う。K1の創立からK10の解散までに綴じは三度やり直され、K12の移管で一度ばらされた。ばらされた紙は番号を失い、番号は後から鉛筆で入れ直された。鉛筆の数字は消しゴムで消える。本索引の頁欄が動きうるのは、そのためである。異名は括弧に入れた。括弧は名の一部ではないが、名の履歴ではある。

教主の行には本名が無い。文書のどこにも書かれていないからではなく、書かれていた頁が四度目の綴じで欠けているからである。欠けた頁を引く文書は多く、そのたびに教主の名は「例の名」として別の頁に現れる。結果として、対応のないこの一行が、本索引で最も長い頁欄を持つ。

焼却簿には頁が無い。簿冊ではなく、縄で括った紙片の束である。紙片には日付と役割名だけが書かれ、本名は書かれていない。書かないことがその仕事の作法だった。本索引は焼却簿から名を採らなかった。採らなかったのではなく、採れなかった。紙片の名は、燃やした紙の名ではなく、燃やした人の名でもない。何の名かは、今も決まっていない。

本索引は二度作られた。一度目は罫紙の帳面に手で書き、二度目は同じ内容を升目の表に移した。二度目を作った記録係は、これを「データ」と呼んだ。紙のときには無かった呼び名である。走査した画像から名を拾うと、裏写りした名が本文の名として混じった。混じった行は消されず、註で説明された。升目は行を足すのが容易で、紙の上では起きなかったことが、データの上では起きた。

## 編纂註

一、この作業は教団の内部で「名寄せ」と呼ばれた。外部の目録作成者は同じ作業を「同定」と呼び、K12の移管の記録では「照合」と書かれている。三つの語は同じ手つきを指すが、名寄せだけが祈りの前に唱えられた。唱えたのは、名を寄せることが教義の禁に触れると知っていたからである。禁を破る作業には、破るための名前が要る。

二、資料の側から言えば、索引は名を本文から剥がす作業である。名はもともと奥付の隅、検印の脇、貸出票の返却欄に、用の副産物としてあった。索引はそれを「人名」という一つの欄に移し、元の位置を頁番号に置き換える。資料は引かれるために書かれたのではない。書かれた結果として引かれる。索引はその結果だけを残し、書かれた理由を頁の裏に落とす。落ちた理由は、どの頁にも載らない。

三、壊れるのは頁である。綴じ替えのたびに頁は動き、動いた頁を引く文書は古い番号を引く。焼却簿には頁が無く、走査では裏写りが名として拾われ、升目では行を足すのが容易すぎる。最も壊れるのは破線の行で、そこには何も書けないため、註が代わりに書き込まれる。対応のない名が、最も多く引かれる。註は資料ではない。資料でないものが、最も多く引かれる行を説明している。
