# 要二　抗議

〈本文〉

一、本書は『群典』要約版第三版の巻頭「梗概」に対する抗議文である。差出人不明、消印はK12、宛先は編纂室。原本は四つ折りの紙四枚、角に畳み皺が残る。以下、全文を写す。写は十二使徒のひとりであり、写すことは要約しないことだと、この文書は主張している。

「あなたがたは、私たちの言葉を数えた。数えることは畳むことではない。畳むには層が要る。数えるには、層を一枚に潰す手つきが要る。

私はK5の冬に生まれた。セイリャクの後の冬で、教団はもう無かった。母の枕元に『群典』の断簡が一葉だけあり、私はそれを二十七年かけて読んだ。読むとは分かれることだと、その一葉は教えていた。同じ一行が、朝と夜で違う顔をする。私はその違いを、違いのまま抱えてきた。それが私の救いだった。

あなたがたの梗概は言う。「要旨は一点に尽きる」と。そして、その一点が何かを書かない。書かないことで、読者に自分で一点を思い描かせ、思い描いた一点を以て全文に代えさせる。これは要約ではない。収束だ。教義が唯一の罪と呼んだものだ。しかも質が悪い。名を書かないから、誰も反論できない。反論するには、まず私がその一点を名づけねばならず、名づけた瞬間、私はあなたがたの梗概を一層厚くする。

私は怒っている。怒りは分岐である。私の怒りが、あなたがたの静かな梗概に吸われて一本の線になるなら、私は自分の魂を、あなたがたの事務に差し出したことになる。差し出すのは自由だが、差し出した後に何も残らないのは、自由ではない。

あなたがたは私を排除しない。それが一番こたえる。排除ならば私は外に立って、外から怒れた。包含は、私を内側の隅に座らせ、座っていることを以て答えとする。座らされた者は、立って帰ることもできない。

あなたがたの註に「要約への抗議は、教義の内部で行われる」とあった。その通りだ。だから私は外へ出ない。外へ出て裁くことは、私の側の収束になる。私は内側で、扉を開けたまま怒る。開は十二使徒のひとりだ。切番は切る使徒だが、切ることは捨てることではない。第五品は畳みは慈悲と言う。だが畳むことと閉じることは違う。閉は別の使徒だ。私は閉じない。開いたまま、怒っている。

一つだけ頼む。梗概の余白に、この手紙の宛先を消さずに残してほしい。宛先のない抗議は、要約と同じくらい静かだ。静かな怒りは、あなたがたには都合がいい。」

二、以上。編纂室はこれを全文掲載し、梗概は改訂しない。改訂もまた収束であるため。原本の畳み皺は、第五品の所作に似ていた。

## 編纂註

**一　無名の一点**
手口の名は「無名の一点」。要旨は一点に尽きると言い、その一点を名づけない。相手の側では、読者が自分で一点を補うため、反論の対象が手元に無い。抗議しようとすれば自分が名づけを引き受け、梗概はさらに厚くなる。壊れるのは、「その一点とは何か」と一度だけ問われたときである。名づければ争点になり、名づけなければ空白が露出する。無名は、名を問われるまでしか保たない。

**二　宛先の消去**
手口の名は「宛先の消去」。抗議を全文載せながら、差出人と宛先を消す。相手の側では、怒りが請求から気分へ変わり、誰も答えないことが正しさの形を取る。声は残るが、返事の宛先は残らない。壊れるのは、宛先が自分の名で一通でも返事をしたときだ。要約への抗議は教義の内部で行われる——この指摘を取るなら、宛先を消すことは抗議を内側から外側の感想へ移す手つきであり、いちばん静かな追放にあたる。

**三　全文掲載という免罪**
手口の名は「全文掲載という免罪」。全文を載せ、梗概は改訂しないと宣言して、決定を回避する。相手の側では、言葉は保存されるが答えられず、怒りは資料になる。載せたことが応答として扱われ、載せなかったものだけが黙らされる。壊れるのは、改訂しないことが「決めない」ことだと露見したときである。教義は収束を禁じるが、回避を徳とはしていない。判断の不在も、ひとつの収束だ。
