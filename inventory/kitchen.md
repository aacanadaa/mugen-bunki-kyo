# 品二　台所

開闕十二年、解散から二度目の冬。旧本部の台所は板の間に霜が降り、蛇口の下に盥が一つ置かれていた。採録は二人で行った。一人が棚を開け、一人が声に出して数を読んだ。以下の表は、その日の午前中に数え終えた分である。午後は火の気のない竈の前で、同じ数を二度数えた。

| 品 | 数 |
|---|---|
| 飯椀（大きさ三種、揃わず） | 四七 |
| 汁椀（縁の欠けたるもの二） | 三一 |
| 箸（片方のみ） | 六八 |
| 揃いの箸 | 九 |
| 鍋（深さ二種） | 九 |
| 片手鍋 | 五 |
| 包丁（いずれも研がれず） | 七 |
| まな板 | 四 |
| 杓子 | 六 |
| 菜箸 | 一四 |
| 飯櫃 | 三 |
| 蒸籠 | 二 |
| 笊 | 五 |
| 摺鉢 | 四 |
| 擂り粉木 | 三 |
| 保存壺（蓋の合わぬもの三） | 一一 |
| 水差し | 八 |
| 湯沸かし | 四 |
| 急須 | 二 |
| 茶碗（揃いならぬ） | 三九 |
| 布巾（洗われたるまま） | 二二 |
| 台拭き | 一七 |
| 桶 | 六 |
| 盥 | 三 |
| 炭 | 四俵 |
| 薪（割りかけ） | 二束 |
| 分岐の杯（儀礼用、傷あり） | 一二 |
| 空の器（用途不明） | 一 |

数え終えて、まず箸の多さが気になった。飯椀は四七、箸は片方だけで六八。片方を失った箸がこれだけあるということは、片方を残した者がいるということである。教団では食器を私物としなかった。食器は棚のものであり、棚は教団のものであった。だから椀は割れても捨てられず、箸は片方になっても棚に戻された。戻す者と、戻さない者がいた。

台所は、教団のなかで唯一、教義が手を触れない場所だった。教主の言葉は食堂の壁に貼られたが、その紙は油で透けていた。教義は椀を洗わない。洗うのは当番の者であり、当番の名はどの記録にも残っていない。

最大の時期、すなわち教団が最も多くの者を収容した年の台所は、この目録のどこにも特記されていない。しかし鍋の底の煤の厚さと、保存壺の蓋の合わなさが、その時期の買い足しを語っている。揃いで買われ、揃わぬまま残った。人は増え、席は減り、椀だけが増えた。

目録は「残ったもの」の記録であって、「あったもの」の記録ではない。解散の日、何が誰の手に渡ったかは、ここには書かれていない。書けないのである。私が確かめられなかったのは、この台所で最後に火が入った日であった。竈の灰は、二度目の冬を越えても白いままだった。

## 編纂註

### 第一条（この文書がしていること）

この文書は、台所に残った品を数え、表にしている。数えるという行為によって、教団を「信者の数」ではなく「椀の数」で読ませる。四七という数字は、四七人がその場にいたことを意味しない。椀は割れ、寄進され、持ち去られ、棚に戻された。数は瞬間のものであり、目録はその瞬間を切り取ったにすぎない。読み手はここで、数を人数に置き換えたくなる。そこが、この文書の壊れるところである。

### 第二条（誰に何をするか）

台所の目録は、教団の最も生活に近い部分である。教義は台所を通らない。教主の言葉は食堂の壁に貼られ、その紙は油で透けた。この目録は、解散後に品を分け合った者と、その家族に、分配の根拠と、教団の日常の輪郭を与える。同時に、記録した者の癖——片付けの順、匂い、音——を混ぜる。生活に近いがゆえに、数えられないものが最も多く落ちる。

### 第三条（どこで壊れるか）

最大の時期の台所は、最も多くの食器と、最も少ない席を持っていた。寄進された揃いの椀と、不足したままの箸が同じ棚にある。鍋の煤の厚さと保存壺の蓋の合わなさは、その時期の買い足しを語るが、日付は語らない。後の読み手は「最大」を「充実」と読み違える。ここで目録は、生活の記録から教団の自画像へと滑る。数字は正直だが、数字の並びは正直ではない。

### 第四条（照合の限界）

解散の日、何が誰の手に渡ったかは記されていない。目録は「残ったもの」の記録であって、「あったもの」の記録ではない。鍋の中から家族に渡された手引きが見つかった、という採録者の注があるが、その手引きは台所の用法を教えても、教団の用法は教えない。宛先のなくなった郵便と同じく、この目録も、受け取る者のいない数量の集まりになりうる。
