# 庫三　配達

庫三は教団の「配達」を担った。名を負わない部署である。庫三という呼び名も、番号と担当の組み合わせにすぎない。彼が残したのは日誌ではなく、受領の控えである。誰が受け取り、何個の箱が届き、何を返したか。それだけが書かれている。

| 日 | 品 | 数 |
|---|---|---|
| K2・春 | 詰め物の詰まった段ボール（中身は記載なし） | 4 |
| K2・夏 | 同じ寸法の段ボール | 6 |
| K3・秋 | 布で包んだ長箱 | 1 |
| K3・冬 | 段ボール、角の潰れたもの | 2 |
| K4・春 | 名のない小包 | 3 |
| K5・夏 | セイリャク事件の後の返却箱 | 5 |
| K6・冬 | 段ボール（宛先が二重に訂正されている） | 2 |
| K7・秋 | 空の段ボール | 1 |
| K8・春 | 段ボール | 4 |
| K9・閉座の日 | 受取拒否の記録のみ | 0 |
| K10・解散 | 返送、宛先不明 | 3 |

合計は数えられない。庫三は最後の頁に「数は、数えた者が決める」と書いた。閉座の日、彼は箱を一つも届けていない。受取を拒まれた記録だけが残っている。解散の年、三つの箱が戻ってきたが、送り主の欄は空だった。

註。配達は、組織が外と交わす最小の契約である。教義は魂の分岐を説くが、配達は分岐しない。一つの箱が一つの宛先に着く。その一回性だけが、教団の外の世界と噛み合っていた。

---

## 編纂註

**一、名付けの手口（呼称の固定）**
相手に何をするか。配達係を「庫三」という機能名で呼び、個人名を消す。受け取る側も、誰が来たかを覚えない。名ではなく役割だけが記録に残る。被害の側から見れば、自分が誰と契約したのか分からないまま、物だけが家に積もる。壊れるのは、記録の外で「あの人」と呼べる関係が消えたときである。

**二、受領の手口（控えの非対称）**
相手に何をするか。渡す側は控えを取り、受け取る側には何も渡さない。受け取った者は、自分の家に何が届いたかを証明できない。後になって「そんな約束はしていない」と言っても、箱はすでに開いている。壊れるのは、控えが一方的に積み上がり、相手の記憶だけが薄れたときである。

**三、返却の手口（宛先の空欄）**
相手に何をするか。解散の年に、送り主の欄を空にしたまま箱を返す。受け取った者は、返す相手を探せない。組織はもうない、という事実を、物の側から突きつける。壊れるのは、箱を開けた者が、中身ではなく空欄のほうを読み始めたときである。
