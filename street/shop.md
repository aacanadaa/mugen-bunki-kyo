# 街一　帳簿

紙と蝋を売る店の、十二冊目の帳面。店の名は〈うすべり〉。記入しているのは店主ではなく、夜にだけ来る帳附けの者で、この街では、売った数を書かなかった日は、なかった日とされた。

| 日 | 客 | 備考 |
|---|---|---|
| K8.11.2 | 十七 | 封筒三束、蝋六。常の日。 |
| K8.11.9 | 十五 | 雨。灯を一つだけ点けて開ける。 |
| K8.11.16 | 四十一 | 同じ紋の外套。封筒六十、白紙二束。名は聞かずに束ねる。 |
| K8.11.23 | 十九 | 教団の人が、釣りは要らぬと言う。要らぬと書く。 |
| K8.11.30 | 六十二 | 月の終わり。街の者が、あの店は数えられていると言う。 |
| K8.12.7 | 二十一 | 常連が二人、来なくなる。理由は書かない。 |
| K8.12.14 | 五十八 | 教団の人の列。買うのは紙と蝋だけ。他の物は買わない。 |
| K8.12.21 | 十二 | 街の者が帳面を三日借りていく。返る。数は変わっていない。 |
| K8.12.28 | 九 | 開ける。灯を消す。 |
| K9.1.4 | 三 | 教団の人が来て、この帳面を閉じよと言う。閉じない。 |
| K9.1.11 | 零 | 誰も来ない。零も数える。 |
| K9.1.18 | 一 | 教団の人が一人、白紙を一枚。代を取らない。取らなかったと書く。 |

この帳面には、売った物と、来た人の数だけが書かれている。誰が何を信じているかは書かれていない。欄がない。欄の外に足された文字は三つの筆跡に分かれ、いずれも日付を持たない。

教団の人が最初に現れたのはK八年十一月である。外套の紋が揃い、買う物も揃っていた。封筒、白紙、蝋。手紙を書くための物だが、書き終えた手紙をこの店は一度も預かっていない。預かれない。店は紙と蝋を売るだけで、宛先を知らない。

客の数は十七から六十二まで動いた。動きは教団の集まりの日と重なった。重なったというだけで、街は店が教団のものだと決めた。決めた者は帳面を三日借り、返した。数は変わっていなかった。変わっていないことが、疑いを強くした。書き換えられない帳面は、書き換えない意志の証拠と読まれた。

この店は街の一筋目、水の出る栓の向かいにあり、店先には数えるための低い机が一つあるだけだ。机の上で蝋を包み、包んだ数を帳面に移す。移す作業は短い。短い作業が十二年続くと、街の記憶より帳面のほうが正確になった。正確であることは、店の味方にはならなかった。

店主は疑いについて何も書いていない。書いたのは、閉じよと言われて閉じなかった、という一行だけである。この教団で、閉じないことは罪ではない。罪は、閉じることである。店主はそれを知らなかった。知らないまま、閉じなかった。知らなかったことは、どこにも書かれていない。

帳面は店の奥、蝋の箱の上に置かれている。誰でも開ける。開いた者は大抵、自分の来た日を探す。探して、数だけがあって名がないことを確かめ、少し安心する。安心した顔を、帳附けの者は書かない。書く欄がない。

K九年一月十一日、客は零である。零も数えた。数えた以上、その日はあった。一月十八日、教団の人が一人、白紙を一枚だけ買った。代を取らなかった。帳面は、取らなかったことを取ったと書いている。数は、いつも少しだけ遅れて届く。

---

## 編纂註

**一　この記録がしていること**

帳簿は、教団を客として記録する。信を数えず、買った物だけを数えることで、検証できない内面を、検証できる足跡へ置き換える。置き換えられた瞬間、教団はこの店と取引のある相手になり、店は教団と取引のある店になる。帳簿は証言しない。ただ列を作り、その列は読む者によって証言に変えられる。この文書の力は、書かれた内容ではなく、書かれなかった欄の形にある。

**二　誰に何をするか**

この記録は、街の者に数を渡す。数は疑いを増やしも減らしもせず、ただ疑いに住所を与える。教団の側には別の作用がある。客として数えられることは紙と蝋を受け取ることに等しく、受け取ることは依頼を一つ完了させることに近い。教団は、自分たちが最も嫌う収束が、店の帳面のなかで毎日小さく行われていることに気づかない。気づけば帳面を閉じさせただろう。店主が閉じなかったので、双方とも気づかないまま、数だけが育った。

**三　どこで壊れるか**

零の欄で壊れる。数えない日はなかったことにされるが、零を書いた日は、なかったことにならない。書くという行為が、不在を一日に変えてしまう。同じ壊れ方が、教団の人の「代を取らなかった」という一行にもある。取らなかったことを、帳面は取引の欄に置く。備考は説明ではなく要約であり、要約はこの教団の唯一の罪に触れる。罪を犯しているのは教団ではなく、備考を書く手である。

**四　疑いの所在地**

街は教団を疑ったと記録されているが、この帳簿が示すのは、街が帳簿を疑ったという事実である。帳面を三日借り、書き換えられていないことを確かめ、それでも疑いを強めた。疑いは対象を変えても強度を保つ。帳簿はその保存装置として働いた。教団が買ったのは紙と蝋だけで、店が売ったのも紙と蝋だけである。それ以外のすべては、欄の外で足された三つの筆跡のものである。
