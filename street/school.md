# 街二　出席

街二区立第二共学舎、三年一組の出席簿の写しである。原本は縦罫の薄い冊子で、表紙には「開闕K12年度」とだけ記され、学校名の欄は空欄のまま残されている。以下は月ごとの集計を転記したもので、出席・欠席はいずれも延べ人数、在籍は三十一名、月の授業日は二十二日で、年度を通じて変わらない。

| 月 | 出席 | 欠席 |
|---|---|---|
| 四月 | 664 | 8 |
| 五月 | 650 | 22 |
| 六月 | 631 | 41 |
| 七月 | 602 | 70 |
| 九月 | 566 | 106 |
| 十月 | 524 | 148 |
| 十一月 | 468 | 204 |
| 十二月 | 396 | 276 |
| 一月 | 322 | 350 |
| 二月 | 250 | 422 |
| 三月 | 178 | 494 |

表を縦に読むと、毎月の合計は六百七十二で動かない。動くのは内訳だけである。四月に八人分だった欠席は三月には四百九十四人分になり、一月で出席を追い越した。にもかかわらず、転出入の欄は十二月まで「なし」の一行で、二月以降も退学・転出の手続は一件も起こされていない。在籍は最後まで三十一名である。

合計が毎月同じなのは、集計の作法による。欠席は出席に加算され、出席は欠席から引かれる。この帳簿では、この二つは同じ一つの数を分けたものであり、片方が増えれば片方が減る。だから帳簿は、年度の終わりまで一度も「足りない」と言わなかった。

教室には三十一の机があり、机には番号が振られている。番号は家の順に振られており、同じ家の子は続きの番号を持つ。だから欠席が増えても、机の並びは崩れない。空いた席は、家ごとにまとまって空く。

担任は年度中に二度変わった。最初の手は細く、出席の「出」の字が毎月わずかに傾いていく。次の手は潰れていて、欠席の数字だけが妙に大きい。十一月から理由欄を埋めるようになった三人目の手は、丁寧で、同じ大きさで、一字だけを書く。それまでは「発熱」「家事」などと細かく記されていた。十一月の初めに、理由欄は「家」で統一された。誰が決めたのかは書かれていない。

欄外の書き込みが三つある。ひとつは「一家で、という。子に聞いても、家が、としか言わない」。ひとつは「出席を取るのが怖い」。最後のひとつは、頁の余白に、別の筆で「疑い」とだけある。三人目の手とは違う。誰の筆かは分からない。

この帳簿の出席は、街の配給の台帳と毎月突き合わされた。出席している子の家には、その月の配り物が届く。欠席が続く家にも、しばらくは届いた。届かなくなったのは二月からである。台帳の担当者は、それを「止めた」とは書かず、「合わない」と書いた。

街の者は、この帳簿の写しを回覧した。回覧の順序は表紙の裏に鉛筆で書かれ、七つの家の名が並び、そのうち四つに小さく棒が引かれている。棒の意味はどこにも記されていない。街はこの帳簿を根拠に教団を疑った。だが帳簿が数えているのは、子ではなく家である。家が来なくなった、と書く欄は、この世のどこにもない。

## 編纂註

一、この記録がしていること。ここには児童の個人が数えられていない。出席は家の連続、欠席は家の保留として計上され、合計は常に六百七十二に保たれる。合計が動かない以上、帳簿は「誰かが来なくなった」ことを表現できない。数えられているのは、教室に座った身体ではなく、その身体を差し出した家の側の意志である。出席の記録は、家の記録である。名簿の裏返しの家系図が、ここに綴じられている。

二、誰に何をするか。この帳簿は、子を家に縫い付ける。転出の欄が空である以上、子が家から離れる手続は存在せず、欠席はいつまでも欠席のままで、退学にはならない。読む者——担任、台帳の吏、そして街——は、家の状態を子の状態として受け取り、子の口から出た「家」の一字を、子の言葉として処理する。記録は子を守らない。子を家の代理として固定し、家の名で出席を求める。

三、どこで壊れるか。一月、欠席が出席を上回る。合計が六百七十二で均衡したまま、教室だけが空になる。この均衡が疑いを不可能にする。街が教団を疑うために開いた帳簿は、家の数しか示さず、家は最後まで三十一のままだった。壊れるのは記録ではなく、記録を読む者の側である。読む者は空いた席を「家」と読み、家を「子」と読み替え、やがて自分の読みを疑わなくなる。疑いは、帳簿の外でだけ育つ。

四、来歴。K10の解散ののち、この帳簿は街の役所の棚に移り、K12になって「欠席」の欄だけが別の紙に転記された。転記した者の名はなく、日付もない。表紙には「開闕K12年度」とあるが、K12にこの学校はもう存在しない。疑いの文書は、常に疑う側の手で作られ、その手を記録しない。この写しも、その手の一つである。
