# 家十　年表

一軒の家の四世代を、教団の暦と並べて置いた表である。左から読むと家の都合、右から読むと組織の都合になる。同じ行にいても、行同士は繋がっていない。

| 年 | 家 | 教団 |
|---|---|---|
| 1971 | 曽祖父三十四歳。町の印刷所に勤め、長男（祖父）が生まれる。家に聖典の類は一冊もない | K1 創立。教主、名を名乗らない |
| 1974 | 曽祖父、胃を悪くして残業をやめる。家計は曽祖母の内職で補う | K2 最初の分岐式。参加者は十九人 |
| 1976 | 曽祖母、近所の婦人会で「分かれ道は選ばなくてよい」という話を聞く。帰り道、同じ話を二度する | K3 支部の立ち上げ。近隣三町に拠点 |
| 1978 | 曽祖父、入会。会員名簿に「家十」とだけ記される。以後、この家は番号で呼ばれる | K4 名簿の統一。世帯単位の記帳が始まる |
| 1980 | 祖父（十歳）、日曜ごとに集会へ連れて行かれる。歌を覚えるが、意味は教わらない | K5 少年部の設置 |
| 1983 | 曽祖母、退会。理由はどこにも書かれていない。台所の会話が減る | K5 後半、会員数の伸びが止まる |
| 1985 | 曽祖父、幹部候補の名簿に載る。家に来る人が増え、畳が傷む | K6 幹部養成。候補は世帯ぐるみで選ばれる |
| 1988 | 祖父、十七歳。入会を保留。進学と集会の日程が重なった、とだけ記す | K6 拠点の再編 |
| 1991 | 曽祖父、急死。葬儀の受付に教団の名があった。香典帳の字は他人のもの | K7 葬儀への関与を始める |
| 1993 | 祖父、結婚。祖母は教団の存在を知らされないまま、同じ家に住み始める | K7 会員の家族への説明義務を定める（守られていない） |
| 1996 | 祖母、初めて集会に同行。二回で行かなくなる。理由は聞かれもしない | K8 家庭内の「未入会者」を記録する様式 |
| 1999 | 父、生まれる。届出の世帯欄は曽祖父の名のまま | K8 |
| 2001 | 曽祖母、死去。遺品の袋に古い会員証。番号は家十のまま | K9 会員証の更新 |
| 2004 | 祖父、退会届を出す。受理の通知は来ない。以後も年賀状だけ届く | K9 退会者の名簿を別に作る |
| 2007 | 父、十二歳。祖母から教団の話を一度だけ聞き、それきり誰も触れない | K10 解散。資産と名簿の行き先は公表されない |
| 2010 | 家の会話から教団が消える。仏壇の位牌だけが残る | K11 名を変えた集まりが、別の地区で確認される |
| 2014 | 父、結婚。母はこの記録の存在を知らない | K11 |
| 2017 | 孫、生まれる。家に教団の記憶を継ぐ者はもういない | K12 |
| 2019 | 孫、箪笥の引き出しから古い名簿を見つける。読めない番号を親に訊ね、答えを得られない | K12 現在 |

## 編纂註

**一** この記録がしているのは、家の内側の時間を、教団の暦に換算せずに並べ直す作業である。残っている紙は三種しかない。会員名簿、古い会員証、葬儀の受付簿。いずれも教団が作ったもので、家が作ったものは一つもない。だから表の左側は、紙と紙の隙間を家族の記憶で埋めた推定である。推定であることを行ごとに示せないのが、この表の弱点である。

**二** この表がするのは、子孫——とくに教団を知らない世代——に、家の歴史を「入った／やめた」の二値で語れなくすることである。曽祖父を信者に、曽祖母を被害者に、祖父を離脱者に固定しない。三人は同じ家にいて、それぞれ別の理由で、別の向きに動いた。表はその動きを一列に並べるだけで、意味づけはしない。意味づけは読む者に残される。

**三** 壊れるのは年の対応である。教団の K は組織の都合で進み、家の年は誕生・死去・進学で進む。K10 の解散は、この家の年表では「父が十二歳だった年」でしかない。逆に曽祖父の死は、教団の側では何の事件でもない。二つの時計を同じ行に置くと、対応しているように見える。見えること自体が、この表の誤りである。

**四** 書けなかったことも記す。曽祖母が退会した理由、祖母が二回で行かなくなった理由、祖父が退会届を出した日の天気。家の年表は、組織の年表と重ならない。重ならないという一事を、この表は二十行を使って示しているにすぎない。
