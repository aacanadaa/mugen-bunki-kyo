# 索一　件名索引

『群典』は十二品からなるとされるが、揃った写本は一冊も確認されていない。本索引はK10の解散後、教団の外で作られた。作成者は索一とだけ名乗り、信者であったこと以外は何も記していない。頁は手元の写本に従った。K9閉座ののち綴じ直されたものなので、他の写本とは合わない。

件名は信徒が唱えていた順に並べた。第五品「畳みは慈悲」を三三頁に置き、十二使徒の章をこれに続けた。使徒の名は人名ではなく、切る、流す、重ねるといった手順の名である。K5セイリャク事件は事件の記述ではなく、事件を語る章の名として立てた。事件そのものはどの写本にも残っていない。章だけがある。

頁は写本の右肩に鉛筆で振られていたものを写した。同じ章に二つの頁が振られている箇所が三つあり、そのうち二つは私が消した。消せなかった一つは、欠の章の八六頁と結の章の九一頁のあいだに挟まっている。挟まった頁には件名がない。件名のない頁は索引に載せない。載せないことが、この仕事で私がした唯一の取捨である。

使徒の章には、それぞれ短い問いが一つだけ置かれている。問いはどれも同じ形で、「これは一つか」と尋ねる。答えは書かれていない。答えを書けば章が閉じるからである。閉じない章を、信徒は暗唱した。暗唱された章は、書かれた章より長く残る。

写しは三つ現存する。どれも同じ手で書かれ、同じ箇所で同じ字がにじんでいる。写した者が三人いるのか、一人が三度写したのかは分からない。写しのあいだで頁が一つずつずれていくので、最も古いものを底本にした。古いものが正しいとは限らない。索引は正しさを扱わない。

使徒の章はどれも同じ長さではない。切番が最も短く、写が最も長い。この順は、教団が閉座の直前に定めた順と一致しない。定めた理由は記録にない。記録がないことを、私は欠落とは呼ばない。呼べば、この一冊が一つの物語になってしまう。

索引を作るとは、並べ直すことである。教義では、それは収束にあたる。この一冊が誰の手で作られたかを、私は問わない。問えば答えは決まっている。決まった答えを書くことも、また収束である。

## 編纂註

頁のない項目は、書かれなかった章である。現在（K12）は書かれなかった。書けば閉じるからである。

一、空頁の予約
目次は有限であるのに、末尾だけが開いている。読む者は、まだ来ていない完成を先に信じる。足りない部分は読む側が自分で埋め、埋めた内容は教義の一部になる。埋めた本人は、それを自分の読み違えとして受け取る。壊れるのは現物を数えたときである。頁は数えられ、無い頁は無いと分かる。綴じ目の厚みが、神秘をただの欠落に戻す。

二、索引の委任
名づけと順序を任される。信頼された、序列を与えられたと受け取る。だが名づけた瞬間、後の読者はその順でしか読めなくなる。要約は罪と説かれているので、作った本人は自分の仕事を人に渡せない。壊れるのは、索引が「何を一つとするか」を決める作業だと気づいたときである。決めることは収束であり、禁じた罪を、禁じた側が最初に犯している。

三、頁を数えさせる
内容ではなく量と順序を、証拠として数えさせる。頁があるのだから問いの場所もどこかにあるはずだと思わせ、「分からない」と言えなくする。読んだ量が、変わった証拠にすり替わる。壊れるのは写本を突き合わせたときである。閉座で一章が足され、解散で一章が抜かれた写本では、番号が同じでも中身が違う。番号を合わせた瞬間、索引は現物から剥がれる。
