# 住四　住所

この表は、真戸（まど）家の四代にわたる住所を、教団の名簿・区の台帳の写し・家族からの聞き取りによって並べ直したものである。曾祖父母の代には教団はまだなく、孫の代には教団はもうない。残っているのは住所だけである。住所は、家の履歴である。どこに住んだかは、その家が何を信じ、何を手放し、何を黙ったかの順序と重なる。

教団はK1に興り、K10に解散した。この家が教団と触れたのは、そのほぼ全期間にあたる。ただし触れ方は一様ではない。入った者、残った者、離れた者、最後まで知らなかった者が、同じ表の中に並ぶ。表は彼らを分けず、同じ二列に収める。

| 年 | 住所 |
|---|---|
| K前31 | 鈍色市梔子区昏田町二丁目（借家）／曾祖父母 |
| K前18 | 同区昏田町四丁目（間借り）／曾祖母・祖父 |
| K前6 | 同区月代台三番街の新築／祖父・祖母 |
| K1 | 月代台（変更なし）／曾祖母、町内の集会所へ通い始める |
| K2 | 月代台（変更なし）／祖母が入信、住所を教団へ届け出る |
| K4 | 白汀の第一分岐寮（教団所有）／一家で転居 |
| K5 | 第一分岐寮（変更なし）／名簿の住所と実住が分かれる |
| K6 | 第一分岐寮（変更なし）／母が婚姻で入居 |
| K7 | 第一分岐寮（変更なし）／長女誕生、教団が生誕の地として記録 |
| K8 | 昏田町の旧宅界隈（単身）／祖父が離脱、名簿から住所抹消 |
| K9 | 名無坂の第二分岐寮／祖母・父一家。母は実家へ一時退去 |
| K10 | 第二分岐寮（変更なし）／解散。住所の管理が止まる |
| K11 | 梔子区の民間アパート／父一家。祖母の欄は更新されない |
| K12 | 月代台の団地／孫。教団を知らない |

表の右側に住所だけを置いたのには、二つ理由がある。第一に、教団が住所を教義の単位として扱ったからである。転居は「分岐」と呼ばれ、同じ屋根の下にいることすら分岐の一つに数えられた。第二に、解散後に名簿の住所と実際の居住が食い違い、住所を消せば家族の順序まで消えるからである。K10からK12の三年は、とくに薄い。名簿は止まり、記憶は争い、表は空欄を抱えたまま現在に着く。

K12の欄に住む孫は、教団の名も、分岐という語も知らない。知らないまま、月代台の団地の一室に住んでいる。曾祖母が通った集会所のあった町から、その団地までは歩いて二十分ほどの距離がある。孫が生まれたのは解散の二年後であり、この住所は教団の名簿に一度も載っていない。載っていないという事実だけが、この欄の内容である。

祖母の欄は、K11で更新が止まる。止まったことは書けるが、なぜ止まったかは書けない。書けないことを空欄にしないために、この表は行だけを残し、住所を置かない。行が残っている限り、そこに誰かがいたことは消えない。

表を作るうえで、三つの出典はしばしば食い違った。名簿は教団の論理で書かれ、台帳は行政の論理で書かれ、記憶は家族の論理で書かれる。もっとも正確なのはどれでもない。もっとも長く残るのは、たいてい台帳である。人が信じたことを忘れても、建物の番地は残る。その番地を手がかりに、この家がどこで教団に入り、どこで教団から出たのかを、表は静かに指している。行数は十四、年数は四十余年。四代のうち、教団の語を自分の言葉として使ったのは二代、使わされたのは一代、知らないのは一代である。

## 編纂註

一、この記録がしているのは、一つの家の住所を年ごとに固定し、教団の名簿上の住所と実際に居住した場所を同じ行に並べる作業である。住所を信仰の単位に変えた教団の手法を、告発の語ではなく配置によって示す。表は誰も裁かない。裁きの代わりに、同じ大きさの枠をすべての年に与える。枠の大きさが揃っていること自体が、この表の主張である。

二、この表がするのは、名を伏せた親族の記録を、読者自身の家の年表に重ねられる形で差し出すことである。入った者には理解を、残った者には同情を、離れた者には正当性を、知らない者には驚きを、読む側が配分する。配分は人によって変わる。表はその変更を禁じない。禁じない代わりに、どの欄も同じ強さで印字されている。

三、壊れるのはK10の行である。解散によって住所の管理者が消え、名簿の住所は教義上の住所と実際に住んだ場所に分裂する。K11以降は聞き取りの重なりで埋めた推定であり、兄弟の記憶は一致しない。表の連続性はここで一度切れ、以後の行は空白の多い推定図になる。欠落を欠落のまま置くことが、この表の唯一の正確さである。

四、年号は教団の暦に従い、K前は創立以前を指す。一つの年に複数の住所を収めたのは、家族が同じ年に別々の場所にいたためである。空欄は欠落ではなく、記録者が知らないという事実の記録である。この区別を守らないと、表は家を裁く装置に変わる。守っている限り、表は家の履歴のままである。
