# 隠二　記録

教主に本名はない。教団の帳簿は、滞在者を名で呼ばない。「隠二」は記録係の呼び名で、代々受け継がれる。以下の表はK12の春から秋にかけて、東の宿舎の入口に掛けられていた一枚である。記入は当番が行い、後から三行が加筆されている。筆跡は二種類ある。誰が加えたかは、どの記録にも書かれていない。

表の欄は三つしかない。名、日、理由。理由の欄に書いてよい語は内規で三つに限られている。「見るため」「数えるため」「戻るため」。この三語で埋まらない滞在者は、埋まるまで帰れない。埋まるまで延びた日は「日」の欄に足される。だからこの表の日数は、滞在の長さではなく、理由が決まるまでの長さである。三語は互いに排他的でもない。同じ滞在者に、季節ごとに別の語が当てられることがある。当て直しは訂正と呼ばれ、訂正は加筆ほど丁寧には扱われない。

| 名 | 日 | 理由 |
|---|---|---|
| 灯守 | 12 | 見るため |
| 岸なし | 9 | 数えるため |
| 三度目の冬 | 21 | 戻るため |
| 白い継ぎ目 | 7 | 見るため |
| 名なしの妹 | 34 | 数えるため |
| 折り目 | 5 | 戻るため |
| 東の聞き手 | 16 | 見るため |
| 二重の影 | 11 | 数えるため |
| 沈黙の代筆 | 28 | 戻るため |
| 仮の窓 | 3 | 見るため |
| 紐の記憶 | 19 | 数えるため |
| 最後の欄 | 40 | 戻るため |

この様式はK1から続くと言われる。だがK10の解散時に運び出された帳簿は一冊だけで、その一冊にこの表はない。様式だけが残り、記入の作法だけが伝わった、と教団は説明する。説明する者は、たいてい隠二である。

滞在中に語られたことがらは、教主の予言、治癒の証言、秘伝の授与、そして試しである。予言は日付を伴わずに語られた。当たった分だけが表の余白に書き写され、外れた分は「畳まれた」と言われて残らない。治癒については、当番が「見た」と一行だけ書いている。熱を測った者も、診た者も、記録には現れない。同じ宿舎で同じ症状のまま退去した者の行は、表にない。治らなかった日は、どの欄にも置き場所がない。

秘伝は、日数が一定を超えた者にだけ渡された。内容は記録しない、と記録に書いてある。書かないという規則だけが几帳面に残っている。試しもまた、方法を書かない。表に残るのは日数だけである。方法を書かない同じ筆で、日数だけが数えられている。何を耐えたかは残らず、耐えた日だけが資産になる。

退去した者の名は表から消される。消された跡は、行の高さで分かる。表の末尾に、理由の欄が空の行が一つある。日は横棒で、名は消されている。加筆された三行のうち一行はこの行のすぐ上にある。消された名の下に、別の筆で「戻るため」と書かれ、それがまた消されている。二度消されている。

## 編纂註

**一、三欄の法**
この手口を、こちらでは「三欄の法」と呼ぶ。滞在の理由は三種類しかない、とこの表は主張している。だが実際に起きているのは、人の動機をあらかじめ三語に翻訳させ、経験をその語の後ろに並べ直させることである。理由が先にあり、出来事が後から合わせられる。壊れるのは、欄の外に理由を持つ者が必ず現れるところだ。その者は記録の上でだけ、理由を持たない者になる。

**二、証言の採取**
奇蹟や治癒を、本人の言葉ではなく当番の一語に置き換える手続きを、ここでは「証言の採取」と呼ぶ。測定した者も、第三者も記録に加わらない。何が起きたのかではなく、誰が「見た」と言ったのかだけが残る。この種の主張は、診断も経過も持たない。壊れるのは、治らなかった者の行を表に置けないところである。空いた行の多さは、治った数の少なさより雄弁だ。

**三、試しの日数化**
苦行を方法ではなく日数として記録する。これを「試しの日数化」と呼ぶ。方法が書かれないので、残るのは耐えた長さだけであり、それが信仰の単位になる。短い日数は本人の不足として読まれ、長い日数は教団の慈悲として読まれる。壊れるのは、退去者が方法を語るときではなく、その日数が自分にとって何だったかを語り始めるときである。教団はそれを秘伝の漏洩と呼ぶが、漏れたのは方法ではなく負荷である。
