# 監一　資産

開闕K1よりK12に至るまでに残された物の目録である。教団はK10に解散し、K12現在、法人格も集会所の使用権も失効している。以下は閉座（K9）時点の簿冊、解散時の引継書、および残置物の実地確認を突き合わせた結果である。金額は当時の帳簿記載をそのまま引き、現在価値への換算はしていない。

| 種 | 額 | 備考 |
|---|---|---|
| 不動産 | 土地一筆（約百二十坪）・建物二棟 | 閉座後は使徒「閉」の個人名義で登記。K10の解散決議に処分条項がなく、名義人はK11に死亡。相続人不在。 |
| 不動産 | 分岐室十二室（賃借） | 契約は使徒「結」が個人で締結。K9以降の賃料支払記録は三箇月分のみ。 |
| 備品 | 折り畳み机四十二脚、長椅子百八脚 | 倉庫二箇所に残置。うち一箇所は鍵の所在不明。 |
| 備品 | 複写機三台、紙裁断機一台 | 第五品の印刷に用いた。K10以降、稼働記録なし。 |
| 備品 | 位牌・名板 約六百点 | 「写」が管理した分岐名簿と対応しないものが四割。 |
| 現金 | 手許金 百四十七万三千円 | K9閉座時の残高。解散時の分配記録がなく、使徒「均」の私的保管と推定。 |
| 現金 | 預金 六百二十万円 | 口座は教団名義。K10以降、休眠。 |
| 現金 | 未収入 約九十万円 | 講の参加費の未納分。回収不能。 |

概算の合計は八百万円前後。ただしこれは「あった額」であって「ある額」ではない。閉座以降、この教団には資産を保全する主体が存在しない。名義、鍵、帳簿は、それぞれ別の人物の手に一点ずつ渡った。それを突き合わせる作業は、もはや監査ではなく考古学に近い。

備品で最も多いのは椅子である。十二使徒の各分岐に一つずつ、という説明が引継書にあるが、百八脚は十二では割り切れない。割り切れないことを記録した者がいない。記録しないことが、この教団の作法であったらしい。

註して置く。資産は、教義より長く残る。教義はK10に解散し、K12現在、誰も唱えない。しかし土地は残り、椅子は残り、休眠口座は残る。教団が「収束」を唯一の罪としたことと、その教団の残骸が未だ収束していないことは、同じ一つの事実の表と裏である。資産の監査とは、要するに、片付けられなかったものの一覧にほかならない。

## 編纂註

一、名義の据え置き。閉座の折、土地と建物を使徒「閉」の個人名義へ移し、教団の帳簿からは落とさない。被害の側から見れば、帰責が一人に集まり、残る十一人は「何も持っていない」ことになる。壊れるのは名義という形式そのもので、名義人の死とともに権利は相続人不在の宙に浮く。

二、鍵の分散。管理を細かく分け、全体を知る者を置かない。被害の側では、自分が何の一部を預かっているのか分からぬまま、責任だけを負う。破れるのは突合の場面である。鍵、名簿、帳簿のどれか一つが欠ければ全体が動かず、欠けた者だけが責めを負う。

三、額の語り。「あった額」を「ある額」として語り、保全の主体が消えた後も残高だけを反復する。被害の側では、存在しない金を前提に分配を争うことになる。壊れるのは死亡や解散という事実の前で、そこでは帳簿の数字が一切通用しない。
