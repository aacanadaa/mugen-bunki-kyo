# 監二　負債

K12年、解散した教団の残務を数えるため、会計簿、使徒の私信、元信者の申立を突き合わせた。教団はもう存在しない。残っているのは宛先と額、そして支払われなかった時間だけである。次の表は、監二が確認できたものに限った。確認できなかったものは、額の欄に現れない。

| 宛先 | 額 | 備考 |
|---|---|---|
| 印刷所「層」 | 1,240,000円 | K7『畳みの書』増刷分。検収印がなく、請求書だけが残る。 |
| 会場主「間」 | 380,000円 | K8閉座式の会場残金。K9以降、返還の連絡は途絶えた。 |
| 使徒・切番の実家 | 2,100,000円 | 敷金、滞在費、仕送り。家族は「貸した」と記す。 |
| 使徒・流の知人 | 460,000円 | 搬送費の立替。領収書は一枚。宛名は教団名でない。 |
| 宿「半日」 | 172,000円 | K5セイリャク事件後の滞在費。部屋は四日分のみ記録。 |
| 運送業「荷」 | 89,000円 | 機材搬出の運賃。搬出先は空欄。 |
| 元使徒・閉 | 300,000円 | 寄付を「貸付」に訂正する申立。教団側の反論はない。 |
| 教主 | 0円 | 借入の記録なし。署名欄だけが残る。 |
| 合計 | 4,741,000円 | 利子、慰謝料、算定不能分を含まない。 |

表の額は、返済の約束ではない。関係の残骸である。印刷所は本の宛先を覚えており、実家は送金の日付を覚えている。教団の帳簿はK9で閉じたが、相手側の記憶は閉じていない。監二の仕事は、この非対称を記録することであって、回収することではない。K10の解散宣言に清算の条項はなく、K12現在、宛先のいくつかはすでに所在不明である。

宛先の多くは、教団の内部名で書かれている。本名でないため、請求の相手に届かない。印刷所「層」、宿「半日」、運送業「荷」は、いずれも取引時の呼び名で、正式な名称ではない。監二は便宜上そのまま記した。この表の宛先は、請求先の一覧ではなく、呼び名の一覧である。

表に載らないものの方が多い。交通費、宿代、差し入れ、家族の休業、通院の付き添い。これらは領収書を持たないため、この表には入らない。だが、負債の重さは額に比例しない。十万円の借用書より、返さなかった一回の約束の方が長く残ることがある。

K11、元使徒・写が私費で印刷所と宿の一部を支払った。領収書には「残りは教団に請求しない」とある。これは返済ではなく、負債の放棄である。放棄された負債も、関係が終わったことを意味しない。宛先は消えても、支払った事実は残る。

教主の欄が零なのは、借りがなかったからではない。記録を残さないことが、この教団の唯一の返済方法だった。署名だけが残り、額は残らない。監二はこの欄を消さずに残した。空欄もまた、関係の記録である。

利子は付けない。付ければ額は増えるが、関係の形は変わらない。監二が見たいのは、誰が誰を覚えているかである。

## 編纂註

**一「恩の前借り」**　入信前の食事、交通費、宿代を先に払い、金額を告げず「気持ちで返して」とだけ言う。相手は借りの輪郭を持てないまま、断りにくくなる。返済の期限も額も自分で決められず、断るたびに恩知らずと読まれる。壊れるのは、金額と日付を明示されたときだ。恩は契約に変わり、貸し手の優越が消える。負債は、関係の記録である。

**二「分割の囲い込み」**　少額を長期に分割し、毎月の連絡を返済の条件にする。相手は完済まで関係を切れず、連絡のたびに教団の言葉を聞く。返済は生活の一部になり、借りは習慣になる。予定表は教団側だけが持ち、相手は残額を自分で計算できない。壊れるのは、一括返済や第三者の肩代わりで接触の口実が消えたときだ。分割表そのものが、相手の拘束を可視化してしまう。

**三「帳簿の共有」**　個々の借りを教団の共有財産として扱い、返済を奉仕に読み替える。相手は「みんなのため」の未払いを負い、退出が裏切りになる。金額は共同体の物語に吸収され、請求の相手が見えなくなる。壊れるのは、帳簿を宛先ごとに閉じ、清算の単位を個人に戻したときだ。物語が剥がれ、ただの未払いが残る。誰が誰に借りたのか、もう言い訳はできない。
