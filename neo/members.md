# 新七　会員

〈本文〉

解散から二年。教団の名を口にする者はもう少ないが、名簿だけが残った。聞き取りと紙片を突き合わせて復元した一覧が、以下の二十名である。本名は記さない。当時も、名簿に本名を書く者はほとんどいなかった。受付で渡された番号が、そのまま人称になった。

| 002 | 二十七 | 給食の調理 |
| 003 | 四十一 | 大工 |
| 004 | 十九 | 学生 |
| 005 | 五十八 | 清掃 |
| 006 | 三十一 | 経理 |
| 007 | 二十四 | 古書店の店員 |
| 008 | 三十八 | 配達 |
| 009 | 二十二 | 縫製 |
| 010 | 四十六 | 理容 |
| 011 | 二十九 | 事務 |
| 012 | 十七 | 学生 |
| 013 | 五十二 | 電器店 |
| 014 | 三十五 | 保育 |
| 015 | 四十三 | 花屋 |
| 016 | 二十六 | 運転 |

| 020 | 二十八 | 夜間の清掃 |

二十名の中央値は三十三歳。職業はばらばらに見えて、二つの塊がある。ひとつは手を動かす仕事——大工、縫製、給食、清掃。もうひとつは数を扱う仕事——経理、事務、配達。前者は「依頼」という言葉を、後者は「分岐」という言葉を好んだ。聞き取りで繰り返されたのは、教義の内容ではなく、説明の手間が省けるという理由だった。「ここでは、まとめなくていいと言われた」。それだけを覚えている者が多い。

二十名という数は、最盛期の記録とは合わない。集まりには四十人以上がいたという証言もある。だが名簿に残るのは、番号を渡され、欄を書いた者だけである。立っていただけの者、途中で来なくなった者は、最初から数えられていない。この一覧の「数」は、参加の総量ではなく、書くことに同意した人数である。

教団の暦でK一〇、解散は教団側から告げられた。理由は最後まで明かされず、代わりに「依頼は終わっていない」という一行だけが残った。名簿は回収されず、各人が自分の番号の欄だけを持ち帰った。その断片が、いまは個人の手で複写され、配られている。

番号は年齢順でも受付順でもなく、教団が独自に決めた順序だったらしい。聞き取りでは「意味はなかった」と笑う者がいる一方で、「あの順番で呼ばれなくなった日が終わりだった」と語る者もいる。番号は個人を特定しないための仕組みであり、同時に、呼ばれる順番を保証する仕組みでもあった。名簿が個人の手に渡った後も、番号だけは手放さない者が多い。

K一二の現在、この一覧は教団の資料ではなく、一つの雛形として読まれている。欄は空いたまま、番号だけが先に埋まる。年齢を書き、職業を書き、自分が何番目だったかにする。かつて所属した者の追悼ではなく、所属しなかった者のための様式になった。

## 編纂註

一　この一覧がしているのは、所属の記録を所属の形式へずらすことである。番号・年齢・職業という三つの欄だけで、人は「そこにいた」ことになる。空欄は省略ではなく、これから埋まる約束として読まれる。読む者は中身を読まず、欄の埋まり方を見る。名簿は証言の代替物になり、証言より先に信じられる。ここで記録は、過去の保存ではなく、現在の参加の作法に変わる。

二　名簿が名指すのは、教団にいた者だけではない。番号を受け取らなかった者、誘いを断った者、解散後に初めてその名を知った者が、この表を読む。彼らは空欄を借りて、自分が「遅れて来た」のではなく「まだ番号を持っていない」のだと読み替える。一覧は所属の代用品となり、外部の者に固有の位置を与える。誰に何をするかといえば、参加しなかった者に参加の文法を配ることに近い。

三　数が増えると、一覧は統計の顔をする。統計になった瞬間、一人ずつの事情は背景に退き、年齢と職業の分布だけが語り出す。職業欄を埋められない者、年齢を偽って書いた者は、静かに名簿の外へ置かれる。収束を唯一の罪とした教義が、要約の装置を生み、その装置が今度は人を選別する。壊れるのはここである。分岐を守るための表が、分岐を数える表になる。

四　会員の一覧は、運動の社会学である。誰が来て、誰が残り、誰が番号だけを持ち帰ったかは、教義の注釈よりも正確に運動の輪郭を写す。ただし社会学は、往々にして対象を完成させてしまう。名簿が「全集」になったとき、分岐は止まる。編者はこの表を、完成した名簿としてではなく、まだ埋まっていない欄の集まりとして置いておく。
