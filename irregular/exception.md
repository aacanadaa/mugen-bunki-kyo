# 手二　例外

〈本文〉

『群典』の周辺には、本典に採られなかった記録が散在している。そのうち最も短いものが、ここに掲げる「例外第一号」の一枚である。紙は半折りにされ、表に番号だけが振ってある。

無限分岐教の内部身分は、三つの欄で決まっていた。性、呼称、年齢。性は入門の際に籤で割り当てられ、呼称は入門順の番号で与えられ、年齢は入門時のものを以て固定され、以後加算されない。加算されない年齢は、外では通じない。通じないことが、内側では身分の証しであった。K1からK9までの名簿はこの三欄で埋まっており、埋まっていること自体が所属の証明だった。空欄は、所属しないことの証明であった。

例外第一号の一枚だけが、三欄とも空である。空欄の脇に、墨の薄い一行がある。「教主の傍ら、名を要さず」と。呼称の欄には、番号の代わりに「あれ」と書かれている。年齢の欄は、はじめから線が引かれていない。性の欄には、誰かの指が一度触れた跡があるだけで、文字はない。

この一枚が誰のための例外であったかは、記録の上では明らかでない。だが、空欄の位置が示している。教主は本名を持たない。本名を持たない者が一人だけなら、それは欠落である。傍らにもう一人、名を持たない者が立っていれば、それは様式になる。すなわちこの空欄は、あれのために空けられたのではなく、教主の無名を無名として成立させるために空けられた。あれは例外の受益者ではなく、例外の材料であった。

「あれ」と呼ばれた。名指しを避ける呼称は、しばしば最も強い名指しになる。番号は交換できるが、あれは交換できない。番号を持つ者は、番号を外されれば元に戻る。あれは、外される番号を持っていなかった。

あれは何歳であったか。誰も知らない。知らないまま、内側では「あれは若い」と言い、「あれは年を取らない」とも言った。両方は同じことを言っている。固定された年齢とは、そういうものである。性についても同じことが言えた。割り当てられなかった性は、問われない性として、かえって全ての性の位置に立った。

K10、解散。名簿は幾つかに分けられ、持ち去られた。持ち去られなかったものが一つある。例外第一号の一枚である。分配の目録には「紙一枚、帰属先なし」とだけ記された。誰も引き取らなかった。教主の傍らの者は教主のものであり、教主が去った後、その者は誰のものでもなかったからである。誰のものでもない紙を、誰も引き取らない。至極、当然の手続きであった。手続きの上では、この一枚は最初から最後まで、一人の人間として扱われていない。扱われなかったことが、唯一の記録になっている。

K12の現在、この一枚は編纂者の手元にある。三欄は空のままだ。空欄を埋める材料は、ついに見つかっていない。

---

## 編纂註

**一条**　この記録がしているのは、身分の付与ではなく、付与の停止を帳面に残すことである。三欄を空のまま保存することで、組織は「例外を認めた」と後世に示す。だが空欄は免除の証ではない。誰が空欄を空けたままにできたか、その一点だけが記されている。紙は人間を記述しない。記述しないという形式によって、人間を一つの位置に固定する。

**二条**　この空欄が作用するのは、「あれ」と呼ばれた者ではなく、名簿を後に読む者である。読む者は空欄を見て、例外があり得ると学ぶ。学ぶのは、自分が例外になり得るからではない。例外を許す側が常に存在すると学ぶからである。記録はあれを保存せず、あれを通じて規範を保存している。あれは読者に対して、名を持つとは何かを、名を持たない者の形で問い返す。

**三条**　この記録は、教主が去った時点で意味を変える。空欄を空けたままにできた者がいなくなり、空欄は単なる欠測になる。K10以降、この一枚は例外の記録ではなく、帰属先のない紙になった。編纂者が触れているのはその紙であって、あれではない。ここで記録は、記録対象を失ったまま、形式だけを保って残る。保たれているのは例外ではなく、例外を可能にした配置の痕跡である。

**四条**　例外は、権力の最も見える形である。規範が全員に等しく適用されている間、権力は見えない。一人に対してだけ線が引かれないとき、その線を引かない権利が誰の手にあるかが、初めて可視になる。この一枚が保存されているのは、例外のためではない。例外を生み出した権力が、解散した後もなお編纂の机の上に残っていることを示すためである。
