# 部一　使用

〈本文〉

K1、二階東側の一室には、まだ名がない。机を二台運び入れたのは教主の指示を受けた信者三名で、用途は「面会」とだけ書かれた。『創立準備記録』の一頁は、日付、人数、「机、運搬済」の六字で終わる。窓は一つ、鍵は二つ。

K2、部屋は事務室になる。書記が帳簿を広げ、会計が封筒を数え、教主は週に二度、窓際の椅子に座った。机の配置は三度変わったが、窓際の椅子だけは動かなかった。当時の『執務日誌』は、同じ一日に「面会」と「事務」の二つの用途を並べて書き、どちらが本来の用途かを決めていない。

K3、用途は初めて文書の間で争われる。会計の台帳は「事務室」、書記の控えは「面会室」と記し、同じ部屋が二つの名で呼ばれる。以後、部屋の名は書いた者ごとに変わる。

K4、部屋は仮眠室を兼ねる。夜直の者が毛布を入れ、朝には再び机が戻る。『備品台帳』には「布団一組」が記載され、その翌頁に「布団、撤去」とある。撤去の理由はどこにも書かれない。

K5、教主が「教えの下書き」を書く部屋になる。若い信者二人が朗読の練習に使い、壁に声が染みついた、という手紙が残る。練習は夕方に行われ、近所の者が窓の下を通った、という記述が別の頁にある。手紙の差出人は、その壁を見たとは書いていない。

K6、面会は週一度に減り、代わりに「相談」が増える。誰が誰に相談したかは記録されない。ある手紙は「あの部屋で聞いた話」とだけ書き、同じ日の報告書は部屋を「空室」と記す。

K7、引っ越しの話が出て、測量の者が寸法を測る。使用の記録はなく、縦横と天井の高さだけが残る。部屋はこの時期、図面の上にしか存在しない。

K8、部屋は保管庫になる。棚が三本入り、椅子は廊下へ出された。ところが『議事録』の同じ頁には、なお「面会室」の語が残り、以後K10まで消えない。

K9、外部の来客の待合に使われる。誰が通したかは記されず、待った時間だけが「十五分」「四十分」と残る。待合の椅子は、保管庫から戻された一脚である。四十分の相手の名はない。

K10、解散。鍵は会計の机に置かれ、誰も受け取らなかった。最後の文書は、部屋の用途を「なし」と書く。書いた者は、この部屋を一度も使っていない。

K11、空室。誰も使わない期間、文書の上では最も多く使われる。各文書が過去の用途を引用し、部屋は引用の集まりになる。

K12、現在。部屋は物置として使われ、段ボールの一つに「面会」「事務」「仮眠」「保管」と書いた紙片が入っている。四つの語は同じ筆跡、同じインクである。誰が書いたかは、どの文書にもない。用途の数だけ、この部屋には入口があった。

書き手は、この部屋を使った者ではなく、使われた用途を数える者である。用途は部屋より長く残り、部屋は用途より先に忘れられる。

## 編纂註

**註一（対象の扱い）**　本章は部屋を描かない。描かれるのは、部屋に与えられた用途と、それを書き留めた者たちの癖である。対象は「使用」という行為であり、部屋はその都度の容器にすぎない。章はK1からK12までを均等に並べ、どの時期にも重心を置かない。結果として読者は、部屋の形も広さも最後まで知らないまま、用途の名前だけを覚える。

**註二（誰に何をするか）**　教主は全章に現れるが、教主に行為を割り当てる文書は一つも引かれない。部屋の名を決めるのは書記であり会計であり、夜直の者であり、来客を通す者である。彼らは互いに相談せず、それぞれの帳簿に自分の言葉で用途を書く。本章が行うのは、その無言の競合を並べ直すことであり、教主を中心に据える読み方を、資料の側から崩す作業である。

**註三（壊れる場所）**　破綻は二箇所に集中する。K2とK6では同じ日付に二つの用途が併記され、K8とK9では「面会室」の語が保管庫の記録に残留する。いずれも訂正されず、抹消もされていない。本章はこの矛盾を解消せず、章の骨格として保存した。整合を取る作業は読者に委ねられ、そのとき読者は、自分がどの記録を信じたいかに気づく。

**註四（用途の集積）**　部屋は、用途の集積である。机、布団、棚、待合の椅子は、いずれも部屋の属性ではなく、誰かが置いた用途の痕跡である。用途が増えるほど、部屋そのものは薄くなり、最後には紙片の四つの語だけが残る。本章が数えたのは部屋ではなく、部屋を通過した人手である。この数え方は、教主の伝記を書く際にも、そのまま当てはまる。
