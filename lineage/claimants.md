# 系二　自称

教主は本名を持たないとされ、その空白は教団の外でも埋められなかった。以下は、空白に自ら名を差し込んだ者たちの一覧である。年は開闕紀年、根拠は現存する資料のうち最も古い一件に限った。

| 名 | 年 | 根拠 |
|---|---|---|
| 灰島繼 | K2 | 宛名のない書簡一通。教主の筆跡に似るが、似せた箇所は一頁だけである。 |
| 白瀬悠 | K4 | 「分岐の夢」と題する口述の記録。本人は教団の名を一度も発していない。 |
| 礒野ミナ | K5 | 第五品の畳み方を伝えたという主張。証人は二人、いずれも後に撤回した。 |
| 名乗玖 | K7 | 収束を禁じた張り紙の筆者と推定。紙は残り、貼られた場所は不明である。 |
| 遠野佐吉 | K9 | 解散を「畳み」と読み替えた講話。録音はなく、聴衆の日記にのみ残る。 |
| 榎本ひすい | K10 | 解散届の余白の署名。届は受理されず、筆跡の照合もされていない。 |
| 薄ミツ | K12 | 再建本文の欄外に「我は畳まれていない」と書き足した者。現在も名乗る。 |

*註　自称は、教義の最も安い継承である。*

根拠欄には、その人物が教主と関わったとされる最も古い一件のみを記した。書簡、夢の記録、伝承、貼り紙、日記、署名、欄外の書き込み。形式はばらばらで、共通するのは、いずれも本人以外の手で保存されたという一点である。七人のうち、自分の名を自分で書いた資料は一通も残っていない。

年は開闕紀年で示した。K1の創立からK10の解散までを一区切りとし、K11以降を現在と呼ぶ。ただしK5以前の資料には年記がなく、年欄の半分は紙質と筆致からの推定である。推定は表の中では確定と同じ顔をする。

七人のうち、互いの存在を知っていたのは二組だけである。灰島と礒野は同一人物とする説があり、薄は教団そのものを否定しながら名乗りを続けた。名乗玖の項だけは、本人の名が資料に一度も現れず、張り紙の末尾の一字から仮に名を充てた。

自称は三つに分けられる。筆跡を根拠にする者、口述を根拠にする者、何も根拠にしない者である。三つ目が最も長く残った。根拠を欠く自称は反証できず、反証できないものは目録の末尾に据え置かれる。本系が七人で閉じているのは、七人しかいなかったからではない。八人目から先の資料が、編纂の途中で失われたからである。

## 編纂註

**一（呼称）** 本稿は教団の内部文書では「系二」、外部の目録では「自称者目録」と呼ばれる。どちらも編纂者が名づけたものではなく、呼び始めた者の名も残っていない。名称が二つあることは、読み手が二種類いたことを示す。内側では系図の一部として、外側では珍しい人名の集まりとして読まれた。呼称の分裂は、本文の分裂より先に起きている。

**二（作業）** 本稿が本文に対して行うのは、選別ではなく配置である。書簡、口述、張り紙、日記という異なる形式の資料から、名と年と根拠だけを取り出し、同じ高さの列に並べる。この操作により、一通の私信と一枚の紙片は等しい重みを持つ。資料の来歴は根拠欄に圧縮され、圧縮の過程で失われた情報は註に回されない。表は資料を保存しない。表は資料の住所を消す。

**三（破断）** 壊れるのは、年が重なる場所である。K10の解散届とK12の欄外書き込みは、同じ筆記具で書かれている可能性が指摘されている。もし同一なら、解散と再建は一人の手から出たことになり、年欄は意味を失う。さらに判読不能の一字を「―」で補った時点で、空白は証拠に変わる。本稿の表は、この二つの事故の手前で止まっている。止まっていることを、完結とは呼ばない。
