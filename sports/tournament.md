# 戯二　記録

本記は、開闕K1より同K10の解散に至るまで、教団が「戯」と呼んで自前で行った競技の勝敗を収める。戯は祈りではなく、分岐の確認である。一つの魂が二つに分かれ、二つが同じ場に立つ。立ち会いの後、負けた側は畳まれ、勝った側に重なる。教団はこれを収束と呼ばず、畳みと呼んだ。第五品の言葉である。

ただし、畳まれた側が本当に消えたのか、誰も確かめていない。確かめれば、それが収束になるからである。記録は、この不確かさを数字の形で保管するために作られた。

凡例。勝ちは畳んだ回数ではなく、畳まれなかった回数とする。同一枝の再出場は一回と数えない。中止は零でも一でもなく、空欄とする。空欄は勝敗のどちらでもないが、順位の計算では零として扱う。この二重の扱いが、後の揉め事の種になった。

記録係は試合を見ない。見れば、どちらが先に畳まれたかを知ってしまい、それは裁定になる。係は終わった後に、両者の申告だけを聞いて書く。申告が食い違った場合は、先に口を開いた方を勝ちとする。口の速さは身体の速さであり、身体の速さは分岐の速さである、と教団は説明した。

| 回 | 勝 | 負 |
|---|---|---|
| 第一回 | 甲‐一 | 甲‐四 |
| 第二回 | 乙‐二 | 丙‐五 |
| 第三回 | 甲‐七 | 乙‐二 |
| 第四回 | 丁‐三 | 甲‐七 |
| 第五回 | 甲‐七 | 丁‐三 |
| 第六回 | 戊‐一 | 甲‐七 |
| 第七回 | （中止） | （中止） |
| 第八回 | 戊‐一 | 己‐二 |
| 第九回 | （記載なし） | （記載なし） |

記事。第一回、甲‐一と甲‐四は同じ名の枝であり、双方が「自分である」と主張した。裁定は抽選で行われた。第三回、甲‐七は三度目の出場で初めて勝った。この時から、記録係は勝ち数を「厚み」と呼ぶようになる。第五回、丁‐三と甲‐七は四日続けて同一の手を繰り返し、勝敗が決まらなかった。五日目、丁‐三が自ら畳まれた。これは勝ちではない、と当時の註は書く。しかし表は勝ちとして扱っている。第七回は中止された。参加者が全員、自分は既に畳まれた枝であると申し立てたためである。第八回、戊‐一は無敗のまま引退を願い出た。認められなかった。第九回は解散の三日前に予定され、会場だけが設けられた。表に記載がないのは、記録係が会場に着かなかったためである。

表は解散後、三つの写しが作られた。一つは畳まれ、一つは焼かれ、一つは行方不明である。焼いたのは記録係ではなく、勝ち数の多かった者たちであった。彼らは自分の厚みが読まれることを望み、同時に読まれることを恐れた。現存するのは、行方不明の写しから転写されたと称する一本のみである。

---

## 編纂註

一、本記が規格化するのは、勝敗という二値である。分岐は本来、数えられない。数えれば序列になり、序列は教義の禁じる収束に近づく。それでも教団は表を作った。表がなければ、畳みが慈悲であることを示せないからである。慈悲は、比べる相手がいて初めて成立する。勝ちと負けの二欄は、分岐の連なりを一直線に切りそろえる。ここに、この体系の最初の矛盾が置かれている。

二、この表は、人に「自分の負けを自分の一部として受け取る」ことを強いる。負けた枝は消えない。勝った身体の中に残り、厚みとして数えられる。読み手は、自分の名が勝ち欄と負け欄の両方に現れることに慣らされる。慣れた者は、序列を内面化する。記録は、身体の序列である。そして序列は、畳まれても消えない重さとして、その後の動作に残る。

三、壊れるのは、勝敗が決まらない場合である。第五回と第七回がその例で、前者は表が勝ちを捏造し、後者は表が空欄を残した。空欄は中立に見えて、実は「決めなかった」という裁定であり、裁定もまた序列の一種である。記録係が会場に着かなかった第九回、表は何も語らない。語らないことが、この体系の最も静かな破れ目である。
