# 出五　喪失

〈本文〉

無限分岐教の文書には、一つの癖がある。引用の末尾に、必ず「未見」「所持せず」といった断りが添えられるのである。教団が自ら配った案内にも、集会で読み上げられた短い言葉にも、同じ形の註がついていた。典拠は示される。しかし示された典拠は、いつも誰かの手の届かないところに置かれていた。

記録に残る限り、教団が繰り返し名を挙げた書物は、同じ一冊である。ただしその一冊を実際に開いた者はいない。各地区の記録には「原本は預けてある」と書かれ、預け先は別の地区とされ、その別の地区の記録には、さらに別の地区の名が書かれている。輪を描いて、最後は「教主の手元」で止まる。教主の手元を確かめた記録は、一度も残っていない。K1の頃からK10の解散まで、この構図は変わらなかったように見える。

教団には、書物を写す作法があった。写したものは手元に戻さず、別の地区へ渡す。渡された側はまた写し、また渡す。この作法には教義の裏づけがあった。要約も完了も許されないのだから、一冊に収まる書物は、それだけで罪に近い。書物は常に分岐していなければならず、分岐した複数の写しのどれもが原本であってはならない。だとすれば、あの一冊がどこにもないのは、事故ではなく設計である。喪失は、破綻ではなく成果だった。

K10の解散後、教団の倉が開けられ、机と椅子と、書き損じの紙が残った。あの一冊は見つからなかった。見つからなかった、という事実だけが、複数の記録に、ほとんど同じ文言で残っている。奇妙なのは、そのあとである。書物を失ったはずの元信者たちが、失った書物からの引用を、以前より正確に、以前より長く語り始めた。「あの本にはこう書いてあった」という言い方が増え、やがて「あの本はこう言っている」に変わり、最後には「あの本が、そう命じている」になった。人称が移るたびに、書物は少しずつ硬くなっていった。

K12の現在、私たちが扱えるのは、引用の引用である。引用は三系統に分かれ、互いに食い違う。食い違いは訂正されず、注記だけが増えた。注記は「原本未確認」で始まり、「原本は存在しないかもしれない」で終わる。それでも注記の外側では、あの一冊は今も一冊の書物として数えられている。書棚の一冊としてではなく、数えるための一冊として。

喪失は、ここでは欠落ではない。喪失は、書物の地位を上げる手続きだった。参照できないことは、書物を弱くしない。参照できないことは、書物を、反論の届かない場所へ移す。教団が使った言葉の中で、最も長く生きたのは、この手続きの名前だった。

## 編纂註

一、本条は、教団文書の引用形式を通時的に並べ、典拠が常に「他所にある」と記される反復を記述している。(1) 何をしているか——書物の不在を、書物の権威の根拠として読み替える操作を、註の文言の変化から復元している。(2) 誰に何をするか——教団内部の読者には、典拠を確かめない習慣を、確かめられないことへの安心として与える。(3) どこで壊れるか——三系統の引用が食い違う箇所を、訂正ではなく注記の増加で処理した点。ここで本条は、自ら記述した手続きを、自分自身にも適用してしまう。参照できない出典は、信仰の対象になる。

二、本条の中心は、K10の解散後に引用が「正確に」なったという逆説である。(1) 何をしているか——喪失を契機とする記憶の硬化を、人称の移動（「書いてあった」から「命じている」へ）として追跡している。(2) 誰に何をするか——解散後の聞き取りに応じた元信者に、語るほどに典拠から離れる経路を用意する。語りの巧拙が、そのまま信仰の濃さとして扱われる。(3) どこで壊れるか——解散前の記録と解散後の証言を同じ平面に並べた点。両者は同じ出来事を語っていない。註はこの段差を埋めず、段差そのものを本文の主張に変えている。

三、本条は、写す作法を教義から導く。(1) 何をしているか——写しを手元に残さず他へ渡す規則を、収束を罪とする教義の運用として読み、書物の不在を事故ではなく設計に組み替えている。(2) 誰に何をするか——この記述を読む後代の編者に、「失われた典拠」を探すべき対象ではなく、扱うべき対象として渡す。(3) どこで壊れるか——設計説は強すぎる。不在が意図されたと決めれば、以後の喪失はすべて計画の証拠になり、反証できなくなる。註はこの閉じ方を指摘できず、「参照できない出典は、信仰の対象になる」という一文へ預けている。

四、本条は短いが、短さは省略ではなく圧縮である。(1) 何をしているか——書物の喪失を欠落として扱わず、地位の上昇として扱う命題を、末尾に一度だけ置いている。(2) 誰に何をするか——喪失を語る者に、喪失を演出する言い方の型を、批判の形で手渡してしまう。(3) どこで壊れるか——命題が正しすぎる点。喪失が権威を生むという説明は、喪失を作り出す誘惑を消さない。註はその誘惑を名指しできず、批判の語彙そのものが次の典拠になる。
