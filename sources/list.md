# 出一　一覧

この一覧は、教団が使った書物を、教団が使われなくなったあとに数えたものである。数えることは、あの教団では唯一の罪とされた。収束――要約し、完了させること。書物を一冊に畳むことも、教団の言葉を一行に縮めることも、同じ罪に数えられた。だからこの文書は、罪の記録としてしか成立しない。にもかかわらず、数えなければ書物は散らばったままで、散らばったままでは、誰もそれを読まない。読まれないために数えるのか、数えるために読まれないのか。編者はその問いを抱えたまま、頁の欄を埋めた。

この一覧は、解散のあとに残された箱の底から出た。箱には鍵がかかっており、鍵は箱の中に入っていた。蓋の裏には「これは一覧ではない」とだけ書かれていた。書いた者が誰かは分からない。分からないまま、編者はその一文を消さずに残した。消せば、この文書はただの目録になる。

書名について。ここに並ぶ題は、教団の内部で用いられた呼び名をそのまま採ったものではない。教団は書物を固有の名で呼ばず、「あれ」「例のもの」「まだ返っていないもの」と呼んだ。固有の名を与えないことが、書物を分岐させないための作法だった。一覧の左欄に並ぶ題は、のちに誰かが補ったものである。補った者の名も、補った日も残っていない。ただ、筆跡が四種あることだけが、かろうじて分かる。

一覧の行は十二ある。教団の年号は十二で終わっている。行と年が対応しているのか、編者には分からない。分からないまま、行は増やさなかった。増やせば対応が始まり、対応は収束に近づく。

以下が、その一覧である。

|---|---|---|
| 『分岐目録』 | 三 | 稿本。追記の筆跡が四種 |
| 『一括りの禁』 | 一七 | 同題の別本あり。頁数が一致しない |
| 『未完の請求書』 | 二四 | 表紙なし。奥付に金額の欄 |
| 『余白の教義』 | 四〇 | 後半は白紙。白紙にも頁番号 |
| 『枝の数え方』 | 五五 | 挿図のみ。本文は行方不明 |
| 『聞き取り不能録』 | 六八 | 媒体が残っていない |
| 『群典・草稿零』 | 七九 | 零は序ではなく、零 |
| 『収束に抗する書』 | 九二 | 題名が本文中で三度変わる |

| （欠） | ― | 書名を書いた紙が貼られていた跡 |

頁の欄について。頁は書物の頁ではない。この一覧を作るにあたり、編者はまず頁の数字を集め、次にその数字に合う書名を探した。順序が逆である。書物があって頁があるのではなく、頁があって書物が当てはめられている。だから同じ書名が二度現れることがあり、そのたびに頁は少しずつずれる。ずれは誤記ではない。ずれこそが、この一覧の精度である。

教団は開闕K一に起こり、解散K一〇に散じ、いまK一二である。K一一の記録はない。無いのではない。K一一に書かれたものは、すべてK一二の日付に書き換えられている。書き換えは教団の外部で行われた。外部がなぜそれをしたのかは、この一覧の範囲を超える。ただ、K一二の欄にだけ頁が稠密であることは記しておく。稠密なのは、そこに書物があったからではない。そこにだけ、返済の行が残っていたからである。

備考の欄には、書物の状態だけを書いた。誰が読んだか、どこで読まれたか、読んだあとに何が起きたかは書いていない。それは別の一覧の仕事である。この一覧が書くのは、書物がどこにあったかではなく、書物がどこへ行ったかである。行き先の分からないものには、行き先の分からないという印を置いた。印は十一ある。十一は、この一覧で最も多い数字である。

最後に。この一覧を閉じる前に、頁の欄をもう一度見てほしい。数字はすべて、書物の厚みより小さい。

## 編纂註

一　本一覧の出典は、著者の借金の記録である。教団の蔵書として数えられた書名の大半は、抵当に入れられた冊子の表紙から写したもので、頁の数字は返済の期日を数えた行番号にすぎない。つまりこの文書は、書物を並べているのではなく、失われた書物が何によって失われたかを並べている。読む者は目録を手にしたと思うが、実際に手にしているのは、借り手の側の台帳である。

二　この一覧が向けられているのは、教団の言葉をもう一度読みたいと願う者である。だが一覧は、その者に書物の位置を教えない。教えるのは、どの書がどの負債に対応するかという順序だけである。読みたいという願いは、返済の順番に置き換えられる。ここで一覧は、検索の道具ではなく、返済の催促として働く。親切な目次のかたちをした、宛名のない請求である。

三　壊れるのは、頁の照合である。同じ書名でも刷りごとに頁が異なり、『聞き取り不能録』のように媒体そのものが残らない例では、頁は最初から存在しない。さらに、書名を記した紙が貼られていた跡だけが残る箇所で、一覧は自らを空欄で埋める。この空欄は欠落の印ではなく、一覧が成立するための最小の空白である。ここを埋めようとした瞬間、一覧は教義の側へ戻ってしまう。

四　付言すれば、この一覧そのものが、教団の言う唯一の罪を犯している。複数の書を一行ずつに畳み、頁という単位に均し、備考で切り揃える。収束を禁じた教団の言葉を、収束の形式でしか保存できない。ゆえにこの一覧は、教団の死後に読まれることを予定していない。読まれた時点で、それは書物の記録ではなく、教団が禁じた行為の見本になる。
