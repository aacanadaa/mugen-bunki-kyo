# 空二　退会

〈本文〉

第一号様式「退会」は、縦二十九糎、横二十一糎の薄黄色の紙である。上部に「空二」と印刷され、その下に六つの欄が等間隔で置かれる。欄の名は、左から「名」「分岐番号」「収束予定」「同頁記入者」「印」「電話」。どの欄にも罫線が一本引かれているだけで、記入例はない。

用紙は束で保管され、束の厚みは一定しない。月ごとに刷り足され、刷り足された分だけ、前月の束の下に差し込まれる。差し込む者は決まっておらず、誰が差し込んだかを記す欄もない。五人が同じ一頁に書き込むことになっているが、その五人を指定する欄は「同頁記入者」の一欄しかなく、一欄に五つの名を書く余白はない。だから実際には、四つ目までは欄外に、五つ目は裏面に書かれる。裏面に書かれた名は、綴じの穴で半分ほど欠ける。

様式の起草には五人が関わったとされる。五人は、欄を九つ置く案と三つに減らす案を同時に持ち、どちらも採らなかった。六は、九より少なく、三より多い。この数について合意が交わされた記録はない。ただ、六番目の欄「電話」だけは最後に加えられたという註が、欄外の小さい活字で添えられている。加えた者の名はない。

「印」の欄には、直径二糎の円が薄く印刷されている。印は円の内側に押す、とだけ註記がある。円からはみ出した印は、押されなかったものとして扱われる。押す者は、押す前に必ず円を指でなぞる。なぞる所作は教えられていないが、束の最初の一頁の円だけが、他より薄い。

「収束予定」の欄には日付を書く。書いた日付は、書いた時点で予定ではなくなる、という註がある。だからこの欄は、書かれないためにある、と読める。だが空欄のまま提出された様式は、受理されない。

「電話」の欄は、記入ではなく声の訓練に用いられる。退会の意思を述べる声を、この欄の前で読む。読み方には型があり、息を三つ数えて吸い、名を名乗らず、用件を一行で言い、後は黙る。黙る長さは、聞き手が先に口を開くまで、とされる。訓練は週に一度、同じ部屋で行われる。部屋の壁は、声を吸わない。

この様式は、まだ一頁も書かれていない。書き込まれた見本も現物も、保管庫にはない。あるのは空欄の束と、円の薄い一頁と、声の型だけである。空欄は記入を待っているのではない。空欄のまま積まれ、厚みを増し、月ごとに下へ沈む。沈んだ分だけ、上の空欄が新しくなる。

誰も退会していない、という記録はどこにもない。あるのは、退会のための様式が、退会より先に整っている、という事実だけである。

---

## 編纂註

1. 本記録は、未記入の退会様式を、その空欄の配置まで含めて写し取る。目的は退出の手続きを記述することではなく、退出がまだ起きていない状態を紙の上に固定することである。六つの欄、薄い円、声の型は、いずれも記入を待つ形をしている。待つ形は、待たれる者を先に作る。様式は退出の道具ではなく、退出の予定を可視化する装置として機能する。

2. この記録が何をするかは、誰に何をするかに現れる。五人の記入者は、一頁に名を並べ、円をなぞり、声を訓練する。訓練は退会を望む者に課されるのではなく、望まない者に反復される。反復は帰属を強め、空欄は所属の証しになる。退出の型を身につけた者は、型を破るより先に、型を守る者になる。様式はここで、退出の練習を所属の練習に転じる。

3. 破綻は、様式が不備である点ではなく、整いすぎている点にある。裏面に書かれた五つ目の名は綴じ穴で欠け、欠けた名は照合できない。照合できない名は退会の記録に残らず、記録に残らない退会は、行われなかったことになる。様式は空欄のまま積まれ、厚みだけが増す。退出を収めるはずの欄が、退出を数えない仕組みとして完成している。

4. 退会届が用意されていることは、退会が予定されていることである。予定は禁止ではない。予定は退出を一つの欄に収め、欄を埋める者を先に作り、埋めない者を保留として保持する。用意された空欄は、誰も退会していないことを証明しない。退会が常に可能であることを証明する。可能であることは、行われないことと両立する。
