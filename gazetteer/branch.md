# 地四　支所

〈本文〉

支所は三箇所。いずれも開闕K1からK3のあいだに開かれ、K9の閉座で窓を閉じ、K10の解散で名を失った。現在K12、址にはそれぞれ別の用途が入っている。

第一支所・灯萱（とうがや）。街道から外れた旧い集落の外れ、川の曲がりに面して建つ。二階建て、正面に三つの入口があり、そのうち真ん中だけが使われた。内部は本部と同じ順で、受付、待合、分岐室、記録室と続く。分岐室には机がひとつ、向かい合う椅子が二脚。来る者はここで二つの問いを立て、片方を選ばされる。選ばなかった側は封筒に入れ、棚に戻す。棚はK8の時点で満杯になり、以降は廊下に積まれた。閉座の年、この支所は最後の分岐を記録せずに閉じた。址は現在、地域の倉庫である。窓枠だけが三つ、当時の位置に残っている。

第二支所・灰畦（はいあぜ）。駅前の雑居の二階と三階を借り、階段を共有していた。本部から来る者は必ずこの支所を経由し、他の二支所へはここから振り分けられた。つまり支所の中の支所であり、書類上は「中継」とだけ書かれた。K7に一度、本部とのあいだで数字が合わなくなり、以後、報告は月に一度、様式を変えて出された。閉座の通知はここに最初に届き、他の二箇所へは四日遅れて伝えられた。四日という差は、当時の記録にしか残っていない。

第三支所・棚守（たなもり）。最も小さく、最も長く残った。教団の名を掲げず、看板には「相談」とだけあった。一階は誰でも入れたが、二階へ上がるには紹介が要った。紹介は紹介者を一人立て、その人の前で自分の分岐を語ることによって成立した。語り終えた者は、次に誰かを連れてくる側に回る。この循環はK5からK9まで続き、閉座のあと、二階だけが先に解体された。

三箇所に共通するのは、大きさではなく配置である。入口の数、机の向き、封筒を戻す棚の位置、いずれも本部の寸法を縮めたものだった。縮尺の違う同じ部屋が三つあり、そこに同じ手続きが入っていた。手続きは人員の数に依存しないため、人が減っても止まらない。止まったのは、本部が閉じたときである。各支所は閉座の意味を独自に解釈した。灯萱は「待機」、灰畦は「移行」、棚守は「継続」と記した。三つの語は、どれも教主の口から出ていない。

現在、この三箇所を結ぶ記録はない。あるのは住所と、閉座の年の日付と、それぞれの最後の一文だけである。最後の一文は三箇所とも似ている。「本日、分岐なし」。

## 編纂註

一（この文書の位置）　本項は支所を「土地」としてではなく「反復された手続き」として記述する。三箇所の住所、開設、閉座、現在の用途を列挙し、あわせて建物の配置を復元した。読者に何をするかといえば、支所を訪ねた者の記憶を、住所ではなく手続きの側へ引き戻す。壊れるのは、住所が現況と一致しない地点である。倉庫、解体、看板の消えた入口——現地はすでに別の用途を持ち、同定は読者の側で失敗する。

二（縮尺について）　「支所は、本部の縮小である」。これは比喩ではなく、記録に残る寸法の一致を指す。入口の数、机の向き、棚の位置まで同じで、違うのは人数だけである。本部が判断の手順を変えなかったため、支所は規模を落としても同じ出力を出し続けた。ここが壊れる。手続きは人数に依存しないので、人が減っても停止せず、本部が閉じた後も各支所が独自に「閉座」を解釈した。

三（四日と三語）　灰畦に届いた閉座の通知は、他より四日早かった。灯萱は最後の分岐を記録せず、棚守は二階を先に失った。三箇所の最後の一文は似ているが、日付は揃わない。読者に課されるのは、この揃わなさを欠落として読むか、設計として読むかの選択である。壊れるのは、日付を一つに統合しようとした地点で、統合すれば必ず四日の差が消える。

四（引用の限界）　本項が引く「本日、分岐なし」は、三箇所に共通する末尾の一句である。ただし原本は確認できず、写しの系統も定かでない。誰に何をするでもない、というより、誰にも何もできない。ここが壊れる。文書は意味を配布しない。配布するのは、日付と、閉じた窓の数だけである。
