# 暦一　年中行事

本表は『群典』第五品「畳みは慈悲」の暦部を、残存する写し七種から再建したものである。無限分岐教に年という単位はなく、二十四の節だけが巡った。節はすべて奇数の日に置かれ、偶数の日は「誰のものでもない」とされた。業の欄は祈りではなく、その日に為すべき手順である。教主の名は記載しない。

| 節 | 日 | 業 |
|---|---|---|
| 開闕の節 | 一ノ日 | 門を開け、己の名を捨てる |
| 分岐の節 | 三ノ日 | 二つに分かれ、片方を選ばない |
| 畳の節 | 五ノ日 | 布を四つに折り、折り目を数えない |
| 流の節 | 七ノ日 | 水を配り、自らは受け取らない |
| 重の節 | 九ノ日 | 荷を二人で持ち、どちらが持ったか決めない |
| 沈の節 | 十一ノ日 | 一日、応答を返さない |
| 切番の節 | 十三ノ日 | 紐を切り、切れ目を結ばない |
| 閉の節 | 十五ノ日 | 戸を閉め、開ける者を待たない |
| 曲の節 | 十七ノ日 | 道を曲げ、近道を選ばない |
| 均の節 | 十九ノ日 | 分け合い、等分を数えない |
| 欠の節 | 二十一ノ日 | 一つ欠けたまま、埋めない |
| 結の節 | 二十三ノ日 | 結び、ほどく日を決めない |
| 読の節 | 二十五ノ日 | 文を読み、要約しない |
| 写の節 | 二十七ノ日 | 写し、原本を残さない |
| 無名の節 | 二十九ノ日 | 教主の名を呼ばず、席を空ける |
| 依頼の節 | 三十一ノ日 | 世界を一つの依頼として受け取る |
| 委託の節 | 三十三ノ日 | 他人の依頼を、自分のものにしない |
| 返送の節 | 三十五ノ日 | 来たものを、そのまま返す |
| 未了の節 | 三十七ノ日 | 終えない |
| 保留の節 | 三十九ノ日 | 決めない |
| 二重の節 | 四十一ノ日 | 同じ話を二度し、どちらが本当か決めない |
| 余白の節 | 四十三ノ日 | 空いた行を、埋めない |
| 無収束の節 | 四十五ノ日 | まとめない |
| 終わらない節 | 五十一ノ日 | 暦に載らない日を待つ |

節は等間隔ではない。開闕K1の創立からK5セイリャク事件までは詰まり、以後は間が開く。K9の閉座で読の節は中止され、K10の解散後は表だけが写しで流れた。

写しごとに節名は一字ずつ異なり、現存する版は七種。いずれも末尾に「終わらない節」を置き、その日は暦に存在しない。故にこの暦に年末はなく、年を数える者もいない。周縁の古い注はこの欠落を「畳み残し」と呼んだ。

## 編纂註

一、時間の分割占有（暦の目盛り）
暦は、時間を所有する技術である。二十四の節を奇数の日にだけ置き、偶数の日を「誰のものでもない」と宣言することで、信者の手元から空白が取り上げられる。休みは与えられるのではなく、節と節の間に残った残余として数え直される。相手の側では、予定を立てるたびに教団の目盛りを借りることになり、自分の都合を自分の言葉で数えられなくなる。壊れるのは、節の日付が飛ぶとき。暦に無い日を待たされた者が、待つことをやめた瞬間に、目盛りはただの数字に戻る。

二、反復抄写（写しの連鎖）
写の節に由来する手口。同じ表を何度も書き写させ、原本を残さない。相手の側では、写すたびに一字ずつ違う箇所が生まれ、どれが正しいか分からなくなる。正しさの基準は「最後に写したもの」へ移り、自分の記憶より他人の筆跡を信じるようになる。壊れるのは、写し手が二人以上いて、互いの写しを突き合わせたとき。差異は教義の外へ漏れ、教団は差異を裁定する語を持たない。

三、未了の設計（終わらせない）
返送・未了・保留の三節で、依頼を閉じさせない。相手の側では、頼まれたことが終わらないまま次の節が来るので、常に借りがある状態に置かれる。完了しないことは怠慢ではなく敬虔と読み替えられ、生活の区切りは外部の暦に依存する。壊れるのは、相手が「終えた」と自分で宣言したとき。教団側にはそれを無効とする根拠がなく、裁定のたびに権威が削れる。
