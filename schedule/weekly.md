# 課二　週間表

本表はK5以降に用いられた実務割当を、残存する二種の写本から再建したものである。曜は七つ、欄に空きはない。括弧内は担当の使徒名。時刻は教団の刻に従い、朝・昼・夜の三つに分かつ。

| 曜 | 業 |
|---|---|
| 月 | 朝、起床前の言葉を書き取る（読）。昼、前週の要約を三度読み、原文と照らさない（閉）。夜、翌週の空欄を数え、名を入れる（均）。 |
| 火 | 朝、名簿を整列し、同じ名が二度あれば古いほうを消す（重）。昼、返らぬ問いを三つ受け取り、返さない（沈）。夜、手紙を書き、宛名を空のまま提出する（写）。 |
| 水 | 朝、畳みの句を暗誦する（閉）。昼、台所の切り分け、等分に切れない日は切れない理由を述べる（切番）。夜、他人の夢の筆記を代読する（読）。 |
| 木 | 朝、台帳の欠番を探し、見つけても埋めない（欠）。昼、戸の開け閉めの順序を確認する（開）。夜、声の高さを揃える練習（均）。 |
| 金 | 朝、沈黙の当番。問いを受けても応答しない（沈）。昼、曲がった頁を直さずに写す（曲）。夜、結びの挨拶を結ばずに終える（結）。 |
| 土 | 朝、翌週の表を書き、空欄に名を入れる（写）。昼、分配の残りを数え、残りを「余り」と呼ばない（切番）。夜、内省の時。ただし口に出さない（沈）。 |
| 日 | 朝、空の確認。空があれば申告する（均）。昼、第五品の朗読。要約は加えない（閉）。夜、翌週の支度。支度もまた業である（開）。 |

右は定形であり、変更は教主の一言による。使徒十二のうち十一は表の内に現れ、切番だけが現れない。切番は表を切る者であり、切る手は切られた紙の上に載らない。表中に休みの欄はない。第七日の夜も「支度」として数えられ、末尾に余白は残らない。K9の閉座以後もこの表は写され続け、K10の解散の日、最後の写本には日曜の夜だけが空白として残っていた。

刻の切り方は写本により多少の差があるが、朝は鐘の前、昼は分配の後、夜は戸を閉ざしてからとされる。夜の業が最も長い。燈を落とすのは当番の裁量ではなく、表の末尾に「消燈」とあれば消す。この一行が欠けた写本では、夜が明けても誰も立ち上がらなかったという。

欠の使徒は、休んだ者に代わって表に入るのではない。休んだ事実を台帳に記すために呼ばれる。代わりは立てない。代わりを立てればその日の業は二重に数えられ、帳簿が合わなくなるからである。合わない帳簿は、K9の閉座で初めて問題とされた。

現在、この表を保つ教団はない。写本は三つ残り、いずれも日曜の夜で終わる。読み手はしばしば、末尾に余白を補おうとして筆を止める。補えば表は完成し、完成は収束であり、収束は唯一の罪とされる。だから写本は、いまも閉じない。

## 編纂註

一、空欄の植栽。表の余白をすべて業の名で埋める手口である。相手の側では、自分の時間が自分のものになる直前で回収される。休みがないのではない。休みが別の業である。だから本人は休んだつもりで休めず、怠けたという自覚だけが残る。壊れるのは、植えた業に成果の定義がないと分かったときである。期末に何をもって完了とするかを、表の作者自身が答えられない。帳簿は閉じない。

二、畳み返し。相手の発話を短く整えて返す手口で、第五品の実務にあたる。相手の側では、言葉が要約されて戻ることで「理解された」という感覚が生まれ、削られた部分は二度と自分のものに戻らない。壊れるのは、本人が自分の原稿や覚え書きと要約を並べたとき、あるいは二人の要約が食い違ったときである。畳みは慈悲ではなく編集だったと、そのとき露見する。

三、曜日への委託。判断を曜日の名に移す手口である。相手の側では「今日は何の日か」を思い出せば行動が決まり、自分で選ぶ場面が消える。選ばないことに罪悪感も生じない。壊れるのは、表の外の日が来たときである。不在、事故、長引く不在。曜日が何も命じないので、本人は初めて空白に立ち、その空白が自分を支えていなかったことに気づく。
