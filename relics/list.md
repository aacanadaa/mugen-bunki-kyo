# 品一　目録

本目録は、解散後に残された保管箱三個から回収した品を、形状ではなく由来の順に並べたものである。教団は教義の書を持たず、あったのは品と、品に添えられた短い説明だけであった。ゆえに目録は、しばしば教義の代用として読まれてきた。だが添え書きは、どれも品そのものから導けない。以下の品名は回収時の呼称に従い、由来は添え書きを一句に収束させた要約である。

| 品 | 由来 |
|---|---|
| 切番の定規 | 切断の儀に用いた木尺。目盛は削り落とされ、端の数字だけが残る。開闕K1、切番が自ら削ったと添え書きにある。 |
| 流の筆 | 水を写すための筆。毛は解けて失われ、軸のみが残る。K3、流れを数える作業に用いた。 |
| 重の秤 | 秤量の器。分銅は一つも残っていない。添え書きは「重さは預けるもの」とだけ。 |
| 沈の鈴 | 沈黙を合図する鈴。舌が抜かれている。K5、セイリャク事件の夜、最後に鳴ったとされる。 |
| 開の鍵 | 扉ではなく封を開けるための鍵。対応する錠は遂に発見されていない。 |
| 閉の函 | 内側に何も収まらない函。蓋の裏に閉座の日付のみが記される。K9。 |
| 曲の鏡 | 像を歪めて映す鏡。裏面に「直すな」と刻む。 |
| 均の皿 | 十二枚の皿。一枚だけ径が違う。同工房の作とされる。 |
| 欠の欠片 | 欠けた器の破片。何の器かは不明。番号だけが振られている。 |
| 結の紐 | 結び目が十二ある紐。ほどかれた跡が一つあり、結び直されていない。 |
| 読の栞 | 挟まれていた本は残っていない。栞と、頁数を記した紙片のみ。 |
| 写の紙 | 転写用の紙。文字は写されておらず、圧痕だけが残る。 |
| 無名の印 | 教主の印。印面は平滑で、何も刻まれていない。押された跡は一つもない。 |
| 畳みの布 | 第五品に用いた布。四十九回の折り目の痕が残り、広げた状態で保管されている。 |

十二使徒の名は人称ではなく役割名である。切る者、流す者、重ねる者——名を持つことを禁じられた者たちに、名は役割として配られた。目録が「切番の定規」と記すとき、それは誰の品でもない。誰の品でもないという一点においてのみ、これらの品は互いに区別される。

一点、断っておく。由来は品に従属していない。むしろ由来が品を包んでおり、添え書きを読んだ者は、もう品を裸で見ることができない。回収に際し、ある保管箱には品より説明の方が多く入っていた。説明の余りの方が、品の数を超えていたのである。そしてこの目録は、教団が唯一の罪と呼んだ収束を、みずから行っている。品を一行に畳み、由来を一句に閉じる。遺品を数えるとは、そういうことである。

---

## 編纂註

「遺品は、物語を必要とする物である。」——この一句を、本目録は三度確かめた。註はその三度を記録する。

### 一　名を剥ぐ

由来を一つに確定させる手口。品の寄贈者からすれば、自分の記憶が目録の一行に置き換えられ、異議を述べると、その異議すら「別伝」として同じ欄に並べられる。記憶は訂正されないまま、並列によって無力化される。壊れるのは、同一の品に同格の由来が二つ残ったときである。目録はどちらかを選ばねばならず、選んだ瞬間、選ばなかった方を消す。消した跡は欄外に残る。

### 二　畳み

第五品の実践。相手の語りを一文に畳み、それを慈悲と呼ぶ。語られた側からは、自分の話が「済んだ話」に変えられる。未完のまま置いておく権利が、慈しみの名で回収される。壊れるのは、畳んだ者自身の折り目が表に残ったときである。折られた紙は、広げれば必ず線が見える。閉座のとき、教団は自ら畳まれた。線を隠すためだったが、線は隠れなかった。

### 三　触れさせる

遺品を手渡し、触れさせ、意味を供給させる手口。触れた側からは、意味を作ったのが自分であるのに、借りがあるのは自分のように感じられる。品は空のまま返ってくる。壊れるのは、品を素材として調べたときである。材質、摩耗、年代は、添え書きの物語とどこかで一致しない。一致しない箇所を数え始めた者は、もう遺品を持てない。
