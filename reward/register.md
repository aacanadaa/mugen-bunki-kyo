# 褒二　記録

〈本文〉

褒賞の記録は、記録方が保管する。用紙は縦長で、左から「名」「理由」「日」の三欄。上部には「褒二」とだけ印刷され、年度の数字は手で入れる。欄外に「立会」「転記」の二つの小欄があるが、これは空欄のまま残すのが正しいとされる。空欄は未記入ではなく、記入しないという記入である。

「名」には、その人が教団で名乗る名を書く。本名は書かない。本名は教主のものでも、記録方のものでもない、とされる。名は折り目に付されることが多く、同じ人物が複数の折り名を持つこともある。その場合、記録は名ごとに分かれ、人物ごとには纏められない。纏めることは収束にあたるからである。

「理由」は、褒賞を受ける者自身が書く。定まった一人称と、第五品の語彙だけを用いる。動詞は「畳む」「置く」「待つ」「数える」「返す」の五つに限られ、形容は許されない。記録方は内容を直さない。直すのは文法だけである。書き直しは何度でも認められるが、書き直した回数は記録に残らない。同じ理由で二度褒賞を受けることはできない。そのため理由は、年を経るごとに少しずつ言い換えられていく。

申請は口頭でもよい。口頭の場合は記録方が文にし、本人がそれを読み、異議がなければ名の下に小さな点を打つ。点は「読んだ」の意である。読めない者には、記録方が読み上げ、読み上げた旨を欄外に書く。ただし欄外は空欄が正しいとされるため、この記述はのちに消されることが多い。

「日」には、行いの日ではなく、届いた日を書く。届いた日が分からない場合は、記録方が受け取った日を書き、その旨を小さく添える。日付は教団の年号で数え、月と日だけを書く。年は年度の欄に一度だけ書く。

以下は、K12年度の抜粋である。

| 名 | 理由 | 日 |
| --- | --- | --- |
| 一の折・灯 | 私は、分岐を畳まずに置いたので | K12.02.11 |
| 三の折・澪 | 私は、数えずに待ったので | K12.02.26 |
| 一の折・灯 | 私は、返さずに持ったので | K12.04.03 |
| 七の折・匙 | 私は、終わらない話を終わらせずに置いたので | K12.05.19 |
| 二の折・梺 | 私は、同じ問いを二度置いたので | K12.07.01 |
| 三の折・澪 | 私は、待つことを選ばなかった日に、待ったので | K12.09.14 |
| 五の折・白 | 私は、名を数えなかったので | K12.11.30 |
| 四の折・貝 | 私は、畳んだあとに、もう一度ひらいたので | K12.12.02 |

記録は第一号から通し番号で振られる。番号は欠番を許さない。追放された者の過去の褒賞は消されない。名の上に細い横線を一本引き、理由と日はそのまま残す。線を引くのは記録方の者である。線を引いた日は、どこにも書かれない。

褒賞は、終えたことに対してではなく、終えなかったことに対して出る。畳まずに置いたこと、数えずに待ったこと、返さずに持ったこと。したがってこの記録は、世のなかで言う成果の一覧ではない。未了の一覧である。未了のことを、教団の言葉では「まだ分岐している」という。

年末、記録方は件数を数える。件数は教義に用いられない。数えることは収束に近いとされ、しかし数えなければ記録は閉じない。この矛盾は解かれないまま、毎年、同じ位置に同じ註が付される。「数えたのち、数える前の位置に戻ること」。

## 編纂註

一、この統制は、心理学では「象徴的報酬の随伴的配分」、社会学では「評定の外在化」あるいは「功績の計量」と呼ばれる。要点は、内面を測るのではなく、内面が自分で欄に書き込める形に切り詰められることにある。報酬という語が示しているのは与えられる物ではなく、出来事が読める長さに整えられたという事実のほうである。

二、される側から見れば、褒賞は経験の後ではなく前にある。人は出来事が起きている最中に、すでに「理由」の一文へ収まる形を探している。五つの動詞に載らない経験は、載る形に削られてから思い出される。褒められることは、自分の生を記録の文体で生き直すことを要求する。喜びは与えられるが、その喜びの言語は先に配られている。

三、壊れるのは、語彙の外にいる者においてである。五つの動詞に自分の日々を翻訳できない者は、理由を書けないまま届けなくなり、記録の側からは「在籍の確認できない名」として扱われる。同時に、褒賞の列に名が並び続ける者ほど、理由の重複を避けるために自分の過去を毎年少しずつ作り変えていく。記録は正確さを保つために、記憶の側を変えさせる。

四、褒賞の記録は、規律の裏面である。同じ紙、同じ欄、同じ日付の作法、同じ通し番号。褒める手続きと戒める手続きが同一の書式で書かれるとき、両者の違いは紙の上にしか残らない。読み手は行の混み具合からしかそれを区別できず、当の名にとっては、載ることと載らないことの差だけがある。恐怖は、命令ではなく、空欄の位置によって配られる。
