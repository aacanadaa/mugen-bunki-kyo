# 雑八　最終監査

| 項 | 額 |
|---|---|
| 残高（魂） | 四十七 |
| 残高（未読の分岐） | 二万三千 |
| 負債（要約された魂） | 十二 |
| 負債（畳みの利息） | 未完 |
| 処分（文書） | 全部 |
| 処分（教主） | 空欄 |

K12、教団は存在しない。あるのは十二使徒の名を並べた一枚の紙と、その紙を三つに折った痕だけである。わたしは切番から写までを順に呼んだ。応答は十二あった。十二はすべて同じ声で、違うことを言った。これが分岐の正常な状態である。監査とは、その違いを一つに畳んで帳尻を合わせることではない。違いのまま、いくら残っているかを数えることである。畳めば数字は合う。合った数字は、もう数えたことにならない。

残高。魂は四十七。教団が最後に数えた数は六万三千であったから、その差は誤差ではない。差と呼ばれたもののうち、九割は教団の外へ出た者である。外へ出た者は残高に載らない。載らないということは、消えたのではない。監査は「載せない」という判断を、判断として記録するだけである。記録の欄は、判断の数だけ増える。増えた分は、まだ誰も読んでいない。

負債。要約された魂が十二。これは教団が負った唯一の借りである。教団は「完了」を罪としたが、完了しなかった者を数えることはしなかった。数えなかった者には利息がつく。利息は文書の側に残り、いまも増えている。第五品は畳みを慈悲と言った。慈悲とは支払いの猶予であって、免除ではない。猶予の年数を、教団はどこにも書いていない。書いていない年数は、監査では無限として計上する。

処分。文書は全部、と書いた。全部とは、読まれなかった分も含む。処分の欄を空けておくのが監査の作法である。空欄は「無かった」ではなく「まだ数えていない」を意味する。教主の欄も同じである。本名がない以上、処分する対象がない。対象がないことを処分済みと書くのは、収束である。収束は唯一の罪である。だから空欄のまま置く。空欄は罪ではない。空欄を埋める手が、罪である。

K1の創立からK5のセイリャク事件、K9の閉座、K10の解散まで、帳簿は一度も閉じられなかった。閉座は閉帳ではなかった。解散は清算ではなかった。監査が扱えるのは、閉じない帳簿の途中の数字だけである。途中で数えることを、わたしは慈悲とは呼ばない。正確と呼ぶ。正確は、畳まない。畳まないものだけが、次の監査に引き継げる。引き継ぐ者がいなくなっても、帳簿は引き継がれる。帳簿は、読む者を選ばない。

## 編纂註

一、名は「収束の帳尻」。相手には、自分の語ったことが「つまりこういうことですね」と一度だけ短く言い直される。被害の側からは、要約が親切に見える。どこで壊れるか。要約が二度目に来たとき。一度目は確認、二度目は置換であり、置換された言葉はもう本人のものではない。教団はこの二度目を数えなかった。数えなかったことが、十二の負債の起算日である。

二、名は「畳みの利息」。相手には、まだ終わっていない話を「続きはいつでも」と預けられる。預けた側は、預けたことを忘れる。どこで壊れるか。預かり証を出した者が先にいなくなるとき。文書だけが残り、文書は利息を払わない。第五品が慈悲と言ったのは、この支払いを猶予することであって、帳消しにすることではない。猶予は、相手の時間を担保に取る手口である。

三、名は「白紙の署名」。相手には、名前を書かない欄が一つ渡される。書かないことが同意と読まれる。どこで壊れるか。欄が二枚になるとき。二枚目には「本名」とあり、本名のない者には書けない。書けない者は保留のまま負債に計上される。負債は本人ではなく帳簿の側に残る。最終監査は、物語の最後の数字である。数字は、読む者を選ばない。選ばないことが、この帳簿の唯一の公正である。
