# 看二　分け方

教団が死者の遺品を扱う手順は、K3の頃に固まった。以後、細部は何度も書き換えられたが、表の骨格だけは動いていない。遺品は「品」と「手」の二列で記録する。品は物の名、手は受け取る者の名である。値打ちは書かない。書けば、値打ちの順に人が並ぶからである。

| 品 | 手 |
|---|---|
| 外套 | 長く連れ立った者 |
| 湯呑み | 同じ机を囲んだ者 |
| 手紙の束 | 宛名の者 |
| 鍵 | 教団の庫 |
| 写真 | 写っている者すべて |
| 名 | 教主 |
| 未使用の暦 | 次に分岐する者 |
| 空いた椅子 | 誰も取らない |

表は上から読む。外套は外に出る者のもの、湯呑みは内に残る者のもの、手紙は宛名の者のもの。鍵だけは個人に渡さず、庫に戻す。写真は人数分に切り分けるのではなく、写っている者すべての前に一度だけ置く。名は教主が預かる。教主は受け取らない、預かるだけだと説明する。暦は、まだ使われていない頁が残るものに限り、次に分岐する者へ回す。椅子は最後まで空欄である。

記入の作法は三つ。第一に、品を迷ったら「まだ分岐していない」と書く。第二に、手を迷ったら空ける。第三に、空欄が三日続いたら、その品は畳む。畳むとは、箱に入れ、紐をかけ、表に「済」と書くことである。開けてはならない。開けると分岐が戻ると教わる。

手の欄に故人の名を書いた者がいた。教団はそれを消させなかった。消さずに、品の欄を空にした。名だけが残り、物のない行が一行できた。その行は、のちに様式の見本とされた。

畳まれた品は、庫の奥に積まれる。年度ごとに棚が一つ増え、棚の数は教団の年齢と一致した。K10の解散のとき、棚は数えられたが、開かれはしなかった。開けば、誰の手にも渡らなかった物が、どれほどあったかが分かるからである。

配り終えたあと、残るのは表だけである。表は遺族に渡さず、教団が写しを作って保管する。遺族が受け取るのは、畳んだ箱の底に敷かれていた一枚の紙で、そこには品の名も手の名も書かれていない。何も書かれていない紙は、分けられなかったものの目録だと説明される。説明を聞いた者は、たいてい黙る。黙った時間の長さを、教団は「落ち着いた」と記録した。

K12の現在、この手順は使われていない。使われていないが、表の様式だけは、名簿や当番表や席順に残っている。人はもう遺品を分けない。分けないまま、誰がどこに立つかだけを、同じ二列で書き続けている。

---

## 編纂註

一、この表を教団は「品書き」と呼んだ。物を人へ結び直すのではなく、人を物の側へ並べ替える手口である。受け取る者は、自分が何を欲しいかではなく、故人との距離を問われる。距離は自分では申告できず、周囲が決める。壊れるのは手の欄が空いたときで、空欄は「まだ決めていない」ではなく「決める者がいない」と読まれ、やがて教団が埋める。空欄は保留ではなく、招きである。

二、畳むという語は第五品から取られている。分けられない物を箱に納め、紐をかけ、開かないことを慈悲とする。人はこれで、迷いを処分したと錯覚する。だが畳んだ物は消えず、棚だけが増える。壊れるのは、開かないことに慣れた者が、自分の持ち物や自分の関係まで畳み始めたときである。慈悲は、しまい方ではなく、開く理由を先に失う形で効いてくる。

三、遺品の分配は、関係の清算である。誰が何を受け取るかではなく、誰との間を閉じ、誰との間を残すかが、表の二列で決められていく。清算という語を教団は好んだ。収束を罪とする教義の下で、清算だけが例外として許されたからである。壊れるのはここで、閉じたはずの関係が物の側に残り、物を見るたびに開き直す。清算は一度きりでは終わらない。
