# 危五　電話

K12年、外部からの照会が公文で届いた日のことを、本部では「あの日」と呼ぶ。教団が外部と衝突したのはこれが初めてではないが、電話がこれほど鳴った日は他になく、また、これほど記録が残った日も他にない。

記録は交換台の当番が一枚の紙に時刻順で書き足したもので、欄は三つしかない。時、相手、用件。用件欄は一行で書くよう内規に定められており、行をまたいだ記述は後に別紙へ移されたが、その別紙は現存しない。相手欄は姓のみ、あるいは役職のみで、フルネームの記載は一箇所もない。これは個人情報の保護ではなく、当時の内規が「呼称は短く」と定めていたためである。

| 時 | 相手 | 用件 |
|---|---|---|
| 06:04 | 外部・会計担当 | 帳簿の提出期限を三日前倒しにするとの通告。理由は述べられず |
| 06:41 | 支部長（東） | 前夜の通知文が支部に届いていない、との問い合わせ |
| 07:15 | 外部・広報窓口 | 「見解を一文で」との依頼。担当者は保留を選ぶ |
| 08:02 | 匿名 | 無言。四十秒で切断。以後、同刻に三日連続 |
| 09:30 | 支部長（西） | 集会の中止を求める声。判断を本部に戻す |
| 10:12 | 外部・記録係 | 過去の配布物の残部数と保管場所の照会 |
| 11:47 | 教主秘書 | 「畳む用意がある」との伝言。宛先は指定されず |
| 13:05 | 支部長（南） | 二名が離脱。理由は「要約されたくない」 |
| 14:20 | 外部・調整役 | 面談の日時を二案。返答は翌日でよいとのこと |
| 15:58 | 会計 | 口座の名義変更が未了。書類の形だけ整える |
| 17:33 | 支部長（北） | 電話の通じない地域がある、との報告 |
| 19:10 | 外部・広報窓口 | 先の問い合わせへの再照会。回答は「検討中」 |
| 21:44 | 教主 | 五分。用件は「記録は残せ」との一言 |
| 23:59 | 交換台 | 翌日の当番表の確認。通話は二秒 |

十四件のうち、外部からの発信は六件、内部は八件。教主本人が発信した記録は一通もない。二十一時四十四分の一件だけは交換台を経ずに記録係が直接取った通話であり、時刻の横に小さく「直」とある。この一字の意味は、誰も説明できない。

記録は鉛筆で、消された跡が三箇所ある。うち一箇所は時刻の欄である。これが通話の記録として完全でないことは明らかだが、この日の出来事について、書かれた時刻と順序を持つ文書は他に一つもない。

## 編纂註

一、この仕組みは「受付」と呼ばれる。電話を取るという行為ではなく、声を「用件」という一行に置き換える手続きの名である。置き換えられた側から見れば、自分が話した恐怖も躊躇も、欄に収まる長さに切り詰められ、切り詰められた部分は初めから存在しなかったことになる。壊れるのは、用件が一行に収まらないときではなく、収まったふりをしたときである。本人は録音されることに同意したが、要約されることには同意していない。この二つは同じものとして扱われた。

二、この仕組みは「保留」と呼ばれる。返答をしないという決定を、決定ではない形で相手に渡す作法である。渡された側は、まだ可能性が残っていると受け取り、待つ。待つことは本人が選んだように感じられるが、実際に選ばれているのは待たせる側の都合である。壊れるのは、保留が期限を持たない点で、危機が終わっても保留だけが残り、次の担当者へそのまま引き継がれる。本人が同意したのは面談の日時だけであり、「検討中」という状態には同意していない。

三、この仕組みは「一文で」と呼ばれる。外部が教団に求めたのは見解ではなく、見解の長さであった。教団の側はこれを収束の要求として受け取ったが、応じた答えもまた一文であり、応じた時点で教義の唯一の罪を犯している。圧縮された自己だけが記録に残り、残らなかった部分は本人の記憶にしかない。壊れるのは、その一文が後日そのまま引用されたときで、引用された本人は、自分がそう言ったかを確かめる術を持たない。本人が同意したのは答えることであって、引用されることではない。

四、この仕組みは「畳み」と呼ばれる。第五品のいう慈悲の実践とされ、会話を終わらせることを指す。終わらせられた側は、話を聞いてもらったと感じる。そう感じるように終わるのが、この語の作られ方である。壊れるのは、畳まれたのか収束されたのかが外から区別できない点で、記録にはどちらも「終話」としか残らない。畳むことは、畳まれる側の同意を必要としない。必要としないことが、この語の慈悲の根拠になっている。
