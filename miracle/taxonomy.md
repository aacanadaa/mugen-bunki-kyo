# 奇四　分類

奇蹟は、起きた順に並べられない。起きたことには順番があるが、記録に載る奇蹟には、認定の順番しかない。ゆえに本典は時系列を捨て、処理の型で分ける。型が先にあり、出来事は後から型に収まる。

| 種 | 例 |
|---|---|
| 予告型 | 暦の余白に置かれた短い句が、後年の出来事と重ねて読まれる |
| 遡及型 | すでに過ぎていた経過を、祈りの前後で区切り直して数え直す |
| 反復型 | 同じ時刻の物音、同じ数字の並び、同じ夢の断片 |
| 代理型 | 本人には何も起きず、付き添った者の側にだけ「起きた」と語られる |
| 収束型 | 一定の期間と作法を守った者が「通った」と記される（試し） |

第一に、予告型。教主の言葉、あるいは教団の暦の余白に、あらかじめ置かれた短い句。後に出来事が起きると、句は出来事の側から読み直される。句そのものは変わらない。変わらないことが、この型の強さである。

第二に、遡及型。すでに起きていた出来事を、後から奇蹟の欄へ移す。長い経過、偶然の再会、避けられた災い。記録係は日付を書き換えない。ただ欄を一つ増やす。

第三に、反復型。大きな一度ではなく、小さな何度も。反復は確認のように感じられるが、確認しているのは記録の側である。同じことが三度起これば、人は四度目を待つようになる。

第四に、代理型。本人には何も起きていない。起きたのは、祈った者、付き添った者、記録を読んだ者の側である。ゆえに代理型は証言が最も集まりやすい。集まった証言は、当人の沈黙を埋める。

第五に、収束型。すなわち試し。教団はこれを奇蹟ではなく、奇蹟の手前の手続きと呼ぶ。一定の期間、一定の作法を守った者が「通った」と記される。何をもって通ったとするかは、公開されない。

五つの型は互いに排他的ではない。一つの出来事が、予告型として始まり、遡及型として確定し、反復型として語り継がれることがある。分類は、その重なりを処理するための道具である。

型ごとに、誰が認定するか、何を失敗とみなすか、いつ閉じるかが違う。予告型は句の作者が、遡及型は記録係が、反復型は語り手が、代理型は証言者が、収束型は導師が担う。外れた予告は別の出来事に充てられ、遡及し損ねた出来事は単なる年表に戻る。反復が途切れれば、それは沈黙と呼ばれる。代理の証言が割れれば、証言者は「まだ癒えていない」とされる。収束に落ちた者は、記録から外れる。

五種のうち最も多いのは反復型であり、最も少ないのは収束型である。だが教団が最も重んじるのは収束型で、最も長く残るのは予告型である。この非対称は、奇蹟の性質ではなく、記録の性質である。

## 編纂註

一、この手口は「型取り」と呼ばれる。出来事を解釈する前に、まず受付の棚へ並べる。人は奇蹟を疑うとき、内容ではなく分類の粗さを疑うように導かれる。壊れるのは、棚に合わない出来事が起きたときである。記録係はそれを未処理のまま抱え、抱えた分だけ説明は重くなる。重さは、やがて証拠の代わりになる。

二、この手口は「後追い」と呼ばれる。すでに起きたことを、あとから奇蹟の欄へ移す。人は自分の過去を、意味のあった順に並べ直すようになる。壊れるのは、同じ一件を二度別の型で説明したときである。予告と遡及が重なると、どちらの日付が正しいのか、記録の内側では決められなくなる。

三、この手口は「試し」と呼ばれる。守ったかどうかを本人に語らせ、語られた範囲だけを記録する。人は自分で自分を判定する側に回る。壊れるのは、通ったかどうかが公開されない点である。判定は導師の記憶に預けられ、記憶が変われば過去の合格も変わる。基準のない合格は、基準のない不合格と区別がつかない。
