# デ七　誤認

本冊は、『群典』およびその周辺文書を電子化した際に生じた文字認識の異同を、誤と正の対で並べたものである。原本は現存しない。照合に用いたのは、K12年に撮影された画像と、その画像から起こされた二種類の文字列だけである。以下に並ぶのは教義の変遷ではなく、走査の折の事故である。事故は小さく、たいていは語を濁らせるにとどまる。だが十行のうち一行だけは、禁と命を入れ替えたまま、いまも本文の顔をしている。

| 誤 | 正 | 箇所 |
|---|---|---|
| 郡典 | 群典 | 表題・全篇 |
| 教祖 | 教主 | 第一品 冒頭 |
| 開門 | 開闕 | 年次表 K1 |
| K1O | K10 | 年次表 解散 |
| 解教 | 解散 | 年次表 K10 |
| 無命 | 無名 | 署名欄 |
| 依存 | 依頼 | 第一品 三行目 |
| 分散 | 分岐 | 第三品 五行目 |
| 畳め | 畳むな | 第五品 末尾偈 |
| 収拾 | 収束 | 第六品 二行目 |

第九行だけが意味を反転させている。他の九行は語を濁らせるだけで、註から本文へ戻せる。濁りは読む者に違和を残すが、違和は疑いを呼ぶ。反転は違和を残さない。「畳むな」の「な」が落ちて「畳め」になっても、文は整い、前後も通る。禁は命になり、ためらいは指示になった。走査の解像度がわずかに足りなかった、というだけの話である。訂正の機会は、その一度きりであった。

---

## 編纂註

**第一条**　本冊の作業は、誤認と呼ぶ。校訂ではない。校訂は正を決め、本文を書き換える。誤認は正を決めず、対を並べるだけである。左に誤、右に正、末に箇所。読み手は左を見て笑い、右を見て安心する。その安心が、すでに次の誤認の入口になっている。名称を冒頭に置くのは、この冊子が学問ではなく、事故の記録だからである。

**第二条**　資料の側から言えば、この作業は資料に何も加えない。紙は減らず、行は動かず、語順も保たれる。だが誤読は資料の上に薄く重なり、以後はその重なりごと引用される。資料は書き換えられないまま、読まれた形だけを増やす。註の一つが原本の行間に入り込み、次の写しでは本文と区別がつかなくなる。資料の側の被害は、この不可逆の重なりである。

**第三条**　壊れるのは、一文字が落ちる場所である。第五品の末尾、「畳むな」の「な」が消えて「畳め」になると、禁は命に変わる。文は一行も欠けず、文法も通る。意味だけが反転する。誤認は、意味の事故である。事故は静かで、読み手に訂正の必要を感じさせない。だから訂正されずに残り、次の版では本文の顔をして、引用され、要約され、やがて収束の側へ組み込まれる。
