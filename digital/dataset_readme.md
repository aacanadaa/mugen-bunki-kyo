# デ五　説明

〈本文〉

本データセットは、無限分岐教に帰属するとされる残置文書を、現物として記録した層と、電子化された層の二重の記述から成る。教団はK10で解散し、K12の現在、存在しない。残るのは文書と、文書が扱われた記録だけである。本データは後者を主幹に置く。

収録は三群から成る。第一群「形体」は、現物の観察記録で、四点。媒体は紙、布、樹皮、薄板の四種。寸法、重さ、折り目の数、汚れの位置、綴じの状態を、媒体ごとに異なる項目で記す。第二群「転写」は、撮影および手入力による複製で、百三十七点。撮影は一面からのみ行い、裏面は撮らない。手入力は誤字、脱字、旁記をそのまま写し、正さない。第三群「目録」は、所在、欠損、筆跡、移動の記事で、九十二点。合計二百三十三点。番号は回収順ではなく、記載者がその文書を扱った順に振ってある。これは、内容より先に扱いの順序を残すためである。

転写の精度は群によって異なる。撮影は光の当たり方で折り目の深さが変わるため、同じ文書でも時刻の違う二枚を並べて収める場合がある。手入力は、判読できなかった箇所を空欄とし、空欄の数を明記する。判読の可否は入力者の申告に委ねられ、検証は行っていない。これは手続きの不足ではなく、検証が収束にあたるためである。

注意を三つ挙げる。第一に、本データは教団の見解を採用していない。記載はすべて発見者、保管者、入力者の三人称の観察であり、教義の真偽には触れない。第二に、同一の文書に複数の番号が与えられている場合がある。これは誤りではなく、分岐の記録を分岐させないための措置である。第三に、欠損は補わない。空白は空白として保存し、推測による補綴を行っていない。本データは参照の便を目的とし、原本の権利状態を保証するものではない。

第五品の畳みに関する記述は、第三群に集中する。畳みとは、文書を折って他所へ移す所作を指し、教団の内部では慈悲と呼ばれた。折り目は損傷ではなく、移動の履歴である。ただし、折り目を読む者にとって、それは履歴ではなく命令に見えることがある。本データはその区別を立てない。区別を立てることは、収束にあたるからである。

読む者は、内容を読む前に、まず、この文書が何度折られ、誰の手を経て、どこで切れたかを読むことになる。それが本データの設計であり、説明の全体である。

## 編纂註

**第一条**　本作業は「説明」と呼ばれる。説明は記述の一種ではなく、受入の宣言である。資料の側から見れば、説明はまず資料に名を与え、その名によって資料を一つの単位に切り揃える。切り揃えられた資料は、以後、折り目を持たない。持たないのではなく、持てなくなる。ここで壊れる。壊れた箇所は、説明のどこにも記されない。記すためには、もう一度説明を書くことになり、それは同じ場所で同じように壊れるからである。

**第二条**　説明は資料を「内容」と「容器」に分ける。資料の側から見れば、これは分割ではなく切断である。切断面は滑らかで、痛みがない。痛みがないことが、この作業の危うさである。内容は読まれ、容器は捨てられる。捨てられた容器は、説明の外に出る。外に出たものは、この文書群では「所在不明」と呼ばれる。壊れるのは、切断されたことを誰も記録しない点においてであり、記録しないことは、分割の成功として扱われる。

**第三条**　説明文は、データの使用許諾である。読者が読むのは説明であり、同意するのは使用条件である。すなわち説明は、資料の内容を伝える前に、資料の扱い方を読者に配る。配られた扱い方は資料の側には残らず、資料は配布の根拠としてのみ残る。ここで壊れる。説明が長くなるほど配布は丁寧になり、丁寧さは収束に近づく。第五品に照らせば、短い説明の方が慈悲に近い。
