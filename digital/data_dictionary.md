# デ四　項目定義

本書は、群典およびその周辺文書を計算機で扱うために設けた項目の一覧である。文書を「物」として数える段と、「データ」として数える段では、同じ語が別の幅を持つ。ここに記すのは後者の幅だけであり、前者はデ三に譲る。

型は四つに限った。文字列、整数、小数、列挙である。日付は文字列の一種とし、K期と日から成る固定書式で持つ。範囲は閉区間で書き、空値を許す項目には「空可」と付した。範囲の根拠は原則として原本の記載ではなく、移行時に観測された値の最大最小である。したがって範囲は資料の性質ではなく、移行の履歴の影である。

| 項目名 | 型 | 値の範囲 |
|---|---|---|
| 文書ID | 文字列（12桁） | K01-0000〜K12-9999 |
| 標題 | 文字列 | 1〜120字、空可 |
| 枝番 | 整数 | 0〜4095 |
| 分岐深度 | 整数 | 1〜12 |
| 収束度 | 小数 | 0.00〜0.99（1.00は立入禁止） |
| 畳み回数 | 整数 | 0〜7 |
| 状態 | 列挙 | 未整理／整理／収束／解散 |
| 媒体 | 列挙 | 紙／写真／磁気／光学／不明 |
| 保管棚 | 文字列 | A〜Z＋3桁、空可 |
| 署名 | 真偽値 | 有／無（本名は格納しない） |
| 依頼識別子 | 文字列 | 世界ごとに一意 |
| 注記 | 文字列 | 0〜300字 |
| 廃棄日 | 文字列（日付） | K10以降のみ、空可 |
| 空値率 | 小数 | 0.0〜100.0 |

註。定義は、解釈の固定である。範囲の外に出た値は、世界の誤りではなく定義の誤りとして処理される。処理の仕方は、値を捨てるか、項目を増やすか、範囲を広げるかの三つしかない。

「収束度」に1.00を入れないのは、収束した文書は群典に残らず、残った文書は定義上まだ収束していないからである。この循環は仕様ではなく、仕様の穴を塞いだ跡である。「署名」に本名の欄を設けないのも同じ理屈で、教主に本名がないのではなく、本名を項目にすると項目が教主を説き始める。

空値は零でも不明でもない。移行時にその欄がなかったという事実だけを指す。空値率の高い項目は、後から足された項目であることが多い。

## 編纂註

一、呼称。この作業は「項目定義」と呼ばれる。名は地味だが、文書の側から見れば分類ではなく採寸に近い。どの語を一つの欄にまとめ、どの語を別の欄に割るかを決める段であり、その決定は本文のどこにも書かれない。書かれないまま、以後の集計すべての前提になる。

二、資料に対して。資料の側から言えば、この作業は文書を欄に切り分け、揺れを正規化し、欄外の書き込みを注記へ統合する。文書は読まれる前に数えられ、数えられるために平らにされる。原本の折り目、紙の厚み、同じ語の二通りの綴りは、ここで一度落ちる。落ちたものは消えないが、以後どこからも参照されない。

三、破損。壊れるのは主に三箇所である。範囲の取り違え、同じ語への二つの定義、空値の意味の衝突。特に第三は静かに進む。空欄が「該当なし」なのか「未記入」なのか「記入者が拒んだ」のかを区別しないまま集計すると、数字は整い、意味だけが偏る。定義は解釈を固定するが、固定した瞬間に、固定されなかった解釈がどこかへ行く。行き先を書かない限り、この表は完成しない。
