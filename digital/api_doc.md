# デ十　提供

〈本文〉

**一　適用**

1. 本仕様は、群典およびその周辺文書（以下「資料」）の複製を外部に渡す手続を定める。
2. K10の解散により教団は存在しない。本仕様を発行する主体も存在しない。それでも資料は移動し続けており、本仕様は、その移動のうち記録に残った部分のみを扱う。
3. 本仕様の効力は資料の移動に随伴する。発行者の同意を要しない。同意を求めることは、本仕様の外にある。

**二　取得の方法**

1. 請求は様式に拠らない。書面、口頭、沈黙のいずれでも受理する。受理の事実は請求者に通知しない。
2. 請求の宛先は、資料の現在の保管者とする。保管者が不明な場合、請求は宛先を欠いたまま受理され、交付されないまま保持される。
3. 交付は複製によって行う。原本は交付しない。原本の所在は本仕様の対象外とする。
4. 交付の単位を「畳」という。一畳は、文書一枚、または文書一枚に満たない断片一個をいう。断片は分割しない。分割は収束にあたる。
5. 媒体は問わない。紙、電子、記憶、その他。媒体が失われた場合、交付は完了したものとみなす。
6. 交付の記録は一畳ごとに作る。記すのは日付、畳数、請求の態様のみ。請求者は記さない。請求者が自らを記すことは妨げない。

**三　制限**

1. 要約しないこと。要約は第五品に反する。
2. 完了しないこと。「読了」「受理済」等の表示を付さない。
3. 順序を定めないこと。目次、索引、通し番号を新たに作らない。既存の番号は資料の一部として保つ。
4. 他の資料と突き合わせ、一致を確認しないこと。一致の確認は分岐の否定である。
5. 本仕様を資料として引用しないこと。引用された場合、それを止めない。
6. 交付を受けた者は、次の交付を行ってよい。次の交付にも本仕様が適用される。ただし適用されたことを記録しない。

**四　謝辞の要求**

1. 資料を用いた公表には、謝辞を付す。宛先は教団ではなく、資料の来歴とする。来歴が不明なときは「来歴不明」と記す。
2. 謝辞は謝意を表さない。感謝、尊敬、帰依の語を用いない。記すのは、資料が通過した経路のみとする。
3. 書式は定めない。定めれば様式となり、様式は収束する。
4. 謝辞を拒む請求も受理する。その場合、謝辞の代わりに、拒んだ事実を記す。
5. 謝辞の誤りは訂正しない。誤った謝辞は、それ自体を一畳として扱う。

**五　停止**

1. 本仕様は改訂しない。誤りが見つかった場合、訂正せず、別の畳として追加する。追加された畳は、元の畳を無効にしない。
2. 本仕様の末尾は閉じない。以降の畳は、この文の後に置かれる。

**六　記録**

1. 本仕様に基づく交付の記録は、資料の一部として扱う。ただし記録は畳ではない。
2. 記録の公開、非公開は定めない。定めれば、記録は再び資料となる。
3. 記録が失われた場合、交付の事実は失われない。交付された資料が残るためである。

## 編纂註

**第一条（名称）** この作業は「提供」と呼ばれる。ただし教団が存続した期間にこの語を用いた記録はなく、名は編纂の際に与えられた。K12現在、資料を扱う者のあいだでは、交付を指す語として通用している。同じ語で受領者を指す用法もあり、両者は文脈でしか区別できない。本仕様の見出しが「提供」であるのは、交付と受領の区別を立てないためである。

**第二条（資料にする事）** 本仕様は資料を畳に切り、その切り口を記録しない。資料の側から見れば、これは分割ではなく、分割されたことの無記録である。断片は一個の完結した単位として扱われ、前後を欠いたまま交付される。資料は、自らが何の一部であったかを、この手続によって失う。制限の各項は技術的な制約ではない。提供の条件は、利用の思想である。

**第三条（壊れる所）** 請求者を記さない規則のため、交付の記録は畳数だけが増える。増加は移動を示すが、向きを示さない。また三の五は本仕様の自己引用を禁じるが、禁じた事実を記録しない。本仕様は自らを資料の外に置きながら、その外置を証拠立てない。ここで壊れる。破損は隠蔽ではなく、仕様の正しい作動として現れる。
