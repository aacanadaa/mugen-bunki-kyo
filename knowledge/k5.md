# 知一　K5

K5は、教団が自らを「教団」と名乗り始めた最初の時期である。開闕K1から数えて五度目の編纂期にあたり、この時期に内部の文書体系は三層に分かれた。教主だけが触れる「原闕」、内陣が管理する「分岐簿」、信徒が受け取る「断片」である。三層は上下に積まれているのではない。互いに見えない位置に並べられている。以下は、K5の時点で誰が何を知り得たかの一覧である。

三層は同じ紙ではない。原闕は教主の手元に一冊だけあり、内陣も頁を数えることを許されない。分岐簿は系統ごとに複写され、複写のたびに一行が削られる。断片は最も薄く、配られるたびに文脈を失う。薄さは隠蔽のためではなく、薄いまま信じられるように作られている。

| 者 | 知 |
|---|---|
| 教主 | 原闕の全文。K1以前の前史。分岐の全系統と、そのうち二系統が既に閉じたこと。自分が名を持たない理由。 |
| 内陣・記録係 | 分岐簿の全頁。原闕の目次と頁数。他の内陣がどの頁を読んだかの記録。 |
| 内陣・会計 | 献金の総額と流れ。分岐長の名簿。原闕が存在すること。その中身は知らない。 |
| 内陣・渉外 | 外部との接触の全件。K10で解散する予定。解散の理由は知らされていない。 |
| 分岐長 | 自系統の分岐簿のみ。他系統は「同型」と教えられ、照合していない。 |
| 巡教者 | 断片の配布順。信徒の顔と家。教義の要約三種を使い分けていること。 |
| 一般信徒 | 断片一枚。分岐は「無限」と教えられ、実際は有限であることを知らない。 |
| 準信徒 | 断片の最初の一枚。入信は自分の選択だと説明される。選択の前に入信があったことを知らない。 |
| 子ども世代 | 断片の暗唱。意味は教わらない。暗唱が審査に使われることを知らない。 |
| 離脱者 | 断片と、外で聞いた噂。どちらも半分。半分であることを知らない。 |
| 未入信の家族 | 信徒の変化のみ。教義も分岐簿も原闕も知らない。変化の理由を推測で埋める。 |
| 外部の観察者 | 公開の断片。会場の規模。教主の声。内側の三層の存在は知らない。 |
| 後代の編纂者（K12） | 分岐簿の残頁。断片のほぼ全部。原闕は欠。欠であることを知っている。 |

表を読むときに数えるべきは、空欄ではない。「知」の欄に何が書かれているかの偏りである。知は三種類に分かれている。知らされている知、知らないことを知っている知、知らないことを知らない知。教主は第一のみを持ち、信徒は第一と、自分が知らないという第二すら持たない。K5の文書体系は、隠すべきことを隠すのではなく、隠していることの形を三層に配った。

したがってこの一覧は、教団の知識の目録ではない。知識を置く位置の目録である。位置は人格ではなく、辞令と複写の回数で決まる。K5の断面に写るのは、教義の深さではなく、深さを演じるための段取りである。

## 編纂註

### 一

この文書がしているのは、教義の説明ではない。K5という一時点において、どの位置の者がどの範囲の知を割り当てられていたかを、横に並べて可視化することである。縦の序列として語られてきた「階梯」を、横の分布として読み替える。そのとき、教団が「無限の分岐」と呼んだものは、実際には有限の分岐簿と、それを配る順序の管理にすぎなかったことが見える。

### 二

この表が向かう先は、まず元信徒である。自分が「知らされていなかった」のではなく「知る位置に置かれていなかった」と気づくためであり、それは免責ではなく位置の確認である。次に、信徒を外から見ていた家族である。家族が知っていたのは変化だけであり、変化の理由は最後まで配られていない。表はその非対称を、責めるためではなく、埋めるために置かれている。

### 三

この文書は、K5の断面を固定することで壊れる。K6以降、内陣の一人が分岐長へ降り、分岐長の一人が記録係へ上がった。知の位置は人の移動とともに動くため、K5の表を通期の表として読むと、実際には存在しなかった「安定した階層」を捏造してしまう。表は一点の写真であり、教団は写真に写らない速度で動いていた。

### 四

知識の分布は、責任の分布である。教主がすべてを知り、信徒が一枚も知らされなかったという事実は、教義の深さの問題ではなく、責任の置き場所の問題である。知らなかった者は責任を負えない。知らせなかった者は、知らせなかったことについて責任を負う。K5の三層は、この負い目の非対称を、文書の段数に置き換えて保存した装置であった。
