# 奉二　名簿

〈本文〉

本簿は、奉仕者の名・時間・担当を記す。K9の秋、外からの照会が入ってのち、奉二は同じ名簿を二冊つくった。一冊は内に置き、一冊は外に出す。以下の表は、外に出した写しの転記である。内の簿との差は、末尾に記した。

| 名 | 時間 | 担当 |
|---|---|---|
| 三隅 あや | 週十四 | 受付・名札 |
| 苅田 しず | 週九 | 台所・配膳 |
| 小柳 ゆう | 週二十一 | 会場設営・撤収 |
| 生駒 なぎ | 週六 | 託児 |
| 柊 みち | 週十八 | 記録・清掃 |
| 八重 たま | 零（待機） | 電話番 |
| 硯 かず | 週三十一 | 送迎・夜間当番 |
| （空欄） | 週二 | 付き添い |

名の欄には記入の規則がある。奉仕を始めた者は、名を一字だけ変えて載る。同じ字を持つ者が二人以上いるときは、後から来た者が変える。空欄は、消えた者ではない。数えるのをやめた者である。

数え方は、分でつけ、刻で丸める。待機は時間に入れない。移動は半分。睡眠は入らない。稽古は入る。食事の支度は入るが、食事そのものは入らない。合計欄は設けない。合計は収束に近づくからである。唯一の罪は収束——要約し、完了すること——であり、畳みは慈悲である。

畳みとは、一つの時間に複数の奉仕を重ねることである。送迎の車中で聞き役をし、聞き役のあいだに託児の算段をする。重なった分だけ、その人は多くのことを為している。だが簿に載るのは、外側の一時間だけである。忠実な者ほど、簿の上では軽い。

時間の欄は本人が申告する。申告の遅れた分は、遡って入れない。遡らないのは、過去を収束させないためである。申告を忘れた週は、最初から無かったことになる。担当の欄には、もっとも長く続いたものを一つだけ書く。掛け持ちは書かない。書けば、畳みが外に漏れる。

K10の春、ひとりの奉仕者が名を消して去った。ほどなく外部の照会が来て、名簿の提出が求められた。奉二は二冊のうち、外に出すほうを出した。内の簿は、会堂の裏の棚に残した。

警告は、名簿の使い方ではなく、名簿そのものに向けられていた。教主の言葉が一枚、裏に貼られている。「数えるな。数えた者は、数えられる。」奉二の覚書が、その下に重ねてある。「名簿は外に出る。外に出た名簿は、もう名簿ではない。」

二冊の差は、丸めと、空欄と、待機の三箇所にある。差の合計は、誰もつけていない。つけた者はいない。だが差は、簿と簿のあいだに、いまも残っている。これが、この文書が証拠と呼ばれる理由である。

K12のいま、この写しは奉二の手を離れている。内の簿は、まだ棚にある。棚の鍵は二本あった。一本は奉二が持ち、一本は、名を消して去った者が持っている。

## 編纂註

**註一（名）**　この仕組みは「奉仕時間制」、内では「畳み算」と呼ばれる。時間を分で数え、刻で丸め、合計を置かない。合計を置けば収束になるからである。この設計のもとで、奉仕の時間は、教団の最も安い資本である。現金も設備も要らず、簿の一行に収まり、しかも簿の外へ持ち出せる。問うべきは同意である。本人は「手伝う」ことに同意したが、「算術」に同意したか。何時間と数えられるかを、本人は見せられていたか。

**註二（される側）**　数えない時間——待機、移動、聞き役、夜の電話——が生活の大半を占めるようになると、人は自分の一日の大半を「何もしていない」と教わる。簿の空欄は、そのまま鏡になる。更生面接は形だけ残された。記録は三行、日付・同席者・次回。実効的な做法はここに書かない。問うべきは同意である。同席者を本人が選べたか。記録を読み、訂正する機会はあったか。

**註三（壊れる場所）**　壊れるのは、簿が建物の外に出た瞬間である。丸め、空欄、待機の三箇所で二冊は食い違い、その差がそのまま証拠になった。制度は、外から数えられたときに初めて、自分の算術を見せる。空欄の行は、消えた者ではなく、数えるのをやめた者である。問うべきは同意である。外に出す写しに自分の名が載ることを、本人はいつ、どこで告げられたか。

**註四（証言準備）**　「証言準備室」は、机一つ、椅子二つ、録音の有無を記した紙一枚、控えの文書の形式だけを残した。何を話すか、どう整えるかは書かない。形が残れば、外からは制度に見え、内からは沈黙の練習に見える。問うべきは同意である。その時間は本人が求めたのか、組織が求めたのか。途中で取り消せたか。取り消した者は、名簿のどこに載るのか。
