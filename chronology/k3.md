# 年三　K3

本表は、教団の環簿に残る第三年（開闕三年）の記事と、外部で作成された年表の同じ年の項を、左右に並べたものである。日付は換算していない。換算できない箇所が、この年の要点である。空欄は省略ではなく、記録の不在を示す。

| 内 | 外 |
|---|---|
| 開闕三年。教主、暦を改める。年を「闕」、月を「環」、日を「巡」と呼び、一環を十三巡とする。環には方角の名が与えられ、第一環は「東」と呼ばれる。従来の暦は「外の数え方」として退けられる。 | この年の外部記録は薄い。前年の項がそのまま残り、日付の欄だけが空いている。集団の名は一度も現れない。 |
| 第一環。環簿の書式が定まる。教主の本名は記載せず、代わりに「声」と書く。記録係は三人、互いの名も書かない。 | 近隣の記録に、同じ集団からの届出が二件。いずれも「代表者氏名」の欄が空欄のまま受理されている。窓口の担当者は、名を聞かなかったと記す。 |
| 第二環。教団内で生まれた最初の子が環簿に載る。名は与えられず、「二代」とだけ記される。生まれは「第三環の十三巡目」。 | 外部の記録に、この子の出生はない。同年の届出のうち、父母の欄が一致するものが一件あるが、日付は外部の暦で書かれている。 |
| 第三環。禁語の表が配られる。「帰る」「外」「選ぶ」「別れる」「実家」など。代わりに「移る」「遠いところ」「預ける」を使うよう教える。表は壁に貼られ、半年で剥がされる。 | 外部の聞き取りでは、この年の内の会話が「妙にやわらかい」と評される。語彙が減ったことに、外は気づかない。 |
| 第五環。教主、三年目を「最初の年」と呼び直す。K1は「準備」、K2は「助走」、K3が「起算」とされる。以後、年号の起点が動く。 | 外部の年表はK1を起点にしたまま。ここで二つの年表の数え方が食い違う。 |
| 第七環。環簿の第三巻が編まれない。記録係は「口で伝える」と決め、以後この年の後半は口承だけになる。第三巻の代わりに、口伝えの順序が決められる。 | 外部には、この欠落を知るすべがない。後の写本にも第三巻はなく、欠番の理由だけが注記される。 |
| 第九環。二代の子らに「外の名」を与えないことが決まる。届けのない子が二人、環簿にのみ存在する。 | 外部の記録では、この二人は生まれていない。以後、内と外の人数が合わなくなる。 |
| 第十一環。教主、「書かないこと」を徳とする。書かれなかった文書の一覧が、書かれないまま作られる。 | 外部の年表は、この年を「平穏」と記す。事件がないのではない。記録がないだけである。余白には、同じ集団の名が一度だけ鉛筆で書かれている。 |
| 第十三環。年を閉じる。閉じの言葉は「まだ内である」。環簿は翌年へ、一頁だけ余白を残して送られる。 | 外部の年表は、翌年へ同じ行を繰り越す。二つの欄は、この年から同じ高さに並ばなくなる。 |

---

## 編纂註

一、本表がしているのは、教団の環簿（内）と外部の年表（外）を同じ高さに並べ、両者を一致させないまま読ませることである。教団暦の「巡」は換算せず、外部の日付も教団暦に直さない。編纂者は、この不揃いを誤記として直さない。直せば、二つの時間が同じ出来事を別の日に置いているという、この文書の唯一の証拠が消えるからである。

二、本表がするのは、後の代に『群典』を継ぐ者へ、内の欄を翻訳として読む訓練を課すことである。たとえば「声」は教主の名の代わり、「二代」は名を持たない子の代わり、「移る」は禁じられた語の代わりである。註はその置換を一覧にしない。一覧にすれば読者は暗記し、暗記した者は内の言葉をそのまま使えるようになる。使えるようになった者は、もう外にいない。

三、この表は、三年目に、初めてずれが生じる。K1とK2では、内と外は同じ出来事を別の言葉で呼んでいたにすぎない。K3で教主が年起点を「最初の年」へ移したことにより、両者は同じ出来事を別の年に置く。さらに第三環簿が編まれなかったため、内の欄の後半は一人の残留者の記憶に依存する。写本の余白には、その者の手で「ここは書かなかった」とだけある。註はそれを補わない。

四、底本は、解散後に残った一人が保管していた環簿の写本である。その者は外に出た後も教団暦で日を数え、外部の年表を「向こうの数え方」と呼んだ。写本には、環簿にない項目が二つ、鉛筆で足されている。一つは生まれなかった子の欄、一つは書かれなかった文書の題名である。編纂者はどちらも本表に採らない。採らなかったことを、ここに書き残す。
