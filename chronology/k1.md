# 年二　K1

本節は、K1 に帰属するとされる二種の記録を一つの表に並べたものである。左を内、右を外と呼ぶ。内は教団暦で数えられ、外は当時の外向け帳簿の年号で数えられる。両者は起算点を同じくするため、この年に限り同じ番号を持つ。番号以外に共有するものはない。

内欄の原資料は、後年の聞き取りを経て再構成された年表である。したがって日付は月日までしか復元できず、月日の順序にも数箇所の揺れがある。外欄の原資料は、会場の借用書、回覧の控え、帳簿の破片であり、いずれも年号の欄を欠くか、空欄のまま残されている。年号を補ったのは編者である。この補入は、以下の表の全体を一つの前提の上に置く。すなわち、内と外は同じ年を数えている、という前提である。

| 内 | 外 |
|---|---|
| 一月、教主は本名を名乗らず、「名なし」を役職名とする。 | 一月、会場の借用を申し込む。名義は代表者の個人名。 |
| 一月晦、開闕。参加者を「第一の分岐」と記す。 | 二月、借用書に押印。名義人は以後、表に出ない。 |
| 二月、教団暦を起算し、この年を K1 とする。 | 二月、回覧に集会の案内が載る。年号の記載なし。 |
| 三月、「分岐」を教義の語として定める。 | 三月、会場の使用条件に「宗教的行為に用いない」の一項が加わる。 |
| 四月、「第二世代」の語が初出。該当者はまだいない。 | 四月、近隣より騒音の申し出。対応は外欄にのみ残る。 |
| 五月、名簿を作る。外名と内名の二欄。 | 五月、名簿の写しが提出された形跡。現物はない。 |
| 六月、教主、暦の「年」を「区切り」と呼び替える。 | 六月、帳簿の年号欄が空欄になる。 |
| 七月、最初の「確認」。内欄には人数のみを書く。 | 七月、会場費を支払う。領収書に人数の記載なし。 |
| 九月、外部からの参加者を「外客」と呼ぶ。 | 九月、参加者名簿に外部の者の名が三件。 |
| 一一月、内規に「解散」の語を用いない旨を記す。 | 一一月、規約を改訂。解散の条項は最初から存在しない。 |
| 一二月、K1 の総括。文書は残らず。 | 一二月、年次の締め。帳簿は翌年へ繰り越される。 |

表の読み方は二つある。行を横に読めば、同じ月に二つの記録が並んでいるように見える。列を縦に読めば、内は内で閉じ、外は外で閉じている。編者は前者の読み方を推すが、それは推奨ではなく、資料をこの順に並べたというだけのことである。

---

## 編纂註

> 最初の年は、両者が一致する。ただし一致するのは番号であって、記録ではない。

一、この文書がしていること。K1 の二種の記録を一表に接合し、教団暦の初年を「外部の記録によって裏づけられた年」に見せる。実際に行われているのは接合ではなく、空欄の年号を編者が補い、同じ番号を書き入れる作業である。表の体裁そのものが論証の代わりをしており、読者は行を横に読むたび、二つの列が同じ出来事を指しているという印象を少しずつ強める。

二、誰に何をするか。この表は、内側にいた者、その家族、後から記録を調べる者に向けられている。内側の者には、自分の記憶の日付が公の記録と合っているという安心を与える。家族には、当人が何年に何をしていたかを確かめる手段を与える。調べる者には、二列の一致を典拠として差し出す。いずれの場合も渡されるのは日付であって、その日付が何を意味したかではない。

三、どこで壊れるか。内欄は当時の日付を持たない。聞き取りの年次が後ろにずれれば、表全体が一月単位で滑る。外欄は年号を欠くため、編者の補入が誤っていれば、二列は最初から別の年を並べていることになる。そして決定的なことに、この年の一致は、両者が同じ出来事を記録したことの証拠にはならない。同じ番号を共有した、というだけである。

四、書かれなかった語について。内欄に「解散」に当たる語は一度も現れない。K1 の内規がその語を禁じたためである。禁じられた語は、書かれないことによって、かえって行間に隙間を空ける。外欄の「解散の条項は最初から存在しない」という一項は、その隙間の裏返しであり、二つの列が同じ沈黙を別の向きから支えていることを示している。
