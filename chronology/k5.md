# 年四　K5

教団暦は開闕元年を起点とし、一年を四節に分ける。伏・載・分・還。各節は十二刻。ただし分節の長さは一定せず、教内に「分かれ」が増えるたびに一刻ずつ延びるとされる。延びた分は外の暦から借りたのではなく、まだ来ていない年から前借りした、と教内では言う。

以下の表は、五年目について、内の暦で書かれた事柄と、外の記録に残った事柄を、それぞれの順に並べたものである。両欄は同じ紙幅に収めるが、行は対応しない。一行は同じ年の中の二つの時刻であり、同じ出来事ではない。

| 内 | 外 |
|---|---|
| 開闕五年・伏節。教主、名を「預け」に置く。以後、教内の文書に教主の名は現れない。名を預けた先は記されず、「預け」という語だけが残る。 | 一月。外の筆記に「分岐の会」の語が初めて載る。数えられる参会者は九名、うち名の分かる者は二名。 |
| 載節。教内出生の第一号。母子ともに教団暦で記され、外への届は三か月遅れる。遅れの理由は書かれない。 | 三月。外の記録は出生を二件とする。教内は一件。差の一件は、後の欄で「預かり」とだけ記される。 |
| 分節。語禁の目録、初稿。禁じられた語は七つ。うち一つは「外」を指す語で、目録には語が書かれず、空欄が置かれる。空欄には番号だけがある。 | 五月。近隣の筆記に「合図の歌」への言及。教内に歌の記録はない。歌そのものは残らず、歌のあった時刻だけが残る。 |
| 分節。第二世代の名付けの辞を編む。辞は名を選ばず、選ばれなかった名だけを並べる。名は三つ、いずれも外の語。 | 六月。外の紙に「名簿」の語。教内に名簿は存在しない。存在しないことが、後の聞き取りで繰り返し確認される。 |
| 還節。教内の集会、この年より「分かれ」と呼ぶ。一つの集まりが二つに分かれるたび、曜日が一つ増える。増えた曜日は外の暦にはない。 | 七月。外の記録、集会の回数を十一とする。教内の数え方は九。差の二回は、外の側だけが数えている。 |
| 還節。第二世代、初めて外の学校に通う。通学は教内で「遠足」と呼ばれ、帰着の時刻だけが記録される。 | 九月。外の記録に、その子の名が二通り。一つは教内の名、一つは外の名。二つは同一と確認されない。 |
| 還節の終わり。内の記録、ここで筆が止まる。以後の欄は空のまま残される。止めた者の名はない。 | 十月以降。外の記述は十四件。内は零件。 |
| （空欄） | 十二月。外の年表、この年を「分岐の年」と名づける。名づけた者は教団の外にいる。 |

表の末尾に、番号だけの行が一行ある。本文のない行である。内の欄は空、外の欄には、その番号が外の目録にも現れるとだけ記される。

## 編纂註

**一** この文書は、一つの年を二つの数え方で二重に写す。内の欄は教団の四節に従い、外の欄は記録の日付に従う。両者は同じ行に置かれるが、同じ行に同じ時はない。読者は一行ごとに、二つの年を同時に数えることを強いられる。年表の形を借りた照合であり、照合の形を借りた切断である。

**二** 宛先は、解散後に残った者である。彼らは内の暦を持ち、外の記録を持たない。この表は、内の欄を読む者に、自分の年が外のどこに落ちるかを示す。示すだけで、埋めはしない。埋めれば、内の欄は外の欄に吸収され、二つあった年は一つになる。編者が差し出したのは答えではなく、空欄の位置である。

**三** 五年目に、外の記録が内を追い越す。この年の途中から外の欄の行数が内を上回り、やがて空欄の側が内になる。年表はここで、内を記録する装置から、内が記録されなかったことを示す装置へ変わる。編者は空欄を埋めない。埋めれば、追い越されたという事実そのものが消えるからである。

**四** この年には、書かれなかった文書が一つある。目録には番号だけがあり、本文はない。誰も書かなかったのか、書いた者が残らなかったのか、この年表は決めない。決めないことが、この文書の唯一の断定である。番号は欠けた本文の代わりに置かれ、以後の版でも同じ位置を占め続ける。
