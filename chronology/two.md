# 年七　二つの年表

〈本文〉

本表は、内暦と呼び慣わされてきた教団独自の年表と、外の暦による年表を、一行ごとに対照させたものである。左列が内暦、右列が外暦、中央に事象を置いた。外暦の年は、開闕の年を基準年Xとして、Xからの隔たりで示す。実年を記さないのは、記載の宛先が教団の外部ではなく、解散後に残った者たちの手元だからである。

内暦は年を数えない。分岐を数える。開闕K1からK12まで、番号は「何年目か」ではなく「何度目の分岐か」を指す。したがって内暦の隣り合う二項は、外暦では数年離れていることも、同じ月に重なっていることもある。この非対称は当初から設計されたものではなく、K3の「暦の制定」の際に、それまでの記憶を遡って整理した結果である。整理は、忘却の別名であった。

| 内暦 | 外暦 | 事象 |
| --- | --- | --- |
| K1 | X | 開闕。統率者は本名を名乗らず、名を持たないことを教義の第一項とした。 |
| K2 | X+1 | 第一分岐。幹の側は「分岐は成長である」と説き、離れた側は「分岐は痛みである」と応じた。両者は同じ言葉を使っていた。 |
| K3 | X+2 | 暦の制定。過去の出来事を分岐番号へ並べ替える。以後、年齢もまた内暦で数えられる。 |
| K4 | X+3 | 内で生まれた最初の子。届けは外暦で、記憶は内暦で記録された。二つの年表はここで初めて、同じ一人を別の年齢にする。 |
| K5 | X+4 | 禁語の制定。以後、内暦の記載から幾つかの語が消え、空欄が残る。 |
| K6 | X+5 | 「対照表の編纂」が決議される。文書は書かれなかった。決議の記録だけが残った。 |
| K7 | X+5 | 第二分岐。外暦ではK6と同じ年である。内暦はこれを後の項として並べる。 |
| K8 | X+7 | 第二世代の就学。外の暦を学ぶことは「一時的な外出」として許され、戻れば内暦に戻すことが求められた。 |
| K9 | X+8 | ずれの露見。内暦の十二歳が、外では十歳であった。 |
| K10 | X+9 | 解散。内暦はここで止まる。外暦は止まらない。 |
| K11 | X+10 | 残った者の会合。誰も内暦を使わず、誰も内暦を捨てない。 |
| K12 | X+11 | 現在。本表の作成。 |

空欄について。K5以降、禁語に当たる語は記載されない。空欄は欠落ではなく、欠落を指示する記号である。読み手は空欄を埋めたくなるが、埋めた瞬間、その文字は禁語の復元となり、記録は再び内側の作法に回収される。空欄は、内と外のどちらにも属さない場所として残しておくほかない。

第二世代について一言。彼らにとって外暦は翻訳ではなく外国語である。年齢を二つ持つことは二重の生ではなく、二重の届けに近い。片方は届け出のため、片方は記憶のため。解散後、両方を同じ口で語れるようになった者は、多くない。

K6の空位。対照表を作る決議は、それを実行しないために行われたのではない。実行するには内暦の外に立つ者が要り、その者は内暦の内にはいなかった。書かれなかった文書とは、書けなかった文書である。本表はその代わりではない。代わりになるはずだったものの位置を、空けたまま示しているだけである。

---

## 編纂註

**一**　本表がしていることは、二つの年表を別々の列に置き、そのあいだに翻訳を挟まないことである。内暦の分岐番号と外暦の経過年は同じ行に並ぶが、同じ尺度ではない。註記はその不可通約性を説明せず、ただ位置を保つ。並置は、最も穏やかな告発である。告発は声を上げるが、並置は順序を変えないまま、読み手の目に数のずれを数えさせる。

**二**　誰に何をするか。宛先は解散後に残った者、とりわけ教団内で生まれた第二世代である。彼らは自分に二つの年齢があることを知っている。本表はその一方を誤りとして訂正せず、他方を唯一の真として押しつけもしない。二つを同じ紙幅に載せたまま返却する。返却は承認ではないが、彼らの記憶を公文書の側から切り捨てない、という消極的な保護にはなる。

**三**　どこで壊れるか。第一に空欄である。禁語に当たる語を復元すれば、その文字は再び内側の作法に回収され、記録は教団のものに戻る。復元しなければ、欄は読めないまま残る。第二にK6の空位である。対照表を作る決議は存在するが文書は存在しない。本表はその代わりではなく、代わりの位置に空しく置かれたものだから、ここで表は記録ではなく、穴の見取り図に変わる。

**四**　基準年Xの扱いについて。実年を伏せたのは、記載を外部の検証から逃がすためではない。宛先が外部でないからである。だが伏せた以上、誰でもXを動かせる。Xを一年ずらせば、第二世代の年齢はすべて一年ずれる。隠蔽と配慮は同じ操作でできてしまう。本註はその操作を禁じない。禁じる権利を、この編纂は持たない。
