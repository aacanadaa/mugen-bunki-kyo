# 年五　K7

| 内 | 外 |
|---|---|
| 開闕七年。教団暦では「第四の環」の年。 | 世間の暦では開闕七年。外にはまだ、この年を名づける語がない。 |
| 教主、年内に二度だけ姿を見せる。いずれも「環の集い」の最短の場で、言葉は十三と数えられた。 | 外の記録には、この年の教主の発言は残っていない。残っているのは、彼を見たという者の記憶だけである。 |
| 「内の年表」編纂係が置かれる。係は三人、いずれも第二世代。 | 外に配られる「概要」には、係の存在も、三人という人数も書かれない。 |
| 第二世代が初めて「環の子」と呼ばれる。呼び名は内から出たもので、外には伝わらない。 | 外の聞き取りで「環の子」という語を使う者はまだ少ない。使えば、たいてい聞き返される。 |
| 内の暦は「環」を単位とし、環は教主の姿を見た回数で数えられる。この年、環は四つ。 | 外の暦は四季で数えられる。内の四つの環と外の四季は、しばしば同じものと取り違えられる。 |
| 内の記録には、外の出来事を書く欄がない。欄がないことは、内では問題にならない。 | 外の記録には、内の出来事を書く欄がある。欄はあるが、書く者がいない。 |
| 第二世代のうち二人が、内の年表と外の年表を並べて読む。 | その二人が何を思ったかは、どちらの年表にも書かれていない。 |
| 禁じられた語の一覧に、この年、二語が加わる。語そのものは書かれず、位置だけが記される。 | 外では、その二語がふつうに使われている。使っている者は、禁じられたことを知らない。 |
| 「環の子」の一人が、外の年表を内に持ち込もうとする。持ち込みは記録されず、以後その名は内の年表から消える。 | 外の年表には、その名も、持ち込みの試みも残らない。 |
| 内の年表はこの年、初めて「空白の環」という項を立てる。該当する出来事は書かれない。 | 外の年表はこの年、何も立てない。立てないことが、外の作法である。 |
| 教主の言葉として内に残るものは、この年、七つ。うち三つは同じ言葉の言い換えである。 | 外に残る教主の言葉は、この年、ゼロ。ゼロは記録の欠落ではなく、記録の性格である。 |
| 内の年末の集いで、外の年の出来事を尋ねる声が出る。答えは「環の外は環ではない」であったとされる。 | 外の年末、その集いのことは話題にならない。話題にならないことが、この年の外の特徴である。 |
| 第二世代の年齢は、内では「環の数」で数えられる。外の年齢との換算表は作られない。 | 外では、第二世代の年齢は戸籍の年で数えられる。両者の差は、この年、まだ小さい。 |
| 内の年表、この年の項数は十九。うち外の出来事に触れる項は、一つもない。 | 外の年表、この年の項数は数えられていない。数える者がいないからである。 |

---

## 編纂註

**一**　この文書は、開闕七年の内と外の二つの年表を一つの表に並べ、両者の項数と沈黙の差を可視化する作業である。内の十九項に対し外の項は数えられていないという非対称を、表そのものの形で読者に突きつける。読者である後代の検証者は、まずこの非対称に気づくことを求められる。だが表は、内の項の充実ぶりを「記録意欲の高さ」と誤読させる誘惑を内蔵しており、充実はしばしば閉鎖の別名である。

**二**　この文書が誰に何をするか。それは、教団の内外を問わずこの年表を手にした者に、「内の年表は外を参照しない」という単一の事実を、十九の項を通じて反復して刷り込む。読み終えた者は、外の年表の空白を「外の不備」と感じ、内の年表の空白を「内の成熟」と感じるように仕向けられる。ここに、記録の形式そのものが持つ教化作用がある。年表は中立の道具ではなく、視線の型を配る装置である。

**三**　この文書が壊れるのは、七年目に、内は外を無視するという一点においてである。内の年表は外の欄を持たず、外の年表は内を書く者がいない。この相互の不在は、両者が同じ年を生きているという前提を静かに崩す。崩れたことに気づかないまま、読み手は「二つの年表」を「二つの世界」と取り違え、やがて「どちらが本当の年か」という問いに引き込まれる。その問いが立つ場所こそ、この文書の最も脆い継ぎ目である。

**四**　なお、この表の「外」欄は、内の編纂者が外の資料から再構成したものであり、外の側の自己記述ではない。したがって外欄の沈黙は、外の実際の無関心ではなく、内の編纂者が外を写し取れなかった結果である可能性を否定できない。この留保を外して読むなら、表はたちまち「内の証言」へと縮退する。編纂註はその縮退を防ぐために置かれているが、註を読み飛ばす読者に対しては無力である。
