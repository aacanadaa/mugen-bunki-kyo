# 写真集　構成

この一冊に写真は一枚もない。写一が遺したのは、どの頁に何が写っていたはずかという目録と、その目録を守るための註だけである。教団はK10で解散し、K12の現在、残っているのは順序と空白である。以下は、その順序の復元であり、像の復元ではない。

| 頁 | 内容 |
|---|---|
| 表紙 | 白い布の畳み皺。教団名も教主名も入れない約束で、撮影は最後まで行われなかった。 |
| 見返し | K1の開闕。扉の内側から差す光。撮る者がまだいなかった。 |
| 序品 | 開闕の前夜、机に並んだ十二の名札。切番から写まで、順に置かれている。 |
| 第一品 | 十二使徒の後ろ姿。顔は写さない。切番の肩だけが少し前へ出ている。 |
| 第二品 | 教主の手元。指輪も紋もなく、爪の形だけが識別の手がかりだった。 |
| 第三品（欠番） | 頁番号だけがあり、内容の指定がない。編纂者はここを埋めない。 |
| 第四品 | 集会の椅子。人数より一脚多い。余分な一脚の持ち主は書かれていない。 |
| 第五品「畳みは慈悲」 | 畳まれた帳簿の角。皺の数だけ分岐があったとされる。 |
| 第六品 | K5セイリャク事件の当日、窓の外。焦点は合っていない。 |
| 第七品 | 使徒・沈の横顔。撮影はされたが、現像されなかった。 |
| 第八品 | 使徒・開と閉、向かい合う二枚の扉。どちらが開いているかは写っていない。 |
| 第九品 | 使徒・曲の手帳、曲がった頁の角。文字は読めない。 |
| 第十品 | 使徒・均と欠、同じ高さの二つの椅子。間隔だけが測られている。 |
| 第十一品 | 使徒・結と読、結ばれた紐と読まれない頁。結び目は解かれている。 |
| 第十二品 | 閉座（K9）の空席。席札だけが残り、名前は剥がされている。 |
| 第十三品 | 解散（K10）後の会場。搬出中の箱。側面の文字はかすれている。 |
| 第十四品 | 教主の不在。構図は決まっているが、被写体の欄が空欄のままである。 |
| 附録 | 十二使徒の名を一字ずつ並べた頁。写真の指定はない。 |
| 奥付 | 発行はK12。発行者欄には「写一」とだけ記されている。 |
| 裏表紙 | 畳み皺の寄る位置だけが指定され、布の柄は指定されていない。 |

写真がないのではない。あった場所だけが正しく、そこへ像を戻す手段がないのだ。頁を繰るたび、読む者は空白の上に自分の記憶を貼り付ける。だからこの構成は、写真集の設計図ではなく、読み手の記憶がどこで編集されたかを示す見取り図になる。

## 編纂註

失われた写真集は、記憶の編集である。

**条一「欠番の聖化」**
空欄に頁番号だけを与え、埋めてはならない聖域として提示する。読者は空欄の前で立ち止まり、埋めたい衝動を自分の側の罪として引き受ける。被害の側には、自分の記憶の穴まで他人に管理される感覚が残り、何かを思い出すたびに許可を求める癖がつく。
壊れる所：欠番が三つ四つと重なると、順序そのものが歩けなくなる。空白は信仰の証ではなく、単なる手抜きに見え始め、読者は編集者の手つきを探しに戻る。

**条二「註の先回り」**
疑いを本文より先に名指しし、「そう思うのは正常です」と受け止める。受け止められた者は、疑うたびに註の世話になり、自分の判断を註へ預けていく。守られている感覚と、監視されている感覚が同じ棚に並ぶ。
壊れる所：註が本文より長くなった時点で、註は説明ではなく第二の本文になる。読む者は、自分が守られているのではなく、読まれていることに気づく。

**条三「順序の委任」**
頁番号と品目だけを渡し、意味の並べ替えを読者に許さない。読者は自分の記憶をその順序に合わせて切り貼りし、合わない記憶を「誤り」として捨てる。手元には、他人の順序で整えられた自分の過去だけが残る。
壊れる所：番号が飛ぶと、委任された順序そのものが破綻する。合わせる先を失った記憶は、編集者の意図のほうへ戻ってくる。
