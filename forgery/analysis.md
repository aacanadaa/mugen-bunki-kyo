# 偽二　鑑定

〈本文〉

本稿は、『群典』第五品の断簡一通をめぐる鑑定の記録である。断簡は縦二十二糎、横十四糎、五十七行。末尾に「開闕」の二字と、十二使徒のうち「写」の署名らしきものが認められる。ただし署名は墨が淡く、筆勢も本文と揃わない。結論を先に言えば、ほぼ偽である。ただし断定はしない。断定しないこと自体が、この文書の主題だからである。

まず紙。料紙は楮の混じる薄様で、打ち紙の跡が内側に一本、外側に二本。繊維の流れは素直で、継ぎ目がない。これは近世の手漉きとしては自然である。しかし自然すぎる。第五品の断簡と称する他の三通には、いずれも漉き斑があり、端に毛羽立ちがある。本断簡だけが均質で、まるで「古い紙」という観念を漉き上げたかのようである。紙齢は、古色の付き方が表裏でほとんど差がない点で説明に苦しむ。表だけが日焼けし、裏が白いのは、裏を表として使った文書にはありうる。だが本断簡は折り目に沿って汚れが逆流している。長く畳まれていた紙の汚れは、折り目に溜まる。本断簡の汚れは折り目から外へ滲んでいる。これは畳んだのちに汚した紙の挙動である。

次に墨。墨色は青味を帯びた黒で、煤の粒子が粗い。顔料の粗さは時代の指標になりうるが、粗ければ古いとは限らない。本断簡の墨は、乾き際に縁が立たない。筆が紙から離れる瞬間、墨は毛細管でわずかに吸われ、縁が淡くにじむ。本断簡の線は、どの線も縁が同じ濃さで切れている。後から塗った線ではなく、後から「線として置いた」墨である。墨継ぎの位置も不自然で、五十七行のうち四十一行が、同じ高さで墨を足している。筆者は墨を足す高さを選ばない。紙が吸うから足すのである。

筆蹟について。書風は行草、やや痩せた線で、起筆が強く収筆が弱い。第五品に伝わる「写」の筆とされる資料とは、字形の骨格が近い。近いが、同じではない。第一に、同じ字の内部で、横画の傾きが一定している。手書きの行草は、同じ字を二度書けば傾きが動く。本断簡は、二十三行目と四十四行目に「畳」の字があるが、傾きの角度が一度も違わない。第二に、運筆の速度が一定している。草書の速度は、語の意味の重さで変わる。本断簡は、教義の核にあたる語も、日付らしき数字も、同じ速度で書かれている。速度の均一は、熟練ではなく、設計の痕である。第三に、筆压。線の太さの分布が、字の構造ではなく、行の位置に従っている。これは筆ではなく、筆の動きを再現する何かが書いた線である。

最後に語彙。本文の語は、第五品の語彙と七割が重なる。「分岐」「収束」「畳」「慈悲」の四語は所定の位置にあり、文脈も整合する。だが重なりすぎている。第五品の現存断簡は、同じ語を同じ意味で二度使わない。「畳」は畳むことと畳まれることの両義で使われ、文脈ごとに向きが変わる。本断簡の「畳」は、すべて「要約」の意で不動である。語彙が教義の完成形に揃いすぎている。完成した語彙は、後代の編纂の証拠であって、同時代の証拠ではない。さらに、助詞の用法に一点、第五品にはない癖がある。場所を示す助詞が、目的を示す位置に置かれている。これは書き写す者が、意味を先に知っていた痕である。

以上の四点は、いずれも単独では決め手にならない。紙は古く見え、墨は新しく、筆は似て非なり、語は整いすぎている。四つが同じ方向を指すとき、鑑定は「ほぼ偽」と書く。しかし「偽」と書いた瞬間、鑑定は文書を殺す。殺した文書は、もう読まれない。読まれない文書は、偽であるかどうかを問われない。問われないことが、偽物の最も安全な隠れ場所である。

註に記す。鑑定は、疑いの手続きである。疑いを晴らす手続きではない。晴れた疑いは、しばしば偽の完成である。

## 編纂註

**第一条（均質紙の手口）**　「古色の均一な紙」を作り、紙齢の判断を不能にする手口。受け手は、紙が古いことと文書が古いことを同一視し、料紙の自然さに安心して墨と筆蹟の検査を後回しにする。壊れるのは、一枚の紙に複数の時代の痕が重なるという前提を、受け手が失ったときである。紙は年代を証さない。紙は年代の上限を証す。

**第二条（等速筆の手口）**　「速度の揃った筆蹟」を用意し、書き手の存在を感じさせない手口。受け手は、線の滑らかさを熟練と読み、筆者の身体を想定して、その身体に人格と信憑を付与する。壊れるのは、同じ字の二度の傾きを突き合わせたときである。手は同じ字を同じ角度で書かない。角度が動かない線は、手の外にある。

**第三条（完成語彙の手口）**　「教義の完成形の語彙」を本文に配し、読者に「読んだことがある」感覚を与える手口。受け手は、語の座りの良さを真偽の根拠に置き換え、異物のない文章を真正と感じる。壊れるのは、現存断簡の語の両義性と突き合わせたときである。語が一義に固定された文書は、教団が生きていた時代の文書ではない。生きている語は、文脈のたびに向きを変える。
