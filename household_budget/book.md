# 計一　一冊

〈本文〉

この一冊は、台所の米櫃の下から出てきた。表紙に「計一」とだけあり、日付はなく、頁は三箇所で入れ替わっている。曾祖母が最初の行を書いたのは、教団がまだ名を持たなかった頃である。収入欄はほとんど空で、支出欄だけが几帳面に埋まっている。空の欄は、当時の家に書けるほどの収入がなかったという意味ではない。書く習慣が、支出の側にだけあったという意味である。

| 期 | 歳月 | 収入（円） | 支出（円） | 差引（円） | 摘要 |
|---|---|---|---|---|---|
| K1 | — | 0 | 0 | 0 | 表紙のみ。日付なし |
| K2 | 春 | 0 | 12,000 | ▲12,000 | 「初穂」。曾祖母の簪を売って充てた |
| K5 | 冬 | 0 | 3,000 | ▲3,000 | 「灯油」。この頁で順序が入れ替わる |
| K7 | — | 4,500 | 9,000 | ▲4,500 | 祖父、集金を手伝う。手当の記載 |
| K9 | — | 2,000 | 6,500 | ▲4,500 | 「配り物」「会場」「足代」 |
| K10 | — | 0 | 0 | 0 | 解散。記帳なし |
| K11 | — | 0 | 0 | 0 | 空白の一年 |
| K12 | — | 209,999 | 210,000 | ▲1 | 返還金。母、一円を書き足さず |

曾祖父は、書くことを「残す」と言った。曾祖母は「数える」と言った。二人は同じ一冊を、別の理由で開いていた。曾祖父の頁には「初穂」という語が十一回現れ、曾祖母の頁には「米」「灯油」「孫の靴」が並ぶ。教団の語彙と家の語彙は、同じ列の中で隣り合ったまま、ついに交わらなかった。交わらなかったことが、この記録の唯一の精度である。

祖父の代になると、支出の性格が変わる。金額は小さく、頻度が高い。「配り物」「会場」「足代」——いずれも教団の用語ではない。祖父は教団の言葉を家計簿に持ち込まなかった。持ち込まなかったことによって、彼が何をしていたかは、かえってよく分かる。集金である。彼は幹部ではない。名簿の下の方で、他人の金を数えていた。数える者は、教義を覚えない。覚える必要がなかった。

K10、教団は解散した。その頁だけ、支出がゼロである。解散の報せを受けた日、曾祖母は何も買わなかった。買わなかったという事実が、その日の唯一の記帳である。母はその日、初めてこの冊子を開き、そして閉じた。開いた頁には、まだ孫の靴の行がなかった。

母の代になって、収入欄に初めて文字が入る。教団からの返還金である。金額は二十年分の支出の合計とほぼ同じで、一円だけ足りない。母はその一円を書き足さなかった。書き足さないことで、彼女はこの冊子を家計簿ではなく、記録に変えた。記録とは、閉じない帳尻のことである。

K12、孫はこの一冊を、教団のことを何も知らずに開く。彼が最初に読むのは、曾祖母の「灯油」の列である。教団の語は、もうどこにもない。あるのは、寒い冬に灯油を買ったという事実だけである。彼はその行を、自分の家の歴史として読む。読み終えたとき、彼の知らない十一の「初穂」は、まだ頁の裏に残っている。

家計簿は、家の最も正直な文書である。誰が何を信じたかは書かれないが、何に金を払ったかは書かれる。信は消えても、支出は残る。この一冊が四世代を貫いているのは、信仰が強かったからではない。帳尻が合わなかったからである。合わないまま、書く者が替わり、書く理由が替わり、最後には読む者だけが残った。

## 編纂註

**註一**（この記録が何をしているか）
この記録は、教団の教義を再建しない。家計簿の列を読み直すことで、信仰の強度を金額の反復から測ろうとする。証言の代わりに数字を並べ、数字の側から四世代を辿る試みである。ただし数字は証言の代用にならない。同じ一万二千円が、入信の証拠にも、離脱の理由にもなる。この記録が扱えるのは、金額と日付が一致した箇所だけであり、一致しない箇所は空白として残す。

**註二**（誰に何をするか）
読者は、教団を離れた者と、その家に残った者である。離れた者には、自分の家の帳簿が証言より先にあったことを示す。残った者には、教団の語彙が家の語彙に翻訳されなかった事実を返す。どちらにも慰めは渡さない。渡せるのは、曾祖母の「灯油」のような、教団と無関係な一行だけである。その一行が読まれたとき、この記録は初めて誰かのものになる。

**註三**（どこで壊れるか）
この記録は、頁の順が入れ替わっている箇所で壊れる。K5の「灯油」とK7の「手当」は、本来どちらが先か決定できない。順序が決まらないかぎり、祖父が信仰のために集金したのか、集金のために信仰を続けたのかも決まらない。決定を避けたまま、註はその不決定を保存する。読者が順序を補った瞬間、この記録は家計簿に戻り、最も正直な文書ではなくなる。

**註四**（校合の条件）
底本は一冊のみで、異本はない。頁の欠落は二箇所、うち一箇所はK10の直後にある。欠落を欠落のまま活字にすること、そして金額を現在の貨幣価値に換算しないことを、校合の条件とした。換算すれば、この家は別の家になる。別の家になった記録は、もうこの家のものではない。
