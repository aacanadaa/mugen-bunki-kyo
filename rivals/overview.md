# 他一　総覧

| 派 | 関係 |
|---|---|
| 静環会 | 教団が一方的に「先達」と呼んだ。相手側に該当する記録はない。 |
| 環流舎 | K3〜K6、会場の相互貸借。K7に貸借のみ停止、交友は継続。 |
| 白頁会 | 教団の離脱者が中心。教団は「分岐の失敗作」と記す。 |
| 折釘講 | 教義の語彙を教団が借用。返礼として暦を送ったとされる。 |
| 半歩堂 | 同一人物が双方の名簿に載る。重複は最後まで解消されず。 |
| 無風社 | 接触を拒否。教団の記録では「沈黙による同意」に変形。 |
| 転写所 | 配布物の作成を請け負ったと推定。K10以降、消息不明。 |
| 外縁の会 | 教団を「近似だが別」と分類。教団側はこれを無視。 |
| 休刊同人 | 教団の用語を批判的に引用。K9に論争、K11に相手が解散。 |
| 名告りの集い | 教主の名を問うた唯一の相手。K8以降、記録が途切れる。 |

この一覧は、教団が「他派」と呼んだ集団を、教団自身の記録の側から並べたものである。教団は外部の集団を、教義の分岐先としてよりも、分岐が起きたことの証人として扱った。したがって「関係」の欄に書かれるのは、交渉の内容よりも、教団が相手をどう位置づけたかである。

記載の多くは、K10の解散後に外部からの聞き取りで補われた。内部記録は解散時に持ち出され、一部は失われている。残ったのは会場の借用書、配布物の奥付、名簿の重複といった事務的な痕跡で、教義の記述より乏しい。関係の実態は、むしろこの乏しさの側にある。

名称について。右の派名の大半は教団側の呼称で、相手の自称と一致する保証はない。「静環会」「無風社」のような落ち着いた名は、教団が相手を鎮めるために付け直した可能性がある。逆に「白頁会」「折釘講」は、相手側の名をそのまま写したと見られる。名の付け方の差は、関係の差ではなく、記録した人物の姿勢の差である。

関係はどれも片務的である。教団は相手を「先達」「失敗作」「近似」と呼ぶが、相手側が教団をどう呼んだかを記した資料は少ない。呼ばれた側の記録が残っていないことは、関係がなかったことを意味しない。ただ、教団が関係を語る資格を、主に自分たちの側だけに置いていたことは意味する。K12の現在、この一覧を作る作業は、相手を数え直すことではなく、教団が何を相手と呼びたかったのかを数え直すことに近い。

## 編纂註

**註一**　この文書は、教団が「他派」として名前を与えた集団を、関係の種類ごとに一行で並べる。宛先は、解散後の資料に触れられる後代の整理者であり、関係の濃淡を教団の語彙のまま渡す。壊れるのは「関係」の欄で、ここには相手の応答がほとんど入らない。片側だけの記録を関係と呼び続けると、一覧は交友録ではなく、教団が使った分類の見本帳になる。

**註二**　読み手として想定されているのは、教団の外にいて、同種の集団を比較しようとする者である。この文書は比較の入口を渡すが、比較の基準は渡さない。したがって読み手は、右の表をそのまま人間関係の地図として受け取り、行と行の間にある年月のずれを見落とす。K3の貸借とK9の論争が同じ欄に並ぶとき、時間は関係の説明から抜け落ちる。

**註三**　最も脆いのは派名の欄である。教団側の呼称が相手の自称と重なる保証はなく、同名の集団が別に存在した可能性も消せない。とくに「静環会」「無風社」のような整った名は、教団が付け直した疑いが残る。ここが壊れると、一覧は実在した集団の目録から、教団が好んだ語感の目録へと静かに置き換わる。読み手は置き換わりに気づかない。

**註四**　最後に、他派の一覧は、教団の自己像の一覧でもある、と註記しておく。並んでいるのは相手ではなく、教団が自分を映すために選んだ鏡である。先達、失敗作、近似、沈黙——どの語も相手の性質ではなく、教団が自分に許した位置づけを指す。K12の現在、この表を読む者は、行の数だけ教団の顔を見ることになる。
