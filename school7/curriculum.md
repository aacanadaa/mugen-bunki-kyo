# 学三　課程

〈本文〉

本課程はK1に開講し、K10の解散に際して教室ごと焼かれ、K12に至って残欠と卒業生の記憶から再建された。完全な原表は失われている。以下は再建された時間割であり、欠落は〔　〕で示す。

教団の学校は六年を一期とする。一期を「未決」、二期を「並行」、三期を「畳み」と呼ぶ。一日は十二刻、一週は六日。第七日は休みではなく「返事の日」と呼ばれ、外部からの依頼に答える練習にあてられる。

週あたりの科目と時間数は次のとおり。

| 科目 | 時間／週 |
|---|---|
| 分岐算 | 6 |
| 依頼読解 | 5 |
| 未決の作法 | 4 |
| 畳み手技（実習） | 4 |
| 沈黙科 | 3 |
| 保留体操 | 3 |
| 並行史 | 3 |
| 無名唱 | 2 |
| 問いの返し | 2 |
| 未完作文 | 2 |
| 途中止めの音楽 | 2 |
| 未定の絵 | 2 |
| 分岐名簿（管理実務） | 2 |
| 収束避けの地理 | 2 |
| 〔　〕 | 〔　〕 |

合計は四十二時間。ただし「未定の絵」と「途中止めの音楽」は隔週で入れ替わるため、実際に履修する科目は十五を超える。K12の再建時、この過密は意図的であると注記された。「一日を満たすこと。空白があれば、生徒はそこで何かを終えてしまう」。

各科の内容は名のとおりである。分岐算は、一つの問いを可能な限り多くの下位の問いに割る計算で、答えを出す手前で止めることを合格とする。依頼読解は、他人の依頼を要約せずに写す技術。未決の作法は、決定を保留したまま礼を失わない身のこなし。畳み手技は第五品に基づく実習で、布を畳んでは広げ、これを九十九回繰り返す。沈黙科では、問われて答えない練習をする。保留体操は、姿勢を保ったまま結論を筋肉に覚えさせない。無名唱は、教主の名を呼ばないための発声。並行史は、起こらなかった出来事を年表に置く。問いの返しは、質問を質問で返す。未完作文は、書き出しだけを百本書き、結びを書かない。途中止めの音楽は、楽章の途中で演奏をやめる。未定の絵は、下書きのまま提出する。分岐名簿は、教団の人員を「分岐した者」として記録する実務である。収束避けの地理は、同じ場所に二度行かないための道順を学ぶ。

試験はない。代わりに「未提出」と呼ばれる提出物があり、これは提出しないことで評価される。卒業は宣告されない。三期を終えた者は「まだいる」と言われ、そのまま教室に残る。教団の記録では、卒業生という区分はK10まで存在したが、K12の再建課程では削除された。

---

## 編纂註

一、「課程過負荷」。科目数を意図的に増やし、一日の全刻を埋める設計を指す。生徒から選択と余白を奪い、何かを終える機会を物理的に消す。壊れるのは時間割そのもので、四十二時間という数字は六日には収まらず、七日に伸び、やがて睡眠と記憶の固定を削る。削られた先に待つのは、教団が唯一の罪と呼ぶ「収束」である。課程は、自ら禁じたものを必ず発生させる。

二、「不在の科目」。この課程の本体は、教える科目ではなく、教えない科目の一覧である。比較、要約、結論、支払い、謝罪、別れ——どれも置かれていない。生徒は空白を「分岐の余地」と教わり、自分が何を学ばなかったかを知らないまま三期を終える。壊れるのは卒業後の場面で、要約を求められた者は沈黙するか、依頼をそのまま返す。返された依頼は、たいてい二度と戻らない。

三、「未決採点」。評価を下さず、合格も不合格も宣告しない運用を指す。生徒は永遠の候補者となり、教室に残ることを身分とする。採点しない者だけが教える側に上がるため、教える者と教えられる者の区別が消える。壊れるのは課程の外にある問いに対してで、外の世界は期限を区切って返事を求める。期限内に畳めない者は、分岐したまま置いていかれる。
