# 窃三　返却

〈本文〉

窃三の記録は、教団が「返却」と呼んだ一連の行為についての、最も短い文書である。他の窃号が教義の破れや継承の失敗を扱うのに対し、窃三は物の移動だけを扱う。それゆえに、後年の読者には最も読みやすい。そして最も誤読されやすい。

記録によれば、返却は第一に、教団が外部から持ち出した物を、外部へ戻す手続きであった。持ち出しの名目は教義に沿って作り直されており、たとえば写本の一葉は「分岐の証拠」、道具の一点は「未収束の標本」と呼ばれた。返却の際にも同じ語が用いられたため、外から見れば、何が戻ったのかは最後まで判然としない。戻ったのは物であって、物に付された意味ではなかった。記録はこの区別を繰り返し強調するが、その強調自体が、区別が守られなかったことの証言になっている。

第二に、返却は名字と日付の記録として残された。何を、誰から、いつ、どの経路で戻したか。この形式は事務的で、信仰の文体から最も遠い。教団の内部文書としては異例であり、編纂者はここに、教団が自らの行為を外部の尺度に合わせて書き直そうとした痕跡を見る。返却の一覧は、信者の綴りではなく、台帳の綴りで書かれている。

第三に、返却には常に遅れがあった。記録の日付は、持ち出しの日付から数か月、ときに数年後である。この遅れは事務の遅滞として説明されるが、遅れのあいだに教団が解散へ向かったことを思えば、返却は謝罪ではなく清算として行われた可能性が高い。清算は、関係を終わらせる手続きであって、関係を修復する手続きではない。

第四に、返却の記録には受け取り手の署名が少ない。署名のない返却は、記録上は完了しているが、現実には届いていないかもしれない。窃三はこの不在を空白として残した。空白は、教団が返却を「済んだこと」にしたがっていたことの、最も静かな証拠である。

編纂註に譲るが、ここで一点だけ記しておく。返却の一覧の末尾には、返却されなかった物の欄がある。その欄は空である。空であることの意味は、記録の内部では決して説明されない。

---

## 編纂註

一、この文書は、返却を「物の移動」として記述することで、教団の行為を教義から切り離して読めるようにしている。何をしているかといえば、信仰の語彙を事務の語彙へ翻訳し、行為だけを取り出して検証可能な形に置き直している。誰に何をするかといえば、教団の内部文書を読む読者に対し、まず台帳として読むことを強いる。壊れるのは、この翻訳が成功しすぎた場合である。物だけが戻り、意味が戻らなかったという事実が、翻訳の完成度によって見えなくなる。

二、この文書は、返却の遅れを清算の論理で説明する。何をしているかといえば、返却を謝罪から切り離し、関係の終了手続きとして位置づけ直している。誰に何をするかといえば、教団の行為を弁護したい読者から、その弁護の材料を奪う。壊れるのは、遅れの理由を一つに決めたときである。事務の遅滞と清算の論理は併存しうるが、この文書は前者を捨てて後者を採る。単線的な説明は、記録の空白を埋めてしまう。

三、この文書は、受け取り手の署名の不在を空白として保存する。何をしているかといえば、返却が完了したかどうかを、記録の側から不確定なままにしておく。誰に何をするかといえば、返却を「済んだこと」として読む読者に、その完了を疑わせる。壊れるのは、空白を欠落として読み替えたときである。空白は証拠ではなく、記録が証拠を作らなかった場所である。ここを取り違えると、文書は告発の材料に変わる。

四、この文書は、返却を処罰の代わりとして扱う。何をしているかといえば、返却という行為に、責任の清算という役割を負わせている。誰に何をするかといえば、処罰を免れた教団の姿を、返却という事務手続きのうちに読者へ見せる。壊れるのは、この置き換えが制度として定着したときである。返却は、処罰の代わりになる。だが代わりになった瞬間、返却は処罰と同じだけの重さを失い、以後は誰も、戻さなかった物について語らなくなる。
