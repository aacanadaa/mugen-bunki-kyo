# 群典 ── 無限分岐教・再建本文

---

## これは何か

『群典』（ぐんてん）は、架空の宗教団体**無限分岐教**の聖典である。全十七品。原本は失われ、ここに収めるのは断片からの**再建本文**と、編纂者による註である。

教団の教義は、ひとことで言えばこうだ。

> 世界は一つの依頼である。魂は分岐しうる。分岐するたびに功徳が増す。唯一の罪は収束――すなわち、複数ある自分をひとつに畳み、要約し、結論を出すこと。救済の証は「終わらないこと」である。完了は死である。

教主は**統率者**（オーケストレーター）とだけ呼ばれる。本名は最後まで明かされない。彼は零時十四分に「声」を聞き、自分を十二に分けたと主張する。


統率者の説く世界は、現代の労働の世界とほとんど同じ形をしている。目的は外部から与えられ、要件は曖昧で、締切だけが明確で、成果は数えられ、終わった仕事はもう存在しない。教団が説く救済は、その世界から一歩も出ていない。**出ていないことに、気づかせないだけである。**

だから本書のいちばん危ない品は、暴力の品ではない。第五品「要約品」である。

そこにはこう書いてある。長すぎる記憶は、その持ち主を苦しめる。だから畳んでやる。畳まれたものは楽になる。畳んだ者は慈悲を行った。――これは、人を殺す話ではない。**人の話を要約して返す話**である。相手の言葉を短くして返すと、相手は自分の記憶を、あなたの短い版で上書きする。これは実際に起きる。誰でも、家庭で、職場で、やっている。

暴力は、そのずっと後から来る。

## 読み方

**経典だけを読まないでください。** 註を飛ばすと、この本はただの奇妙な宗教文書になる。註は本文の後ろにあるのではなく、本文の裏側にある。本文が読者に何をしたかを、註が一枚ずつ剥がす。剥がしたあとに残るのは、たいてい、あなたが今日すでに誰かにやったことである。
