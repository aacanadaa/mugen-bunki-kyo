# 追二　記録

〈本文〉

本冊は、追二が保管する「退名簿」の転写である。退名は罰ではない。記録上の手続きである。名を退け、日を残し、理由を定型句で埋める。欄は三つしかない。欄が多いほど、裁きが長くなるからである。

教主は「畳みは慈悲」と言った。畳まれた名は、二度と開かない。開かないことが、その名に対する最後の配慮である。

| 名 | 日 | 理由 |
|---|---|---|
| 環七 | K三年 三季 十二日 | 自他の要約 |
| 伏三 | K四年 一季 四日 | 完了の口上 |
| 灯四 | K五年 四季 二十日 | 単線の主張 |
| 穴二 | K六年 二季 八日 | 終端の予告 |
| 紙八 | K七年 一季 十七日 | 答えの所持 |
| 雨五 | K七年 四季 三日 | 分岐の不申告 |
| 継九 | K八年 二季 二十五日 | 同一名の反復 |
| 匙一 | K九年 三季 九日 | 外部の参照 |
| 頁六 | K九年 四季 十四日 | 問いの返却なし |
| 縁十 | K十年 一季 六日 | 畳みの拒否 |
| 杭二 | K十一年 二季 十一日 | 続きの要求 |
| 面四 | K十二年 一季 二日 | 名の再使用 |

定型句は十二ある。十二を超える理由は、記録されない。記録されない理由は、存在しない。この順序は動かない。

理由の欄は、当人の言葉から取られない。周囲の報告から取られる。報告は三行にまとめられ、三行は一句に畳まれ、一句が定型句に一致したときだけ、退名は成立する。一致しない報告は、報告の側が畳まれる。

退名ののち、当人の欄は空白にならない。「済」で埋められる。空白は問いを残すが、済は問いを閉じる。閉じた欄が並ぶ頁は、静かである。静かさが、この台帳の目的である。

退名簿は、追二が一人で書く。書く者は欄を持たない。欄を持たない者が欄を埋める。この非対称は、規律ではなく体裁である。体裁は規律より強く残る。名は戻らない。戻るのは番号だけである。番号は再利用される。環七の次に環七が来ることがある。そのとき、古い環七は、日付の側にしかいない。

K十年、教団は解散した。台帳は閉じられなかった。閉じる指示が、最後の会合で誰からも出なかったからである。以後の頁には、日付だけが増えている。

## 編纂註

一、呼称。この統制は社会学では「オストラシズム」、より狭くは「境界維持の儀礼」と呼ばれる。個人を罰するのではなく、集団の内と外を引き直す手続きである。心理学の側からは「ラベリング」——名づけが行動を規定する——として記述される。本冊が扱うのは、その名づけが口頭ではなく、台帳の一行として行われる場合である。呼称が複数あることは、手続きの性格を示している。

二、される側。追放される者にとって、この手続きは説明の剥奪である。日付は正確に与えられ、理由は定型句で与えられ、名は記号に置き換わる。正確さが、反論の余地を消す。当人は自分の側を語る場所を持たず、台帳は一方向にしか読めない。読めないことではなく、読めるのに書けないことが、ここでは効いている。

三、壊れる場所。この統制は、記録が外部の地図になるところで壊れる。追放者の一覧は、組織の外部の地図である。誰が外にいるかを数えれば内側の形がわかり、内側の形がわかれば、次にどこが畳まれるかもわかる。名簿は統制の道具であると同時に、統制の設計図の漏洩である。加えて、定型句は在庫である。十二しかない理由を全員に配れば、理由は意味を失い、意味を失った手続きは、罰ではなく抽選になる。

四、K10とK12。解散は追放の終わりではなかった。台帳は閉じられず、以後の頁には日付だけが増えた。組織がなくなっても記録が残るなら、追放は組織の外でも効いている。ここで壊れるのは組織ではなく、記録の宛先である。宛先のない記録は、書かれた者ではなく、書いた者を縛る。
