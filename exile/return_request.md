# 追三　申請

〈本文〉

教主の名をもって発される文書に、宛名はない。あるのは欄である。帰還を望む者は、第一欄に己の分岐の数を記す。第二欄に、そのうち収束させた数を記す。第三欄に、収束させなかった数のうち、いまも沈黙している数を記す。三つの数が合わぬ申請は、受け取られない。受け取られないことは、却下ではない。記録に載らないというだけである。

様式は第三号による。表題「帰還申請書」。罫は六行。用紙は教団が配る。自筆に限る。浄書は認めない。訂正は二重線とし、訂正の数が三を超える申請は、書き直しを待つ。書き直しの待機は、順番を持つ。順番は、受付番号による。受付番号を、申請者が決めることはできない。

以下、条件。

一、申請者は、自らを「離れた者」と称さねばならない。「追われた者」という語は、様式に存在しない。
二、申請者は、離反の理由を一つに限る。二つ以上を並べた申請は、理由の選択が未了であるとみなされる。
三、申請者は、帰還の後に用いる名を、申請の時点で記さねばならない。名は、教主の承認を経て効力を生ずる。
四、申請者は、申請の事実を自ら他に語らぬことを誓約する。誓約は、申請書の末尾に、同じ筆で書かれる。
五、申請者は、待機の間に教団の暦に従う。従ったことは、申請者自身が記録する。

条件は、満たされるものではない。満たしたと認められるものである。

却下の理由は、理由欄に印刷されている。選択肢は三つ。甲「要約の痕跡」、乙「時期尚早」、丙「保証の不在」。申請者がそこから一つを選ぶことはできない。記入は審査の側が行う。申請者は、その欄が空であることを、受け取った時点で知る。空欄は、決定が済んでいることを意味する。済んだ決定は、郵便で届く。封は、教団の封をしている。

却下された申請は、破棄されない。番号を与えられ、棚に置かれる。再申請は、同じ番号で行う。番号は、申請者のものではなくなる。

帰還した者は、しばらく、申請書の写しを持つことを許される。許されると書かれている。写しを持つ者が、いつしか写しを読まなくなることを、教団は急がぬ。

---

## 編纂註

一、この手続は、社会学の用語でいえば「強制的再社会化」の書式化された残余であり、心理学的には「服従の合意」を、同意ではなく記入によって成立させる装置である。申請者は、自分が何を求めているかを、欄の数で先に決められてしまう。求めを言葉にする前に、言葉の枠が配られている。される側に残るのは、書いたという記憶と、書かされたという疑いだけである。この種の統制が壊れるのは、記入が巧みになったときである。様式に最適化された申請は、様式を読めなくする。

二、条件は五つで、いずれも内面の証明を求めない。求めないことが、この制度の冷酷さである。内面は測れないから、測れるもの——数、名、筆跡、暦——に置き換える。置き換えられた者は、自分が服従しているのか、服従を演じているのか、区別できなくなる。区別の消失は、制度の側では成功である。される側には、成功の感覚が残らない。壊れるのは、申請者が条件を一字一句守り終えたときである。守られた条件は、服従の証拠にならない。

三、却下の理由が三つに閉じていることは、審査の不在を意味しない。むしろ理由が少ないほど、申請者は自分の位置を読み違える。甲を避けた者は乙に落ち、乙を避けた者は丙に落ちる。避ける行為そのものが、理由を選ばせている。ここで壊れるのは、理由欄が空のまま届いたときである。空欄は決定の完了を示すが、申請者はそれを未記入と読む。読み違えは記録されない。記録されないものが、次の申請の第一欄に現れる。

四、追放は、この教団では事件ではなく分類である。追三は、追放された者のうち、申請の資格を残した第三種を指す。資格は失われるのではなく、棚に残る。それゆえ追放者は、外にいるのに簿冊の内側にいる。この位置の曖昧さが、帰還の願いを永続させる。壊れるのは、棚が満ちたときである。満ちた棚は申請を受理せざるを得ず、受理は、条件の緩和として読まれる。
