# 予五　一覧

本一覧は、教団が「証拠」と呼んだものの目録である。日付は教団の紀年、内容は告知されたままの文言、結果は後から付された一語である。三語の意味と、この一覧が何を隠しているかは註に譲る。

| 日 | 内容 | 結果 |
|---|---|---|
| K1 | 教主の指示は宇宙の唯一の依頼と一致する | 成就 |
| K2 | 東の街区に「畳まれぬ朝」が来る | 分岐 |
| K3 | 床に伏す信者に徴が現れた、と教団は記録した | 成就 |
| K4 | 名を捨てぬ反対者を、教団は「収束した」と記した | 収束 |
| K5 | 第五品の宣布により、担い手は倍になる | 成就 |
| K6 | 大水は集会所を避ける | 分岐 |
| K7 | 教主は解散の年に「畳み」を行うと告げた | 収束 |
| K9 | 試しを受けた者が徴を見た、と教団は主張した | 成就 |
| K10 | 教団は解かれる、ゆえに教えは残る | 分岐 |
| K12 | 分岐した魂は一つの依頼へ戻る | 分岐 |

現在に属する行も、すでに三語のいずれかで書かれている。この一覧に、空白の欄はない。

## 編纂註

一、名。この手口は教団の内側で「三つの語」と呼ばれた。成就は的中、分岐は保留、収束は相手の側の罪である。人が出来事ではなく語彙で判定を下すようになり、まず「失敗」という語が消える。壊れるのは、予言の文面を先に固定してから結果を照合したときである。三語のどれを当てても筋が通ることに気づけば、分類は説明をやめ、ただの事務になる。

二、記録。徴も治癒も、本人の語りではなく書式に移されて残る。日付・人数・立会人の欄に収まり、語りの揺れは落ちる。人は自分の経験を共同体の書式で語り直すうち、書式のほうを記憶する。壊れるのは、同じ事象の別稿を並べたときで、欄ごとに人数も場所も動く。医学的な裏づけは初めから無い。ここに挙げた徴は、教団がそう呼んだというだけである。

三、試し。身体の負荷を信仰の証拠に変える手続きを、教団は「畳み」と呼んだ。耐えた者には資格が、降りた者には沈黙が配られる。壊れるのは、降りた者の記録が最初から残らない点である。証拠の不在が、証拠の代わりを務めてしまう。方法をここに書かないのは、書けば手順になり、手順は反証を招くからである。
