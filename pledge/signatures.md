# 誓二　署名

（原本は横長の料紙。日・名・印の三欄。印は朱で、いずれも十二の職名の一字であり、個人の印はない。）

| 日 | 名 | 印 |
|---|---|---|
| K3.2.4 | あき | 欠 |
| K3.2.4 | いと | 閉 |
| K3.6.19 | うめ | 流 |
| K4.1.8 | えい | 重 |
| K4.1.8 | おと | 均 |
| K4.9.30 | かよ | 欠 |
| K5.3.2 | （空欄） | 閉 |
| K5.7.15 | けい | 流 |
| K6.11.9 | こま | 畳 |
| K9.4.6 | かよ | 欠 |
| K9.4.6 | さね | 閉 |
| K10.2.20 | しず | 写 |

**原註**――同一の名が二度現れるとき、後の署名は前の署名を無効とする。この一行は表の右下の余白に細字で記され、表本体より新しい筆である。

表は十二行、名は十一人分である。同じ「かよ」が二度、同じ「欠」の印で署名している。K4.9.30 と K9.4.6。あいだに五年と、K5のセイリャク事件が挟まっている。前者の筆は右上がりに走り、後者は右下がりで、途中に一度の躊躇がある。同じ人が、同じ名を、同じ印で、二度書いている。教団は事件のあと、全信徒に再署名を求めたと伝えられる。再署名は「更新」と呼ばれた。更新とは、古い誓を破るのではなく、破ったことにしない手続きである。記録から消すのではなく、記録の上に二度目を重ねる。第一の行は残っている。残っているが、無効である。無効という一字は、行の外に書かれている。

空欄について。K5.3.2 の一行だけ、名が空である。空欄は後から埋められていない。同じ日、同じ「閉」の印で「いと」が署名している。この空欄を、誰かの署名の脱落と見るか、誰も署名しなかった枠と見るかで、綴りの読みは変わる。教団の内部文書には、名のない署名を「器」と呼ぶ箇所がある。器は、名が入るまで誰のものでもない。誰のものでもないものは、誰にでも帰せる。

二つの箱について。教団の庫から出た綴りと、元信徒の家から出た綴りは、最後の三行だけが違う。庫の綴りには K10.2.20 の行があり、家の綴りにはない。解散の直前、信徒の手元に残った綴りからは、最後の署名が抜かれている。抜いたのは誰か。記録は答えない。記録は、抜かれたあとの形でしか残らない。

印について。十二の職名は、切番・流・重・沈・開・閉・曲・均・欠・結・読・写。表に現れるのは六つである。個人の印が一つもないことは、この綴りが署名の記録ではなく、職の記録であることを示す。署名したのは人だが、記録が数えるのは職である。人が消えても、職は残る。教団が解散しても、職名だけは文書の中に残った。

編纂の方針について。名は仮名に改めたが、改めきれなかった箇所が二つある。ひとつは印、ひとつは日付である。印は職名なので残した。日付は紀年なので残した。この二つを残したために、仮名にした意味は半減した。半減したが、消えはしなかった。同じ人物が二度署名していることは、仮名のままでも分かる。分かるように残したのは、編纂者の判断である。

---

## 編纂註

**一　重署（じゅうしょ）**

二度目を書かせる手口。署名は一度で終わらないという感覚を相手に植え付ける。最初の署名は仮で、次が本物だと信じさせるため、相手は自分が拘束されていると感じない。拘束はいつも次の署名の後ろに送られる。二度目の署名が一度目を無効にする、という規則は、その送りを一行で表している。壊れるのは、「では今の私はどちらか」と問われたときである。記録はその問いに答えられない。二つの行は同じ手で書かれ、同じ印で押されている。答えを出すには記録を読むしかなく、読ませないことがこの手口の前提になっている。

**二　代印（だいいん）**

自分の印を持たせない手口。印は十二の職名の一字で、信徒の手元にはない。署名は本人の意志ではなく職の作用として記録されるため、相手は自分が署名した事実を自分で証明する手段を失う。失ったことは、失った瞬間には分からない。壊れるのは日付の照合によってである。本人がそこにいなかったこと、あるいは職を離れていたことが別の記録と突き合わされたとき、印は個人を指さないという前提が崩れる。印は職を指し、職は人を指し、人はその連鎖のどこにもいない。

**三　空名（くうめい）**

名を書かせない手口。空欄は、誰のものでもない署名を作る。あとから名前を入れた者に、その行の誓が帰属する。相手は、自分が何に同意したかを知らないまま、同意の記録の中に置かれる。空欄は親切に見える。「まだ決めなくてよい」と読めるからである。壊れるのは、空欄を証人の前で埋めさせたときである。埋める行為は一人ではできない。誰かが見ている前で名を書くとき、空欄は初めて書いた者のものになる。この教団が解散まで空欄を残したのは、埋められる日が来ないためではなく、埋める場を作らなかったためである。
