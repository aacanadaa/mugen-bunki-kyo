# 誤四　訂正の誤り

〈本文〉

初版の奥付には、訂正を書き入れるための余白が三行ぶん取ってあった。装丁の都合ではない。教団の印刷所「支流舎」が、誤植を「分岐の痕跡」として保存する方針をK5に定めていたからである。誤りは消さず、細い罫で囲み、訂正者の名と日付を添える。読者は頁ごとに、罫の内と外のどちらが本文かを決めねばならない。この作法は、本を読むという行為を、正しい一つの読みへ向かう旅ではなく、複数の読みが併存する状態の管理へと変えた。

K7、第三刷の校正で、奉教者が「唯一の罪は収束」を「唯一の罪は収斂」と組み違えた。意味はほとんど同じである。だが訂正の途中で、別の校正者が前頁の「分岐」を「分技」と見つけた。二人はそれぞれ別の頁で、別の誤りを直した。訂正記録は二枚に分かれ、どちらも自分を「正しい版」と書いた。ここで初めて、誤りは語ではなく、手続きの問題になった。

K8の通達は、両方を残せと命じた。訂正とは本文を一つに戻す行為ではなく、誤りにもう一つの経路を与える行為である、と。二枚の記録は並べて綴じられ、第三刷には同じ語が三通りに現れた。整合性を持ったのは註だけである。読み手は註から先に読み、そこで初めて、本文が複数あることを知る。本文は薄くなり、註が厚くなった。

K10の解散後、この版は古書として流れた。買い取った者が驚いたのは、余白の訂正の多さである。本文より註の多い頁があり、註のほうが先に読まれた。誰かが鉛筆で「直しすぎだ」と書き、別の誰かがその線を消し、消した跡に「消すな」と書き足した。貼り足された紙片が三枚重なり、その下の本文はもう読めない。訂正は、本を閉じても止まらなかった。むしろ閉じられてから増えた。

現在、この版を所蔵する記録は三つある。いずれも「第三刷」と称し、頁数が一致しない。一致しないから偽物だとする論と、一致しないことこそ正しいとする論があり、私は前者を取る。だがその判断も、この本の余白に残った誰かの訂正の一つにすぎない。私はそれを消さずに書いておく。消せば、また一つ、訂正の誤りが増えるだけだから。

## 編纂註

一、この記録がしているのは、教義の解説ではなく、訂正の履歴を本文の位置に繰り上げることである。誤植、罫、貼り紙、鉛筆の消し跡を順に並べ、読み手に「どれが本文か」を決めさせる。ところが並べる行為そのものが、分岐した記録を一つの物語に収めるという、教義の禁じた収束にあたる。註に書いておく。訂正の誤りは、本文より長く残る。

二、この記録が読者に与えるのは、正しい本文ではなく、正しい本文に到達する手続きである。奉教者には、探していた一つの版が存在しないことを告げ、反教者には、矛盾が矛盾のまま保存されていることを告げる。どちらにも手に入るのは本ではなく、本を扱う作法だけである。作法は譲渡できるが、譲渡のたびに少しずつ変わる。

三、壊れるのは、所蔵記録の頁数が一致しない地点である。三つの記録は同じ版を名乗りながら、同じ本を指していない。ここで編者は「第三刷」という名を選ぶが、その選択を裏づける現物はない。名が先にあり、本が後から合わせられる。註はこの順序を指摘できるが、訂正することはできない。

四、壊れるのはもう一つ、余白の再現の地点である。鉛筆の線、消し跡、貼り紙の下の本文は、写真でも複写でも同じようには残らない。記録はそのたびに、読める部分だけを読み、読めない部分を「欠」と書く。欠は誤りではないが、誤りと同じ場所に溜まる。次にこの本を開く者は、欠を本文と取り違えるかもしれない。
