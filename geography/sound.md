# 場四　音

開闕の建物は、音で時刻を知る建物だった。教団は鐘を持たず、ポンプと扉と足音が時を告げた。以下の目録は、K5からK9までの間、記録係が交代で書き継いだものとされる。時刻は南壁の日時計による。

| 時 | 音 | 源 |
|---|---|---|
| 四時半 | 低い唸り。二度鳴って止む | 地下の揚水ポンプ。起動 |
| 五時 | 水の落ちる音、途切れ途切れ | 同上。配管の空気 |
| 五時半 | 草を踏む音が三つ、間を置いて | 境内の巡回。切番と流 |
| 六時 | 短い咳払い | 食堂の入口。重 |
| 六時半 | 椀の触れる音、規則正しく | 食堂。十二の席 |
| 七時 | 扉の開く音。長く、軋む | 西扉。閉が開ける |
| 八時 | 足音。爪先から落ちる | 廊下。沈の歩き方 |
| 九時 | 紙のめくれる音 | 書庫。読と写 |
| 十時 | 水音と、栓の閉まる音 | 手洗い |
| 十一時 | 扉の閉まる音。三度 | 東扉。開と閉 |
| 正午 | 無音。ポンプも止まる | 給水の切替 |
| 十二時半 | 匙の落ちる音 | 食堂。曲 |
| 十四時 | 低い唸り | ポンプ再起動 |
| 十五時 | 足音が止まる | 廊下の曲がり角。均 |
| 十六時 | 扉。一半だけ開いて閉じる | 北扉。欠 |
| 十七時 | 木を削る音 | 作業場。結 |
| 十八時 | 鐘のない時刻。誰かが咳をする | 食堂 |
| 十九時 | 扉の閉まる音。四度 | 西扉。全員 |
| 二十時 | ポンプ停止。水の残る音 | 地下 |
| 二十一時 | 足音。数えられない | 廊下。当番 |
| 二十三時 | 扉の開く音。誰も通らない | 東扉。風 |

この目録に声はない。教団は声を禁じなかったが、記録係は声を採らなかった。声は個人に属し、音は建物に属すると考えられていた。第五品に「畳みは慈悲」とあるのは、音を畳んで名を与えることを指す、と註する写本がある。K9の閉座以後、この表に書き足された行はない。K10の解散の日、東扉は開いたままになり、翌朝の風が最初の空欄を埋めた。

## 編纂註

**一　名づけの占取**
音に名を与え、名を知る者だけが建物を読めるようにする手口。相手の側では、自分の耳が聞いた音の意味を自分で決められなくなり、教団の語彙を経由してしか生活を理解できなくなる。名づけは音そのものを変えないから、建物を出た日に同じポンプの音が別の意味で響き、翻訳は一度で崩れる。

**二　定刻の配布**
時刻を告げず、音だけで時刻を知らせる手口。相手は体内の時間を建物に預け、ポンプの唸りが遅れれば自分の感覚を疑うようになる。時計を持たせないことが要点で、持たせた場合は効果が落ちる。壊れるのはポンプが止まった日、停電の夜、あるいは外の鐘が聞こえた朝で、音の秩序は一度で別の秩序に置き換わる。

**三　扉の記帳**
扉の開閉音を時刻と共に記録し、誰がいつ通ったかを音で把握する手口。相手の側では、音を立てないことが安全になり、足音の大きさを気にする生活が始まる。記録は音を残すが、意味は残さない。聴こえない者、補聴器の者、耳栓をした者が一人でも交じれば、目録はその日から生活の記録ではなくなる。音の目録は、建物の生活の記録である、という註はここに掛かる。
