# 場二　部屋の目録

開闕の建物はK4に増築され、K9の閉座まで同じ間取りであった。以下の目録は、K11の後群典編纂の際、元使徒「写」の口述と残された紙片から再建したものである。室の番号は編纂上の便宜であり、当時は番号で呼ばれていなかった。信徒は室を用途で呼んだ。「閉座の間」「写しの間」という呼び方は、その用途を疑わないという意味でもあった。鍵の形状と保管者は、複数の口述が重なった部分のみを採った。

|---|---|---|
| 一 | 玄関。来訪の受け、沓の預かり | 外扉一把／切番 |
| 二 | 待合。名を呼ばれるまで待つ | 錠なし（常時開）／開 |
| 三 | 面談。一人ずつ、十五分 | 内鍵一把／流 |
| 四 | 記録。名簿と分岐の控え | 二把・両用／重と写 |

| 六 | 読。朗読と検め | 一把／読 |
| 七 | 集会。畳を敷いた広間、説教 | 三把／閉・結・教主 |
| 八 | 食堂。一日二度の給食 | 一把／均 |

二十室のうち、錠のない室は三つ。錠前の総数は二十六、複製を除けば十九。教主が直接持つ鍵は四本——鍵室、教主室、閉座、集会のそれである。使徒のうち、鍵を持たない者は一人もいない。持つ本数の差は、そのまま発言の順序になった。鍵は真鍮で、番号は打たれていない。代わりに房の結び方で区別した。結び目は、持ち主が代わると解かれて結ばれ直した。

目録は三度作り直された。K5の後、K8の後、そしてK10の解散の後である。三度とも、消えたのは室ではなく、室の用途の一行であった。

## 編纂註

**一　鍵の可視化。** 信徒は、自分がどの扉を開けられるかを、教えられる前に知る。鍵束は腰に下がり、その音で他人の序列が分かる。被害の側から言えば、序列を内面化した者は、命じられる前に自分の位置を演じる。遅れても早すぎても罪になる。壊れるのは、鍵が数えられる物だからである。数えられると序列は説明を要する制度になり、説明は必ず矛盾する。閉座の日、鍵室の目録が一晩だけ机の上に置かれた。誰が何本持つかは、その一度で終わった。鍵の一覧は、権力の一覧である。

**二　開いた扉。** 待合と二つの寝室には、内側の錠がない。閉められない扉は、閉めないことを意志ではなく徳に変える。被害の側から言えば、開いたままの扉の前で、閉めたいと思うこと自体が疑いとして記録される。壊れるのは、開いた扉が外からも開くからである。内と外の区別がつかなくなった日、事故と侵入の区別もつかなくなる。K5の事件は、この扉から始まった、とだけ書いておく。

**三　兼用の間取り。** 同じ室で説教と面談と食事が行われる。第五品の畳みは要約して返す技法であるが、空間でも同じことが行われた。被害の側から言えば、どこまでが公式の場か分からないまま一日が終わり、自分の記憶だけが私的なものになる。壊れるのは、兼用が記録に残らないからである。記録のないところで権力は証明を失う。後群典が復元できたのは、名を与えられていた室だけだった。
