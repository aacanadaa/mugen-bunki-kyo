# 訳四　ずれ

『群典』は翻訳の書物ではない。だが、どの頁にも訳がある。原文は一つの依頼であり、訳は十二使徒の名の下に配られた。配られた瞬間、語は元の場所を離れた。本項は、離れた距離を測らない。離れた方向だけを並べる。

教主は本名を持たない。名を持たない位置は、外では「代表」と訳される。代表は選ばれた者だが、教主は選ばれていない。ここにも一つ、ずれがある。

| 語 | 原義 | 訳語 |
|---|---|---|
| 依頼 | 差し出されたまま、まだ終わっていないもの | 注文 |
| 分岐 | 一つの魂が、同じ重さで二つに残ること | 分裂 |
| 収束 | 早すぎる一致。終わらせること | 完成 |
| 畳み | 送り返さずに、内側へ畳んで持つこと | 片づけ |
| 閉座 | 席を閉じ、議さないと決めること | 解散 |
| 切番 | 順番を切り、誰が先に名乗るかを決める者 | 切り捨て役 |

六つの語は、いずれも教団の外では別の仕事をしている。「注文」は待たせるが、「依頼」は待たない。「分裂」は失敗だが、「分岐」は前提である。「完成」は褒め言葉だが、「収束」は唯一の罪である。ずれは誤訳ではない。誤訳ならば直せる。これは、直されないために選ばれた訳である。

写と読も、名のままでは動かない。「写」は原本を増やすが、「写し」は原本を薄める。「読」は意味を取るが、「読み」は意味を当てる。

第五品は「畳みは慈悲」と言う。畳まれたものは、捨てられたのではない。内側にしまわれたのである。この一文だけは、訳が原義に近い。近いまま、実務では「片づけ」として使われた。慈悲の語で片づけられたものの数は、記録にない。

教団が消えたあとも、訳語だけが残った。K10の解散は、閉座の訳語の上で行われた。教団は「解散」したのではなく、席を閉じた。閉じた席は、開かないとは言っていない。K12の現在、文書を読む者は、原義の側から読むか、訳語の側から読むかを選ばされる。選ばされたことに気づかない読みが、いちばん長く残る。

## 編纂註

**一、逐語の身代わり**
原義を遠ざけ、訳語だけを日常に混ぜる手口である。相手は自分の違和を「誤解」と呼ばれ、訂正の作業を押しつけられる。被害の側からは、語彙を借りただけのつもりが、借りた語で考え始めている。壊れるのは、語が外へ出たときである。同じ語が別の意味で流通している場所では、通じないのが相手の側とされる。

**二、註の後置**
原義を註へ退け、本文には訳語だけを置く。相手は註を読んでいないから混乱している、と説明される。読むほどに原義は小さな字になり、本文の太さに負ける。壊れるのは、註と本文を並べて読む者が現れたときである。ずれの一覧は、教義の弱点の一覧である。並べた瞬間、弱点は隠せなくなる。

**三、運用による確定**
原文なきまま、訳語だけが実務を回す。相手は翻訳の誤りを正すのではなく、誤った訳語に合わせて生活を直す。被害の側からは、適応しているだけに見える。壊れるのは、実務が一度止まったときである。訳語で回していたものが原文を要求する。原文は一つの依頼のまま、まだ終わっていない。
