# 記四　噂

〈本文〉

一、井戸のこと。

町の井戸は朝の四時から開く。教団の家の者は、いつも一番に来て、二桶だけ汲んで帰る。それがいつの頃からか、三桶になった。誰が数えたのかは誰も覚えていないが、三桶だという話だけが残った。井戸端で交わされる挨拶が、家ごとに違うという。ある家は「おはよう」と言い、ある家は「分かれ」と言い、ある家は何も言わずに会釈だけをする。教団の内側では、その三つは同じ意味だと説明されているらしい。だが井戸端では、同じ意味の言葉が三つもあるなら、どれか一つは嘘だということになる。噂はそこで止まった。止まったが、消えなかった。

二、米屋の帳面のこと。

米屋の主人は、教団に米を売っている。売り方は普通で、値も普通で、支払いも遅れない。ただ、帳面が三冊ある。同じ日の同じ量が、三冊に三様に書いてある。主人は、どれが正しいかを決めないまま、三冊とも取ってある。店の者が「一冊にすればいい」と言うと、主人は「一冊にしたら、どれを捨てるのだ」と答える。この答えが気に入られて、教団の者が時々、帳面を見に来るという。見に来るだけで、書き換えない。書き換えないので、主人はますます決められない。町の者は、あの店の米は三つの味がする、と言う。もちろん、そんなことはない。だが、そう言われてみれば、という顔をする者が、何人もいる。

三、垣根のこと。

隣り合う二軒の間に、低い垣根がある。片側の家は教団の者で、もう片側はそうではない。垣根は年に二度、刈られる。一度は東から、一度は西から。刈り方が違うので、夏の終わりには、垣根はどちらの側から見ても少しずつ傾いて見える。教団の者は「垣根は分かれているのではない、二つの手が同じ垣根に触れているのだ」と言う。隣の家の者は「では、どちらの手が先に触れたのか」と問う。この問いに、教団の者は答えない。答えないので、町では、あの垣根は教団が隣の土地を少しずつ削っているのだ、という話になった。削っている証拠はない。だが、垣根が傾いていることは、誰の目にも明らかだった。

つづいて、教団の内側の噂が一つ。

これは町の者が語るものではない。教団の台所で火の番をする者が、夜中に教主の部屋の灯りが三度ともったのを見た、と言った。一度目は短く、二度目は長く、三度目は明け方まで消えなかった。何をしていたのかは誰も知らない。だが、側近の一人が、教主の言葉を三通りに書き分けている、という噂がある。同じ日の同じ言葉が、三つの紙に、少しずつ違って残っている。側近は「教主は一度も同じことを言わない」と説明する。説明としては通る。通るが、台所では、それは説明ではなく、記録の作り方だ、と言われている。

町は、教団のことを疑っている。教団は、教主のことを疑っている。教主は、自分のことを疑っている。三つの疑いが、同じ井戸の周りで、同じ水を汲んでいる。

## 編纂註

**註一（この記録がしていること）**　本条は、井戸・帳面・垣根という三つの生活の場に流れた噂を、検証せずに並べたものである。教団の教義にも、教主の言葉そのものにも触れていない。触れないことによって、この記録は、噂が教義をどう削るかではなく、噂が生活のどこに棲みつくかを示そうとしている。三つの噂に共通する「三」という数は、記録者の作為である可能性が高い。原本には数による整理はなく、こちらの編纂時に生じたものと思われる。

**註二（誰に何をするか）**　この記録が読者に与えるのは、教団の内実ではなく、教団を数えるための道具である。三桶、三冊、三つの紙。読者はこれらを覚えるだけで、教団について何かを知った気になる。誰に何をするかといえば、読者に対して、判断を保留したまま参加したという満足を与える。噂は、関心の最も安い形である。関心を払わずに、関心があるふりをするための形式であり、この記録はその形式を丁寧に整えて保存している。

**註三（どこで壊れるか）**　壊れるのは、数が意味に変わるところである。三桶は、二桶より多いというだけのことで、そこに教団の意図はない。三冊の帳面は、主人が決められないという一事を示すにすぎない。だが記録が三つを並べた瞬間、三つは一つの体系に見え始める。教主の灯りが三度ともったという台所の話も、同じ壊れ方をする。三度目が明け方まで消えなかったという事実だけが残り、なぜ三度だったのかという問いは、誰も立てない。問いを立てないことが、ここでは証拠の代わりになる。

**註四（この記録の弱さ）**　台所の噂については、語り手の名も、灯りを見たという時刻も、記録に残っていない。側近が言葉を三通りに書き分けているという話も、紙そのものは残っていない。この二件は、町の三件と同じ欄に置かれているが、同じ強さの記録ではない。編纂時にそれらを区別しなかったのは、区別すると、この記録が言おうとしている「三つの疑い」が崩れるからである。崩さないために、根拠の薄いものを、薄いまま並べた。
