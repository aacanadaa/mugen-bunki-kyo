# 記二　年表

街の年表は、市参事会の書記が毎年一月に、前の年の分を書き足してきた。河の氾濫、橋の架け替え、市場の移転、条例の改正。人の死は数で書かれ、人の名は書かれない。以下の表も、その写しである。原本は市の倉にあり、水に濡れた年が二度ある。濡れた箇所は書き直され、書き直した者の名も残っていない。

| 市歴 | 事 |
|---|---|
| 三八八 | 市の境を測り直す。石を十二置く。 |
| 三九一 | 春、東の河が氾濫し、下流の二町が水に浸かる。 |
| 三九二 | 仮橋を架ける。材は上流の杉。 |
| 三九四 | 市場を駅の北へ移す。反対の署名、千二百。 |
| 三九五 | 条例を改める。夜間の荷揚げを禁ずる。 |
| 三九七 | 東の丘に、名のない男が立つ。のちに教主と呼ばれる者。開闕K1。 |
| 三九九 | 市の学校を建てる。教室は四つ。 |
| 四〇〇 | 北の倉が焼ける。人の死はなし。 |
| 四〇二 | 橋を架け替える。二度目。 |
| 四〇三 | 上水道の管を東へ延ばす。 |
| 四〇四 | 下流の二町、市への合併を願い出る。 |
| 四〇五 | 丘の集まり、座を閉じる。開闕K9。 |
| 四〇六 | 同じ集まり、解散を告げる。開闕K10。 |
| 四〇八 | 仮橋の跡に、石の標が立つ。 |

教団の項目は三つしかない。開闕K1、K9、K10。創立、閉座、解散。この三行は、橋の架け替えや市場の移転と同じ欄に、同じ字の大きさで置かれている。街が教団を疑わなかったのではない。疑うための語を、まだ持っていなかったのである。教主の名はどこにもない。名がなかったからではなく、書記が聞かなかったからである。街は教団を天候のように扱った。降るか降らないかを記録し、なぜ降るかは記録しない。降られた側の事情も、欄には入らない。

閉座と解散は、街の語彙では同じくらいの重さを持つ。だが教団の内側では、この二つは別の出来事である。座を閉じるとは、魂の分岐を止めること。解散とは、分岐を続けたまま、名を降りること。会って話す者、金を集める者、名を名乗る者は、それぞれ別の日に別のことをした。表はこの差を、一文字も示していない。三行に畳まれた分だけ、街の側の記憶もまた畳まれた。

最後の行は四〇八年である。教団の内部紀年では、この年がK12にあたる。表にK12はない。書記がまだ書いていないのか、書かないことにしたのかは、この記録からは分からない。分からないまま、行だけが増えていく。年表は完成しない。完成しないことが、この表の唯一の誠実さである。

---

## 編纂註

一、この記録がしているのは、出来事を欄に均すことである。橋の架け替えと教団の創立が、同じ高さの行に並ぶ。読み手は行の数を数え、欄の埋まり具合で年を測る。均された結果、教団は街の出来事の一つになる。だが行の高さは意味の重さではない。ここで壊れる。

二、「街の年表は、教団を一行で処理する」——正確には三行である。三行のうち二行は教団の内部語彙で書かれ、街の語彙に翻訳されていない。読む者は、閉座を「中止」と読み、解散を「終了」と読む。意味はそこでずれ、ずれたことは註にしか残らない。

三、年号の照合は一点でしかできない。市歴四〇六年と開闕K10がそれである。教団側の記録は解散を翌年とし、街は同年とする。どちらが正しいかは決められない。決められないまま、二つの年表は別々に読まれ続ける。照合を求める者ほど、この一点に集まる。

四、表には空いた年がある。三九三、三九六、四〇一、四〇七。書記は書かなかった。読み手はこれを平穏と読む。だが空白は、何もなかったことの証拠ではない。書く者がいなかったことの痕跡である。空白を埋めようとする手が、次に何をするかは、この記録の外にある。
