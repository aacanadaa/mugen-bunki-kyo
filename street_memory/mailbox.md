# 記六　郵便受け

〈本文〉

K九の閉座から一年、解散を告げたのちの二百三十日間に、街の郵便受けへ何が届いたかの記録である。差出人の記されたものは少ない。宛先だけが正確で、中身の薄いものが多い。それがこの時期の特徴であった。

北二番路の仕立屋の家には、四月のはじめ、教団名の入った封筒が二通届いた。一通は解散の通知、もう一通は同じ文面の再送であった。仕立屋は二通を重ねて台所の戸棚に置き、秋まで開けなかった。開けたのは、封筒の角が湿気で膨らんだ日である。中身は通知のほかに、白紙が一枚多かった。

同じ路の八号戸には、宛名のない葉書が届いた。表には「あなたの家は正しい」とだけ書かれ、裏は白かった。八号戸の住人は、それを誰にも見せずに箪笥の裏へ入れた。似た葉書は、この路だけで十一軒に届いている。文言は三種類あり、いずれも家を肯定する文であった。肯定される理由は、どの葉書にも書かれていなかった。

東の共同井戸のそばの小家には、五月、差出人不明の小包が届いた。中には木の栓の瓶が一つ、空で入っていた。瓶の腹には、教団の印が焼き付けられていた。住人は瓶を井戸の縁に置き、三日後に割って捨てた。割れた瓶は、その後の記録には出てこない。

教主の家には、K十の秋にも一通届いている。差出人は教団の名で、宛名は教主の本名であった。本名のない者に本名で宛てた郵便は、受け取りの記録がなく、返送もされていない。教主はこの一通について、側近にも街にも語っていない。語らなかったことだけが、側近の手帳に残っている。

教団の側近の一人は、自分の家の郵便受けに、自分が書いた書簡の写しを受け取った。差出人は自分、宛先も自分。消印は教団の作業所のものであった。彼はそれを教主に見せ、教主は「私のところにも来た」と答えた。教主の家に届いたのは、閉座の日に読まれるはずだった式文の草案で、第七節だけが切り取られていた。切り口は定規で切ったようにまっすぐで、切り取られた紙は同封されていなかった。教主はその晩、草案の残りを読み返し、第七節に何を書いたかを思い出せないと側近に告げた。側近は、教主が書いたのは第七節ではなく第八節だった、と訂正しなかった。六月にも同じ写しが届き、二通目には側近自身の筆跡で「受領」とあった。彼は書いた覚えがないといった。

街の者は、教団と関わりのない郵便まで疑うようになった。町内の回覧は二度刷られ、一度目は配られ、二度目は回収された。回収の理由は今も分からない。配られた回覧の余白に、誰かが「これは本当か」と鉛筆で書いていた。同じ筆跡が、三つの家の回覧にあった。筆跡の主は名乗らず、回覧は次の月から、各戸の郵便受けではなく、井戸のそばの板に留められることになった。板に留めた紙は、雨の日に一枚だけ流された。

K十二の春、教団の事務所の郵便受けに、切手の貼られていない封筒が一通だけ残っていた。中には何も入っておらず、封もされていなかった。事務所を最後に閉めた者は、それを捨てずに机の抽選に入れた、とだけ書き残している。「抽選」は「抽斗」の誤記である。誤記は訂正されないまま、記録に残った。

---

## 編纂註

**一**　この記は、教団の解体を事件としてではなく配達の一覧として書き直している。誰が何を告げたかを消し、どの家の郵便受けに何が入ったかだけを残す。これによって、教主の自疑も側近の疑いも街の疑いも、同じ高さの出来事に均される。読み手は、責任の所在を探す代わりに、届いた物の重さを量ることを求められる。記録が均すのは事実ではなく、事実の格である。

**二**　宛先の選び方に、この記の作為がある。仕立屋、八号戸、井戸端の小家、教主、側近、事務所。私的な家から教団の内部へ、最後に空の封筒へと戻る順序は、疑いが外から内へ浸み、また外へ出る道筋をなぞる。郵便受けは、家の最も私的な部分である。そこに何が入ったかは、その家が誰に宛てられたと感じたかを示す。差出人が消えているぶん、宛先だけが告発のように残る。

**三**　この記は、読み手に一つの操作をさせる。空の瓶、白紙、切り取られた第七節、封のされていない封筒。いずれも中身がなく、それゆえに読み手が中身を補ってしまう。補われた中身は、記録の外にある。編纂者はそれを消さずに残した。疑いを記述するとは、疑いの対象を書かずに、対象を書いた者の手つきを書くことである、という原則がここにある。

**四**　壊れるのは、宛先と住人の対応が崩れた時である。八号戸の葉書は十一軒に届いたが、そのうち何軒が「正しい」と信じたかは書かれない。回覧の筆跡も、瓶の行方も、第七節の内容も、記録の途中で切れる。切れ目は不注意ではなく、この記が扱える限界である。編纂は、届いた物の一覧で止まる。届いた者の内側は、この記の外にある。
