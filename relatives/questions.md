# 親三　質問

（家族に渡した手引きの裏面。問の並びは原文のまま）

| 問 | 答 |
|---|---|
| これは宗教ですか。 | 届のうえでは任意団体である。教団はこの問いに答えず、「あなたにとって何か」と問い返す。この往復そのものが答えの代わりになっていて、尋ねた側は、自分が何を問うていたのかを忘れる。 |
| 入ると家族に会えなくなりますか。 | 禁じてはいない。ただ、会う日は分岐の前後に寄せるようになり、こちらの暦で指定される。会えないのではない。日を選べない状態になる、という違いである。 |
| なぜ帰ってこないのですか。 | 帰らないのではない。帰る理由を先に数えるようになる。教団の言い方では「戻る枝をまだ確認していない」となる。枝は増えるが、確認は終わらない。 |
| お金はどこへ行くのですか。 | 会費、印刷、会場。領収は残る。残らないのは、その徴収の理由を説明した記録のほうである。帳簿は閉じているのではなく、開いても読めないように書かれている。 |
| 洗脳されているのではありませんか。 | 教団はこの語を嫌わない。否定せず、「その語を使う人とは同じ問いを共有している」と返す。家族が投げた語が、教団の語に翻訳されて返ってくる。 |
| あなたは変わった。 | 変わったのは、あなたの前で使う語のほうである。教団はこれを成長と呼び、家族は喪失と呼ぶ。同じ出来事に二つの名があり、名づけた側が勝つ。 |
| いつ帰ってくるのですか。 | 最大の時期が終わったら、と答える。その時期は毎年延びる。延びているのではなく、終わりを数えない数え方を採用している、と手引きは説明する。 |
| 教祖はどんな人ですか。 | 本名がない、とだけ答える。名を問わないのは謙虚に見えるが、名を負わない者には責任の宛先がないということでもある。宛先のない郵便が、いまも教団に届いている。 |
| 会いに行ってもいいですか。 | 構わない、と手引きは書く。ただし来る日は教団が指定し、滞在は短く区切られる。会えないのではなく、会ったあとに何を話したかを、家族の側が思い出せなくなる。 |
| 家族も入れますか。 | 勧めない、とだけ書く。理由は書かれていない。書かないことで、この問いは家庭の中で何度でも蒸し返される。蒸し返されるたびに、教団の語が少しずつ家に残る。 |
| 手引きは誰が書いたのですか。 | 著者名はない。K10の解散時に、所持品目録の私物欄から同じ版が三冊出てきた。うち一冊には、宛先のない封筒が挟まっていた。 |
| 私たちは何をすればいいですか。 | 何もしないでください、と手引きは書く。この一文が最も親切に見え、最も家族を無力にする。無力な家族は、問いを立てることをやめる。 |
| これはカルトですか。 | この問いには答えの欄がない。欄がないこと自体が、編纂上もっとも雄弁な回答である。手引きは、最後の一行だけ白紙のまま渡される。 |

---

## 編纂註

一、この文書がしているのは、質問に答えることではない。家族が口を開く前に、尋ねられるはずの問いを先に並べ、答えの語彙を教団の側で用意しておくことである。問いを「想定」した時点で、その問いはもう教団の管理下にある。効いているのは答えの内容ではなく、問いの順序である。手引きの裏面に小さく刷られ、渡す側は読まれないことを初めから見込んでいる。

二、宛先は家族である。ただし読むのは、残った者ではなく、残された者であることが多い。教団は家族を説得しようとしない。家族が使う語を教団の語に置き換え、家庭内で交わされる言葉の通貨をすり替える。K10の解散時に作られた所持品目録では、この手引きは配布物ではなく私物として記帳されている。私物であれば、回収の対象にならない。

三、壊れるのは、家族が実際に口を開くところである。想定質問は、教団の最も正直な不安である。本物の問いはここに並ぶより短く、具体的で、しばしば質問の形をとらない。答えの欄は、問いが的外れだったときにだけ、空白として残る。宛先のなくなった郵便と同じで、届かないことが宛先の不在を証明してしまう。

四、教団の読書は註の連なりで、原典より註のほうが厚い。註は原典を守るためではなく、原典を開かせないために書かれる。最大の時期とは、参加者が最も多かった時期ではなく、質問が最も少なかった時期を指す。K12の現在、教団はその時期をまだ終えていないと記している。終えないことにしておけば、帰る日を約束しなくて済む。終えないための問答が、この一枚である。
