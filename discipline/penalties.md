# 規三　罰

本規は、教団が「罰」と呼ぶものの全部を、重い順に並べたものである。列挙されるのは行為ではなく、記録の位置である。手段は本規の対象外とされ、本規のどこにも書かれない。書かれるのは、どの欄に、どの語で、何が残るかだけである。

罰は三つの欄に現れる。台帳、名簿、呼称である。台帳は行を増やし、名簿は順を変え、呼称は時制を変える。この三つ以外に、本規が扱うものはない。段は飛ばせず、戻れない。戻る欄は設けられていない。

| 段 | 罰 |
|---|---|
| 一　記 | 台帳の摘要欄に一行が加わる。呼称は変わらず、当人への告知もない。罰は記録によって事後に知られ、知った時にはもう記入済みである。以後、その行は訂正されない限り、当人の現在より長く残る。 |
| 二　順 | 名簿の順序が末尾に移される。読み上げの割当から外れ、以後その名は他人の口を経てのみ響く。声はまだどこにも禁じられていない。禁じられていないことが、この段の重さである。 |
| 三　単 | 名が単独で記され、他の名と並べられなくなる。返答は書面に限られ、その書面は要約を禁じられる。長さの指定はない。指定がないため、書き手は毎回、自分の全部を測り直すことになる。 |
| 四　反 | 過去の言葉が引用され、訂正を一度だけ求められる。以後の応答は「承知」の二文字で処理され、内容は問われない。問われないことが、次の段の予告になる。予告は罰ではなく、事務の見込みとして記される。 |
| 五　無 | 呼称が「前・某」となる。記録は消えず、現在の欄にだけ現れない。当人は過去形で引用され、現在形では名指されない。名指されないまま、書類の上では完全に現役である。 |
| 六　収 | 「収束」が宣告される。以後、その名は「済」の一字で閉じられ、問い合わせには第五段の記録が返される。返されるのは記録であって、理由ではない。理由の欄は、最初から設けられていない。 |

各段のあいだに期間は定められていない。定められているのは、前の段の記録が閉じたときに次の段を起こす、という順序だけである。したがって罰は、速くも遅くも進む。速さを決めるのは規則ではなく、摘要を書く手の空き具合である。

六段のうち、身体に触れる段は一つもない。触れるのは欄と語だけである。しかし欄は人より長く残り、語は人より早く広がる。第五品は「畳みは慈悲」と言う。末尾が「済」の一字であることは、その教えの実務的な姿にほかならない。運用は、罰を決める会議ではなく、摘要を書く書記の手に委ねられている。決める者と書く者が別であるため、誰も全段を見ない。見えないことが、段を数えられなくする。

---

## 編纂註

**一**　この統制は、心理学では段階的制裁、社会学ではラベリングおよび社会的死の系譜に置かれる。教団内部の呼称は「畳み」であり、罰則ではなく整理と呼ばれる。整理は制裁を否定しない。制裁を、手続の別名に置き換える。段の数は、その組織が何を想像できるかの数でもある。罰の段階は、組織の想像力の段階である。

**二**　される側から見れば、罰は一度も告げられない。当人は台帳の摘要で自分の段を知り、やがて自分の摘要を自分で書くようになる。要約を禁じられた者が、みずから要約する。恐怖は最初の段にだけあり、以後は手続の反復がそれを運ぶ。気づいたときには、訂正を求められる側ではなく、訂正を済ませた側になっている。

**三**　壊れるのは、欄が戻せないと分かったときである。訂正は一度きり、順序は不可逆、呼称は時制を変えたまま戻らない。「収束」は、まだ語っている者にも適用できる。その瞬間、組織は自分が唯一の罪と呼んだものを、他人に対して行う。完了と沈黙の区別が失われ、記録は人より正確になる。正確さが、ここでは最も危うい。
