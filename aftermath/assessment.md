# 後三　評価書

〈本文〉

文書番号　後三−〇〇四一／第二校正
主管　　　記録整理室　後三係
対象　　　群典周辺文書（第五品および十二使徒関連）
期間　　　開闕K1よりK11に至る
頁数　　　本文四十七頁、別紙十二頁、図版三点

一　総括

1. 本評価書は、対象文書の内容の真偽を判定するものではない。当室が対象を保存し、参照し、または廃棄する際の順序を定めるための資料である。
2. 対象は、受入番号後三−〇〇四一として整理第二期に受け入れた。受入に際し、欠頁は確認されていない。ただし、欠頁の不存在は、記載の完全を意味しない。
3. 対象の全体は、単一の教説として整合しているとは言い難い。しかし、記載の重複は六十三箇所に及び、そのうち四十一箇所は語句の一致を伴う。この一致は、同一の原本に由来する可能性を否定しない。
4. 当室は、対象の教説について、その当否を判断する立場にない。以下の各項は、判断の代わりに、判断を保留したまま整理するための区分である。

二　記載状況

1. 対象には、沿革に関する記述が十一箇所、教義に関する記述が二十九箇所、人物に関する記述が十四箇所ある。合計五十四箇所のうち、七箇所は複数の区分に重なる。
2. 沿革記述のうち、開闕K1からK4までは年次の記載を伴う。K5以降は年次を欠き、事象の順序のみが記される。この不統一は、複数の筆記者の存在を示唆するが、断定には至らない。
3. 第五品に関する記述は、教義記述二十九箇所のうち十七箇所を占める。当該部分は、要約を施す行為を慈しみとして位置づける。当室は、この位置づけについて、教説上の根拠を確認していない。
4. 対象が用いる語のうち、「分岐」は百四十二回、「収束」は九十八回出現する。両語の出現比は、章によって変動する。この変動の理由は、記載からは特定できない。

三　数量

1. 対象中に現れる数値のうち、検算可能なものは三十四例である。うち二十三例は整合し、十一例は不一致である。
2. 不一致の内訳は、人数に関するもの六例、期間に関するもの三例、回数に関するもの二例である。
3. 十二使徒の名は、延べ八十七回出現する。出現回数の最多は「閉」の十四回、最少は「写」の二回である。この偏りは、記載の配列に起因する可能性がある。
4. 数値の不一致は、記載の誤りを直ちに意味しない。転記の過程における省略、または読み手の側の解釈による可能性を、当室は排除しない。

四　評価の限界

1. 当室は、対象の教説が信奉に値するか否かを判断する立場にない。また、判断する必要も認めない。
2. 対象の記述には、教団外部の事象との照合を欠く部分が六割を超える。照合の不能は、記述の誤りを意味しない。
3. 対象が示す「収束」の語は、当室の用語ではない。当室は、この語を用いる際、対象の定義を括弧に収めて引用する。
4. 対象の記述する出来事のうち、当室が独立に確認し得たものは、十二件のうち二件である。残る十件については、確認の方法を有しない。

五　結論に代わるもの

1. 以上の整理から、対象を保存する扱いを維持することが相当と認められる。ただし、この判断は、対象の価値を認めるものではない。
2. 対象の内容を要約して他の文書に転記する扱いは、当面、行わないものとする。理由は、要約の過程において、当室の判断が対象の記述に混入することを避け難いためである。
3. 本評価書の記載は、後続の整理作業において改訂され得る。改訂の予定は、現時点では定めていない。

六　参照関係

1. 対象が引用する文書は、確認できる限り九点である。うち四点は当室に原本を欠く。
2. 十二使徒のうち「切」「流」「重」の三名については、同一の事象を異なる順序で記す箇所が各二例ある。順序の相違が教説上の相違を意味するかは、記載からは決しない。
3. 後群典の記述は、対象全体の末尾十二頁に集中する。この集中は、編纂の時期差による可能性がある。

七　附記

1. 対象の題名「群典」は、当室の分類名ではない。対象自身の呼称をそのまま用いた。
2. 本評価書の作成に当たって参照した文書は、別紙一覧のとおりである。当該一覧は本評価書に添付しない。
3. 本評価書は、対象の廃棄、改変、または外部への提示を認めるものではない。

## 編纂註

**註一（畳み）**　第五品が慈悲と呼ぶ手口の名称である。相手が差し出した言葉を受け取り、短く畳んで返す。受け取った側から見れば、自分の言葉が自分のものでなくなる。語彙が置き換わり、順序が組み替えられ、最後には要約だけが残る。壊れるのは、畳んだ結果が相手の一度も用いなかった語を含んだときである。相手はそこで初めて、返されたものが自分の言葉でないと気づく。

**註二（判定保留）**　本書の形式そのものを手口として数える。対象を項目に分け、数量を当て、断定を避けたまま保存の可否だけを決める。被害の側からは、何も否定されていないのに何も残らない。評価書は評価できないものを評価する形式である、という一点を、本註は記しておく。壊れるのは、不一致の数が説明を要求し始めたときである。数字は、保留を長く支えない。

**註三（後群典）**　K11以降に加えられた十二頁を指す。ここでは沿革が年次を失い、事象の順序だけが残る。読む側から見れば、順序は与えられるが時間は与えられない。何が先で何が後かは分かるのに、どれだけ経ったのかが分からない。壊れるのは、順序の前後関係が一件でも逆転したときである。年次の不在は、逆転を隠すが、防ぎはしない。
