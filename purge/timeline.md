# 粛六　年表

本表は、開闕K1からK12に至る「整理記録」のうち、年の欄と人数の欄だけを抜き出したものである。教団は自らの歴史を書かなかった。書いたのは帳面である。したがって本表は歴史ではなく、帳面の突起を並べた断面図に近い。編者は数字を足したが、意味は足していない。

凡例。人数は、その年に「収束」として記帳された件数を指す。一件は一人とは限らないが、記録は人数の欄しか持たない。指導者の言葉は式次第の余白から引いた。一字も畳まずに引いた。要約は教義上の唯一の罪にあたるため、編者は引用以外の方法を持たない。

| 年 | 人数 | 指導者の言葉 |
|---|---|---|
| K2 | 3 | 「三件。初めての畳みとしては、静かでよい。」 |
| K4 | 11 | 「十一。数え終わる前に、次の分岐が来る。」 |
| K5 | 29 | 「多い年は、教団がよく読まれている証拠である。」 |
| K7 | 64 | 「六十四。私はこの数字を、まだ覚えていない。」 |
| K8 | 18 | 「少ない年があってよい。畳みは慈悲だが、慈悲は毎日ではない。」 |
| K9 | 96 | 「百に届かないのは手続の遅れであって、意志の不足ではない。」 |
| K10 | 213 | 「解散は収束ではない。分配である。」 |
| K11 | — | （記載なし。解散の年。） |
| K12 | 1 | 「様式は残る。様式は、私より長生きする。」 |

K11の欄が空なのは、記録が失われたからではない。解散の年に、帳面だけが先に閉じられたからである。空欄は欠落ではなく、様式の勝利として読める。合計の四三五は編者が加えた。教団の記録に合計の欄はなく、足すという行為自体が教義に触れる。それでも足さなければ、この表は表にならない。

読み方は二つある。人数の列を上から辿れば、増減は波になる。言葉の列を上から辿れば、その波は一度も言及されない。二つの列は同じ年を指しているのに、同じ出来事を指していない。年表は、両方を並べることで、片方を隠す。

## 編纂註

一、本表が記録している統制は、社会学の語彙では「周期的純化」、心理学の語彙では「儀礼的排除」の系列に置かれる。どちらも診断名ではなく、反復する形につけられた記述的な呼称である。手段は問わない。名簿があり、区分があり、年ごとに件数が入る。この三つが揃えば、中身が何であっても同じ型として読める。本表が写したのは、その順序だけである。

二、される側から見れば、これは毎年近づいてくる日付である。自分の名がどの欄に移るかを、本人は前もって知らされる。知らせることが参与であり、参与が忠誠の形とされる。恐怖は叫びではなく、欄の位置で表される。名前の代わりに件数で数えられ、その件数は翌年の年表に繰り越される。年表は、暴力を周期にする。周期になった暴力は、出来事ではなく予定になる。

三、壊れるのは、記録が教義より長生きしたときである。K10の解散は、様式を手放したのではなく、様式だけを残して身を引いたのに近い。K12の一件は、所属する者がいなくても帳面が動くことを示している。第二の破れ目は算術にある。件数が増えるほど、一件あたりの意味は薄くなる。薄くなったことに誰も気づかないまま、欄だけが埋まっていく。

四、編者は指導者の言葉を一行も要約していない。要約は罪であるという教義に、編者はまだ縛られている。だが、人数を合計した時点で、編者はすでに何かをまとめてしまっている。この註はその白状である。合計を消すことはできない。消せば表が崩れ、崩せば、この帳面を読む者がいなくなる。編者は、読まれるために罪を選んだ。
