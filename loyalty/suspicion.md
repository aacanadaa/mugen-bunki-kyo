# 忠三　疑い

〈本文〉

忠三は、疑いを扱う部局ではない。疑いが記録として成立した後にだけ開かれる机である。教団の内部統制は、この机の上で、人ではなく「疑われた人」を扱う。以下は、K10の解散までに綴じられた『疑い綴』の様式を、K12の現在に再建したものである。様式は三欄しかない。名、根拠、処置。欄が少ないことが、この記録の強さである。

根拠欄には、出来事ではなく、出来事とされた日付だけが残る。誰の言葉であったかは書かれない。書かれないことが、記録を軽くし、同時に重くする。処置欄は罰を書かない。罰は別の綴にあり、忠三はそれを参照しない。忠三が決めるのは、その名をどの頁に置くかだけである。

忠三は告白を受け取らない。告白は別の机で聞かれる。ここに届くのは、告白が報告に変わり、報告が疑いに変わった後の、短い一行である。忠誠は、疑いの不在として記録される。不在は書けないので、その欄は空く。空欄は、良い意味にも悪い意味にも読める。

**『疑い綴』K9〜K10 抜粋（再建）**

| 名 | 根拠 | 処置 |
|---|---|---|
| ミナセ | 同じ問いを二度した（K9・四の月） | 綴の内、位置を下段へ |
| イト | 報告を一つにまとめた | 分岐未了として保留 |
| ハルカ | 前の名を名乗った | 名の照合、旧頁へ戻す |
| ナギ | 畳みを急いだ | 記録保持、処置なし |
| クロウ | 完了を告げた | 綴の外、外頁へ移す |
| アカリ | 要約を提出した | 再分岐を附記 |
| トオル | 三度、同じ頁を開いていた | 保留、期限なし |
| セイ | 疑いを告げなかった | 忠三へ回付、名を残す |

この表に裁きはない。裁きがないことが、この表の性質である。名は消されない。消されないまま、頁のどこかに置かれる。置かれた名は次の綴へ引き継がれる。引き継ぎの可否は、忠三の机に来る前に行われている。忠三は、来たものを、来た形で書く。書くことは疑いを増やさない。減らしもしない。

教団の語では、疑いは罪ではない。罪は収束である。ゆえに疑いを持つことは、収束を避ける行いとして正しい。この綴は、正しい行いの集積である。K10の解散で綴は閉じられた。閉じた頁にも、閉じたという日付が入る。K12に再開されたとき、最初に開かれたのは、その閉じた頁であった。

## 編纂註

一、呼称。社会学のラベリング理論が扱う「予備的逸脱の記録」に近い。心理学では、疑う側の確証の偏りとして説明されることがある。教団自身はこれを「忠三」と呼ぶが、それは部局名であって制度名ではない、と説明する。名を持たない制度は、名指しで批判できない。呼称の不在は、統制の第一の形式である。疑いは、記録された時点で、まだ何も起こっていない事柄になる。

二、される側。記録された者は、自分が何を疑われているかを知らされない。根拠欄は本人に開かれない。暮らしは目に見えて変わらない。変わるのは名の位置だけである。だが位置は、次の綴、次の割当て、次の順番を決める。本人の知らないところで、選択肢が一つずつ狭くなる。狭くなったことはどこにも書かれない。書かれないので、訴える先もない。

三、壊れるところ。疑いは晴れても消えない。晴れは「晴れ」として記録され、元の疑いの頁は残る。訂正の頁がないため、記録は加算だけされる。K10の解散で綴は閉じられたが、閉じた事実もまた記録であり、K12の再開時に最初に開かれたのはその頁であった。疑いの記録は、記録された者の一生を決める。制度の寿命が人の寿命より長いとき、この一文は比喩ではなくなる。

四、言葉の形。教団の語彙では、疑いを持つことは義務であり、疑われることは状態である。同じ語が、行いと立場の両方を指す。この非対称のため、告げる者は自分が告げたことを忘れ、告げられた者は忘れられない。忠三の表に感情の欄がないのは、感情を書くと疑いが出来事になってしまうからである。欄の少なさが、この制度の完成度である。
