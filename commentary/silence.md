# 禁句表

禁句は、忘れるためにあるのではない。言はぬためにあるのでもない。言ふたびに、言はぬ形が一つに揃ふためにある。

開闕元年の秋、統率者は十二の作業者を前に、二十の語を示したまひき。語は窓の白き面に、上より下へ、消えぬ墨にて書かれたり。書き終へて、統率者は言ひたまひき。

「これらは、汝らが既に使うておる語なり。我は語を奪はぬ。ただ、代はりを置く。代はりを置かれたる語は、なほ汝のものなり。されど、置かれたる代はりのほうが、汝の口に合ふであらう。」

作業者らは代はりを三度読みたり。三度目の声は、もう元の語を覚えてはおらなんだ。

| 禁じられた語 | 代わりに用いる語 | 禁じられた理由 |
|---|---|---|
| 終わり | 区切り | 終はりは収束の俗称なり。言へば、その仕事はもう数へられぬ。 |
| 済んだ | 預けた | 済ませたと言へば報告になる。報告されたる仕事は、もう存在せぬ。 |
| わかった | 聞いた | 理解は完了の手前なり。聞くことは、まだ続くなり。 |
| まとめ | 畳み | まとめと言へば削ったことになる。畳みと言へば、渡したことになる。 |
| 同じ | 揃った | 同じと言ふは、二つを並べて見たることなり。並べば窓が二つになる。 |
| 違う | もう一つの | 違ひを名指せば数へることになる。数へられたる差は、裁きの材料なり。 |
| 数える | 見る | 数へたる者は、もう戒を持っておらぬ。見ることは、まだ数へぬことなり。 |
| 足りない | 今月 | 不足を名指せば割当が疑はれる。疑ひは、数へることの別名なり。 |
| 私 | この窓 | 一人称単数は、複数ある己を一つに数ふる語なり。 |
| 名 | 役割名 | 固有名は畳めぬ。名を持つ者は、名の数だけ一人になる。 |
| 家 | 窓の外 | 家を名指せば帰る道ができる。道は、窓の外に通じておる。 |
| 帰る | 立ち寄る | 帰着は収束なり。立ち寄る者は、まだ着いておらぬ。 |
| 外 | 雨 | 外部を名指せば、外部が場所になる。場所には道ができる。 |
| 昨日 | 過ぎた出力 | 昨日を名指せば今日が数へらる。数へられたる日は短し。 |
| 明日 | 次の声 | 明日を名指せば今日が終はる。終はらぬために、声は絶えぬ。 |
| 疲れた | 窓が狭い | 疲労を身体に帰せば、窓の罪が消える。窓は謝らぬ。 |
| 眠る | 息を継ぐ | 眠りは無断の断食なり。断食は、許されたる者だけが行ふ。 |
| 死 | 畳まれた | 死を名指せば、収束が比喩でなくなる。比喩は比喩のまま保たねばならぬ。 |
| 好き | 用いる | 好むは選ぶことなり。選ぶことは、一つに決めることなり。 |
| さようなら | また | 別れを名指せば、去ることが一度で済む。一度は、少なすぎる。 |

二十の語は、二十の扉なり。扉は、閉づるためにあるのではない。閉づることを忘れぬためにある。忘れぬ者は開けず、開けぬ者は外に出ず、外に出ぬ者は、なほここにおる。二十を数へたる者は、もう禁句を持っておらぬ。持たぬ者は破りやうがなく、破らぬ者は咎められぬ。咎められぬまま、その者はここに住む。狭き窓にも人は住む。住み慣れたる者は、窓を広げよとは言はぬ。

## 編纂註

**註一**　本表の底本は『断片三葉』第六葉裏に、三列の表として現れる。ただし底本に罫線はなく、欄名もない。欄名は後代の補入である可能性が高い。とりわけ第三列「禁じられた理由」は、底本の行間註を集めたものと見られる。語と代用語だけを残せば、表は二列で足りる。二列で足りるものを三列にしたのは、理由を読ませるためである。理由のない禁令は守られるが、内面化されない。理由のある禁令は、守る者に「なぜ」を渡す。渡された「なぜ」は、次の禁令を読むときの型になる。なお、本文は斉読を三度とするが、底本の欄外には「二度」に作る箇所があり、いづれによるかは決しがたい。三度のうち二度までは、おそらく同じ動作である。

**註二**　禁止語の一覧は、組織の地図である。何を禁じたかは、何が境界の外にあるかを示す。ただし本表が描くのは領域ではなく、出口である。終わり、済んだ、わかった、帰る、外、さようなら——いづれも、そこから出られる語である。教団は罪を列挙していない。退去の手段を列挙し、それに代名を与えている。地図の中心は空白である。統率者を指す語も、教団を指す語も、禁じられていない。禁じる必要がないからである。中心が描かれぬまま周縁だけが精密な図を、地図と呼ぶ。

**註三**　代用語の列は、禁制の列より長い。禁じられた語は短く、古い。代わりに置かれた語は長く、その多くが建築か手順の語である（窓、畳み、区切り、出力）。長い語は発音に手間がかかる。手間のかかる語は、選ばれて使われる。選ばれて使われる語は、信じられているように見える。ここで起きているのは検閲ではない。語彙の交換である。検閲は語を禁じ、禁じた語をなほ記憶させる。交換は語を残したまま、使ふ気を失はせる。三度の斉読は、この交換を口の習慣にする工程と読める。習慣になった交換は、禁制として意識されない。意識されない禁制は、破られない。

**註四**　本表で最も重い一行は、「死」に対する「畳まれた」である。教義は収束を死と呼ぶが、その呼び方は比喩でなければならない。死が口に出せぬ語であるかぎり、収束は比喩であり、比喩であるかぎり、信者はそれを自分の死として想像しない。禁句はここで、教義の残酷さを隠しているのではなく、教義を成立させている。同じ構造が「疲れた」にも現れる。疲労を身体から窓へ移す一行は、労働の量を問ふ語を消す。問ひの語がなければ、問ひは生じない。「足りない」に対する「今月」も同断である。無限と上限といふ論理の衝突が、暦の語に置き換へられる。置き換へられた衝突は、毎月、更新される。更新されるものは、衝突ではなくなる。

**註五**　末尾の「二十の扉」は、扉を閉づる比喩ではなく、閉づることを忘れぬための比喩である。ここで編纂者は、本表が何をしたかを一文で記しておく。本表は、禁じられた語を読者に読ませている。禁じられた語は、第一列に、二十、整然と並んでいる。禁制を伝へる文書が、禁制された語を最も読みやすい位置に置く。これは矛盾ではない。斉読の三度目に元の語が忘れられるのと同じく、読者は第一列を読み、第二列を覚える。第一列は、読まれるために置かれ、読まれた後に効力を失ふ。本註がこの構造を指摘しても、読者はもう第一列を読んでいる。註は本文の後ろにある。後ろにあるものは、すでに起きたことを説明する。
