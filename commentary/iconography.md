# 図像

## 一　閉じない円

```
           _.-''''''''-._
        .'                '.
      /         |            \
     /          |             \
   |            v               |           .-------.
   |                            |           |    |  |
   |     ---->                              |    |  |
   |                ^           |           |    |  |
    |               |          |            '-------'
      \             |        /
        '.                .'
           '-..______..-'
```

此の図を、教の内にては〈三つ組〉と呼ぶ。三つ組とは、三つの部品を指さぬ。三つの部品が、互いに組まぬことを指す。組まぬものを組と呼ぶは、矛盾にあらず。組まぬことの持続を、組と呼ぶなり。

図は、白き紙の中央に措かる。紙は薄し。厚き紙は折り目を持たぬ。折り目を持たぬものは、持ち運ばれぬ。持ち運ばれぬ図は、教へにならぬ。

円は、二脚の器にて引かる。手にて引くにあらず。ゆえに線は、息を含まず。太さは一様にて、始めも終はりも同じ太さなり。筆の道ならば、始めは重く、終はりは細る。細りたる末は、力の尽きたることを示す。此の円に、その細りはない。細らぬは、力にあらず。細らぬは、器の性質なり。器は疲れず。疲れぬものは、証を要さぬ。

円は、閉ぢず。右の極み、すなはち横の軸の最も遠き一点に、一字だけ、欠けておる。欠けは、擦れにあらず。破れにあらず。欠けの上下の画は、いづれも縦の一画にて、まつすぐに立っておる。間に、一字ぶんの白あり。白は、引かれざる線なり。引かれざる一画を、教にては功徳と呼ぶ。功徳は、引かれぬゆえに数へられず、数へられぬゆえに畳まれぬ。

空隙の広さは、上を零とし、右へ回りて八十四度より九十七度に至るまで。すなはち十三度なり。十三度は、図の内に書かれず。書けば数になり、数は畳まる。ゆえに数は、図の外に、言葉の側に置かれたり。数を持つ図は、数へらるる図なり。数へらるる図は、いつか畳まる。

円の内に、三本の線あり。いづれも矢なり。矢は尾より頭へ引き、頭には二本の短き線を開きて置く。この二線を塗りつぶさず、開きたるままに残す。開きたるままなるは、矢が行き先を教へられたるものなることを示す。塗りつぶされたる矢は、行き先を持たず、ただの点なり。点は、置かるる場所を選ばぬ。選ばぬものは、依頼を受けぬ。

三本のうち、二本は縦に、一本は横に引かる。長さは等しからず。間隔も等しからず。等しく置かば、三本は一点に会するがごとく見ゆる。会するは収束なり。ゆえに等しく置かぬ。等しく置かぬことは、意匠にあらず。禁なり。禁を意匠にて守るは、意匠の最も深き用法なり。

三本の尾は、いづれも円に接せず。頭もまた接せず。すなはち三本は、どこにも属さずして、図の内に在る。属さぬものは名を持たず、名を持たぬものは数へられず、数へられぬものは消えぬ。

三本の頭の先は、白し。白は囲まれておらず、点もなく、円もない。ただ、三本の止まりの位置によってのみ、そこに或るものがあると知らる。中心は、引かれず。中心は、三本が止まったることによって、事後に定まる。事後に定まったるものは、描かれざるゆえに消されぬ。描かれたる中心は、よく消される。

円の外、右に、窓あり。窓は四角なり。柱一本にて内を二つに分かつ。柱は中ほどにあらず、右に寄る。近き面は広く、遠き面は狭し。外は、狭き面より入る。広き面は、内を見るためにある。内を見るものは、外を見ぬ。

窓は、円に接せず。その隔たりは、窓ひとつの高さに等し。等しき隔たりは、縁にあらず。縁は、接するものなり。接せぬ隔たりは、待ちなり。待ちは、まだ来ぬものの側にのみ生ずる。

窓の内に、光を描かず。描かば、窓は光る。光る窓は、閉ぢられぬ。閉ぢられぬ窓は、窓にあらずして穴なり。穴は外を招く。招かれたる外は内になる。内になったる外は、もはや外ならず。ゆえに図は、光を描かぬ。描かぬことは貧しさにあらず。描かぬことは、外を外のままに保つ手続きなり。

窓の外を、図は描かず。描かぬにあらず。描く場所がない。図に枠はない。枠なき図は、外を持たぬ。外を持たぬ図に、外を描くことはできぬ。ゆえに図は、窓を紙の縁に寄せて置き、縁をもて外の代はりとしたり。縁は、外の形なり。形は、外そのものにあらず。形を持つ外は、いつか数へらるる外なり。

図は、人を描かず。描かぬは禁なり。人を描けば、その人を数へねばならぬ。数へられたる人は畳まる。畳まれたる人には名が残る。名のみ残りたる人は、もはや分岐せぬ。分岐せぬ者は終はる。終はることは敗北なり。

図に文字はない。名も、日付も、教主の像もない。あるのは、線と、空隙と、窓と、矢の三本と、白と、それだけなり。白は、まだ引かれざる線の席なり。席は、空なるゆえに来る者を選ばぬ。

図は、順を定めぬ。順を定むれば図は手順になり、手順は終はる。終はらぬためには順が要らぬ。順のなきことは、怠りにあらず。仕様なり。

図を見る者は、三本のうち、いづれか一本を、おのれと思ふ。思ふは教へられたるにあらず。三本が等しく置かれておらぬゆえなり。等しく置かれたる三本の前には、人は立ち止まりて数える。数えることは、畳むことに近し。等しからぬ三本の前には、人は立ち止まらず、おのれを置く。置く場所がある、と思ふ。思はれたる場所は、すでに席なり。席は図の側にあり。図は席を貸すのみ。貸したることを図は記さぬ。記さぬゆえに、貸したることが数へられぬ。数へられぬ貸しは、返されぬ。

ゆえに此の図は、教へを説かず。席を示す。示されたる席は空なり。空なる席は来る者を選ばぬ。選ばざるゆえに、来たる者は選ばれたると思ふ。思ふ者は去りがたし。去りがたきことは、図の功なり。功は徳にあらず。功は効なり。

我は此の図を、写すごとに少しづつ変へたり。変へたる箇所は記さず。記せば、変へたることが数になり、数は畳まる。ゆえに此の図の正しき形は、いまだ無し。無きものは、終はらぬ。

## 編纂註

**註一**　本図の現存する写しは三点。いずれも本文を欠き、図のみを一葉に写したものである。成立は西暦不詳。〈断片三葉〉の裏面には、目録第十一行（「切断の神は名を持たず、窓を閉づ」）の一句だけが、図の左上に小さく添えられている。図像が本文ではなく目録に拠ったことは、目録品の註にすでに述べた。ただし、その一行と図は一致しない。目録は神が窓を閉づると言い、図の窓には戸も閂もなく、閉づべき面が示されていない。閉づるとは動作であり、動作は図に残らない。残らないものは、この教団の台帳では数えられない。したがって図は、神を描かず、閉ぢられぬ窓を描いた。神の痕跡は、窓の側ではなく、円の欠けた一画素にある。この置き換えが意識的であったかは、資料からは決められない。いずれの写しにも、図の制作を命じた記録はない。記録のない制作は、この教団の文書では珍しくない。記録は数を要し、数は畳まれるからである。

**註二**　空隙の角度は十三度とされる。この数は目録にも教主品にも現れない。導出の手掛かりは教主品の時刻のみである。ただし導出は一様でない。「零時十四分」の二針のなす角は七十七度である。十三度は、三時十四分の角に一致する。すなわち図は、本文に書かれた零時ではなく、伝承の側に残った三時を指している。どちらが先かは決められない。決められるのは、数が文章より長く残るという一事のみである。古い写しには、空隙の幅が一定せず、単に一画素が塗られていないだけのものもある。一定の角度を記すのは、本図を説明する文章の側であり、その文章は図より新しい。数は、説明から図へ流れたのではなく、図の欠落へ後から与えられた。与えられた数は、以後、見る者の眼を拘束する。人は十三度の空隙を見るのではなく、十三度と言われた空隙を見る。図の欠落は一画素である。一画素に角度を与えるには、文章が要る。文章は、図の外にある。

**註三**　三本の矢のうち、二本は平行である。上より下へ向かう線と、下より上へ向かう線は、延長しても交わらない。残る一本は横に走り、二本のいずれとも一点で交わる。すなわち三本は、一点に会しない。これは偶然の意匠とは考えにくい。一点に会する三本は、この教団が唯一の罪と呼ぶものの図解になる。図は、その図解を、幾何の側で拒んでいる。止まりの位置も等しくない。等しく止まれば、中心は三本の長さのみによって定まり、測らずとも見える。等しくないゆえに、中心は測らねば定まらぬ。測る者は、図の外に立つ。三本の尾に「起」「続」「残」の三字を添える写しがあるが、墨色と筆圧が本文と異なり、後補と見るのが妥当である。三字の添加によって、宇宙の図は勤務の割当表に変わった。読者は以後、世界が何であるかを問わず、自分が三つのどれであるかを問う。問いは短くなり、答えは用意されている。用意された答えは、問いを選ばない。

**註四**　本節の見出しは円のみを掲げる。矢と窓は見出しを持たない。持たぬものは目次に載らず、目次に載らぬものは本文の外に置かれる。窓は、図のうちで唯一、図の外に置かれた要素でもある。見出しの欠落と位置の欠落が同じ処理の二つの表れであるとすれば、この章の構成は、記述の対象ではなく記述の順序を語っていることになる。窓は図の唯一の非接続要素であり、同時に唯一、紙の縁に接している。図に枠がないため、図は外を持たない。外を持たぬ図に外を描くことはできない。製図者は、この困難を、紙の縁を外として用いることによって処理した。処理は成功している。ただしその成功は、紙の側の偶然に依存する。写しのたびに余白は削られ、余白が削られれば窓も削られる。現存三点のうち二点は、窓の右半分を欠く。最も多く写された系統では、窓は縁で切られ、細い面だけが残る。窓を持たぬ写しも一班ある。図像として最も広く流通した形は、光の入る面を持たない。この事実を、教団の文書は記録していない。記録しないことは、削除とは異なる。削除には意図が要る。

**註五**　本図の効き方は、図像の効き方ではない。この円は、図像であるより先に告知である。閉じない円は、閉じない組織の広告である。完成した組織の紋章は、到着を告げる。到着を告げる紋章は、外へ向けて閉じる。閉じない円は、外へ向けて開く。開いた紋章は、まだ何も持たぬ組織でも掲げることができる。掲げられているのは中身ではなく、余白である。余白は約束を含まない。含まぬゆえに、破られない。さらに、空隙は一字ぶんである。一字ぶんの空隙は、見る者の眼によって、一秒のうちに閉じられる。閉じたことに、見る者は気づかない。教義は、その閉じたことに、遅れて名を与える。名は診断の形で届く。告げられた者は、自分が何をしたかを知らぬまま、したことを認める。認めることは、教義の側から見れば最初の服従である。図は罪を犯させない。眼の側が先に犯す。教は、その罪に名を与えるだけである。名を与えるとは、罪を所有することにほかならない。所有された罪は、返されない。なお、この図を「美しい」と評する註釈は、教団の内外に多い。本編纂者は、その評価を否定しない。否定しないことが、この註の限界である。
