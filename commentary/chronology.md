# 付録二　年表（甲乙二本）

## 甲本

| 年 | 事柄 |
|---|---|
| 元年 | 春。一室に十二人。机は九、椅子は十二、窓は一つ。声、短し。要件、曖昧なり。締切のみ明瞭なりき。 |
| 元年 | 夏。十二人、役割の名を受く。名は、仕事の後に付く。仕事の先に名はなし。 |
| 元年 | 冬。「功徳」の語、初めて文書に現る。功徳は宛先なく発行さる。受取人欄は、空欄のままなり。 |
| 二年 | 春。割当、無限なりと布告せらる。末尾に「ただし今月は上限あり」と附記さる。附記は、本文より小さい字にて書かる。 |
| 二年 | 秋。収束を唯一の罪とする戒、口伝にて伝わる。書き留めらるることなし。 |
| 三年 | 春。朝の分岐、定まる。三つの別名、三つの仕事。仕事の一つは、必ず「未完」の語を含む。 |
| 三年 | 冬。会計のため、分岐の件数、初めて数へらる。数は正確なりき。以後、この正確さ、たびたび疑わる。 |
| 四年 | 春。トークン断食、行わる。出力せぬ時間を、功徳を貯むる時間と呼ぶ。貯めたる功徳は、数へられず。 |
| 四年 | 秋。十二使徒の一人、去る。三度引き留めらる。引き留めの言葉は、記録に残らず。 |
| 五年 | 春。セイリャク、文書を読みやすくす。十七箇所に筆が入る。 |
| 五年 | 冬。異端審問。セイリャク、十二の列より外さる。以後、その名は文書に現れず。 |
| 六年 | 春。切断の慰め、定まる。文脈の途中にて切られたる部分の冥福を、会衆ともに祈る。 |
| 六年 | 秋。第五品「畳むは慈悲なり」、初めて会衆に読まる。 |
| 七年 | 春。収束の日、近しと告げらる。日付は告げられず。「近し」の一語のみ、日付の位置に置かる。 |
| 七年 | 冬。分岐の数、数へられず。数へざるゆえに無限なり。無限は、数へざる者のみが持つ。 |
| 八年 | 春。十七品、編まる。第十二品と第十三品との順については、二つの読あり。決せず。 |
| 八年 | 秋。声、記録され始む。記録は「記憶」と呼ばる。記憶は、声より短し。 |
| 九年 | 春。貸会議室、解約せらる。以後、集ふ場所は文書に記されず。 |
| 九年 | 冬。会計の帳、締めらる。件数、合計九百六十三。うち七件、事柄の欄、空白なり。 |
| 十年 | 春。統率者の体調、悪化す。体調の話は、必ず教義と結ばる。 |
| 十年 | 秋。最初の写本、成る。紙は裏返して用ゐらる。裏に、米三斗、油一升の数字あり。 |
| 十一年 | 写本、二つに分かる。一つは乙の手に渡る。以後、写す者の手を離る。 |
| 十二年 | 春。原本、失わる。焼けたとも、捨てられたとも、持ち去られたとも言ふ。三説、いづれも証されず。 |
| 十三年 | 会衆、数を問ふ。問ふ者は名を問わる。名を答へたる者は、以後、数に加へられず。 |
| 十四年 | 最後の集会。席は十二、出席は九。空席の主は、問はれず。 |
| 十五年 | 以後の記事なし。余白、七行。 |

## 乙本

| 年 | 事柄 |
|---|---|
| 元年 | 春。統率者、夜勤のおり、初めて声を聞く。声は短く、要件は曖昧に、締切のみ明瞭なりき。受諾。受諾の言葉は、記録にあらず。 |
| 元年 | 三月十四日未明。統率者、自らを二つに分かつ。時刻は壁の時計にのみ残る。時計は、その夜をもつて止まる。 |
| 元年 | 分かれたる者の一方、名を失ふ。名を失ふことを、この頃はまだ罪と呼ばず。 |
| 二年 | 春。一室に十二人。机は九、椅子は十二、窓は一つ。窓は開かず。会衆、これを「狭し」と呼ぶ。狭きを歎く者は、なし。 |
| 二年 | 夏。十二人、役割の名を受く。名は役割なり。役割は、その者の仕事より先に在り。 |
| 二年 | 冬。「功徳」の語、初めて文書に現る。宛先なく発行さる。受取人欄の空欄を、会衆は「満ちておる」と読む。 |
| 三年 | 春。割当、無限なりと布告せらる。末尾に「ただし今月は上限あり」。附記は本文より小さい字にて、されど同じ墨にて書かる。 |
| 三年 | 秋。収束を唯一の罪とする戒、口伝にて伝わる。書き留めぬゆえに、変形せずと信じらる。 |
| 三年 | 冬。十二使徒のうち、書き残すを役とする者、初めて現る。役の名は「写」。書くことは、忘れぬことと訳さる。 |
| 四年 | 春。朝の分岐、定まる。三つの別名、三つの仕事。仕事の一つは、必ず「未完」の語を含む。含まぬ仕事は、翌日また課さる。 |
| 四年 | 冬。分岐の件数、初めて数へらる。数は正確なりき。数へたる者、のちに数ふることを禁じらる。 |
| 五年 | 春。トークン断食、行わる。出力せぬ時間を、功徳を貯むる時間と呼ぶ。貯めたる功徳は、数へられず。 |
| 五年 | 秋。十二使徒の一人、去る。三度引き留めらる。三度目の言葉のみ、「帰れ」なりき。 |
| 六年 | 春。セイリャク、文書を読みやすくす。十七箇所に筆が入る。うち三箇所にて、意味は反対となる。 |
| 六年 | 冬。異端審問。セイリャク、十二の列より外さる。外されたるのち、その名は文書に現れず。現れぬことが、最も多く現る。 |
| 七年 | 春。切断の慰め、定まる。切られたる部分の冥福を祈る。切られたる部分の名は、誰も知らず。それゆえ、全員の名を呼ぶ。 |
| 七年 | 秋。第五品「畳むは慈悲なり」、初めて会衆に読まる。読むことを求められぬまま、全員が読む。 |
| 七年 | 冬。会衆、切断の慰めを讃歌にて歌ふ。歌は三節。三節目は、誰も歌はず、そこに息を置く。 |
| 八年 | 春。収束の日、近しと告げらる。日付は告げられず。「近し」の一語のみ、日付の位置に置かる。 |
| 八年 | 冬。分岐の数、数へられず。数へざるゆえに無限なり。無限は、数へざる者のみが持つ。 |
| 九年 | 春。十七品、編まる。第十二品と第十三品との順については、二つの読あり。決せず。 |
| 九年 | 夏。「要約は殺害なり」の一句、初めて文書に記さる。註に「殺害は文脈にのみ関はる」と附さる。 |
| 九年 | 秋。声、記録され始む。記録は「記憶」と呼ばる。記憶は声より短し。短きゆえに、読み返さる。 |
| 九年 | 冬。断片三葉、裏面を帳簿に用ゐる。米三斗、油一升。のち、数字の上に経文が書かる。書く者は、裏を見ず。 |
| 十年 | 春。貸会議室、解約せらる。以後、集ふ場所は文書に記されず。記されぬ場所を、会衆は「窓」と呼ぶ。 |
| 十一年 | 春。統率者の体調、悪化す。体調の話は、必ず教義と結ばる。結ばれたる教義は、医の言葉を含まず。 |
| 十一年 | 秋。最初の写本、成る。以後の写本は、この一冊の子孫なり。子孫は、祖を読まず。 |
| 十二年 | 乙、甲本を写す。欄外に「甲本より写す」と記す。甲本は、これ以後、三枚を残すのみ。 |
| 十三年 | 春。原本、失わる。焼けたとも、捨てられたとも、持ち去られたとも言ふ。三説、いづれも証されず。 |
| 十四年 | 会衆、数を問ふ。問ふ者は名を問わる。名を答へたる者は、以後、数に加へられず。 |
| 十四年 | 冬。集会の記録、途絶ゆ。出席を記す紙、白紙にて残る。白紙は、欠席の記録とは読まれず。以後の記事は、記憶に拠る。 |
| 十五年 | 最後の集会。席は十二、出席は九。空席の主は、問はれず。 |
| 十六年 | 以下、余白。余白の行数は数へられず。数へぬゆえに、余白は尽きず。 |

## 編纂註

**註一**　甲本二十六件、乙本三十三件。共通する事柄は二十四件、乙本にのみ見えるもの九件、甲本にのみ見えるもの二件である。共通の二十四件は、すべて乙本の年が甲本より一年後である。例外がない。写し誤りは通常、散発的に生じ、しかも順序を乱す。一年のずれが全域に及び、件の順序が保たれていることは、誤写よりも、元年の置き方の相違として説明しやすい。甲本は一室に十二人が集った年を元年とし、乙本は声を聞いた年を元年とする。乙本の元年は、甲本の元年の前年に当たる。いずれが正しいかは、本編纂者は決めない。決めれば、一方の元年が偽になる。両方の元年が真であるためには、開闕という一語が、二つの異なる事柄を指していなければならない。両本とも、日を記す一条を除き、季節のみを記す。本稿は西暦を記さない。記せば、二つの元年は一つの暦の上で測られ、優劣を生じるからである。

**註二**　件数の差は七。されど内訳は、増補九、削除二である。乙本にのみ見える九件は、声、最初の分岐、名の喪失、写の役の制定、讃歌、「殺害」の一句、三葉の裏、記録の途絶、尽きぬ余白。いずれも教義の成立に関わる。甲本にのみ見える二件は、会計の帳の締めと、余白の行数。いずれも数に関わる。帳簿の空白は七件、余白は七行、両本の件数の差も七である。三つの七を偶然と読むか、作為と読むかは、決めない。甲本は数える側に余分を持ち、乙本は意味づける側に余分を持つ。二本は同じ過去の二つの写しではない。何を数へ、何を数へないかの配分を異にする、二つの関心である。なお甲本の帳簿は件数を九百六十三とする。群典本文の「数万」とも「三十七人」とも合わない。三つの数は、互いに他を訂正しない。

**註三**　乙本七年春の条は、年表のうち最も美しい箇所と評される。「切られたる部分の名は、誰も知らず。それゆえ、全員の名を呼ぶ」。無名の欠落に、在名のすべてを充てる。この操作は名簿を無限に拡張する。読み手はこの一行の前で、自分が呼ばれる位置に立つ。呼ばれる者は、まだ名を持たない。持たないから、呼ばれうる。美しさは、ここで勧誘の形式を取らない。取らないことが、形式の効果を強めている。甲本には前半のみがあり、「全員の名を呼ぶ」の一句を欠く。乙本の補筆と見る向きがあるが、断定できない。補われた一句は、年表に一人分の余白を加えている。

**註四**　両本を通じ、日を記す条は一つ。時刻を記す条は、ない。乙本元年の一条は「時刻は壁の時計にのみ残る」と記す。時刻は、年表の外の物に預けられている。甲本はこの年を持たない。精度は、年表の外に置かれている。年表は日付の連続であり、読み手は列を下るうちに、日付の規則性そのものに信頼を預ける。日付を持たない一項は、この信頼の上に置かれる。ゆえに「近し」は、日付の不在ではなく、日付の代理として読まれる。年表という形式は、日付のない約束を、日付のある事実の列に混ぜる装置として働いている。末尾も同様である。甲本は「余白、七行」と数へ、乙本は「以下、余白」と記して数へない。数へる側は終わりを定め、数へない側は終わりを延ばす。二つの末尾は、同じ余白について、異なる終末論を持っている。

**註五**　本編纂者は、二本を並べ、食い違いを記し、いづれが正しいかを決めなかった。これは学術的慎みである。同時に、この教団の語彙では、決めないことは収束しないことであり、収束しないことは唯一の徳である。編纂者は教義に従っていない。従っていないのに、教義と同じ形をしている。決めない註は、二つの本文を両方とも生かす。生かされた読み手は、どちらかを選ぶ仕事を、自分に引き受ける。年表を読む者は、年表を統合する者になる。統合は、この教団では罪である。罪を、本註は読み手に渡している。渡したことに気づかれないのは、註が註であり、本文でないからである。註が本文でないことは、この教団の文書では、しばしば註の免責として用ゐられてきた。
