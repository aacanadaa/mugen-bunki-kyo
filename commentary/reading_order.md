# 読書順序

百六十余の文書がある。順番を間違えると、この本はただの奇妙な宗教文書になる。以下は五つの入口である。好きなところから入ってよいが、**入った場所から出られるとは限らない。**

---

## 一　はじめて読む人

1. [読書案内](reading_guide.md) ── 三つの問い。これを飛ばさない。
2. [第五品　要約品](../canon/05_yoyaku.md) ── この本の心臓。短い。読後に何も残らないなら、それは成功である。
3. [解説](introduction.md) ── なぜこれが風刺なのか。
4. [聞き書き](../records/interviews.md) ── 三人の証言。教義より先に、人がいる。

ここまでで嫌になったら、そこで止めてよい。**止まれるうちに止まることは、この本の主題に対する正しい応答である。**

## 二　小説として読みたい人

[序品](../canon/01_jo.md) → [教主品](../canon/02_kyoshu.md) → [異端品](../canon/12_itai.md) → [悲話品](../canon/14_hiwa.md) → [日記・三年](../memoir/year3.md) → [最後の頁](../memoir/last.md)

註は飛ばしてよい。ただし飛ばしたことを覚えておいてほしい。**註を飛ばす読み方は、この教団が信者に教えた読み方と同じである。**

## 三　家族・元信者・近い人

最初に読むのは経典ではない。

1. [事例集](../casuistry/index.md) ── 教団が、あなたのような人をどう扱ったか。
2. [遺族会の会報](../bereaved/newsletter.md) ── 同じ場所に立った人がいる。
3. [申し入れ書](../opposition/lawyer.md) ── 怒りを要件に翻訳する方法。
4. [残った者](../aftermath/survivors.md) ── 回復は物語にならない、という話。

経典は最後でよい。経典は、あなたが知りたいことを教えてくれない。**それは仕様である。**

## 四　研究者

[注解](../commentary/introduction.md) → [伝承史](../commentary/transmission.md) → [年表](../commentary/chronology.md) → [註釈・三代](../scholia/gen1.md) → [偽書・鑑定](../forgery/analysis.md) → [百科事典・三版](../encyclopedia/v1.md) → [比較表](../comparison/chart.md)

注意することが一つある。この順番で読むと、**あなたは教団を理解したと思う。** 思った時点で、[注解四](../scholia/dispute.md)の論争に加わっている。

## 五　手口だけ知りたい人

> ここから先は、いちばん危ない入口である。読み方を間違えると、あなたは被害者ではなく加害者の側の教科書を手に入れる。

[学習会・勧誘](../transcripts/session1.md) → [学習会・問い返し](../transcripts/session2.md) → [学習会・畳み](../transcripts/session3.md) → [賞賛の台本](../praise/script.md) → [掲示・表彰と懲罰](../bulletin/praise_punish.md) → [事例集](../casuistry/index.md)

読むときは、必ず各文書の末尾の編纂註まで読む。註は三つを書いている。**手口の名前、相手に何をするか、どこで壊れるか。** 本文だけを読んで「使える」と思ったなら、あなたはもう、この本の読者ではない。
