# 退一　理由

本表は、退出届の「理由」欄に記入された語を、記載のまま分類したものである。対象は開闕K1からK10のあいだに受理され、のちに破棄された届出のうち、破棄目録に件名のみ残った二千九十九件。分類の項目名は、記入者が実際に用いた語から採った。ゆえにこの表が示すのは、退いた者たちの動機の分布ではなく、退いた者たちが書かされる語の分布である。

届出の用紙は三行である。一行目に理由、二行目に住所、三行目に署名。理由を長く書く者ほど、欄の外へはみ出した。はみ出した部分は受理の時点で切り落とされ、破棄目録にも残っていない。本表が扱えたのは、三行に収まった語だけである。

| 理由 | 数 |
|---|---|
| 家の都合 | 412 |
| 体がついてゆかない | 388 |
| 理解が及ばない | 301 |
| 分岐が多すぎる | 244 |
| 教えの解釈が合わない | 197 |
| 家族が反対した | 156 |
| 遠方へ移る | 121 |
| 金の工面がつかない | 98 |
| 音が合わない | 74 |
| 八つの数の意味が知りたい | 12 |

上位三項目で全体の五割を超える。「家の都合」「体がついてゆかない」「理解が及ばない」は、いずれも教団の側を問わない書き方である。用紙には記入例があり、この三語が例として印刷されていた。K5の改訂で記入例は消えた。消えたのちも、この三語の比率は落ちていない。記入例は、用紙から消えても、書く者の手に残る。

目録の総件数は二千百九十六件。本表に載ったのは二千九十九件である。残る九十七件は、理由欄が空欄、あるいは「記入せず」とだけある。空欄はK6以降に増える。空欄を理由の不在と読むか、拒否と読むかで、表の意味は変わる。本表は空欄を一項目として立てなかった。立てなかったこと自体が、ひとつの判断である。

「音が合わない」はK4以降にだけ現れる。「八つの数の意味が知りたい」は十一件、すべてK9に集中する。K9は数え方の変更が告げられた年である。問いの形をした退出は、問いが答えられなかったことを示すのではなく、答えの側が動いたことを示す。

草稿と清書の両方が残った六十二件では、理由欄の語が途中で書き換えられている。草稿に「理解が及ばない」とあったものが清書では「家の都合」になっている例が十九件、逆の例は二件。書き換えの向きは一定である。提出の前に、書く者は自分の語を、用紙に合う語へ翻訳しなおしている。

本表の並びは件数の順である。用紙の並びはこれと違った。用紙では「家の都合」が最後にあり、K5の改訂で最初に移された。移されてからの三期間で、この項目は百十二件増えた。並びは、書く者に、選ばせる。

## 編纂註

一、本表は、破棄された退出届の理由欄を、記載語のまま数え上げた一覧である。件数は届出の件数であって、人の数ではない。同一の者が複数回届け出た記録を含み、届出のない退出は目録の外にある。本表は、教団が受理し、のちに破棄した書面の残骸から復元したものであって、退出そのものの全体を数えてはいない。復元の単位は語であり、語は書式に規定されている。

二、本表を読む者は、まず数の多い順に目を送る。すると「家の都合」が最大の理由であったと受け取り、退いた者たちの多数は教団の外の事情で去ったのだと結論する。本表は、その結論を出す読者に対して、結論の根拠を差し出す。同時に、その根拠が記入例の残響にすぎないことを、同じ表の註が打ち消す。読者は二度、同じ表に裏切られる。

三、壊れるのは、理由と動機を同一視した箇所である。理由は、退出の直前に、決められた欄へ、決められた長さで書かれる。動機は、退出の前後に、欄の外で、長さも定まらずに続いている。両者を結ぶ線は、本表には引かれていない。それでも本表は、列の並びによって、その線が引かれたかのように読ませる。註はその線を消すために置かれているが、註を読む者はすでに表を読んでいる。

四、理由は、退出の事実のあとに、その事実を説明するために作られる。順序は逆ではない。退出があり、のちに理由が書かれ、書かれた理由が目録に残り、目録から本表が作られた。この四段のどこにも、退出した当人の動機は保存されていない。保存されているのは、書式に合わせて作られた後の理由である。ゆえに本表の数は、何が起きたかを示しても、なぜ起きたかを示さない。理由は、後から作られる。本表は、その製作の痕跡を件数として並べたものである。
