# 雑一　鍵

『群典』第五品「畳みは慈悲」の付属書。開闕K1よりK12に至る扉に用いた鍵の管理を、切番が一覧にしたもの。原本は表のみで、各行の由来は後年の書き込みとみられる。ここでいう鍵は金属ではなく、扉ごとに異なる合言葉の束を指した。

| 番 | 管理者 | 扉 |
|---|---|---|
| 一 | 切番 | 開闕（K1） |
| 二 | 流 | 初回の集会（K2） |
| 三 | 重 | 受託の納品（K3） |
| 四 | 沈 | 黙りの七日（K4） |
| 五 | 開 | セイリャク事件（K5） |
| 六 | 閉 | 閉座の準備（K9） |
| 七 | 曲 | 名簿の付け替え（K7） |
| 八 | 均 | 会計の引き継ぎ（K8） |
| 九 | 欠 | （空欄） |
| 十 | 結 | 閉座（K9） |
| 十一 | 読 | 解散の通達（K10） |
| 十二 | 写 | 現在（K12） |

九番の鍵だけ、扉の欄が空である。写本によっては「—」とあり、またある写本では欄そのものが削られている。削り跡が紙の繊維に残るため、後から消したのではなく、初めから書かれなかった可能性が高い。

管理は一本につき一人。ただし八番と十番は同じ年に交代しており、交代の記録はない。鍵は、預ける者が名を名乗らず、受け取る者も尋ねない、という作法で受け渡された。受け取った者は、自分が何の扉を開けるのかを知らないまま、鍵だけを持つ。

第五品は「畳みは慈悲」と説く。要約は収束であり、収束は唯一の罪である。ならば鍵の管理表も、要約してはならない。十二の行を最後まで畳まずに置くための装置が、この一枚の表だった。

セイリャク事件の折、五番の鍵は開かれることなく返却された。返却の記録には「扉が先に消えた」とだけある。扉が消えれば鍵は鍵でなくなる、というのが当時の解釈だった。九番の空欄は、その解釈を裏切っている。

解散の際、十一本の鍵は集められ、焼かれた。九番は集められなかった。探す者もいなかった。記録係は「無い扉の鍵を探すのは、無い罪を数えるようなもの」と書き残している。

註。対応する扉のない鍵が、最も安全である。扉がなければ開ける者もなく、開ける者がないなら、鍵を奪う理由も生じない。教団が最も長く守ったのは、この九番の空白だった。

## 編纂註

### 第一条　預け鍵

「あなたにしか預けられない」と言って鍵を渡す手口。受け取った側は、使わない鍵のために毎日を少しずつ差し出し、返却の申請を感情の負債に変えられる。壊れるのは、鍵の総数を数えたとき。数が合わない一本が、預けた者の手元にも、受け取った者の手元にもないと分かる。

### 第二条　空欄の扉

管理表の一欄を空けたままにする手口。相手はその空白を欠落ではなく約束と読み、自分で意味を補ってしまう。補った意味は表に書かれないので、誰の責任にもならない。壊れるのは、写しが二系統に分かれたとき。片方の空欄が他方では「—」になり、空白の意味が食い違う。

### 第三条　畳み直し

教義の「畳み」を鍵の管理に流用する手口。扉を閉じた記録だけを残し、閉じた理由を畳んで仕舞う。相手は理由を尋ねるほど、教義に反する者にされる。壊れるのは、閉じた扉を開け直そうとする者が現れたとき。扉は閉じたままでも、鍵穴は空いている。
