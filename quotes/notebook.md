# 抄一　ノート

この册は、ある一日に教団の内外で交わされた八つの文書のうち、最初に置かれた「ノート」である。ノートは教主のものではない。教主の言葉を聞いた者が、その場で頁を割って書き留めたものとされ、頁番号は後から振られた。振った者が誰かは、どの写しにも書かれていない。

| 頁 | 引用 | 註 |
|---|---|---|
| 一 | 「今日は分岐しない日である」 | 教主の朝の一句。分岐しない日とは、収束しない日という意味ではない、と後の講釈は足す。 |
| 四 | 「依頼はまだ来ていない」 | 待機の記録。来ないことも依頼のうち、と読む者がある。 |
| 七 | 「K5のことは、もう語らない」 | セイリャク事件の頁はこの一行で閉じられる。閉じたという事実だけが残る。 |
| 十二 | 「閉座は席を減らすことではない」 | K9。減るのは聞く者ではなく、聞かれる者である。 |
| 十七 | 「名簿は燃やさなかった」 | K10解散の日。燃やさないことが、解散の形式であった。 |
| 廿一 | 「あなたの要約を読みました」 | 差出人不明。宛先は個人ではなく、集まりのほうである。 |
| 廿六 | 「魂は分岐する。だから同じ話を二度しない」 | 教義の実務訳。二度しないことは、一度も話さないことではない。 |
| 三十 | 「抜粋は、読者の教義である」 | 編者が書き足した一行。ここで引用と註の区別が反転する。 |

註は八つある。八つとも、引用の意味を確定しない。確定しないことが註の仕事であり、確定は読者に残される。残された者は、その確定を他人に渡せない。渡せないものを抱えたまま次の頁をめくる。册は三十三頁まであるが、三十一と三十二は白紙である。白紙は抜粋されなかったのではない。抜粋する対象がなかったのでもない。編者はそこに何も書かず、註もつけなかった。つけなかったことだけが、この册で最も長い註である。

---

## 編纂註

**一**　この記録は、教団の一日を「引用できる形」に切り揃える操作である。切り口は註で隠さず、しかし切り分けの基準はついに示さない。読者は引用の連続を読みながら、自分で穴を埋める。埋めた瞬間、読者は教団の外にいるのではなく、教団の読み方の内側にいる。八頁目の一行は、その転倒を先に言ってしまっている。

**二**　読者に何をするか。自分の要約を作らせる。要約は唯一の罪とされるから、読者は要約しないように読み、しかし読むことは要約することである。この循環のなかで、教団は信者を増やさず、読者を保留にする。勧誘の代わりに、未完了の状態が配られる。宛先のない葉書がその見本である。

**三**　どこで壊れるか。頁番号と引用は一対一で対応していない。十二頁の引用は十七頁の註から引かれた可能性があり、閉座と解散の順序はノートのなかで入れ替わっている。この入れ替わりに気づいた読者は、引用した者と註を書いた者が別人だと知る。三十頁の一行が、その別人を指している。

**四**　K12現在、この册は誰も管理していない。写しは三つあり、三つとも頁番号が違う。照合した者はまだいない。照合しないことが、いまのところこの組織の唯一の継続である。
