# 抄六　索引

〈本文〉

本索引は、群典正編および周辺文書から採った抜粋の位置を、件名と頁だけで示す。抜粋の本文は再録せず、要約も置かない。頁は各省の丁付に拠る。異版のあいだで頁の一致しないものには※を付し、照合の順序を末尾に記した。

凡例

一、件名は原本の表題をそのまま写した。表題のないものは、書き出しの語を括弧に入れて代えた。

二、頁は原本の丁付であって、写本の頁ではない。写本には写本の頁がある。

三、「同」は直前の件名を承ける。承けたことを忘れた読者のために、件名を繰り返す版もある。

四、本索引は抜粋を評さない。評は抄七に譲る。

頁の異同について。底本は三系統あり、甲本・乙本・丙本と呼ぶ。甲本は丁付が粗く、乙本は抜粋の順序を入れ替え、丙本は頁を振り直した。本索引は甲本に拠り、乙本・丙本との対照は抄八に譲る。※の箇所は、三本のいずれかで件名自体が失われている。

七、参照の順序

朝の部から読み、昼の部を飛ばし、夜の部で戻る、という読み方が推奨されている。推奨は強制ではない。強制は収束に近い。だが実際には、多くの読者が朝から順に頁を引き、夜の部で止まる。止まった場所を、本索引は記録しない。記録しないことが、この索引の唯一の作法である。

本索引は抜粋の地図である。ただし地図を読む者と、地図を塗る者とは違う。頁を辿る者は、抜粋の本文に触れ、みずからの位置を知る。索引を作ることは、抜粋を束ねることではない。束ねれば収束になる。だから本索引は、件名と頁のあいだに余白を残した。余白は空欄ではなく、読む者が書き込むために開けてある。

## 編纂註

**註一（何をしているか）**　本索引がしているのは、抜粋の件名と頁を並べ、本文を再録しないことである。読み手に要約ではなく移動を渡し、どの抜粋から開くかを選ばせる。索引は、抜粋の地図である。地図は土地ではなく、辿る者が余白に書き込むもので、頁を辿った後に残るのは要約ではなく足跡だ。本索引が件名の順序を時系列から外してあるのは、その足跡を消さないためである。

**註二（誰に何をするか）**　読む者に順路を渡す。順路は強制ではないが、索引を目次と取り違える者には、抜粋を読まずに頁だけを引かせる。編者はそれを承知で、あえて章立てを粗くした。粗い章立ては、読む者に「どこからでも開ける」と言い、同時に「どこから開いても終わらない」とも言う。この二つは、同じ約束の裏表である。

**註三（どこで壊れるか）**　壊れるのは版の境目である。底本は甲・乙・丙の三系統あり、頁は改訂のたびにずれ、※の箇所は三本のいずれかで件名そのものが失われている。照合できない頁を、本索引は埋めない。埋めれば収束になるからだ。だが、埋めない頁の前で読む者は立ち止まる。立ち止まることを、編者は破損とは呼ばない。

**註四（付記）**　本索引は抄七の用語表と対になっている。件名の語は用語表の見出しに還元され、頁は還元されない。還元されない頁だけが、抜粋の現在地を示す。索引を閉じた後、どの頁が残るかは読む者に委ねられる。委ねることは放棄ではない。放棄は「もう書かない」と言うが、索引は「まだ書かない」と言って頁を開けたままにする。
