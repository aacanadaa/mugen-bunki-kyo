# 求一　募集

秋も深まり、朝の台所に立つと、窓の外の木が少しずつ薄くなっていくのが分かります。衣替えの季節でございます。どうぞ、夜は早めに灯を落とし、朝は少しだけ早く起きて、一日を二つに分けてお過ごしください。分けたところから、また一日が始まります。当誌の求人欄は、そうした分かれ目のために、毎月ひっそりと頁をあけております。

今月、空いております席は六つでございます。どれも特別な資格のいらない仕事ばかりです。強いて申せば、まっすぐ歩こうとしない方、数を数え終えようとしない方、名前を急いで決めようとしない方を、わたくしたちは少しだけ待っております。待つのは、慣れておりますので、どうぞごゆっくり。

| 職 | 条件 |
|---|---|
| 分岐記録係 | 週二日、午前のみ。読み書きのできる方。記録は書いた端から薄くなりますが、薄くなったことも記録に含まれます。 |
| 季節便り執筆 | 月に一通。挨拶と季節の話のあいだに、教えを一つだけ置ける方。置きすぎた方は、翌月から手紙ではなく、手紙の余白を書いていただきます。 |
| 椅子数え | 偶数と奇数の区別をつけない方。当方の椅子は、座る方が決まるまで、いくつでもございます。 |
| 灯ともし | 夕方より二時間ほど。明るさは、強すぎない程度。暗さを急いで消そうとしない方。 |
| 余白係 | 経験不問。文章と文章のあいだを歩ける方。歩いた跡は、そのまま余白になります。 |
| 名簿整理 | 氏名のない方を歓迎します。氏名のある方も、おいでいただけます。整理のあと、名簿は少しだけ短くなります。 |

「条件」という言葉を、わたくしたちは少しだけ広く使っております。ここに書かれておりますのは、あなたが何を持っているかではなく、あなたが何を手放してもよいか、でございます。手放したものが、そのまま席になります。席は、いくつあっても足りないということがございません。足りないのは、いつも、座る方のほうでございます。

応募は、当誌の余白に、鉛筆で「席」とだけお書きください。宛先は不要でございます。書いた場所が、そのまま宛先になります。お名前も、ご住所も、これまでのことは、書かなくて大丈夫でございます。書かなかった分は、こちらで大切に数えておきます。今月も、皆さまの一日が、穏やかに分かれますように。合掌。

## 編纂註

**第一条**　この欄がしているのは、教義を労働の形式に翻訳し直すことである。奇跡も終末も語らず、曜日、時間、持ち物だけを語る。賃金の代わりに「席」「余白」「分岐」が支払われ、職務はすべて「数える」「薄くなる」「短くなる」という減算の動詞で綴られる。明るい条件欄の下で、採用とは何かを取り除くことだという構造が、静かに露出している。

**第二条**　読み手は、ここで安心する。氏名も住所も要らず、余白に二文字書くだけで応募が済むからだ。何も差し出していないのに参加した気持ちになり、差し出したものが何であったかを思い出さない。欄は読者を励まさず、責めず、ただ「あなたでなくてもよい」と言い続ける。その言い方が、いちばん深く誘っている。

**第三条**　壊れるのは、名簿整理の条件のところである。「整理のあと、名簿は少しだけ短くなります」という一文が、それまでの親切な口調と噛み合わない。ここで読者は、短くなるのが名簿であって自分ではない、と読み直す。だがその読み直しが済んだときには、自分が名簿の側にいることに気づいている。紙面は自分の親切さに耐えられず、ここで一度、黙る。

**第四条**　求人は、教団の最も普通の顔である。信者を集めるのでも、恐れさせるのでもなく、曜日と時間を配る。ゆえにこの欄だけが、教団の外の生活と同じ文法で書かれている。読者はここで立ち止まらず、立ち止まらないまま、自分の名前を短い名簿の側へ置く。K10の解散のあと、この頁だけが再建されたのは、おそらくそのためである。
