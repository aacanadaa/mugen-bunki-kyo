# 時二　遅刻

「時二」は、教団が自前の暦と並行して用いた内部記録の巻である。収めるのは、集会・畳み・分岐の儀に参じる者が、定められた刻限に間に合わなかった事実の一覧である。記録係は遅れた者を責めない。ただ、名と、分と、理由を書く。書かれた瞬間、遅れは個人の事情から教団の財産に変わる。

以下はK12年の春、三つの集会場から上がった記録を、分の多い順に並べ替えたものである。名は教団名、分は申告された遅刻の分、理由は本人の弁のまま、一字も直さずに写した。

| 名 | 分 | 理由 |
|---|---|---|
| 六折 | 44 | 分岐の合図を二度聞き逃した、とだけ述べた |
| 無名位 | 44 | 名を書かれるのを拒み、その分だけ遅れた |
| 欠号 | 31 | 理由を述べず、座った |
| 続灯 | 26 | 前回の分を返しに来た |
| 十時 | 19 | 別の刻限を信じていた |
| 東畳 | 12 | 前夜の畳みが終わらず、自分の分を数えていた |
| 裏面 | 8 | 表の記録を見てから来た |
| 灯屋 | 7 | 灯を点す順番を待っていた |
| 呼子 | 5 | 呼ばれるのを待っていた |
| 空位 | 4 | 空いた席が自分のものだと思っていた |
| 四折 | 3 | 呼吸を整えていた |
| 三布 | 2 | 衣の畳目が合わず、結び直した |
| 白盤 | 1 | 数えの途中で、数を忘れた |
| 半畳 | 0 | 遅れていない。記録だけを残した |

表の末尾に、書記が鉛筆で一行だけ書き足している。「この表に載らない時間がある」。誰の筆かは記されていない。

分は返済されない。返済の代わりに畳まれる。第五品の「畳みは慈悲」に従えば、遅れた分は折り目として衣の内側に縫い込まれ、本人が忘れた頃に他の者へ配られる。受け取った者は、それが誰の分かを受け取らない。分は物のように渡り、渡った先で名を失う。ゆえにこの表の数は、遅れた者の負債ではなく、教団が保管する時間の目録である。名を書かれることを拒んだ無名位の四十四分だけが、どの欄にも収まらないまま、欄外に小さく記されている。

## 計上の作法

記録は集会の終わりに読み上げられる。読み上げは罰ではない。ただ、読み上げられた名は、次に遅れた者より先に呼ばれる。呼ばれる順が、そのまま教団での順になる。順は教義ではなく、運用である。運用は誰の記憶にも残らない。残るのは表だけである。

表は毎年畳まれ、古い分は新しい分の下に入る。下に入った分は消えないが、読まれなくなる。読まれないことが、この教団における完成である。

---

## 編纂註

**一、規格化するもの。** この巻が規格化するのは、遅れの量ではなく遅れの単位である。分は個人の体感から切り離され、集会・畳み・分岐という三つの異なる儀に共通する尺度になる。理由欄は設けられているが、理由の長さは分に換算されない。換算されない理由欄は、聞き取りの形式を保ちながら、実際には何も測っていない。測っていないことを明記しない点に、この様式の性格が出ている。

**二、人に対してするもの。** 書かれた者は、自分の遅れを自分の言葉で説明することを求められる。説明は最後まで聞かれる。だが聞かれた内容は、分を一つも減らさない。減らないと知った者は、次第に理由を短くし、やがて理由を書かれることそのものを遅れとして数え始める。表は罰しない。罰しないまま、自己申告の習慣だけを残す。遅刻の記録は、時間の所有の記録である。

**三、壊れるところ。** 壊れるのは、名を書かれない者が現れたときである。無名位の四十四分はどの欄にも収まらず、欄外に小さく残った。申告しない者、時計を持たない者、別の暦で生きる者は、この表の外にいる。表は彼らを裁けない。裁けない代わりに、存在しないことにできる。所有は、書かれた者より先に、書く者を縛る。
