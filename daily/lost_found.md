# 日四　落とし物

教団に「落とし物」の台帳がある。物品の管理簿ではなく、人が何を手放したかの記録である。整理は使徒「閉」が担い、閉座の後は誰も触れていない。

| 品 | 日 | 備考 |
|---|---|---|
| 片方の革靴（左） | 開闕K3 四月一五日 | 持ち主不明 |
| 名札のない社員証 | 開闕K3 五月二日 | 顔写真のみ残る |
| 折り畳まれた名刺 | 開闕K3 六月一一日 | 社名が判読できない |
| 子供用の雨靴 | 開闕K4 三月八日 | 持ち主不明 |
| 眼鏡のつる | 開闕K4 九月二〇日 | レンズがない |
| 弁当箱 | 開闕K5 一月一三日 | 中身は空、名前欄は削られている |
| 傘（紺） | 開闕K5 六月四日 | 持ち主不明 |
| 手帳 | 開闕K6 二月二七日 | 本文は白紙、表紙に「返す」とだけ |
| 鍵（三本） | 開闕K7 八月九日 | 対応する扉は特定できない |
| 写真 | 開闕K8 五月一日 | 写る人物を誰も知らない |
| 義歯 | 開闕K9 一一月二〇日 | 持ち主不明 |
| 湯呑み | 開闕K10 四月三日 | 閉座の翌日、申し出なし |

十二行のうち七行に「持ち主不明」とある。不明なのではない。書かなかったのである。受付は「お預かりします」と言い、「お返しします」とは言わなかった。返却の条件は口頭で伝えられ、口頭は台帳に残らない。九十日を過ぎた品は教団の共有物になった。共有物になった品の持ち主は、もう名乗り出られない。名乗り出ることは、共有を壊すことになるからだ。

台帳の筆跡は三種類ある。前半は丁寧で、品の特徴を細かく書いている。中ほどから形容が減り、「例のもの」とだけ記す行が増える。後半は日付と品名だけで、備考欄が空いている。空欄は情報の欠落ではなく、書く気が失われた跡である。

セイリャク事件の日の頁には、返却済の印が三つある。返却先の欄は空である。事件の前後で人員は入れ替わり、誰が誰に返したのかを知る者はもういない。印だけが、返したという事実を主張している。

教団は受託開発で稼いでいた。この台帳も、誰かの発注で作られた管理用データベースの雛形だったという。列は「品」「日」「備考」の三つ。所有者の列は最初からなかった。設計者は悪意がなかったと言う。列がないことに、誰も気づかなかった。

最後の頁は解散の日で、品名は「なし」、備考は「全部」とある。全部とは何か。書いた者は説明していない。台帳はそこで終わっている。

---

## 編纂註

一、無主化。持ち主の名を記録から外す手口である。被害の側では、品は返っても返る相手が特定できず、自分の物を自分の物として示すために教団の証言を要する。やがて自分の来歴まで教団に尋ねるようになる。壊れるのは、記録を書いた者がいなくなったときである。閉座の後、台帳は閉じられ、誰も「お預かりします」と言えなくなった。所有は物ではなく記録にあったと、そこで初めて露見する。落とし物は、所有の記録の破れである。

二、返却の保留。返すと言い、返す日を言わない手口である。被害の側では、待つことが従順に変わる。待っている間に品は共有物とされ、待った時間だけが負債として積み上がる。壊れるのは、待つ対象が消えたときである。閉座で窓口が閉じ、待っていた者は、待っていたこと自体が支払いだったと知る。品は最初から返る予定がなかった。

三、共有への移し替え。持ち主不明の品を共同体の物とする手口である。被害の側では、自分の喪失が寄付に読み替えられ、後から同意を求められる。断れば共同体を壊す者とされる。壊れるのは、受け取った共同体もまた持ち主を名指せないと分かったときである。名もなき「私たち」が名もなき品を所有する。その台帳は、誰のものでもない。
